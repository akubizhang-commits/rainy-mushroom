# 自然成长与流派差异复核，2026-11-01

目标：保留清怪、对单、覆盖、持续伤害等差异，检查是否存在连续阶段全面、显著领先的一套固定流派。本轮不以全部构筑同用时为目标。

## 数据层次

1. `*-101/211/307.json`：六路线×三种子，从新档通过实际Campaign交易，完成1–9层。随后继续正常刷第9层，以实际经验、物品与货币进入后期。`postClear`将首次成长与补充刷层分开；不能把刷层时间混入首次通关。
2. `*.mature.json`：延续各自真实最终存档，营地正常退款、学习，统一30级和实际投入80点，保留自己获得的装备；每种子重打第9层。不是免费补等级/装备的合成档，也不是完全同装备对照。
3. `prerequisite-check/`：原追击学习顺序漏了御剑4级所需的凝神诀；加入此前置后，三个种子从头复跑。保留原始结果，不能用漏前置的结果直接断言御剑弱。
4. `pursuit-101.mature-diag.json`：原战斗精确回放，记录剑影在Boss存活期间发出的斩击与实际命中。诊断只观察，不改战斗。
5. `*.mature-balanced.json`（如存在）：追击将剑影10级改为7级，把点数转给剑气及心法的实际80点对照。属于搭配分支，不替换原样本。
6. `isolated-skill-probes.json`：156个120秒定点探针（等级、进化阶数、80/200距离）；验证伤害单位与覆盖，不用于声称真实Boss吃满。

## 约束

- 不吃修为丹；突破丹和回血丹正常购买/消耗。完成当前层后回营地突破，不为抄近路中途主动退层。
- 怪物、血量、伤害、CD不修改；同一已修正走位机器人、60Hz、横屏视野。死亡/超时保留。
- 全部学习/退款走Campaign，终局快照校验、重复领奖拒绝及存读档逐次检查。
- 原学习策略只会为首次进化退还母版，不能主动从其他技能挪点，因此曾把四象卡在差1点；用营地正常重配验证真实成型能力，不把机器人策略限制当成游戏门槛。
- 自然成长策略不是全局最优解。不同路线装备掉落和适配评分不同；不能把几秒差距直接归因于某个伤害系数。
- 自动走位结果不是人类通关率，也不是所有装备、所有技能搭配的穷举。

## 复现与校验

`snapshot/`为冻结源码及原自然成长策略。`batch.py`启动18个新档；拒绝覆盖已有原始输出。`mature.mjs`延续存档，`mature-batch.py`等待相应自然档完成后执行。初版成型配点被前置断言拦下的记录保留在日志，修正后的终局JSON才纳入分析；`mature-status.json`可保留首次尝试的失败码，以最终`verification.json`为完整性依据。

`summarize.py`汇总成长；`mature-summary.py`汇总80点成型；`dominance.py`做连续阶段筛查。30%仅是调查筛选线，不是用户接受阈值，也不是严格支配的数学证明。`verify.mjs`最终检查完整性、点数、禁用修为丹、源码稳定及18场80点成型结果。

本轮不修改生产数值。报告见 `../../design/balance/balance-check-natural-build-diversity-2026-11-01.md`。
