# 藏经阁无纵向滚动阅读

正式游戏阅读页使用窄顶栏、书页两侧箭头和单行底部序号。正文常规20布局单位，小横屏25布局单位（844px视口约16.5px）；插画按留给小记后的剩余空间自适应。书页内容不挂ScrollView，目录列表仍可滚动。

长内容按真实文字高度分成连续对开。每个物品左页完整显示身份、插画、定位及小记；右页效果、条件、提示、来源、注意事项全部保留。箭头先翻内容页，再到同章下一件。逆向到前一件的末页；品质切换回第1页；目录返回保留页次。

验证脚本 scripts/verify-library-pages.cjs：遍历76个条目的所有品质与每一内容页，检查两页子节点边界、无ScrollView、正文逐项完整、角色状态不变，并以真实方向键验证连续翻阅与目录返回。1280×720、844×390、1280×900均记录JSON报告与截图。旧verify-library-integration.cjs入口转向新契约。
