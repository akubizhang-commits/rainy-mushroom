## 结论

山水场景、宣纸底、墨绿文字与青玉按钮已经形成可延续的基调；无需推倒重做。主要不一致来自旧功能页、各自实现的弹窗及细节层级。应统一基础组件，同时保留典籍的双页阅读和炼器结果的仪式感。

### P1 · 装备对比卡透出底层文字，影响阅读

- 证据：`equipment-detail-844.png`（1280版本同名）。卡片后方的“人物·装备”、容量、筛选按钮和角色仍可穿透，叠在物品名称、境界要求附近。
- 位置：`TowerInventoryPanel.ts:6` 的半透明card颜色，以及 `:350` 的detailCard。
- 建议：详情文字区使用不透明纸底，或在成组详情卡后增加统一遮罩；场景感只保留在窗外。保留物品图标当前125px主体规则与原格子尺寸。

### P1 · 旧功能页页头拥挤，且混入战斗HUD造型

- 证据：`loadouts-844.png`、`training-844.png`、`gate-844.png`、`tutorial-0-844.png`、`affairs-844.png`。右上圆头像、酒红色生命条、境界牌与资源一行发生交叠，和主菜单纸质头像条不一致。
- 位置：`TowerMenu.ts:213` 至 `:230`；非hall旧页使用battle样式并单独摆放钱包。
- 建议：所有宗门功能页共享纸质页头，人物信息、资源拥有独立布局区域；长数值也必须避让，不能仅靠缩字。让正文和主要操作多获得一行空间。

### P2 · 确认弹窗缺乏同一套窗口结构

- 证据：`dismantle-844.png`完全遮住背包并拉开大面积空白；`skills-reset-844.png`和`skills-points-844.png`变成整页纸底；设置、角色、购买仍是可见背景的浮窗。结算遮罩明显更深。
- 位置：`TowerInventoryPanel.ts:405`；`TowerMenu.ts:1373`；`TowerView.ts:551`。
- 建议：共用墨绿半透明遮罩、纸底、边线、标题间距、底部操作区和安全边距。分解采用与背包“分解”按钮一致的赭色危险主按钮；重置保留返还明细。结算可以保留居中标题及金线，但共用基础材质与按钮规范。

### P2 · 返回、关闭及不可用控件表达不同

- 证据：设置只有“点空白/Esc返回”，角色/购买有右上×，典籍有文字按钮“主峰/合卷/返回内容”，工具页用方形<和×；物品详情还有看似可点但未接入的分享图标。
- 位置：`TowerMenu.ts:752`；`TowerLibraryPanel.ts:212`及`:313`；`TowerInventoryPanel.ts:359`。
- 建议：普通弹窗右上统一关闭入口和触摸热区，页面左上统一返回；典籍保留“合卷”用语但采用相同控件尺寸。未开放分享入口隐藏或明确标注不可用。阻塞保存错误页必须保留重试约束，不能机械加一个可绕过保存的关闭按钮。

### P2 · 配装、演武、事务和指引仍是旧版长卡片

- 证据：`loadouts-844.png`、`training-844.png`、`affairs-844.png`、`tutorial-0-844.png`至`tutorial-5-844.png`。宽幅文字卡及连续大按钮占用窄横屏高度，部分“下一步/跳过”需要滚动才能看到。
- 位置：`TowerMenu.ts:541`（通用卡片）、`:2106`、`:2124`、`:2211`。
- 建议：复用技能详情的“分组标题+细线+属性行”，配装用明确装备槽/属性摘要，指引使用固定底部导航；正文独立滚动并显示滚动提示。不要简单压缩字号，亦不删除必要规则说明。

### P2 · 菜单名称与规则提示有历史残留

- 证据：`battle-result-844.png`仍写“前往丹鼎阁”，当前场景名称为丹霞峰；山门写新档御剑术1级，指引写剑气斩1级；指引/事务仍称“全洗/初始化”，新技能按钮已叫“重置加点”。
- 位置：`TowerView.ts:260`、`:263`；`TowerMenu.ts:2163`、`:2167`、`:2204`、`:2216`。
- 另有源代码残留：`TowerView.ts:233`仍设置“可修至3级；高阶与秘传请回藏经阁”通知，本轮技能截图未显示该通知，需清理避免后续重新露出。它不是当前实际升级限制。
- 建议：名称统一“丹霞峰”“重置加点”，起始技能以当前实际新档数据为准；提示必须读取当前规则。技能学习/升级要求不得加入通关层数或首通门槛。
- 注意：当前“获取技能点”的道悟研习仍显示通关条件，首通也可作为技能点奖励来源；这些与“技能升级门槛”不是同一项。本次未修改经济或成长规则，若要取消获取途径上的通关条件，需要单独明确范围。

## 推荐统一基准与次序

1. 先修装备详情透字及旧页页头相互遮挡。
2. 提取共享窗口/标题/返回关闭/按钮规范，将设置、购买、分解、重置、提示与结算接入。
3. 更新旧卡片菜单，固定指引导航；统一菜单术语与规则提示。
4. 按本图集再跑双尺寸对照，另做实际手机横屏触摸、关闭返回、滚动和长数值检查。

沿用纸白/青玉/墨绿/旧金/赭色，不额外引入现代后台式蓝紫控件。信息优先级统一为标题、关键数值、说明、附注；危险操作依靠文案与色彩共同区分。既有典籍插图、物品尺寸、场景原画和技能成长条件保持各自明确规则。

本轮新增的是接入核验与审查材料；以上新发现尚未进行第二轮全面修改。
