# C 类 UI 优化

用户已确认：C01 始终显示短标签；C04 先做声音与减少动态效果；C05 统一 Esc、方向键、确认与可见焦点。无待决策项。

| 编号 | 实施内容 |
| --- | --- |
| C01 | 背包分类保留图标并始终显示名称；宗门抽奖、设置、技能、背包加固定短标签，图标和文字共用点击区域。 |
| C02 | `TowerMenuChrome.ts` 集中普通菜单、物品、书页色板；物品格与详情沿用背包灰绿，普通弹窗与书页保留纸色；文本、主操作、禁用、警示色复用语义常量。 |
| C03 | 宗门峰名、未开放说明、庭院入口统一加强深绿描边和阴影。未开放峰仍显示明确的“未开放”文字。 |
| C04 | 设置增加 0/25/50/75/100% 音效音量和减少动态效果。偏好独立保存，不写游戏进度；写入失败保留旧值并提示。现有青萍、剑气爆裂音效均接入音量。减少动态效果抑制镜头震动、设备震动、突破全屏闪光与炼器结果装饰动效，保留技能范围、命中与威胁提示。当前无背景音乐，设置明确标注“尚未接入”，不提供无效开关。 |
| C05 | 共用键盘焦点控制器：方向键选择，Tab 顺序选择，Enter/空格确认，Esc 关闭当前窗口或返回。跳过禁用项，弹窗隔离底层操作，滚动项自动进入视野。搜索框可获得焦点并输入；战斗方向键仍用于移动，Esc 暂停／继续。必须处理的保存失败对话框不会被 Esc 绕过。 |
| C06 | 背包、交易收获、通关收获共用数量角标；保留并复用物品边框、详情数据、数量控件、弹窗标题、正文滚动和数值换行入口。新增色板、偏好、键盘导航的集中实现与代表性截图验收脚本。 |

## 验证

- 107 项针对性测试全部通过：背包／交易 UI、设置写入原子性、音效音量与暂停、减少设备震动、弹窗焦点、已销毁菜单与不可绕过对话框。完整结果见 `focused-tests.log`。
- C 类浏览器验收全部通过，未捕获页面异常。浏览器脚本：`scripts/verify-ui-c-fixes.cjs`，覆盖 844×390、1280×720、960×360 三种横屏配置；截图与最终结果见本目录 `browser-report.json`。
- 本轮不制作或替换静态美术，不使用 Scenario 额度。
- 浏览器验收不等同于微信真机的听感、震动体验验收。

## 扩展测试记录

曾运行历史炼器专用测试与上述 UI 测试的组合，共 127 项，其中 23 项失败。失败主要仍在查找“凡器购置”“武器”“防具”等旧入口，与现行炼器页面不匹配；本轮没有将这些断言记为通过，也没有为了通过而恢复旧界面。完整输出保留在 `legacy-forge-suite.log`。

## 用户追加：结算收获

移除“实际入账”行与结算修为文字。灵石按实际入账值拆为各品阶图标，贡献紧随其后，材料沿用原有八列网格；战报详情使用同一实现。货币格的数量不按物品的 99 上限截断，大数可简写，点击显示完整数量。材料库存自动出售、钱包上限说明与首通技能点提示继续保留。仅调整展示，奖励与存档计算不变。

此要求取代 A06 原先固定显示收入文字的布局；现在固定的是“本次收获”提示，所有奖励图标在同一滚动列表内。

结算追加验收通过：`scripts/verify-settlement-currency.cjs` 在三种横屏尺寸检查修为文字移除、灵石品阶格、贡献完整数量、八列换行、滚动与固定操作按钮，页面异常为 0。截图及结果位于 `reports/settlement-currency-2026-11-02/`。共用数量角标增加细浅色描边，避免数字与图标图案混在一起。最新 web-mobile 预览已成功构建。
