# 四页交互与UI布局验收

参考依据：`design/commerce-ui-reference-2026-11-01/README.md` 与用户上传的六张截图。

- 四页：武器装备购买、丹药购买、炼器、炼丹。配色保留项目宣纸/青玉。
- 商店为分类 + 三列商品卡片，点击后进入购买数量与价格弹窗；材料不挤入购买页。
- 炼制为分类 + 配方网格 + 成品与材料 + 固定数量、费用、炼制按钮。
- 炼制确认后才提交；成功按实际结果显示获得物品；失败保留重试凭证。
- 复用现有素材；9种未有图的炼器材料以名称显示，制图 prompt 见设计目录。

验证：103 项相关测试通过。浏览器在 844×390、1280×720 验证四页入口、购买/取消、炼制确认/取消、获得物品和详情弹窗，无页面运行错误。`browser.json` 记录实测结果；`tests.tap` 记录单测结果。

最终构建：`build-verified/web-mobile`，已同步到标准预览目录 `cocos-pilot/build/web-mobile`。

`four-pages.png`：上排为两个购买页，下排为两个炼制页。`dialogs.png`：购买、炼制确认、获得物品弹窗。
