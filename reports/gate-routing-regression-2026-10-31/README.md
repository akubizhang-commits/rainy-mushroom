# 安全门寻路回归

`snapshot/` 保存本轮固定运行时和正式机器人。游戏数值未改；机器人改为选择可达门内位置、绕开柱子和活体碰撞、缓存路线、阻塞时重算、进门后停止。

`run.mjs` 复用原后期补测的固定配装。第8层剑阵/两仪各5个种子，剑气/混搭/天地各3个种子，第9层剑阵/天地各3个种子，共25场。只通过正常移动输入战斗。advance的观测包装只读取机制区，不修改结算。

`results.json` 保留逐场结果及安全门观测；`insideAtBlast` 是首次到达结算时刻时，角色是否在实际半径要求内，未到结算的机制保持null，不算作通过。`firstInside` 和 `starts` 的差为首次进门耗时，不是真人反应时间。

`summary.json` 由 `summarize.py` 核验完成状态、25场数量、源码稳定性和每次进门结果。`inputs.json` 列出输入存在性和与上一轮运行时差异。`tests.log` 为相关回归测试。

重跑：`node reports/gate-routing-regression-2026-10-31/run.mjs`；之后执行 `python3 reports/gate-routing-regression-2026-10-31/summarize.py`。脚本会覆盖本目录结果，如需保留历史请另建目录。

限制：合成合法配装，不是自然资源获取；不代表真人失败率。测试覆盖当前第8/9层组合，并未穷举任意地形、并发弹幕或安全区组合。
