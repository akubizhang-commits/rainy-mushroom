# 菜单风格统一 · 完成与自检

本轮按用户批准的全菜单审查建议实施，沿用水墨场景、宣纸底、青玉操作色与墨绿文字。源码和 Web 构建已更新；微信代码也已生成，但微信包体预算校验仍失败，不能作为可发布包验收。

## 已完成

- 新增 `TowerMenuChrome.ts`，设置、角色、背包、购买、分解、技能重置、战斗提示和工具菜单复用遮罩/关闭图形；普通纸质窗口统一基础底色和圆角。
- 装备详情改用不透明纸底，消除底层标签透字；隐藏未接入的分享图标，提供明确“返回背包”。
- 分解改为保留上下文的纸质浮窗，展示名称、返还和不可恢复提示；取消与右上关闭均不提交动作，确认沿用原始校验和失败原子性。危险按钮使用赭色。
- 宗门旧功能页使用纸质头像条，钱包独立避让；支持大余额，正文新增随滚动更新的提示条。
- 配装/演武的武器、防具、戒指改成等高三栏摘要，完整保留各装备属性；操作前移。通用卡片统一标题、左对齐、分隔、正文与按钮间距，宽卡片采用两列操作。
- 指引的下一步/完成/返回固定在底部，正文单独滚动。藏经阁返回入口与宗门导航统一，典籍保留双页阅读特色。
- 统一“丹霞峰”“重置加点”，修正新档武器/技能说明，移除旧“塔内只能修习低阶/3级”提示。未改变技能学习升级规则，更未增加通关门槛。
- 修复丹霞主殿热区延伸到可见画面之外的旧问题，只裁剪不可见部分。
