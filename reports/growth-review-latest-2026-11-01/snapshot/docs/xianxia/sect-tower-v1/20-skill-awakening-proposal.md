# 塔内领悟与藏经阁进修：技能成长调整方案

2026-10-28｜**待用户确认的设计提案，尚未修改游戏代码、正式数据或存档。**

> **后续方向已更新**：学会即自动生效、心法各有脚下光环、全部16节点同页，见[21号](21-skill-tree-proposal.md)。用户又要求以境界技能点为主要升级来源，见[23号最新提案](23-skill-point-budget-proposal.md)：30境界点＋封顶6额外点，技能分档消耗。下文旧“4＋4出战、免费清波练至3级、逐级高阶买书、只退4–5级妖丹”作为历史方案保留，不能与新技能点规则叠加；后续实施须整套切换版本。

后续用户要求技能树，并明确特殊/大技能需藏经阁购书解锁；树形整合见[21号方案](21-skill-tree-proposal.md)。该补充确认购书锁定方向，不代表本稿所有价格、教学波次和免费重修参数已获批。

本稿回应功能试玩反馈：只有御剑术的新角色进入首层，要连续打20波，攻击手段变化太慢。当前生效规则仍见[18号决策记录](18-decision-register.md)、[12号技能表](12-skill-books-v2.md)和[19号功能合同](implementation/19-functional-alpha-contract.md)。本稿批准后，才替换其中“技能只能在宗门学习升级、清波不赠技能等级”的部分。

## 1. 推荐结论与体验目标

采用“低阶实战领悟永久保留，高阶与特殊功法回宗进修”：

- 基础功法、基础心法在塔内自动学会；所有已学技能的Lv2–3可以通过实战自动升级。
- 特殊功法/心法首次学习、所有技能Lv4–5、四种进化和洗点在藏经阁完成。
- 塔内领悟立即生效，死亡、撤离、重试均保留永久等级。修为、技能、装备仍是三个独立成长系统。
- 首轮只改这一成长闭环；本层临时战技列为后续实验，不加入此次必须开发的范围。

目标是首层清完第1波拥有第二种攻击，清完第3波拥有三种攻击，后续每隔几波出现一次明确成长反馈。第二招在首次入塔后30–45秒出现是试玩目标，需实际测量，不能用静态波号证明已达到。

不要求新玩家先读商店说明并购买第二本书。初始御剑术Lv1、20妖丹、300贡献和3颗回春丹保留；赠送妖丹可留给第一层通关后的特殊功法。

## 2. 技能分工

| 类别 | 技能 | 首次学习 | Lv2–3 | Lv4–5 |
| --- | --- | --- | --- | --- |
| 基础功法 | 御剑术、剑气斩、万剑诀 | 御剑初始赠送，其余塔内领悟 | 塔内自动升级 | 藏经阁进修 |
| 基础心法 | 金刚诀、剑心通明、聚灵阵 | 塔内领悟 | 塔内自动升级 | 藏经阁进修 |
| 特殊功法 | 一线天、剑影分光、两仪剑阵 | 藏经阁，20妖丹/本 | 学会后可在塔内自动升级 | 藏经阁进修 |
| 特殊心法 | 青萍剑意、剑骨、剑开天门 | 藏经阁，10妖丹/本 | 学会后可在塔内自动升级 | 藏经阁进修 |
| 进化秘典 | 万剑归宗、无我剑境、天地一剑、四象剑阵 | 藏经阁，240妖丹/本 | 不适用 | 永久拥有，按前置激活 |

塔内不能凭领悟得到尚未购书的特殊技能或进化。高级技能有自己的解锁门槛；“可在塔内升到3级”不等于所有技能都能免费学会。

保留门槛：一线天/剑影/青萍/剑骨通第1层开放；两仪/剑开天门通第2层开放。任何技能Lv3需已通第1层，Lv4需通第3层，Lv5需通第5层。进化需已通第6层、母功法Lv5及对应心法Lv3。

最多出战4功法＋4心法、最多2种进化替换对应功法，不增加第五个攻击槽。已有逐级效果先沿用12号表，先校准获取时机，再观察实际清群能力。

## 3. 首次成长路线

下表的数字是角色跨尝试累计完成的真实清波数。首次顺利挑战时，1–18对应第一层相同波次，21对应下一次挑战的第一波；若死亡重试，累计继续。

| 累计清波 | 自动成长 | 玩家能感知的变化 |
| --- | --- | --- |
| 初始 | 御剑术Lv1 | 远程自动索敌 |
| 1 | 剑气斩Lv1 | 增加近身扇形攻击 |
| 3 | 万剑诀Lv1 | 增加环绕攻击，走位距离开始影响输出 |
| 6 | 金刚诀Lv1 | 获得基础减伤 |
| 9 | 御剑术Lv2 | 主力远程技能加强 |
| 12 | 剑气斩Lv2 | 扇形伤害和范围提高 |
| 15 | 万剑诀Lv2 | 环绕伤害和范围提高 |
| 18 | 剑心通明Lv1 | 获得暴击能力 |
| 21 | 聚灵阵Lv1 | 增加拾取范围 |

第1、3次清波及其后每3次清波触发一次领悟机会，不新增“悟性币”、可储存技能点或需要分配的新钱包。首批基础教学完成后，每次从当前出战、已经学会、满足通层门槛、未到低阶上限的技能中提升一级；优先等级最低者，同级按“功法槽1–4、心法槽1–4”的顺序。先过滤不合格技能，再选择候选，不能被一个尚未解锁的等级卡住。

通首层前低阶上限为Lv2，通首层后为Lv3。通层状态与清波奖励一并提交；已到Lv4–5的技能不参与自动升级候选。

教学授予取现有等级与目标等级的较大值，不会把已有高等级降下来。已拥有教学指定等级时，把该次机会用于一个合格的出战低阶技能，同次最多处理一个技能，不补发额外机会。没有合格候选就不发奖励、不攒点、不换资源；不会反复提醒“已满级”。基础教学获得的技能若不想使用，可回洞府调整出战。

新学基础技能只自动填入当前配装空槽，绝不替换玩家已配置的技能。槽满时仍永久学会，提示“已领悟，可回宗整备”；以后升级一个已卸下技能不会把它强塞回槽位。其他两套已保存配装不随新技能自动改变。

## 4. 永久成长、死亡与恢复边界

- 每个真实尝试的每一波只记一次清波。重试可以继续积累清波并训练低阶技能，第一层反复刷也最高练到Lv2，不能绕过通层门槛。
- 演武场、未清完的波、仅击杀部分怪物均不给领悟机会。修为突破、吃培元丹不触发领悟，避免金丹封顶或场外吃药影响技能训练。
- 已完成清波获得的永久技能，死亡/主动退出全部保留。相同时间步死亡优先于清波；不能在已经死亡后补发清波领悟。
- 清波计数、领悟记录、永久等级、当前出战技能等级、冷却、资源和战斗推进在同一可靠快照保存。以`(attemptId, wave)`去重，累计清波数取“入塔前基数＋本次有效清波数”，不能在每次checkpoint时反复累加。保存失败冻结当前推进，重试同一候选结果；刷新不能重复领悟或复活已计奖敌人。
- 暂停和刷新恢复同一技能等级与计数。当前尝试获得的新技能/等级可以即时进入战斗，但不开放塔内任意换装、买书或洗点。
- 新学技能在下一波开始时进入施放流程；升级既有技能保留其剩余冷却，不凭升级重置冷却。已发出的攻击和区域沿用施放时参数，后续新施放使用新等级，避免多算伤害。
- 永久等级封顶后停止低阶领悟。不存在无限累积的技能点，也不把免费等级折成妖丹。

主界面保持简洁：清波时技能图标亮起，显示约1.5秒“领悟·剑气斩”或“万剑诀 Lv2”；第一次可附一句用途说明。技能栏更新等级，不新增常驻资源条，不强制打断走位选卡。宗门技能页明确标注“实战可修至3级”“4级需藏经阁进修”等来源。

## 5. 藏经阁的持续作用与价格

藏经阁负责拓展新流派、提高技能上限、学习进化，以及重新分配高阶投入。

| 项目 | 妖丹费用 | 说明 |
| --- | ---: | --- |
| 特殊功法首次学习 | 20 | 指定学习，不抽取 |
| 特殊心法首次学习 | 10 | 指定学习，不抽取 |
| 功法Lv3→4 / Lv4→5 | 80 / 120 | 原门槛和费用保留 |
| 心法Lv3→4 / Lv4→5 | 55 / 80 | 原门槛和费用保留 |
| 进化秘典 | 240 | 一次学习永久拥有 |
| 换出战技能/切换配装 | 免费 | 仍在洞府整备，不算洗点 |
| 高阶重修（洗点） | 首轮试玩免费 | 退回实际支付的Lv4–5妖丹，保留低阶等级 |

基础技能Lv1–3和已解锁特殊技能Lv2–3不再出售收费升级书，避免让玩家误买免费训练即可获得的等级。

洗点仅限场外，以单个技能为单位，一次撤销其Lv4–5投资并回到Lv3，100%退回实际支付的对应妖丹。特殊技能的解锁书、进化秘典不退款，已经永久学会的内容不会被删除；玩家可以重配高阶发展方向。

每次收费升级记录真实支付成本与是否已退款；退款、降级、核销未退额度同次保存。免费等级不能退款，重修/再升级/再重修也只能退尚未退还的真实投入。价格以后校准时依账本原价退款，不能按新的更高售价套利。

母功法重修后不满足Lv5的，关联进化在三套配装中全部自动停用，保留母功法及进化所有权；重新修到Lv5后可免费重新装备秘典。藏经阁确认页必须显示退款额和受影响配装。配套心法只作为学习进化的前置，不新增必须携带的限制。

现有新模式测试档保留已学等级，对本次改为免费的等级一次返还可核实的已付妖丹。迁移版本标志与退款同次保存；初始赠御剑Lv1、其他免费获得或来源无法核实的等级不能按买书价格伪造退款。不迁移其他旧试玩模式。

## 6. 经济与强度初查

按当前12项技能、4本秘典、初始赠御剑Lv1计算，忽略重修循环，永久全收集成本：

| 项目 | 妖丹 |
| --- | ---: |
| 六功法全部Lv4–5 | 1,200 |
| 六心法全部Lv4–5 | 810 |
| 三特殊功法＋三特殊心法解锁 | 90 |
| 四本进化秘典 | 960 |
| **新总额** | **3,060** |
| 旧全收集总额 | 3,940 |
| 免费低阶成长减少的支出 | 880 |

现有九层首次通关收入加初始赠礼共1,118妖丹，未计失败和重试收入。新全收集剩余1,942妖丹；以第九层常规约159妖丹计，约13次完整通关。3,060是全技能满级加四进化的收藏成本，不是一套可用配装的必需投入，且免费重修允许调配高阶预算。这只是余额算术，不能解释成需要13局才能通塔，也不是实际养成时长或真人留存证据。

建议先保持妖丹产出与高阶书价，不因为低阶免费立刻涨价。玩家通完首层已有93妖丹（含初始20），可以明确选择一线天、剑影等新招；原有“先花钱补齐基础攻击”环节不再阻挡前期体验。

技能获得提前会显著改变清群能力，不能拿旧单御剑路线的515秒首层或旧942项测试证明新方案平衡。御剑飞剑增加仍共享总伤害，万剑仍共享命中窗口；装备30%上限、修为金丹上限、生命继承、妖兽阶位与九层20波不改。

## 7. 低阶练满后的重复体验：后续实验

永久低阶成长有终点。在基础六项全部携带、无其他技能分流、及时通首层的理想路径中，累计48波可把这六项练到Lv3。高级技能、进化与不同配装接手长期目标；如果试玩仍觉得一层内变化不足，再试验“本层战技”。

候选实验：通首层后，第5/10/15波提供一次本层技能变化，最多3个、每技能最多1个，只作用于已出战的非进化功法；没有候选就跳过。可以自动推荐，也可由玩家选择。离塔/死亡清除，暂停刷新保留；永久等级继续保留。

示例：御剑“分光”增加飞剑数量但平分原有总伤害；剑气“展刃”扩大角度而缩短距离；万剑“游环”扩大环绕范围而降低每次伤害。目标是改变打法，不靠每波永久堆攻击百分比。

此实验**不作为本次方案必须实现的内容**，不预先承诺数值或选择界面，不引入新的永久货币。先验证塔内低阶领悟闭环，再用玩家实际反馈决定是否需要。

## 8. 实现拆分与验收门槛

用户确认本提案后，先更新18号决策记录、12号技能设计、经济数据生成与19号快照合同，再按现有文件所有权并行：

1. 养成/存档：Campaign的领悟账本、低阶来源、升级费用、真实投入退款、进化停用和新测试档迁移。
2. 战斗：Run累计有效清波、教学授予、出战低阶升级、即时生效与快照。现合同锁定入塔配装，需要明确允许“同技能升级及新领悟填空槽”，不能直接放开所有配装编辑。
3. UI：藏经阁学习来源/高级进修/重修说明，清波领悟反馈，洞府空槽和未装备提示。
4. 集成与数值：真实操作首层→回宗买特殊书→再次入塔练级→高级进修→重修换流派，随后九层回归。

重点验收：

- 新档不去藏经阁，清第1/3波分别拥有2/3种实际攻击；第1波时长达标，动画和作用可区分。
- 所有低阶免费技能可获得；满槽、同级候选、等级门槛及已购买特殊技能正确；演武/未清波不给领悟。
- 同一清波刷新、重载、保存失败重试不重复升级；死亡保留已经提交的等级；同tick互杀不发清波等级。
- 配装切换不丢永久等级；塔内不开放手动换装；升级不重置冷却或修改已施放伤害。
- 免费等级不能退款；收费等级退款一次；进化所有权与可装备状态分离；迁移不反复退款。
- 新路径首层时长、死亡点、第二/第三技能出现时刻、首轮可购买内容与第3/5层压力实际记录。把原版与新版同种子结果比较，再校准敌人节奏，不为保住旧耗时机械加血。

## 9. 本轮交付与决策边界

本轮交付为设计文档与经济算术校核，没有开发、构建或新版游戏测试。已由独立代理只读复核，补齐清波去重、跨功法/心法候选顺序、退款核销、进化所有权与启用资格分离等边界；没有据此宣称运行时已完成。

需要确认的是上述核心策略整体：**永久低阶领悟＋特殊/高阶藏经阁进修＋高阶投入可退款重修**。首层具体波次可在该方向批准后按试玩微调；临时战技暂缓。
