# 装备八阶、境界与特殊标签需求

日期：2026-10-30。状态：**数值评审完成，当前四阶已实装；后四阶及特殊标签仅预留。** 定稿数值见[62号](62-equipment-tier-balance-review.md)，开发范围、验证结果与未关闭问题见[63号交付报告](63-equipment-tier-delivery.md)。

本稿覆盖31、40–44、49、52及59号中的旧装备大阶命名与对应境界。未涉及的技能、九层塔、金丹27级上限、横屏规则不变。数值、费用与软概率不因名称更新自动重算；具体冲突和实施顺序见[61号复核](61-equipment-tier-implementation-review.md)。

## 1. 已确定的八个等级

| 顺序 | 装备等级 | 颜色 |
|---|---|---|
| 1 | 凡器 | 白 |
| 2 | 法器 | 绿 |
| 3 | 宝器 | 蓝 |
| 4 | 灵器 | 紫 |
| 5 | 法宝 | 橙 |
| 6 | 灵宝 | 红 |
| 7 | 仙器 | 金 |
| 8 | 神器 | 彩／幻金 |

适用于武器、防具、戒指。“法宝”在本表是装备等级，不新增第四个装备槽。“黄、玄、地、天、仙”旧阶序退出新规则，不能把旧的五个展示按钮继续当作八阶体系。

| 角色境界 | 使用装备 |
|---|---|
| 炼气期 | 凡器 → 法器 |
| 筑基期 | 法器 → 宝器 |
| 金丹期 | 宝器 → 灵器 |
| 元婴 | 灵器、法宝 |
| 化神 | 法宝、灵宝 |
| 炼虚 | 灵宝、仙器 |
| 合体 | 仙器 |
| 大乘 | 仙器、神器 |

箭头表达该境界的装备成长方向，不表示突破时自动把现有物品升级。当前可玩范围对应前四阶；后四阶登记为未来内容，不提前进入当前抽池，不因此开放元婴及以后修为。

## 2. 需要与等级分开的两个维度

**建议保留现有下品／中品／上品／极品，作为同一大阶内部品质。** 用户本次没有要求删除这一维度。它继续决定同阶词条档位及槽数，八种颜色仅表达大阶；例如“宝器·上品·青霄剑”。这是本稿的实施建议，不是用户已确认的新概率方案。

品质通过文字、边框细节或有限明暗变化区分，不能将“极品凡器”画成金色从而与仙器混淆。神器以彩／幻金表现，仍显示“神器”文字；具体色值、描边与渐变待横屏实景验收。白色凡器需有深色边缘，不能在宣纸底色上消失。

**特殊标签独立于大阶与品质。** 标签不插入八阶排序、不自行改变颜色，也不自动附加一层数值倍率。

| 特殊标签 | 用户给定定位 | 本稿建议边界，尚未实现 |
|---|---|---|
| 本命法宝 | 玩家可以长期养成的主武器 | 绑定一个武器实例；养成有境界上限，保留实例身份与投入记录。何时绑定、升阶材料、替换／解绑规则另定；不能仅通过名称直接授予“法宝”阶属性 |
| 古宝 | 秘境掉落 | 作为来源与特性标签；先设计掉落事件、概率和领取事务，再开放内容。不能仅给普通炼器结果改名就宣称秘境掉落已完成 |
| 仿灵宝 | 灵宝的下位替代品，抑制前期数值膨胀 | 建议以法宝阶承载，低于同定位灵宝的预算；不绕过装备境界门槛，不提前复制完整灵宝数值 |
| 玄天宝 | 特殊标签 | 尚未指定获取方式、能力及对应大阶，暂只登记标签；不擅自设为神器以上的第九阶 |

“本命法宝”标签与“法宝”阶可同时出现，但两者语义不同。标签可否组合、组合限制与加成预算须显式配置；未定义组合不应随机产出。本命养成是新的独立系统，现有 `refine=0` 和“本期禁用强化”不因登记此方向自动解除。

## 3. 境界门槛的实施建议

用户给出了各境界使用范围，尚未给出炼气／筑基／金丹内部何时解锁第二档。建议把表理解为主要成长区间，高境界仍可继续佩戴低阶物品，突破不强制卸装。不得把这个建议描述为已确定的严格可穿戴白名单。

可供实现评审的最低境界为：

| 装备等级 | 建议最低境界 | 当前实现范围 |
|---|---|---|
| 凡器 | 炼气 | 当前 |
| 法器 | 炼气，具体小阶段待定 | 当前 |
| 宝器 | 筑基，具体小阶段待定 | 当前 |
| 灵器 | 金丹，具体小阶段待定 | 当前 |
| 法宝 | 元婴 | 未来 |
| 灵宝 | 化神 | 未来 |
| 仙器 | 炼虚 | 未来 |
| 神器 | 大乘 | 未来 |

获取与穿戴应分别校验：库存持有不等于可以装备。普通炼制应只列出已开放且可获取的等级；未来阶只作为明确标注的预览。直接设置配装、切换配装、读档恢复、战斗快照与UI预览必须使用同一门槛定义，不能只禁用按钮。

## 4. 当前内容重新分配

建议初始普通铁剑、粗布道袍、素银戒归入凡器；仍使用独立“初始赠送／不可分解”标记保留保护，不能继续依赖 `tier=iron/basic` 识别初始物品。初始物品是否保留无随机词条的品质0，需要在数据合同中显式定义。

旧黄／玄两阶的23把非初始武器以及防具、戒指必须逐件指定新阶；**不得以整批黄→法、玄→宝的改名代替四阶设计**。保留物品身份、原图与可复用图标，不因新大阶重绘全部素材。形成逐件映射表后再生成新目录，特别检查每个可抽“部位×大阶×品质”都有合法候选。

物品静态图标继续按主体最长边约98%接入，128px画布为125px主体，等比、居中、完整透明边缘；使用 `scripts/art/item_icon.py` 导出和检查，原图保留。大阶颜色放在边框／标题，不能靠放大格子或染坏图标实现。

## 5. 数值与经济边界

1. 四阶必须沿当前炼气→筑基→金丹曲线重新标定，不能在现有两阶之间插入完整倍增后再保留所有原倍率。先冻结每阶最低境界和参考攻击，再定固定攻击、词条及防具生命范围。
2. 固定攻击、百分比增伤、暴击／会心、冷却缩减与本命养成必须列清各自预算。旧“35%”文字与测试口径冲突已按62号收敛；以同修为同技能初始铁剑＋5、无属性戒指为基线，固定攻击与所有输出词条合计不超过35%。
3. 防具仍以生命、减伤和受击恢复为职责，戒指以输出辅助为职责，不把新名称视作重开武器吸血等已删除机制的理由。
4. 保留当前同阶下／中／上／极品47/35/15/3%基础概率及既有软概率曲线、无硬保底；这不是八个大阶的随机概率。用户选择／解锁大阶与抽取品质是两步。
5. 现行玩家入口为武器池与防具池，后者产生防具或戒指；单次100灵石＋100贡献，十连900＋900。见代码和61号。更换大阶不能意外回退到44号旧入口／价格。
6. 本次不采纳49号尚未实施的分阶价格建议。如果随后引入不同价格，需同时解决跨阶共享软概率带来的低价积累、高价兑现问题，并单独确认概率计数规则。
7. 古宝和本命材料的渠道、概率、资源支出尚未设定，禁止凭空给新档发放高阶战力来补齐演示。

## 6. 数据和验收要求

建议新增共享装备等级配置，统一维护顺序、显示名、色彩语义、最低境界、是否开放；保留 `tier`（大阶）、`quality`（品质），另设标签与可选养成状态。字段名只是建议，需与严格实例校验器一并落地。

实施至少满足：

- 八阶顺序和八境界对应与本稿一致；当前27级范围不产出法宝及以上装备。
- 当前四阶三部位的目录、随机候选、词条、分解收益、价格与说明一致，无空池。
- 各阶门槛前／当级／后，普通装备、直接配装、切换配装、保存重载均一致。
- 品质概率不误当大阶概率；软概率边界m=14/15/16/28/29、极品归零、十连逐抽和整批回滚通过。
- 战斗逐阶覆盖固定攻击、暴击资格、会心计数、冷却收益、防具恢复和混搭预算；不能只修改旧测试中的阶位名称或放宽断言。
- 八色在1280×720与844×390横屏的炼器、结果、背包、配装和详情一致；低品质也清楚显示大阶，未来阶状态可辨。
- 标签与养成若暂未实现，页面不得宣称可绑定、可升阶或已开放秘境掉落。
- 存档结构变化可按项目约定重置该模式不兼容旧档，不删除其他模式或账户数据；当前合法档的失败原子性、随机状态恢复、重复领奖校验仍必须通过。

实施定稿：当前四阶门槛为Lv.1/4/10/19；74件物品身份保留，非初始物品支持四品质，初始三件使用品质0保护。逐件分配、固定攻击与词条表、35%总输出预算以62号为准。本命养成及其他标签玩法仍待独立设计，未开放。
