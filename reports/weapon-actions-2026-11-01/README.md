# 武器与普攻改造验收

本轮按对话批准范围实施。元素强化只出现在**宝器、灵器**，凡器、法器不出现。未使用付费静态素材，未发布或提交 Git。

## 已接入规则

- 初始剑基础攻击为 4～6，均值 5；其他固定身份也有固定范围。每次施放只抽一次，多段共享该攻击快照，同名武器的词条仍固定。
- 独立近身普攻：基础 1 秒一次、0.2 秒动作，攻击力 30%，单目标。普攻独立于御剑术。
- 普攻与技能启动、前摇、主动多次挥击共用动作通道。读条期间不挥剑；已发射飞剑和落地阵法可以继续。
- 普攻就绪后最多让一个新技能先行，随后获得动作机会；技能不重置普攻计时，等待不积攒多刀。暂停与恢复保留动作及伤害快照。
- 攻速只缩短普攻间隔与动作，不缩短技能冷却或读条。
- 独立附伤按本次攻击力计算，每次直接施放对每个目标最多一次；不暴击、不递归触发被动或附伤，不为持续阵法每跳追加。主伤害已击杀目标时不制造额外伤害。
- 元素与物理/法术是两条独立分类轴。匹配元素强化与现有武器增伤加算一次；混合伤害不重复享受。通用高阶武器为全元素，剑气专精偏风，剑阵专精偏雷。
- 背包、图鉴、技能面板已更新；战斗中主伤害与附伤分别显示，附伤带元素文字。

## 首版数值

| 品阶 | 普攻攻速 | 独立附伤占攻击力 | 元素强化 |
|---|---:|---:|---:|
| 初始剑 | 0 | 0 | 无 |
| 凡器 | 2% | 0.5% | 无 |
| 法器 | 4% | 1% | 无 |
| 宝器 | 6% | 1.5% | 0.75%～1.5% |
| 灵器 | 8% | 2% | 1.25%～2% |

新属性从原增伤预算分配。真实近身模拟发现凡器攻速改变剑气斩节奏，曾导致三个场景比初始剑低 0.1%～1.8%；已给凡器通用增伤补回 2 个百分点。没有提高测试容差。
