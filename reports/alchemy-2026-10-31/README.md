# 丹药炼制交付记录

已按批准方案实现，未调用Scenario或其他付费制图服务。尚未制作的新图使用文字占位。

## 功能

- 13种丹药：回血3种、修为6种、突破4种；11种材料。效果、成丹售价、炼制贡献和材料配方分别配置。
- 修为丹按炼气、筑基、金丹共享额度，每大境界6颗。错境不能服用；修为溢出与超过可服额度的库存分别确认。
- 丹霞峰提供炼丹／购丹、类别、可炼筛选、1至99炉、缺料来源跳转。确定成功，一炉一颗。
- 普通怪按6%掉落草药，精英按50%掉落分层主药，Boss保证2份主药；原Boss稀有材料掉落保持原规则。实时、暂停和结算均显示材料。
- 背包材料分类、来源、出售；已有Boss材料继续支持直接突破。图鉴收录配方与材料。
- 炼制持久化序号与回执防重放，保存失败不扣资源；重复检查点不重复奖励，库存溢出转换灵石并报告损失。
- 新存档schema25；依照项目约定不兼容旧模式存档，正常存读档、失败原子性与重复领取校验仍保留。
