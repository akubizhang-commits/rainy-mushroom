# 手持武器清晰度开发与接入（2026-11-03）

本轮继续已批准的一细一宽两把剑：素问剑、镇岳剑。生产代码已加载 v2 素材；沿用真实设计图换装、无品阶绿光、头发与服装不随装备变化。

## 改动与原因

此前高清长条图以单层线性采样缩小到约 61–66 个设计像素，剑边出现断续锯齿；报告又放大了截图，进一步暴露低分辨率。现在在上传 ImageAsset **之前**启用线性 mipmap，1024×128 的二次幂纹理兼容 WebGL 1 自动生成缩小层级。透明区域向外延展 12 像素 RGB，避免透明黑色污染边缘；可见 RGBA 和 alpha 均逐像素保持。素问剑剑身 66→74、镇岳剑 61→72 设计像素，保持等比和握持对齐。

原始设计图、旧版运行图全部保留；没有付费生成。其他武器继续使用原先银灰后备剑，不将这两把剑的验收扩展到全部武器。

## 构建与边界

默认共享构建目录发生 polyfills.bundle.js 的 MD5 文件冲突，npm 包装脚本仍报告 Built；该结果不算通过。改用本报告内 `cocos-project` 独立工程构建，再在真实浏览器验收。有效包为 `cocos-project/build/web-mobile`，没有将此快照覆盖其他任务的日常构建目录。代码和素材已接入主工程，下次正常构建会包含此次修改。

未做微信发布或手机真机性能认证；浏览器高像素密度测试也不能替代真机。未改战斗规则或存档，未提交 Git。
