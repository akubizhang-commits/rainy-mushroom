## 应先解决的描述问题

1. **纵横剑气：确定错位。** 当前`cross-burst`在角色周围取目标并一次结算，面板仍说“两道月牙组成飞行十字斩”；形态和定位栏也沿用飞行十字斩。应同时改描述、形态名、范围和定位，不能只改开头。
2. **剑心通明：面板自相矛盾。** 主描述已包含持续功法逐次暴击，作用范围却写“自身的直接攻击”。应区分可独立暴击的功法伤害与继承上游结果的衍生伤害。
3. **剑骨：保留旧机制措辞。** 描述仍提“击杀爆发”，当前剑气爆裂已改成直接命中触发。也不宜笼统声称不增强爆裂：当前爆裂走普通伤害结算，`outgoingDamageFactor`会加入剑骨增伤。持续剑痕可继承原攻击增益，但不应再次叠乘同一加成。
4. **剑破虚空：视觉没写进描述。** 现描述只有直线剑气，没有飞剑划开、裂口张合这一主要特征；应说明裂缝是表现，不是持续伤害区。
5. **剑破虚空：原地同路连刺文本需单独复核。** 面板说首刺锁定起点，代码每次释放却取角色当前位置；方向与起点不是同一件事。新短描述暂不承诺“所有剑击沿完全相同的线”。
6. **无我剑境：主描述未突出区别。** 应突出错轨游剑、随身移动、持续存在以及近身覆盖，区别于普通周天剑阵的定时剑环。
7. **御剑术、碧落斩：首段过于技术化。** 派剑预算、在途伤害扣除、剑痕预算合并等适合详细规则区。主描述优先告诉玩家“做什么、打哪里、怎样成长”。
8. **两仪/四象：剑数与结算次数需分开。** 特效里一轮有多把落剑，不等于每把独立结算伤害。保留按脉冲结算的说明，不按画面剑数宣传攻击次数。

## 建议优先级

1. 先修描述确定过时的纵横剑气、剑心通明、剑骨；再补足剑破虚空和无我剑境的辨识特征。
2. 先定名字：弦月斩、剑啸八方、蚀骨剑意、剑罡爆裂、护体剑罡、周天剑域、一剑开天。分光连斩属于较温和的可选优化。
3. 图标先解决三张：剑破虚空、纵横剑气、碧落斩。其余以原图复用或局部调整为主。
4. 推荐进阶关系：御剑术→万剑归宗；周天剑阵→周天剑域；剑破虚空→一剑开天；两仪剑阵→四象剑阵。
5. 不强行把18项都改成四字，也不为“酷”加入实际不存在的吸血、冻结、毒伤、无敌、复活等暗示。

## 静态素材制作原则

优先复用合格母图、局部改色或重新构图。若确需新图，由助手提供prompt、用户出图后审核；不用Scenario付费生成静态图。原图与历史版本保留。技能图标不套用物品图标98%主体规则，按菜单圆形遮罩和小尺寸可读性验收。
