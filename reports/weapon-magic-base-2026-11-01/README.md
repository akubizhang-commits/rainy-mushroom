# 武器基础法术攻击

已把基础攻击拆为物理、法术两项，各自有固定均值与浮动范围。当前剑类两项使用相同首版数值：初始剑都是 4～6、平均 5；后续品阶分别查独立数值表，具备独立调整能力。

## 计算

- 物理技能与普通挥剑使用物理攻击力。
- 法术技能使用法术攻击力。
- 混合技能使用 `技能倍率 × (物理攻击力 × 50% + 法术攻击力 × 50%)`，随后物理、法术部分分别计算对应增伤，暴击也保留各自基础。
- 例如物理攻击 100、法术攻击 160，100% 倍率混合技能在增伤前为 50 物理 + 80 法术 = 130，不是 260。
- 武器的两项加值分别加到角色基础上，不将两项相加为同一个“总攻击”。现有剑类数值相同，补齐字段本身不会翻倍伤害。
- 每次施放用同一次随机抽样在两项各自范围取值，多段、飞行物、阵法保存并共享施放快照。新增法术快照必须存在且在合法范围内，人物法术攻击也参与快照校验。
- 元素强化仍只在宝器、灵器出现，和基础法术攻击是不同属性。

## 显示与存档

装备详情、图鉴分别显示基础物理攻击和基础法术攻击；人物信息显示物理、法术攻击力，混合技能面板说明两项各取 50%。当前开发存档版本递增，遵守项目允许重置旧模式存档的约定。
