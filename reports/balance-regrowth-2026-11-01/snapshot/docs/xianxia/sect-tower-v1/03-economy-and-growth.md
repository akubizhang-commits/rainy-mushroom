# 历史归档：旧资源、双池自选与丹符伙伴方案

2026-10-27归档。本稿所有旧玩法与算例均已退出现行规范，不是待实现候选。用户已在[18决策清单](18-decision-register.md)确认完整规则并允许开发；现行资源、消费和技能分别见[09资源规范](09-resource-standard.md)、[11产消总表](11-economy-v2.md)、[12永久技能书](12-skill-books-v2.md)。

## 1. 历史方案及处置

| 已废止方案 | 现行处置 |
|---|---|
| 灵石购物、寻器砂/结缘砂、铸印/结缘印并行 | 灵石只加修为，妖丹只买技能书，宗门贡献用于抽取、场外丹药与有限强化；新档不迁移旧资源 |
| 双池首期同时开放、剑修获得灵兽、通第2层赠拾灵雀 | 首期仅剑修三剑武器池；灵兽只属未来御兽师，灵兽园为预留 |
| 12/40抽进度兑换指定物品、兑换券与自选进度 | 全部取消；品质保底保留，但不保证指定身份。指定买技能书和买丹药仍保留 |
| 装备18%＋灵兽6%＋增伤药4%的28%模型 | 各职业装备统一30%，包含强化；未来御兽师削武器基础输出配平灵兽，不另降装备上限 |
| 法衣8%生命、法衣品质升级/强化及佩饰强化 | 一期法衣/佩饰仅基础款，不抽取、不升级品质、不强化 |
| 每层1丹1符、自动触发、凝神丹/清心丹及三种战斗符 | 一期无战斗丹药/符箓槽；符箓只能后续符师使用，效果另行设计 |
| 凝露灵狐6%伤害配额、拾灵雀拾取范围、岩甲龟盾 | 旧剑修伙伴效果全部废止，不自动沿用为御兽师方案 |
| 每层丹符45预算、首通可同时消费双池的抽数结论 | 已失效；持久生命、场外购丹与武器强化取舍须按新规则另算并实测 |

## 2. 现行规则入口

- [01建筑](01-sect-buildings.md)：八处可用建筑，灵兽园/灵符堂为未来职业预留。
- [11经济](11-economy-v2.md)：武器和未来灵兽每抽100贡献，独立20/30抽极品保底；回春丹5贡献恢复50%最大生命，培元丹20贡献增加50修为。
- [17生命与收益](17-entry-exit-and-loot-proposal.md)：出塔/再入/下层继承HP，死亡回宗1HP；仅场外每分钟恢复1%最大生命，离线也计算；塔内即时回血掉落保留。

## 3. 证据边界

旧五币产出、双池消费、战斗丹符预算及28%伤害算例不再作为现行经济或职业平衡证据。归档只整理被替换的方案，不表示已重新模拟，不改动data目录、生成器或运行时。后续结果须注明所用规则、输入版本及实际运行的检查；历史公式通过不能证明新方案可玩或平衡。
