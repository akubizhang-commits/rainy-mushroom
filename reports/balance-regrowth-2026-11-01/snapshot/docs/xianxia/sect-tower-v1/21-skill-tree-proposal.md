# 剑修全技能树与心法光环

2026-10-28｜阶段：技能方案与交互原型。当前预览已改，正式塔战尚未接入本方案。

> **最新升级策略见[23号技能点提案](23-skill-point-budget-proposal.md)**：用户要求按技能强度分档点数、境界主要发点、提高技能等级上限。本稿单页布局、自动生效、心法光环继续采用；下文5级、低阶免费研修、逐级高阶买书和退妖丹等为此前交互基线，被新点数方案建议替代。原型明确标注两者，不将新点数视为正式实现。后续七职业领域见[22号](22-class-domains-proposal.md)。

## 1. 本轮明确的方向

用户连续明确：所有技能放在同一页，通过分支区分流派；学会功法即可自动释放；心法是被动，学会后入战在脚下显示独立光环，多种心法同时生效便同时显示多圈。特殊技能与大招仍须回藏经阁购买解锁。

因此，本稿覆盖此前的独立心法页、手机流派切页、出战/不出战、4功法＋4心法槽及最多2个启用进化。**不再进行技能装备操作**。装备系统中的武器/法衣/佩饰不是技能，不能因此删除装备系统。

[20号领悟提案](20-skill-awakening-proposal.md)中的基础教学、低阶实战成长、高阶回宗、书价与重修参数继续作为试玩建议；具体教学波次和免费退款尚未作为完整方案验收。[18号记录](18-decision-register.md)区分旧运行时与新方向。金丹27级、修为曲线、装备30%上限、三资源、血量与抽取规则均不变。

## 3. 学会即生效，不再选择出战

- 已学功法自动进入施法循环，仍分别遵守目标、距离、冷却、蓄势和命中规则；自动释放不等于没有目标也造成伤害。
- 已学心法自动提供对应战斗属性或触发能力，无须手动开启。条件型被动拥有常驻能力，实际事件仍按自己的触发条件发生。
- 四进化都可以购买并同时生效，各自自动替换其母功法。进化不是第七至第十个额外攻击通道，母功法不与进化同时重复攻击。
- 主动重修母功法至3级时，该通道暂时恢复基础版；重练5级自动恢复已有进化，不重买。所有权与当前生效版本分别保存。
- 六个功法全学会后就是六种攻击通道，六种心法全部常驻。不能继续套用旧4＋4配装下的平衡结果。

流派先体现为学习顺序、高阶投资和战斗行为的不同，不是互斥职业。允许全学后，长期满级角色的技能组合会趋同；这是该方向的实际取舍。当前不偷偷增加流派锁或新的携带限制来制造差异，后续再评估武器特性对玩法的影响。

## 4. 领悟、进修与重修

初始御剑术1级；首次累计清1波领悟剑气斩，清3波领悟万剑诀，之后补基础心法与低阶升级。教学累计跨尝试，死亡或撤离不清技能等级。特殊节点即使条件满足，也不能在塔内自动获得或自动花丹购买。

所有已学1–2级技能均可参与低阶实战研修，不再检查出战槽。宗门可以指定一个优先研修目标；固定教学不受干扰，之后优先目标，无法升级时按最低等级、固定技能顺序均衡训练。未解锁技能不能设为目标。通首层前最多自动练至2级，首层后最多3级；不发技能点货币，突破或吃丹不赠点，满低阶不存点。

特殊功法首次20妖丹、特殊心法首次10妖丹；功法4/5级80/120，心法55/80；4级需通3层、5级需通5层，进化通6层。高阶与特殊首次学习只在藏经阁。结构变化不新增收费节点，全收集参考成本仍3060妖丹，但这只是算术，不证明培养节奏合理。

提议藏经阁免费重修：仅退实际尚未退款的4–5级投入，降至3级；免费低阶无钱可退，特殊解锁和进化所有权永久保留。退款、降级和投资核销必须同一事务保存。预览仅验证内存状态，真实存档的抗重复退款尚未接入。

## 5. 心法光环：玩家直接看得到的被动

每个已学心法入战生成一个独立脚下光环。多心法则多圈，使用固定且不同的半径，升级不再额外增加圈数。未学不显示；回宗、死亡收起；暂停冻结。悬停剑保持原样，光环投影在角色脚下地面，随角色移动，不能跟着挥剑或衣摆漂移。

| 心法 | 颜色与纹样 | 常态 / 事件反馈 |
| --- | --- | --- |
| 剑心通明 | 冰蓝细环，四向剑芒 | 低亮常驻；暴击时四枚剑芒短亮 |
| 金刚诀 | 淡金环，六边护纹 | 低亮常驻；受伤时纹样短亮，不能暗示额外护盾值 |
| 聚灵阵 | 青绿珠环，向心光点 | 低亮常驻；拾取时光点收拢，不改变掉落数量 |
| 青萍剑意 | 青玉双弧，叶纹 | 低亮常驻；施加剑痕时叶纹短亮 |
| 剑骨 | 银白细环，剑脊刻纹 | 低亮常驻；移动时缓流，不给每次直伤制造强闪烁 |
| 剑开天门 | 淡紫断环，门阙纹 | 低亮表示具备能力；实际击杀爆发时门阙短亮，并非每次击杀触发 |

这六圈均表示自身能力，不代表范围Buff、攻击范围或队友增益；聚灵光环半径也不是拾取判定半径。触发提示不追加伤害、不改变原效果或冷却。相似的蓝青色仍由剑芒/光点/叶纹区分，不能只靠颜色。

### 叠加与战场可读性

- 六种半径固定，少学一个时其他圈不重新排列，便于识别。原型参考半径58/76/94/112/130/148，正式版按战斗角色尺寸整体缩放，绝不当作判定单位。
- 所有圈低饱和、细线、中间透明；叠加超过三种降低单圈亮度，而非隐藏某个已学生效的心法。
- 轮廓慢速流动，避免六圈高速各转各的。触发短亮约0.65秒建议值；密集事件合并限频，不能每次命中重叠出一圈特效。
- 敌方预警、敌弹轮廓在光环之上，角色实体遮挡其后侧投影。光环不做高柱、实心色盘或遮住落点的强光。
- 减少动态效果模式保留静态六圈和形状识别，关闭流动与短亮。无需新增常驻战斗HUD标签。
