# 武器、戒指与防具职责修订

状态：用户已批准同时开发武器、防具、戒指。本文记录已批准的实施方向；具体范围见[44号三类装备合同](44-three-equipment-contract.md)，当前业务已实现、643项回归测试通过，两尺寸浏览器操作验收已通过。本文覆盖41号的单武器词条归属与预算分配、42号的防具和回血戒指方案；最新用户覆盖：入口改称“炼器房”，三类炼制采用47/35/15/3%基础概率及软概率递增，取消硬保底和本期强化；费用与宏阶门槛保留。部位统一称“防具”，物品名可以保留“法衣”。

## 1. 三种装备，一眼看懂

| 装备 | 负责什么 | 可见词条例子 | 不再出现 |
|---|---|---|---|
| 武器 | 基础攻击、具体技能、流派伤害 | 攻击力＋3；御剑术伤害＋4%；剑气伤害＋5% | 暴击率、暴击伤害、会心、吸血 |
| 戒指 | 暴击率、暴击伤害、周期会心 | 暴击率＋3个百分点；暴击额外倍率＋2个百分点；每5次有效施放触发会心 | 受伤回血、减伤、独立基础攻击词条 |
| 防具 | 减伤与回血 | 受到伤害减少；受伤后回复生命 | 攻击、暴击、会心、反伤 |

例子仅说明表达方式，不是批准把这些数值任意组合。所有最终数值必须通过联合预算校验。

**特殊词条的归属：**将原武器“会心”移到极品戒指。原“饮露/吸血”从新武器池撤出，不搬进戒指；防具承接受伤回血。防具不采用按攻击伤害吸血，避免高输出同时放大防具治疗。回血遵守第5节的受伤延迟回复规则，不继承42号的六槽回复机制。

会心与暴击保留区别：暴击随机发生；会心每5次有效直接攻击触发一次，按一次施放计数，不能多弹多目标重复计数。持续伤害不暴击、不触发会心。

## 2. 不再强迫每个部位拥有六条词条

旧的2/3/4/6数量与其强度是在单件武器上设计的，拆分后不能再给武器补回同样数量，再给戒指一整套，否则必然增加预算。

| 品质 | 武器槽位 | 戒指槽位 |
|---|---|---|
| 下品 | 1个基础攻击选项＋1个具体技能 | 暴击率 |
| 中品 | 1个基础攻击选项＋2个不同具体技能 | 暴击率＋暴击伤害 |
| 上品 | 1个基础攻击选项＋1个具体技能＋1个流派 | 暴击率＋暴击伤害（范围提高） |
| 极品 | 1个基础攻击选项＋2个不同具体技能＋1个流派 | 暴击率＋暴击伤害＋会心 |

- 基础攻击选项仍是“固定攻击力 / 物理伤害百分比 / 法术伤害百分比”三选一，不得同时生成。
- 同一技能不能重复生成；原技能与进化算同一家族，一次伤害只吃一个具体技能词条。
- 戒指少而清楚，不为凑数量加入多余触发条件；中品开始给暴击伤害是本次批准方向，替代旧武器仅极品开放的限制。
- 武器槽位数量为2/3/3/4；戒指为1/2/2/3。防具下、中、上品固定两条：减伤、单次回复比例；极品保证第三条“回复等待从3秒缩短至2秒”。冷却和整层限额是共同约束，不占奖励词条。

## 3. 原上限变为两个输出部位的共同上限

比较基准仍是相同修为、相同技能、相同敌人的铁剑角色，允许单次暴击高于平均输出上限。正式戒指尚未装备时，不额外赠送戒指预算。

下面是**已批准预算上界**（本期强化禁用，原强化份额已按最终范围重分配至基础词条，不再额外叠加）。戒指列表示其对已装备武器角色的最大边际平均增伤，不是直接显示给玩家的“戒指伤害＋x%”，也不是可直接填写的暴击率。

| 同档组合 | 原联合上限 | 武器份额上限 | 戒指边际份额上限（约） |
|---|---:|---:|---:|
| 黄阶下品 | 6% | 4% | 1.9231% |
| 黄阶中品 | 10% | 7% | 2.8037% |
| 黄阶上品 | 14% | 10% | 3.6364% |
| 黄阶极品 | 18% | 13% | 4.4248% |
| 玄阶下品 | 12% | 8% | 3.7037% |
| 玄阶中品 | 18% | 13% | 4.4248% |
| 玄阶上品 | 26% | 19% | 5.8824% |
| 玄阶极品 | 35% | 25% | 8.0000% |

戒指份额按 `(1+联合上限)/(1+武器份额)-1` 反推。内部保存精确比值，表格四舍五入结果不能用于放宽上限。例如玄阶极品是 `1.25 × 1.08 = 1.35`，不是武器35%之后再叠戒指8%。黄阶极品与玄阶中品仍采用相同的18%联合预算。

混搭按各自份额验算，不拿高品戒指为低品武器“升级预算”。八档武器与八档戒指共64种组合全部检查；铁剑、无戒指也单独检查。最高组合仍不超过35%；两件均非极品时按各自份额验算，不借用极品预算。相同预算不保证每一种技能配置都恰好吃满。

## 4. 必须算真实期望，不能把词条数字相加

没有会心时，暴击的边际影响可直观理解为：

`(1 + 新暴击率 × 新暴击额外倍率) / (1 + 原暴击率 × 原暴击额外倍率)`

例如暴击伤害150%中的“额外倍率”为0.5，暴击伤害增加10个百分点后为0.6；不是把总伤害直接加10%。

实际验算还必须包含：

1. 固定攻击力改变技能基数，也影响暴击与会心的基数；不能照搬原武器固定攻击力范围。
2. 百分比基础、具体技能、流派沿用加法（强化本期为0），不能重复乘算；物理/法术混合伤害只增加对应分量。
3. 戒指暴击率与暴击伤害必须联合取最大值测试，包含现有所有被动和各修为状态。
4. 会心按5次完整周期验算，并覆盖短战斗中已有计数的情况；计数变化不改变单次暴击可超过平均预算这一规则。
5. 持续伤害、直接伤害分别验证；来源更名或进化不能重复获取加成。

预算表是生成合法范围的约束，不是运行时偷偷压低伤害的阈值。生成前确定各槽合法范围，以最坏组合校验；不允许面板写＋10%实际只生效＋3%。最终词条数值见44号；业务回归通过不等于真人实战平衡已完成。

## 5. 已批准的实施合同

### 防具：减伤与受伤延迟回复

减伤硬上限6%（本期强化为0），没有攻击、攻速、暴击、技能增伤、反伤、吸血或最大生命加成。进入本层时固定最大生命基数 `H`，之后升级不放大本层防具治疗额度。

实际扣血 `L > 0` 且角色存活、没有待回复事件、20秒冷却已结束时，安排一次回复：普通品质等3秒，极品等2秒。20秒从受伤触发时起算。回复量为 `min(本件回复比例 × H, L, 回复时缺失生命, 本层剩余额度)`；比例最多1%，本层累计实际回复最多 `10% × H`。后续受伤不叠加、取消或重置已经安排的回复；不能复活。暂停不推进时间，存取档保留待回复、冷却和已用额度。

满血会让本次实际回复为0，不返还冷却。层内不能换装刷新额度；重新读档不能重置本层状态。没有“每秒回复1%”或“每次命中吸血”的效果。旧42号4%回复增幅上限属于被替换机制，不与本方案叠加。

### 炼器房、仓库与保存

入口统一为“炼器房”，操作为“炼制武器 / 炼制防具 / 炼制戒指”。武器每次100下品灵石＋100贡献；防具与戒指各80下品灵石＋40贡献。黄阶初始开放，玄阶金丹初期（19级）开放，同类别黄玄同价且共用连续未出极品次数；三个类别的计数和随机状态独立。

三池基础下/中/上/极品概率改为47/35/15/3%。连续未出极品少于15次，下一次极品仍为3%；累计15次未出，下一次5%，之后每失败一次再加2个百分点，上限33%。增加部分只从下品扣除，中品35%、上品15%固定。出极品归零；没有任何固定次数必出。精确公式和边界表见44号。

**最新规则替代此前40/35/20/5%、第20次硬保底和0–4强化提案。** 本期隐藏所有强化入口、价格与属性说明；后端强化请求返回 `refinement-disabled`，不扣费、不保存新状态。保留的 `refine` 字段为0，纯模块校验只接受0，不能仅隐藏按钮却允许旧调用强化。

没有指定兑换，重复身份仍生成独立物品，不自动分解。三类共享240格，普通铁剑、基础防具和基础戒指也计入。场外可装备、锁定和主动分解；基础、锁定及任意配装引用物品受到分解保护。三套配置各含武器、防具、戒指。

使用schema6，已授权重置本模式不兼容旧测试档；当前档正常保存、失败原子性和重复结算保护仍必须成立。余额不足、满仓、未解锁、禁用强化或保存失败，不能推进随机状态、未出极品计数或扣币。已生成候选结果在保存失败重试时不得重抽。
