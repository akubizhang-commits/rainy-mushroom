# 机缘抽奖试玩接入验收 · 2026-11-01

已接入共享游戏逻辑、Campaign 存档与 Cocos 横屏页面，支付未接入。默认网页预览已更新，原构建保留在 previous-web-mobile。入口：炼器峰庭院 → 机缘抽奖 → 领取一次 10 张试玩券。起始券数为 0，没有充值、灵石换券或重复领取接口。

## 规则与体验

- 武器、防具、戒指、丹药及普通材料在同一池；法器、宝器、灵器分别保存极品保底与心愿。达到对应境界解锁，没有 Boss 击杀门槛；凡器不进入奖池，仍只购买。
- 基础分支概率：下品装备 20%、中品 20%、上品 17%、极品 3%、基础丹药 15%、进阶丹药 15%、普通材料 10%。同品质的三个装备部位等概率，部位内按固定名册均分。
- 连续 39 抽未出极品，第 40 抽必出；心愿未中后，下次极品必中当前心愿。更换或取消只清空心愿未中记录，保留极品抽数。单抽和十连逐抽使用相同规则。
- 丹药根据境界、六次服用额度、库存和突破阶段过滤；无适用丹药时改发公示的普通药材。极品 Boss 专属核心不进材料池。
- 概率页显示下一抽的实际概率，包括库存过滤、保底和心愿必中，不把基础概率冒充当前概率。
- 抽到的同名装备直接使用炼器共用的固定属性工厂；没有抽奖独占强化版本。免费制作成本和掉落未因抽奖调整。
- 目前提供一次性试玩券；持续免费券投放、付费价格和购买流程尚未设计或接入。本轮不对付费体验给出已验证结论。
