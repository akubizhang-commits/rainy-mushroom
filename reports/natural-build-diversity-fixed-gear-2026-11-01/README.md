# 新固定装备版：自然成长与流派差异复查

本轮响应用户“新装备已定稿，继续重跑”。旧 `natural-build-diversity-2026-11-01` 结果保留，不计入本轮样本。

## 范围与方法

- 六条路线：剑气、无我剑境、混搭、天地一剑、四象剑阵、剑影追击；种子 101/211/307。
- 每条从真实 Campaign 新档开始，完整战斗按 60Hz 运行；只使用初始及战斗所得资源。
- 不吃修为丹；正常购买回血、突破丹、技能书和研究点，营地突破。达到境界上限也完成当前层，不提前退出。
- 各技能按路线优先级投入。御剑高等级补齐凝神诀前置。营地进化可回收被替代父技能和低优先级辅助投入；保留炼体与金刚的防御投入。已解锁的进化后续等级保留所需点数。
- 采用新固定装备炼制：每次营地每部位最多一炉，只做品阶/品质升级；只用已获得材料，不为刷特定身份重复炼制。保留至少 100 灵石、20 贡献。高品阶优先，同品阶高品质优先。
- 武器心愿：剑气/天地选剑气，双剑阵选剑阵，混搭/剑影选通用；防具偏稳固，戒指偏回转。心愿不保证本炉命中，实际获得什么就用什么。角色不获赠目标装备。
- 通关后最多续打第9层三次，获得实际等级与资源。随后另作 30级、80SP 的营地合法重配装比较，沿用该档实际装备。
- `*.mature.json` 才是统一 80SP 的成型结果；`summary.json` 的 mature 字段是自然路线后期重复层，不可混为一谈。
- 每层校验快照、正常结算、重复结算拒绝、存档重载一致性。源码有冻结副本与哈希，最终另核对工作区差异。
- 156组单技能探针：80/200px静止单目标、120秒、60Hz；用于排查伤害实现，不是真实玩家配装或移动Boss输出。

## 结论边界

用户目标是保留流派差异、避免断档式全面领先；未指定硬性百分比及统一Boss秒数。30%同时清怪/Boss领先只是调查筛选，不是验收阈值。机器人成功率不是玩家成功率；三个种子不能证明全种子、全流派组合绝对平衡。本轮不评估全极品毕业材料周期或真人操作难度。
