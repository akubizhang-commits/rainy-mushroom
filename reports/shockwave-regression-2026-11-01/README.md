# 环形震波躲避回归

正式工具对M15采用完整扩散扇区作为规划避让区，保持原有角度缺口，并给撤离增加连续距离评分。运行时伤害范围不变，其他环形技能不变。

- `snapshot/`：冻结源码及正式机器人。TowerRun仅为伤害日志额外增加`diagnosticIncoming`，其余运行时与上一轮安全门回归相同。
- `run.mjs`：25场固定配装回归；第8层剑阵/两仪各5种子、剑气/混搭/天地各3种子，第9层剑阵/天地各3种子。
- `results.json`：所有场次、受击来源、M15预警与命中注册、M19进门观测。
- `waves`统计包括未完成的预警，不可将预警总数当成完整施法次数。实际伤害由最终选中的攻击编号归因，另核对机制区`hit`。
- `summary.json`：运行`summarize.py`产生，核对完成状态、数量、源码稳定性、新旧HP与Boss击杀时长。当前源码对比剔除纯诊断字段。
- `inputs.json`：输入存在性及与前轮运行时差异。
- `tests.log`：相关测试结果。

运行顺序：`node reports/shockwave-regression-2026-11-01/run.mjs`，然后`python3 reports/shockwave-regression-2026-11-01/summarize.py`。脚本覆盖同名结果，要保留历史需另建目录。

局限：合成合法配装、固定机器人，非自然成长资源获取或真人失败率。完整避让区是一种较保守的移动策略，不代表最优DPS路线。
