# 素材加载与首屏修复 · 2026-11-01

已接入不依赖图片的深青 / 淡金剑环加载动画。浏览器从 HTML 阶段显示启动层，Cocos 首帧完成后交接到游戏内加载界面。游戏内的图片和图集元数据通过同一队列加载：按路径和资源类型合并请求，成功资源保留到宿主销毁，页面重建可同步复用；可选音效不阻塞进入。

加载过程中保留不透明遮罩并拦截输入，战斗不推进。资源回调完成后再准备两帧绘制，避免图集绑定尚未完成就露出占位图。失败自动尝试最多三次，单次超时 15 秒，之后显示重新加载按钮。手动重试沿用原来的图片绑定，过期回调和销毁后的回调不会生效。
