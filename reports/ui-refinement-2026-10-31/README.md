# 六项 UI 精修验收 · 2026-10-31

## 已落地

1. 技能详情增加独立细滚动条，位置随滚轮、触摸滚动及程序滚动更新；节点销毁时事件一同清理。
2. 技能说明保留原字号，收紧行距与段落空隙；小标题突出，冷却和效果数值按左右列排版，条件文本完整保留。
3. 技能树顶部显示“可用技能点”“重置加点”；确认页同步显示“重置加点”“确认重置”。技能升级条件中没有首通要求。
4. 背包选中分类显示名称，排序显示“最近 / 品阶 / 名称”；原有图标、物品格子和图标尺寸保持不变。
5. 宗门已开放地点保留亮色描边，未开放地点名称稍小、阴影减弱；保留文字及建筑本体的原有点击区域。
6. 战斗波次增大并增加淡墨底板；资源字体增大，大额完整整数按长度分配宽度；目标名牌和机制提示提高字号，并同步修正刷新路径的名牌高度。

## 验证结果

- 最终 Cocos Web 构建通过：build.log。
- 独立浏览器在 1280×720、844×390 均通过：分类、排序、技能滚轮与游标同步、滚动末尾、升级/退点、重置确认页和取消。
- 密集战斗渲染使用隔离的 42 怪物初始测试场景，推进后截图包含 37 只怪物和 1 个攻击效果；额外验证目标名牌。
- 大数值测试：极品灵石 ×999999、贡献 ×2000000000 均保持 24 设计像素字体；目标名牌保持 20 设计像素。没有使用截断数值或缩写。
- HUD 定向测试 5/5 通过：hud-tests.log。
- 技能条件、表现与背包测试合计 73 项，72 通过。剩余 1 项是已有的 844×390 丹药商店“丹霞主殿 y”布局断言，修改前源文件对照同样失败：inventory-baseline.log。
- 30 张物品图标及 21 张阅读插图检查通过：icon-check.log。
- 独立代码检查：名牌刷新高度问题已修正，未发现其他新增可操作问题。

浏览器测试不读取用户正常浏览器存档。测试用战斗怪物与资源只存在于隔离会话。此次没有进行真机性能验收，也没有声称 60 FPS 保证。
