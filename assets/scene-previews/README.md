# 场景选择预览

十二张 JPEG 来自当前项目的 Cocos Creator 3.8.8 / HabitatWorld，使用场景内真实几何、材质、动物、光照和阴影，无 HUD。每张 640 × 360，列表页只加载预览图片，不创建额外 3D 场景。

更新场景美术后，先运行 `npm run cocos:build`，再运行 `npm run cocos:capture`，在浏览器打开命令打印的本机地址。该服务只接受固定十二个场景文件，使用独立内存存档，同时写入本目录与 Cocos resources/previews，全部完成后关闭。最后再次构建，将新预览图纳入游戏包。

这些图片展示场景示例；重复探索时的天气、菌物与动物位置可能变化。
