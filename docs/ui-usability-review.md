# UI 与交互检查 · 2026-09-14

本轮保留森林绿、暖纸色和生态分区配色，统一菜单、收藏、手记的主题变量。未替换游戏的3D美术。

## 已调整

- 统一主要按钮、次要按钮、分页按钮的字号、描边和圆角，减轻卡片阴影，增强辅助文字对比度。
- 小屏菜单适当放大，按照实际顶部安全区留白；背景树纹保持静止，避免菜单局部刷新时跳动。
- 小按钮有44像素触摸容错范围；点击视觉区域优先，邻近容错区域取最近按钮，避免抢占相邻操作。
- 菜单和游戏操作有按下反馈；移出、取消触摸和切后台会清除反馈。菜单滑动不能误点另一按钮，连续点击不同操作不受同按钮防重复限制。
- 探索中的“离开”改为“暂停”。暂停保留世界、位置、朝向和时间；继续回到原地，返回场景列表会明确提示离开本局，收藏仍保留。
- 收藏提供“全部 / 待鉴别 / 已鉴别”筛选，分别记住页码。鉴别后待鉴别列表变短时，只在原页已不存在的情况下退到最后一页。
- 场景预览图可直接进入场景；场景、收藏、菌物名录和寻找笔记采用同一分页样式。
- 鉴别照片可以直接点击切换，同时显示当前张数。鉴别和详情照片完整适配显示，不裁去菌柄或边缘。
- 图片失败显示“图片暂不可用”；长反馈支持换行。空收藏筛选有明确下一步入口。
- 收藏、详情和鉴别线索增加字号；界面统一使用“照片”和“已采集”等与实际功能一致的词语。

## 验证范围

- `npm test`：216项通过，包括触摸取消、点击容错、筛选页码、窄屏/安全区、照片失败与完整显示、长反馈换行。
- `npm run check`：包括游戏模块及预览、运行验证、UI检查页的内嵌模块脚本。
- `scripts/voxel-smoke.html`：真实WebGL与触摸处理验证。覆盖12个场景、41种模型、采集/鉴别/结算、动物与猛兽、跳跃、后台切换、资源释放，以及本轮新增的筛选、照片切换、暂停恢复和按下反馈。
- `scripts/ui-review.html`：独立测试数据，不读写玩家存档。320×568、375×812、430×932、390×844四种尺寸，22个主要页面状态；另用浏览器实际字体度量检查41种菌物的线索、答题、冷却、详情共164种排版状态，均无文字越界、文字重叠、按钮与文字重叠或截断报告。
- 自动化还覆盖320×568、顶部安全区78像素的极端组合。

验证在Node与浏览器预览环境完成。本轮未进行微信真机性能测试，浏览器检查不等于所有机型上的触感和性能保证。

## 后续维护

主要菜单颜色集中在 `js/ui/theme.js`。新增页面可加入UI检查页；新增菌物会自动纳入全部菌物文字检查。照片加载与实际手感仍需结合微信真机复核。
