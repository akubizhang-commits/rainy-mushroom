# 生态采集与收藏鉴别

## 当前平衡参数

| 参数 | 实现值 | 设计目的 |
| --- | --- | --- |
| 每局目标 / 地图数量 | 8 / 10，每个目标计1朵 | 额外25%，避免小样本整数取整失真 |
| 动物觅食宽限 | 搜索页累计30秒 | 给玩家时间熟悉场景和操作 |
| 进食耗时 / 进食后休息 | 3.5秒 / 16秒 | 看到提示后仍能抢先采摘，避免连续瞬间清空 |
| 动物每局消费上限 | 合计2朵 | 等于额外供应量，保证剩余资源可达标 |
| 模式 | 180秒竞采 / 不限时采集 | 原90秒调整为180秒以适应步行探索 |
| 鉴别错误冷却 | 首次45秒，连续错误最多2分钟 | 抑制盲猜，不累加到更长等待 |
| 冷却范围 | 单个物种 | 其他收藏、照片线索、所有采集场景保持可用 |

25%的余量适合作为起始参数，不是已验证的最优值。若动物无限制抢食，只有20%–30%的额外菌物可能很快耗尽，因此本版限制总消费。它降低资源竞争造成的挫败，同时仍会改变玩家的寻找路线。以后应结合首次完成率、动物实际吃掉数量、单局时长再调整，不能只看停留时间。

已按后续确认的优化方案缩短到45秒／120秒，并加入错误答案对比。等待期间继续允许观察、探索和鉴别其他种类；不设广告跳过。

## 生境与动物

| 生境 | 场景特征 | 动物配置 |
| --- | --- | --- |
| 暖湿针阔混交林 | 松针、松树与少量阔叶树、根际和腐殖层 | 野猪抢菌，鹿漫游 |
| 高寒草甸 | 更明显的缓坡、碎石、矮草和小花，无乔木 | 两只牦牛，漫游吃草 |
| 红松白桦混交林 | 白桦斑纹、红松、混合针叶落叶层 | 鹿漫游，松鼠抢菌 |
| 林缘湿草地 | 开放草地、小花与边缘树群 | 鹿漫游，野猪抢菌 |
| 冷湿针阔混交林 | 密林、针阔混生、厚苔与枯木 | 松鼠和野猪，共享2朵消费上限 |
| 冷湿河谷 | 下切溪槽、连续水面、亮色水纹、河岸石和高草 | 狍类外观鹿模型漫游，松鼠抢菌 |
| 落叶阔叶林 | 栎类树冠、暖色落叶层和起伏坡地 | 野猪抢菌，鹿漫游 |
| 山脚林缘 | 林草交界、稀疏树木和腐殖土 | 鹿漫游，野猪抢菌 |

动物使用原创棱面几何，包含躯体、口鼻、四肢、角或尾巴。移动时腿部摆动；进食时躯体俯动。觅食采用半米导航网格，选择附近10米内、可通过地面路径接近的菌物；不处理爬树摘菌。被玩家提前采走或预算已满时取消动物目标。

牦牛的草食设计核对了 Animal Diversity Web 的 Bos grunniens 条目中 Habitat、Food Habits 两节；页面记载高山草甸等栖息环境，以低矮草本为主要食物。该条目为2003年更新的教育资料，不用于当前种群或保护状态判断。参考地址：`https://animaldiversity.org/accounts/Bos_grunniens/`。各场景动物组合与食性行为是游戏化简化，不宣称每种动物现实中会食用地图里的每种菌物。

## 采集和存档

- `ForagingState` 管理当前玩法；旧 `ExplorationState` 保留作为历史原型基础和兼容层。
- 采集不再检查毒性或仅观察标记。采集、动物消费共用可用状态，不能重复计数，也不能同时消费同一目标。
- 8朵时自动结算；失败局已采集收藏仍保留。超时不批量删除未被动物实际吃掉的目标。
- 收藏鉴别不依赖当前关卡。旧存档中的已鉴定状态保留；新冷却字段随收藏记录保存。
- 冷却用本机绝对时间戳，正常重启保留、离线期间继续计时。当前没有服务端可信时间校验，调整设备时钟可影响冷却；本地原型不宣称防作弊。

## 验证

Node测试覆盖八个场景十处目标的步行可达与射线可选性、各类菌物采集、抢食宽限和预算、重复消费、暂停、超时、自动完成、存档迁移、45/120秒冷却和跨物种不受限。浏览器 `/scripts/voxel-smoke.html` 另验证实际WebGL渲染、直接点击采集、动物绘制、收藏学习、冷却禁用和结果页。尚未用手机真机测定帧率和操作体验。

## 猛兽遭遇规则

每局实际采集时间达到 60 秒后，按场景出现一只狼、老虎或熊。暖湿混交林、河谷、落叶阔叶林使用熊；高寒草甸、湿草地与山脚林缘使用狼；寒温带混交林使用老虎。这是游戏场景配置，不是当地野生动物分布清单。

猛兽从距玩家至少 8 米的可通行位置出现，沿可通行路径追踪玩家。HUD 始终显示倒计时或危险状态，入场警报持续 8 秒。接触距离 0.85 米内且中间无地形阻隔时立即判负；已采集收藏保留，不计成功或发成功奖励。仅生态挑战模式适用，悠闲模式无致命猛兽，离开场景和切后台暂停计时，重新开局重置猛兽。猛兽不占用蘑菇余量。

后续体验规则以 [探索体验优化](expedition-experience.md) 为准：悠闲动物最多吃1朵，挑战最多2朵；挑战50秒足迹预警，60秒猛兽入场，依靠视线而非全知追踪。
