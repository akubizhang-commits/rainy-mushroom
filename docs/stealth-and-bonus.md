# 蹲下观察、动物反应与达标后继续探索

本轮实现上一轮建议中优先的三项玩法，沿用原有场景、物种池和收藏存档。

## 移动和观察

- 右下角“蹲下／站起”切换姿态；浏览器键盘也可按C。
- 站立视高1.58，蹲下视高0.78，平滑过渡。低视角可用于观察草丛、树根及倒木周围；不通过姿态按钮直接揭示菌物。
- 默认步行速度2.65，蹲行1.05，快跑4，单位为游戏世界单位／秒。摇杆幅度仍影响实际速度。
- 摇杆推到外圈（幅度大于0.88）请求快跑；浏览器按住Shift配合WASD也可快跑。蹲下时快跑请求无效。
- 碰撞与坡度检查继续生效。动物判断所用速度来自玩家实际位移，被树木挡住时不会因按住快跑而产生虚假的移动速度。

## 动物反应

普通动物每250毫秒检查一次附近玩家。静止或蹲行的避让距离为1.1；实际速度超过1.5时为2.8，超过3时为5。需要双方之间有无遮挡视线。

受惊后动物中止原有嗅闻或进食，寻找远离玩家的可达路径；不会瞬移。如果无路可走则暂留原处。牦牛避让速度1.1，其他普通动物2.2；约4.5秒后恢复漫游，觅食有短暂恢复间隔。

食菌动物找到目标后先嗅闻1.8秒，再沿路径走向菌物。附近可见时展示提示，玩家可保持距离跟随。未改变原有30秒觅食起点及每局吃菌数量上限。动物吃掉或玩家采集目标，都会取消对应觅食动作。

猛兽视距：蹲行为6，普通移动10，实际速度超过3时14。朝向、地形遮挡、最后位置搜索和6秒脱险规则仍然生效；蹲下不会免疫近距离触碰。这里是游戏可读性参数，不作为现实动物行为或接近野生动物的指导。

## 达标后的探索

1. 采满8朵仍立即保存本局成功并显示结算。
2. “继续探索 · 成果已保存”返回原场景，保留位置、朝向、姿态、动物状态、已采集／被吃掉的目标和观察委托。
3. 之后的采集计入额外收获，不再每采一朵自动弹出结算。即使林中没有剩余菌物，也可继续完成路线观察。
4. 左上角“结算”随时结束。进入其他生境或离开到主导航也会整理当前额外探索结果。
5. 额外探索遇到猛兽或时间耗尽时结束，但本局仍为成功，基础与额外收藏全部保留。结算注明结束原因。

挑战模式不补充时间，阅读结算／手记时暂停；悠闲模式继续不限时。一局只可从首次达标结算进入一次额外探索，结束后不能再次续局。不重复增加场次、通关数，也不再次触发成功插屏广告。

基础成功和每次采集会保存到收藏存档。与现有探索一致，进行中的场景不跨应用重启恢复；关闭应用不会撤销已保存收藏，但不会保存一份可继续移动的地图现场。
