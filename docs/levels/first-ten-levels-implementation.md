## 新机制与美术
承重叶根据人物／石头载荷下沉，携带站立者，卸重后逐渐恢复。漂浮树皮能从岸边推入水，携带人物随水流前进，载荷影响浮高，在岸边停止；错失树皮可从暂停菜单重置本段。
苔地、湿岸、根际共用现有图集并调整配色和植被组合。树根踏点改为程序绘制露根轮廓。保留巨大背景树干、统一旅人、现有推物和攀爬动画。图集仍76帧／2048²。
