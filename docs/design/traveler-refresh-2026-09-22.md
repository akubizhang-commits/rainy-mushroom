# 冒险者整体造型更新

2026-09-22 · 试玩版美术迭代。以本次造型覆盖此前长雨衣、斜挎包和爬行背包方案。

目标是轻盈、精神、可爱，同时保留森林冒险者的辨识度。蓝色兜帽、暗色脸部和橙色围巾继续作为三个主要色块；减少细碎缝线、绑带与扣件，优先保证游戏实际尺寸下的清晰轮廓。

- 服装：收至胯部的短款雨衣，露出裤腿；前中拉链、两条口袋线和一枚叶片胸章。所有姿态移除外凸挎包，不在臀后添加装饰轮廓。
- 头部：提亮蓝色布面，缩减边缘碎线；扩大暖白眼睛与眼神光，抬起眉形；叶片帽针朝上，短围巾随动作保留。
- 鞋裤：深蓝裤装与轻便短靴，浅色薄鞋底，避免沉重长靴和裙摆遮腿。
- 爬行：继续手掌和膝盖支撑，上身离地；短外套覆盖肩胯，衣摆收在腰胯处，不拖尾。四肢交替步态与移动速度保持原规则。
- 全动作统一：站立、跑步、跳跃、落地、推物、攀爬、携带、滑翔、俯身、爬行、休息与倒下使用一致配色和服装。背面攀爬同步短雨衣；受伤/倒下闭眼，不沿用笑脸。
