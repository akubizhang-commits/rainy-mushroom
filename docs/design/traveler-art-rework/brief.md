# 冒险者角色与动作返工简报

2026-09-23；状态：当前造型被用户否定，未产出新美术样张，未替换运行资源。

## 问题与失效的验收

用户截图显示：兜帽呈硬质蛋壳/潜水头盔，脸部开口像单眼面罩；大头接窄肩细直躯干；手臂和裤腿管状，双腿僵直站立，鞋底扁长。多处对称轮廓与机械曲线削弱了林间冒险者的布料感和生命感。

静态截图能证明上述造型问题，不能单独证明完整步态节奏。上一轮图集检查还显示，行走和跳跃虽改侧向，其他动作仍在正面、侧面、背面间切换。游戏测试通过只说明被测功能成立，不构成美术验收。

已尝试：用现有矢量零件重绘侧向头身、用参数化关节点重排步态、再补跳跃九阶段。解决了部分朝向问题，但用户仍明确否定造型及动作。停止把局部朝向修复当作角色整体质量完成；不再以增加帧数、改速度或更多程序曲线作为唯一美术方案。

## 新方向：穿软布雨衣的林间小旅人

以下为待样张验证的设计假设，不是已获用户认可的新造型。

- 保留蓝色衣服、暖橙围巾与森林环境的色彩联系；不再把现有几何轮廓当成必须保留的角色身份。
- 兜帽有布料折叠、帽沿、接缝和受重力下垂的后部，去掉封闭头盔式圆环。脸有额头、鼻尖或脸颊的侧面结构，不用巨大圆眼舷窗代替整个脸。
- 先以约3.5头身探索比例：头不再压住肩部；肩、胸、腰、胯能读出来。该比例是草案，必须在游戏实际尺寸检查，不机械套数值。
- 外套有厚度与下摆，袖口连接手腕；手、膝和靴子有体积。靴子短而结实，腿不能画成两根直管。
- 站姿有轻微重心偏移，双膝放松，前后脚错开；侧向移动仍必须朝前，不能退回正面横走。
- 风格为温润、简洁的绘本游戏角色：少量大色块与柔和阴影服务轮廓，避免高亮塑料壳、细碎装饰、写实皮肤纹理和硬线堆砌。

## 样张先验证什么

先完成一张统一造型的三视图：正面、侧前方三分之四、侧面。再用同一造型画四张关键姿势：自然站立、迈步承重、跳跃收腿、手膝爬行。不要一开始批量生成全部动作。

关键姿势必须检查：

1. 缩到当前游戏角色大小，依然看得清脸朝向、手脚和轮廓；放到现有森林背景里不突兀。
2. 去掉颜色看剪影，站立、行走、跳跃和爬行能辨认。
3. 步态体现触地→承重→离地→摆腿；承重脚不滑，手臂与对侧腿配合。
4. 起跳能看出蹬地，落地有脚、膝、髋的承重先后；动作过渡不阻塞按键。
5. 爬行保持用户已要求的上身离地、手膝支撑，头身视角一致。
6. 每张图的头身比例、衣服结构、左右手和近远肢体关系一致。不能站姿漂亮，动起来换人。

造型和关键姿势达到可评审质量后，再制作行走循环和跳落序列，提供原速与慢放实景，最后扩展推物、攀爬、滑翔、开箱和受伤。游戏逻辑测试与人工美术验收分别记录。

## 可交给美术或图像工具的首张样图任务

原创横版森林冒险游戏角色设定。小旅人，柔软蓝色布料兜帽短雨衣、暖橙围巾、深色裤子、短而有体积的旅行靴。头、肩、胯比例协调，约3.5头身作为起始探索；兜帽帽沿自然，脸有温和的五官与侧面结构。亲切、灵巧、能在林间攀爬，温润绘本质感，克制细节、清楚轮廓。画同一角色的正面、侧前方三分之四与严格侧面站姿，完整身体，统一尺寸和基线，浅色干净背景。不要圆形硬壳头盔、单眼面罩、塑料高光、管状四肢、扁长鞋、机械对称站姿、武器、文字或品牌。现有截图仅作为缺陷说明，不能照抄其轮廓。

后续每张游戏精灵动作表独立一个动作家族，稳定身份、全身入格、不跨格；采用与角色颜色不冲突的纯绿抠图底，再清理边缘并确定脚底和手部挂点。
