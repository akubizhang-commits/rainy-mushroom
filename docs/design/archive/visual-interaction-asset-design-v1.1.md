## 1. 总体美术方向

### 1.1 第一眼与长期观感

**微小旅人走在雨后森林里：环境庞大而真实可触，冒险者酷、轻巧、略可爱；阳光让空间有呼吸，动作让机关有重量。**

采用手绘块面与克制纹理的2D侧视画面。轮廓略有不规则，接触关系准确；不做写实摄影贴图、亮塑料玩具或统一描黑边的贴纸拼贴。可爱主要来自人物头身比例、眼神和受力反应，不给石头和所有植物画脸。

画面注意顺序：当前动作／危险 → 旅人与落点 → 目标方向 → 环境细节。同一视口最多三个主焦点；阳光、花色、眼睛、UI不能各自争最亮的位置。

必须延续：昆虫尺度、统一C旅人、混合直伸／斜生／低垂蕨丛、完整扎根植物、普通落地安全。禁止微缩整树、悬浮叶板、直立断枝桥、碰撞白线、空中出口光圈、无关花纹覆盖脚部，以及每只生物整图匀速滑动。

### 1.2 色彩与明度

以下HEX是母色板，不是对每个像素锁色；环境色、阴影、材质变化从母色偏移。同一场景保持约五种主要色族，暖色只占小面积。

| 色板ID | 候选色 | 主要用途 | 限制 |
|---|---|---|---|
| COL-01 深林青 | `#203E39` | 最远树干、空间暗部 | 不用作所有实体的统一边线 |
| COL-02 雾青 | `#66877A` | 远景散射、背景层间区分 | 不整屏覆盖玩法层造成灰蒙 |
| COL-03 苔绿 | `#7E9255` | 苔土上沿、叶背与根部过渡 | 路线不只靠此颜色区分 |
| COL-04 叶面绿 | `#A0AF69` | 近处承重叶、透光叶缘 | 只点亮朝光面，不全株荧光 |
| COL-05 湿土褐 | `#655845` | 土截面、湿根、洞壁 | 不把根／岩／土全部涂同一褐色 |
| COL-06 朽木灰褐 | `#948B6C` | 树内木纹、浮树皮干边 | 高光有方向、纹理不抢角色 |
| COL-07 旅人蓝灰 | `#648E9A` | 兜帽、肩、袖口主色 | 阴影仍保留冷蓝身份 |

| COL-09 围巾琥珀 | `#C58D50` | 围巾、少量个人装备 | 环境不用大块同色围住角色 |
| COL-10 日光乳金 | `#F1DDA6` | 日斑、光孔、微小轮廓反射 | 不作为死亡／治疗的唯一标识 |
| COL-11 界面米白 | `#F4EFDF` | 图标和短文本 | 置于稳定底板，不能直接压在亮光斑上 |
| COL-12 受伤赭红 | `#AF6558` | 心形失去一格、瞬时受伤提示 | 不做满屏高频红闪；与形状变化同用 |

以灰度检查视觉层级：玩法物体上表面、身体与背景应有明确明暗差；远景纹理低于玩法实体。候选UI文字对底色对比目标4.5:1，图形目标3:1，作为本项目验收目标测量；装饰画面不机械套同一数字。背景复杂时加局部底板，不给整个场景描白边。

### 1.3 比例、边缘与材质字典

角色可见高度V约56逻辑单位、碰撞高度H=44；立绘按V画，落点／碰撞按H测。大图源文件可提高采样密度，但游戏中的实际比例不随源图分辨率变化。角色不能因换动作忽大忽小。

| 材质 | 大形／边缘 | 中尺度细节 | 小尺度与反射 | 接触反馈 |
|---|---|---|---|---|
| 湿苔土 | 顶部软团簇，下面土壁有断层 | 根须、少量石粒嵌入 | 湿边略深，偶有小亮点 | 靴底轻压，少量湿尘，不冒烟 |
| 干／湿树皮 | 纵向纤维、不齐边；厚薄有区别 | 裂缝沿生长方向 | 湿面较暗，干边较浅；不镜面 | 脚步轻硬，擦过有纤维屑 |
| 石头 | 不规则但有稳定底面 | 2–4个大切面，局部苔 | 零散湿亮点，不每条边发白 | 推动摩擦、受阻停止、底部接触影 |
| 叶与柔茎 | 连续主脉、叶柄确实连根 | 叶脉沿结构分叉 | 光照处薄透、背面偏暗；不玻璃化 | 受力弯曲与碰撞同步，恢复有阻尼感 |
| 虫壳 | 圆拱主体、分节缝清晰 | 壳瓣／背中线 | 稍亮的宽反光，少量锐点 | 站立处阴影跟随壳面，不压扁坚硬壳 |
| 软体 | 轮廓连续，分节不画成珠串 | 腹足／裙边／伸缩褶 | 柔和湿润反射 | 腹足接地、局部形变，承重面不能跳变 |
| 布料 | 兜帽与短披风有厚度 | 折线由肩、肘、腰牵引 | 大面哑光，薄边少量反光 | 布料落后躯干，不先于身体飞走 |
| 水 | 水线有薄厚变化 | 波纹、岸线与流向 | 局部碎光，非规则横线铺满 | 入水波纹与落点同心，树皮下沿有湿线 |

*系数指该层随镜头移动的相对比例，是设计起点。垂直攀爬不直接套用横向系数使背景树干接缝断开；可按zone统一布局。

实体物体不能因为“只是装饰”就突然可穿透。背景小菌／草与可承重同类的区别要来自远近层、尺度、对比与位置；背景不能恰好长在玩家会试跳的落点上。宽叶边的细羽片无承载能力，但主轴必须连续可读。

### 2.2 稳定的视觉语言

- 能站：有体积、连续上表面、下方有支撑，脚下接触影稳定；不依靠白色描边。
- 能抓：连续粗柄／根须与可辨握点，不用梯子刻痕装在所有树干上；靠近才出现手掌上下文。
- 能推：轻石露出完整底边；柔茎根盘不移动，茎身有弯曲余量。重石埋土、宽底，不伪装成同尺寸轻石。
- 有危险：攻击前姿态／节奏＋真正接触部位。颜色仅辅助；翅膀、光束和远景剪影不制造虚假伤害面。
- 入口／庇护／CP／休息点／终点分别成形，不能全部用发光圆圈表达，细则见6、9。

### 3.1 统一旅人外形

![现有旅人动作参考，身份锚点而非本轮新稿](../../../design/forest-polish/traveler-actions.png)

参考图仅用于既有人物身份和绘制风格；其部分动作参考不等于最新状态全貌。完整源见`scripts/microforest/traveler.py`，当前背面攀爬和倒下应继续使用已迭代的原源。

| 部位 | 设计要求 | 禁止与验收 |
|---|---|---|
| 总剪影 | 头宽、肩窄、短披风收腰、靴底明确；候选头高约0.38–0.43V | 不在未确认下换角色比例；缩到实际尺寸仍有“头—身—腿”三段 |
| 兜帽 | 不对称软布折面；帽沿包住脸，侧后有缝合线 | 帽沿不是金属圆环，不能层层同心圆像头盔 |
| 脸与眼 | 保留深蓝脸、小乳金眼；关注点随目标微移，眨眼克制 | 不新增复杂鼻嘴／性别特征；眼光不投射手电筒式照明 |
| 躯干 | 肩线接袖、腰带与小挎包交代装备重量，披风两角有厚度 | 不用碎饰件填满胸腹，不遮推物手掌 |
| 手 | 正面握、侧面推、背面抓、撑地四种可读手型；拇指与掌跟明确 | 小尺寸允许省略指缝，不能省成无方向圆球；手与物体不隔空 |
| 腿与靴 | 胯、膝、踝方向连贯，鞋底平面清楚；两腿前后明度不同 | 不能细直腿配悬浮大鞋；承重脚不漂移 |
| 围巾 | 小块琥珀色，末端随惯性滞后 | 大幅翻转不穿头／手，不当攻击飘带 |
| 挎包／携物 | 包在固定身体侧；蒲公英有握柄与携带连接，换姿势不穿披风 | 不能把人物图片镜像后文字、背带归属任意变化；方向稿先定左右策略 |

方向包：左／右侧向与三分之四正面共用身份；背向攀爬单独稿，不用正面眼睛覆盖背帽。先用一张角色转面与手型表验收，再生产动作。光照仅改变受光强度，不把蓝灰旅人染成一团绿色或使帽内脸消失。

### 3.2 十二类动作的具体交付

帧数是动作源建议，不是未经测量的图集新增承诺；已有可用帧优先复用。动画由真实状态／位移驱动；“播放完动画才让玩家动”不是默认策略。

| 动作ID | 关键姿态与节奏 | 接触／事件 | 最小交付与失败标准 |
|---|---|---|---|
| AN-01 待机 | 重心落在双脚，微呼吸，偶尔观察 | 无位移就不播踏步；持蒲公英有独立手姿 | 静态主姿＋轻动层；无高频眨眼、无整身上下浮动 |
| AN-02 移动 | 支撑、蹬地、腾脚、落脚八相；上身略前倾 | 以移动距离驱动落脚；阻挡时转撑住，不原地滑步 | 现有8步态；左右与坡面都看脚底 |
| AN-03 跳／落地 | 蹬腿、收膝、顶点展开、下落找地、缓冲 | 起跳输入即生效；落地缓冲不锁移动 | 至少起跳／空中／下落／落地四关键姿；不能落地还持续下落姿 |
| AN-04 攀爬 | 后背朝镜头，左右手交替抓、对侧脚换点 | 握点停住时手固定，暂停输入停相位；上下有重心差异 | 现有8相基础，补停挂／顶端转站；没有前脸穿到背面 |
| AN-05 推物／压茎 | 肩前送、肘略弯、掌跟抵住，腿小步蹬 | 轻石按位移走；重石推不动时双脚撑地；压茎手位置随弯曲接触 | 移动推／受阻撑／压茎三支；不以走路帧替代所有推物 |
| AN-06 携带／滑翔 | 身侧握柄→举起展开→双臂承担下坠感→收回 | 获取即看见，展开与升力同步；过期手回空手，绒毛先散后消失 | 取用、携带、展开、收起／消散；不无伞滑翔、不“持物贴在脸前” |
| AN-07 藏身 | 屈膝收肩，帽靠近根缝，眼神仍可辨 | 进入后按前后壳层遮挡；离开立即正常移动 | 一组收低／隐藏／退出；不是透明化穿实心根 |
| AN-08 生命耗尽 | 屈膝、单手撑、侧倒、停留、淡出 | 保留现有六帧约0.9秒；只在HP耗尽使用 | 靴底／撑手落点统一；无一闪传送，不重复播放计数 |
| AN-09 孢子弹射 | 冠面压缩时下沉、伸腿释放、上冲收身 | 约0.14秒蓄力按PRD；喷发和实际弹射同帧 | 可复用跳姿加受力稿；普通踩冠不触发全套 |
| AN-10 水／沟耗尽 | 落水下沉遮挡、无底沟失足淡出 | HP归零使用，独立于尚存活救回；镜头外也有可理解反馈 | 基础失足／下沉＋遮挡为HP接入必需；额外中间帧P1后补，任何档位不能空中横躺 |
| AN-11 轻伤 | 肩／手护住受击侧，脚找回重心 | 硬直候选0.15秒，保护1秒；保护用低强度轮廓变化，不持续闪烁 | 两方向受伤与恢复姿；不可误播死亡或把危险体变透明可穿 |
| AN-12 救回 | 失足／落水短反馈→遮挡过渡→安全面站稳 | 候选0.6秒；HP保留剩余值，回CP，非满血复活 | 原地伤害不调用；与耗尽回R有不同提示和音效 |

过渡清单：跑→停、跑→推、推→受阻、攀爬→停挂→顶端站、跳→展开→到期、载具→跳离、受伤→落水、死亡→暂停→恢复。脚底世界锚点、手部接触点、道具握点分开记录，不靠随意移动整张贴图抵消错误。

### 4.1 首批六类互动生物

### 6.2 DEC-01装饰套件与对象纪律

装饰套件拆为`DEC-01-moss/grass/bell/cap/root/fiddlehead`：苔团、草、铃形草花、地面小菌、细根须、幼卷芽，各两个轮廓起点。新增`DEC-01-debris`为碎叶纤维／小土粒的共享小件，不另立机关。

中远景花草采用较少叶脉、偏暗偏灰；近景只作边角框景，不围成遮挡整条路线的墙。高饱和花朵不放在隐藏的无用角落诱导误判奖励。装饰露水只在局部叶缘出现，不让每个像素都闪光。

素材重复控制：连续三屏不以相同株形、相同朝向、相同高度重复；用根部错位、叶簇大小、前后层和合理裁切变化。不能把同一实体任意压扁伸长以凑平台宽度；需要宽度变体就提交匹配轮廓数据。

| SCN-06 地下／光井 | 安静、湿润、发现出口 | 土壁细粒、根须顶棚、光井向上引导 | 暗处仍有最低可读底光；光井小范围暖光，滴水短尾而非长混响 |

编号映射：PRD的ENV-M／ENV-W／ENV-F分别采用SCN-01／02／03；空间类型Z-TREE、Z-CANOPY、Z-BURROW分别采用SCN-04／05／06。SCN与LGT是呈现配方，不是模拟分区ID。连续地表／枝冠同一zone，按GDD 5.5和LDD 2.6；切SCN／镜头段只改变构图、光域／声场，不冻结支撑，不重建碰撞。

终局林缘是SCN-01/05的柔暖变体，不新建一套画风：扩大可见天空空隙、减少前景遮挡、降低操作压力，用空间打开表达“到家”，不靠突然把整屏染金。

### 7.2 斑驳阳光：从头顶叶隙落下来

目标画面：地表由叶隙切出不规则暖亮块，保留苔与土纹理，脚下接触影始终稳定。首轮基础档使用静态世界日斑，旅人跨光域整体柔和变亮；标准增强可试少量空气束／叶影，再试“先帽顶、后肩手”的局部接收，后者不是基础档必验条件。

**光源方向。** 每个zone记录一个主方向`sunDirection`，候选从画面左上向右下、偏离竖直20–35°。同一树体内的相邻区域保持方向一致；若换到树的另一侧，过渡区先展示空间变化。日斑、投影、帽沿反光、树皮高光都服从这个方向，不每个素材自带不同光源。

**亮斑形状。** 交付三张不规则叶隙遮罩：宽叶切口、细碎羽叶、稀疏枝影。每张有大空隙与细碎过渡，不用噪声平均撒点。候选一屏5–9个可辨主斑簇，大簇宽0.8–2.5V，小碎边少量点到为止。单簇既有较清楚的内边也有柔过渡，不能整块高斯模糊到没有形。

**明暗与色温感。** 阴影保留冷青环境色，受光偏乳金；以“色彩关系”表现暖冷，不把真实色温数值当作美术完成标准。候选受光比当地未受光面亮约15–25%，混合层不透明度先从0.12–0.22试起；最终以渲染效果验收，数值不等于物理照度。衣物在日斑中仍是蓝灰，暖光不漂白脸和眼睛。

**移动与相位。** 日斑固定在世界物体上，镜头移动时通过它，不随屏幕漂移。无风时可几乎静止；微风候选3–6秒完成一次轻摆，位置摆幅不超过0.15V、亮度小幅变化。环境闲风与机关风分开：上升风停歇时，头顶叶仍可轻动，但入口草絮必须按机关相位停上涌。不得让玩家把环境阴影摆动误当机关启动信号。

**接收与遮挡。** 各档静态地、枝、叶的日斑均锚定世界；动态石／角色基础档按世界位置采样整体明暗，过渡0.15–0.3秒，不瞬间漂白。标准增强的局部接收蒙版才按身体／石面覆盖区域着色。倒下、攀爬和移动物仍采样同一光域；接触影随支撑更新。启用空气束时必须被前景树干／洞顶裁切，无束基础档不必为通过验收增加束体。

**剪影保护。** 路线下方若本来很暗，不用强亮斑制造假的小平台。亮斑不能恰好遮掉菌盖边、甲虫头部预兆、绒毛轮廓。角色眼部只保留很弱的身份亮点，不用永远发光的人物描边抵消布光问题。UI与字幕不参与日斑混合。

**首个镜头脚本，12秒。** 0–3秒旅人从阴影走到固定苔台，整体受光平缓变化；3–6秒停下，观察固定世界日斑与接触影；6–9秒推石穿过日斑，手与石接触清楚；9–12秒跳／抓蕨柄背面上攀，相机上移后光向不变。基础档允许叶影静止、无束／微尘。标准对照使用同一路径，可加入慢叶影、束体及帽顶到肩手局部受光，并单独记录是否启用这些增强。录像标注档位与开关，不新增强制过场。

### 7.3 空气、雾和雨后湿度

可见光束是稀疏点睛，每个普通视口先限制1–3束；主体宽0.3–1.2V，上方窄、向下略散、到暗处渐隐。束内微粒候选8–18颗低速漂移，大小不规则但低于道具拾取粒子；不整屏飘雪。空气微粒无碰撞、不产生物品反馈音。

雾分远景底雾与少量水岸近雾。远雾帮助分开树干，不覆盖玩法层；近雾只能在低处局部漂动，透明度候选0.04–0.10，不能遮沟边、地面或角色靴底。地下用层次明暗表达深度，不强行填同款森林雾。

雨后不意味着一直下雨。默认无全屏雨丝；叶缘偶有装饰滴落，频率低、落点不在危险教学附近。机关大滴有聚滴和冲刷全过程，普通装饰滴只造成细小水纹，形状／音量明确不同。后续天气系统未进入本批，不能因需要湿润氛围引入持续降雨机制。

### 7.5 角色、物体和阴影的细则

- 靴底接触影宽随承重变化，跳起后缩弱并留在地面投影位置；不把接触黑块贴在人物图片底部随人飞。
- 虫壳较亮的宽反光随转向平滑变化；足下小影比全体大椭圆更重要。透明翼只接少量光，不投大块不透明黑影。
- 叶薄透限于朝光薄面与边缘，主脉保持体积；主承重叶不能透明到背景穿过去像不存在。
- 石头的日斑遮罩随世界位置采样，湿高光面积小；推入根后阴影时不仍顶着固定白边。
- 木壳／土壁必须遮住后方亮区；庇护缝只露足够识别的眼部与轮廓，不让角色身体发光穿墙。
- 旋转屏幕只改变构图，不旋转太阳方向或重置叶影相位。暂停冻结表现时钟；跨zone按原规则冻结未激活空间。

### 7.6 低成本实现与降级次序

本批先用2D局部蒙版、软渐变和独立光影贴片；不预设需要法线贴图、逐像素动态阴影、全屏模糊或真实体积光。静态洞壁可预画受光基底，但动态物、角色、风预兆与移动阴影不能烘进背景。

| 档位 | 保留 | 可降级 | 绝不能降级掉 |
|---|---|---|---|
| 基础档（S1必验） | 环境底色、世界静态日斑、角色／移动物柔和整体受光、接触影、可读孔口 | 无束／微尘，叶影静止，水碎光可静态 | 危险预兆、握点、落点、HP／绒毛状态 |
| 标准档（启用后验收） | 基础＋1–2束柔光、局部慢叶影；可选局部身体／石面接收蒙版 | 局部接收可关闭退回整体明暗；减少粒子／反射 | 图层遮挡、光向、机制与基础档一致 |
| 高档候选（后补） | 已验证标准项＋更多细小反射 | 仍不增加密集闪光，不定义独占玩法提示 | 与基础档相同的可达性与信息 |

**颜色叠加顺序：** 角色底色／固有体积阴影→世界环境受光（基础整体或标准局部）→隐藏状态的可读暗化→轻伤短局部色差→死亡淡出alpha。HUD不参与。各状态提供参数，由一处表现合成写最终颜色／透明度，不能多个系统每帧互相覆盖`Sprite.color`。固有明暗用于表达帽／衣厚度，强方向高光独立层；左右镜像不翻转世界太阳，背包身体侧归属按方向稿检查。暗化和受伤均保留帽内脸／手脚可读，死亡alpha最高优先且暂停冻结。

先测画面透明叠加和移动稳定性，再决定贴片分辨率；不承诺一定维持单图集或60fps。用现有平台矩阵实测帧时。任何性能降级不得让同一危险在低档看不见、在高档才有预兆。

### 8.2 镜头与前景

2026-09-21试玩修订：以角色躯干为构图中心，中心区按顶栏下沿与触控区上沿计算；横向也以角色为中心，仅在关卡边界限制滚动。地面、攀爬、枝冠均连续平滑跟随，不再等角色贴近顶栏才上移。快速弹射限制跟随滞后，头部始终留在顶栏下方；下落跟随承接方向。镜头可以采用负向世界偏移，减少低处场景无意义的地下留白，不改变实体世界坐标。

受伤不默认震屏；孢子弹射可用很轻的局部受力感，首批先验收无震动版本。减少运动选项若加入，关闭镜头脉冲／强叶影摆动仍保留危险预兆。进入洞口的0.35秒过渡与救回0.6秒、耗尽0.9秒分别由状态拥有，不能三个淡出叠在一起。

近景草遇到关键接触可局部淡化而非整层消失；需要可读性的首选是摆放避让，不能依赖到处“见人就透明”补救。前景图像不能遮盖HP／按钮或拿来当跨场景加载遮羞布。

## 10. 声音设计

### 10.1 声音方向

声音是微观尺度的“触感”，不是给每个模型配一段持续噪声。近处靴底、叶柄受力、甲壳足声细而明确，远处森林是柔和空间底；不把小昆虫做成巨兽吼叫、把日光做成魔法嗡鸣。

所有关键操作静音仍能理解。光斑、阴影、空气微粒默认无声，声音只来自对应物体／环境事件。生物声在未核验种类前可采用克制的动作拟音，不宣称录到了该物种的真实叫声。

### 10.4 混音与播放合同

建立Master、UI、关键反馈、普通动作、生物、环境、音乐七组。以受伤／危险预兆为参考电平，普通脚步先低4–8dB，环境低10–16dB，音乐低12–18dB试混；这是内部相对起点，不是手机最终响度承诺。输出留余量，不削波；不用一味提高高频让小喇叭刺耳。

候选并发：关键反馈3、普通动作4、生物动作3、环境2、音乐1、UI 2；多蚂蚁聚合成队列声，不逐足创建声音。关键预兆使环境／音乐短暂降低约3–6dB，结束后0.25–0.5秒恢复，不改变危险时钟。环境切换同时占用两条环境声交叉淡化；若以后音乐需双轨过渡，单独测量预算，首批音乐可用单轨淡出后淡入。

**抢占与去重：** 关键组不被普通／生物组抢占。组内满额先替换最低priority；同priority危险预兆优先预计接触时间更早者，其次距离更近者、稳定ID，其他同优先级替换最早的尾音。若3条都是危险预兆，新预兆仅在排序更高时替换排序末位，否则不播放并记录voice-limit；此极端组合不得用作首次教学，所有危险仍有独立视觉预兆。暂停前已消费单次事件不因恢复、重绘、加载回调再消费；被限流的历史单次事件不补播。测试至少覆盖两种预兆＋受伤同时可闻，奖励／背景先让位。

预兆续播读取剩余预兆时长，裁切音频包络，不重新发出起音或延长机制窗口。真正离开模拟zone则停止其预兆声；回访若仍处于冻结的预兆中，仅续剩余段。临近但不可见的不同SCN在同一zone内按距离／遮挡衰减，不因为镜头越界停掉脚下物体声音。

循环音要有起／停淡化，推石松手、风衰减、生物停步都停对声音。暂停冻结／淡出循环，恢复依表中resumePolicy；切模拟zone仅活动区音可闻，冻结区不继续响。音频加载失败仍可玩，视觉预兆不能缺；未解锁时等待实际用户操作，不以无声错误阻塞游戏，也不解锁后集中补播过期事件。

声像随世界对象相对玩家位置变化，但左右幅度克制；手机扬声器、单声道与耳机都验收。不使用“听哪边才知道唯一落点”的谜题。首批提供总音量／音效／音乐与静音设置；保存范围和入口沿用平台配置，不顺手加账号系统。

## 12. 素材交付、命名与技术美术合同

### 12.1 每项资产的最小交付包

1. `assetId / variant / status`：沿用PRD稳定ID；状态为已有待打磨、本批新增待样板、背景可选、后续候选。一个ID可有多个子件，不因拆图重命名玩法对象。
2. 可编辑源：现有矢量与参数化植物沿用可编辑源；位图保留分层母稿。正文示意图不是最终sprite，不能直接贴进游戏充数。
3. 导出图／图层：主体、前后肢、前沿遮挡、道具、光影蒙版、必要特效分别交付；不把HUD、光束或可移动机关烘进背景。
4. 元数据：逻辑尺寸、源尺寸、pivot、脚底／握点、支持面ID、实体与危险区域、图层、包围盒、材质、动画事件、关联声音、版本与依赖。
5. 预览：实际比例单体、明暗背景接触、关键状态序列、复杂场景录像；制作镜像方向时同样检查手脚与背包归属。
6. 许可：来源、作者、使用授权、改动记录；AI辅助素材记录生成与编辑过程，不混入不明外部图、字体或音效。

候选命名：`CHAR-01_move_right_v01`、`BIO-04_roll_v01`、`ENV-07_portal-front_v01`、`LGT-02_leaf-mask-wide_v01`、`SND-03_stem-return_02`。这是交付命名建议，接入时保持现有资源索引兼容，不无故迁移已用atlas键。

### 12.2 图像、动画、地图与音频

| 类型 | 交付要求 | 接入前验证 |
|---|---|---|
| 角色／生物 | 按动作家族独立源表；建议2×4或紧凑网格，足够边距；装配最终atlas再统一排布 | 尺寸／锚点／无裁切／无跨格／动作身份一致；不强制所有动作同一宽度导致倒下裁掉 |
| 植物／实体 | 正常、受力、恢复形态与轮廓同源；参数化件附有效参数范围 | 可见冠缘可站，弯曲不脱根，恢复不穿人，贴图外沿不假承载 |
| 场景 | 底景、玩法连接件、前沿遮挡、装饰、光影与触发元数据分开 | 相机上下左右接缝，入口配对，实体碰撞不来自背景一张图猜测 |
| 透明／抠图 | 正式交付干净alpha；生成素材若需底色，先判断绿色主体冲突，植被优先用不混色的洋红底 | 深／浅底各验收毛边，不把纯绿／洋红反射残留到主体上 |

| 音效 | 无损母文件，明确采样率／位深／声道／响度记录，切好有效段与循环点；现有管线确认后再定压缩导出 | 无削波、无直流偏移、循环不爆点／明显接缝；平台加载与首操作播放通过 |
| 字体／UI | 图标统一网格、有效触区另记；中文覆盖与许可、回退 | 长文本、缺字、锁定／失败／选中状态，不把触区等同图标像素边界 |

纹理是否分包、光影是否单独图集、源图尺寸和音频格式由样板测量决定。当前2048²图集不意味着新增资源都能无损塞入；不为了维持一个数字把旅人或关键生物缩糊。

## 13. 验收与生产顺序

### 13.2 最小代表样板与顺序

1. **光与角色样板S1：** 苔地、巨根、旅人、石、蕨柄；基础世界日斑、整体受光与接触影完成12秒必验录屏。标准增强另作对照，未启用空气束或局部身体受光不阻塞基础样板。
2. **三个空间样板：** 树内侧孔、枝冠上下镜头、地下采光井；每个先一组连接件，验证可读性与原尺度，不铺满十关。
3. **六类生物与关键物接触样板：** 优先修现有甲虫／蜗牛，再做队列、蜷球、毛虫承载、蜻蜓预兆；与HP／R／空间切换夹具同步验证。
4. **声音闭环：** 脚步、推物、叶受力、风与绒毛、受伤／救回／耗尽、进洞／休息；混音稳定后再加环境细节和主题音乐。
5. **量产扩展：** 样板审美、动作、触控和性能通过后，按第11节逐关组合；优先少量高质量轮廓，不把候选库全部制作。

本轮完成标准是设计覆盖、ID／规则一致和示意可读。未完成事项仍包括最终素材、录屏样板、声音文件、真机验证与用户审美确认；不能把本文或示意图当作游戏已完成的画面升级。
