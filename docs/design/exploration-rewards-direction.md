# 森林冒险 · 探索奖励方案

版本：v0.3，2026-09-21。阶段：方向已获开发授权，基础奖励循环已接入，尚未通过玩家验证。按可玩性设计，不用工作量作为删减理由。

本文件已纳入本轮十关重设计的候选基线；配套[游戏PRD](../prd/game-design-prd.md)、[关卡PRD](../prd/level-design-prd.md)、[视觉交互规范](visual-interaction-asset-design.md)现已同步至GDD/LDD v1.4、素材规范v1.2。候选参数仍待样板验证，不能把本文当作已上线功能。旧v0.2已归档，旧评审保留其日期背景。评审与问题闭环见[评审记录](exploration-rewards-review.md)。

## 1. 玩家体验与方向选择

看见秘密线索 → 判断绕路、操作和生命风险 → 运用环境抵达 → 收到明确的发现 → 试用新工具／记录收藏 → 在营地选择准备 → 继续探索。

即时目标是“那个地方能不能到、藏着什么”；单关目标是“发现一处秘密并完成旅程”；长期目标是“形成自己的工具组合与森林见闻”。奖励服务观察、操作、自由路线和微观森林氛围。

选择“探索发现＋有限工具选择＋收藏表达”。单纯金币分数缺少用途；不断加跳高/血量容易冲掉关卡约束；高难随机装备会让挑战结果受运气支配，均不作为主方向。原型乐趣仍待测试，不以有商店或有收藏等同可玩性提升。

### 方向原则

- 主路不需要购买、全收集或某件支线独占装备；所有基础能力随流程保证。
- 奖励既有可用工具，也有空间发现、短路、生物帮助、见闻和外观。收藏不只是一段文字，应有可见纪念或营地展示。
- 一般绕路兑现资源，独特挑战兑现独特发现；不把所有难度折算为更多金币。
- 永久探索收获保留，失败仍重做当前挑战段；不引入买命、体力等待或击杀刷钱。
- 暂不引入付费、广告、随机抽取、多货币、装备品质与数值强化。

## 2. 奖励体系

| 类别 | 价值与来源 | 获取后去向 | 重复规则 |
|---|---|---|---|
| 通用金币（暂名） | 主路首次完成、少量可见拾取、探索支路 | 钱包，营地购买永久工具和表达物 | 每个来源首次一次，重开不刷新 |
| 工具发现 | 宝藏直接给完整试用体验，认识新解法 | 首件教学工具免费永久获得；其他工具可当地借用试用，购买后永久拥有 | 不做“先找配方再交钱才能第一次用”的双重门槛 |
| 本段工具次数 | 已拥有工具带来的有限行动 | 当前尝试内使用，详见第4节 | 新挑战尝试补满；小CP、跨区、手动恢复不补 |
| 环境补给 | 治疗芽、蒲公英等 | 直接作用于当前状态 | 沿用游戏PRD，不进入永久金币体系 |
| 独特纪念与外观 | 树冠操作挑战、秘密、生物观察 | 收藏册/外观库/营地，直接授予 | 不掉重复物，不转换成无限金币 |
| 世界回报 | 开短路、找到景观、获得生物接送 | 本段空间状态或永久发现记录 | 空间变化随原物体恢复范围重置，发现记录保留 |

所有工具、收藏和表达物不占有容量上限的消耗背包；永久记录按稳定ID去重。金币使用非负整数；第6节样例最多300，不能截断正常收益，异常存档走恢复流程而非静默清零。

金币不是现实尺寸的大圆币，先视作旅人使用的小铜片；名称、美术待确认。收藏以落羽、蜕壳、见闻记录等叙事包装示意，不默认捕杀生物。重要宝藏固定内容，符号预告工具/纪念/补给类别；不采用概率空奖。高难宝藏不会只给临时效果。

## 4. 次数、世界部署与恢复

| 事件 | 永久资产 | 次数与部署 |
|---|---|---|
| 普通受伤／CP救回 | 保留 | 不补次数；恢复事件清除部署 |
| 手动重置本段物体 | 保留 | 清除扣绳部署和叶杯水，不返次数；不能刷资源 |
| 生命耗尽／重新开始 | 保留 | 新挑战，次数补满；世界和CP一并回退 |
| 新苔窝首次休息 | 保留 | 满血、记录点、清部署、补次数，可准备换装 |
| 回到旧苔窝 | 保留 | 不补、不开放中途换装 |
| 切区 | 保留 | 部署和观察效果清除，不返次数；回来无旧的魔法桥或积水 |
| 暂停／商城／前后台暂停 | 保留 | 冻结模拟，不耗持续时间 |
| 退出续玩 | 保留 | 从最近记录苔窝续玩，剩余生命和次数保留，部署不跨读档 |

扣绳只有在现场拆回时恢复可用次数。免费观察工具获得不自动覆盖装备，不补主工具次数。购买不自动装备，确认显示花费和购买后余额；已拥有不得重复扣款。

## 5. 宝藏、挑战终点与安全返程

- 宝藏在世界中事先存在：树洞藏匣、果壳小包、枝间旅人旧包、天然收藏点。解谜可打开遮挡或容器，不突然在空台面凭空生成木箱。
- 奖励落点是固定安全面，容器不遮落脚边缘、手掌目标不与藤蔓/洞口重叠。金币只放在已验证的可达轨迹，不以金币引导必死跳跃。
- “抵达型挑战”在安全落点开箱完成，旁边可开返程短路；“往返/运送型挑战”从开始就说明终点，抵达中途不发最终奖励。
- 已领取的永久奖励死亡不扣回；死亡前未完成交互不领取。开箱/发奖/死亡同帧见第9节。
- 开短路本身也是奖励。返程可以是落回安全地面、滑行出口或可逆洞口，不强迫原路重复难跳。
- 接受安全落地回主路，不为防“拿完就跳下”惩罚用户既定自由落地规则。若玩家普遍故意死亡返程，先改善出口。
- 不要求收集齐全部物品才开下一关。章节纪念以主题发现组合解锁，多条可替代发现路径；极难独占物提供专属表达，不决定结局资格。

## 6. 金币收支与营地选择

只设一种通用货币，无兑换链、利息、交易或过期。来源为固定首次奖励；购买为固定价格永久所有权，没有修理费、重复补充费。工具与表达物并列，显示用途、限制和已有状态；购买需明确确认，余额不足不引导充值。重复确认不重复扣款。

### 可计算的十关纸面样例（不是最终平衡表）

| 项目 | 样例数值 | 含义 |
|---|---|---|
| 每关主路首次完成 | 20，共200 | 不探索也能获得工具选择；老存档按已完成关卡补发一次 |
| 每关探索货币目标 | 10，共100 | 同关两条可替代支路共享这笔奖励，走任一条即可；各路独特纪念仍分别获得 |
| 观察灯 | 免费 | 不进入下方商店价格 |
| 三种可购工具 | 40、60、80，共180 | 顺序对应花蜜、扣绳、露水；目录在进入L03/L06/L07准备时开放，分别紧接虫道／柔茎／叶杯用途 |
| 三种商店表达物 | 20、40、60，共120 | 与挑战专属外观分开，无能力差异 |
| 全部来源/全部商品 | 300/300 | 有限章节，不靠无限刷取维持收支 |

上表的10金币是每关全部探索货币预算，沿途拾取也计入这10，不额外叠加。为保持双路线共享目标，样例先用整笔10金币首次奖励；若后续拆成多处拾取，必须重做去重与替代路线账目。

零探索者通十关有200，可买齐全部工具余20；探索者更早有选择且更容易买表达物。只买表达物者仍可通关。进入L03前主路已有40，可买40的花蜜诱饵包或留存；L03完成后主路累计60，扣同工具余20；完全探索此时90，扣同工具余50。不是每关都立刻开店，L01/L02先展示获得与保存，L03进入前再引入一次消费选择。

买齐所有商品需要完成十个可替代探索目标，这是可选完成度，不作为通关/结局要求；若试玩显示像清单作业，降低总价或减少收集要求。两个支路共享货币目标，避免为了经济收益被迫两路全走，界面必须标明“本关探索金币已获得”。

重复通关不给同一金币。重玩价值来自漏掉的独特发现、另一条路线与自选技巧挑战，不靠刷最短关。已有来源仍保持空箱/已记录的世界反馈，不让玩家以为漏发。未消费余额永久保留；未来章节独立核算新增收入和商品，不能无限加金币却没有用途。满收集后停止展示不存在的金币目标，不设周期性消耗税。

若某种工具成为必买最优解，先改工具适用范围与路线题目，不靠涨价隐藏失衡。购买后永久拥有，误选不会锁死主路；查看和试用须先于消费。

## 7. 十关配置与唯一路线来源

逐关区域、奖励位置、返回路径及失败用例统一由[关卡PRD v1.4](../prd/level-design-prd.md)§3负责，不在奖励文档再维护一份不同路线表。[拓扑数据](../production/first-ten/redesign-topology.json)记录每关main/explore和两类独特grant。

L01安全小秘密；L02外侧弹射与树内跨水，X或F免费灯同grant；L03首次商城选择花蜜、虫道与风；L04双向桥/地下滴水；L05诱饵与推石挡虫；L06扣绳柔茎与高低载荷路线；L07露水叶杯与岸湾漂流；L08分段高枝/侧风；L09队列和根间交通；L10多路同归、普通结局无收藏门槛。

每关X观察和Y技巧共享一笔10探索金币，X/Y各有独特纪念。低操作替代也要观察/绕行，不能无条件发币；L10普通结局不锁任何工具。所有点位需真实尺寸灰盒验证，表述“有替代”不等于已实现公平。

## 8. 视觉、声音与操作提案

玩家先看落脚和危险，其次看宝藏线索，最后才看获得提示。工具/纪念/金币分别用轮廓图标和简短名区分，不靠品质色光柱。湿木匣、旧布包、果壳使用统一森林材质，不添加人类尺度金属宝箱；远处只给克制的反光/布条标识。

开箱需在固定面新按一次手掌，短翻找动作；有危险接近时允许移动取消，奖励提交点在动作结束。拿到后小幅物件展示与短音效，角色仍可见，危险音优先；详细说明在暂停页，不在空中强制弹窗。金币按用户要求与心形生命一起显示在顶部；不增加背包格和品质列表。

候选工具操作：准备时选一个；在安全站立且有合法目标时，现有手掌旁情境显示一个工具触区，图标＋剩余次数。空中/攀爬/受伤/推物时不出现，工具因此设计为地面准备型。键盘候选F，不抢E；触区隐藏后不得留下幽灵点击。进入工具目标与手掌目标是不同动作，不能靠长按/短按隐式切换导致误开箱或误用道具。

这是已同步到GDD11与素材规范9.4的候选增量，不是现有运行UI已适配。额外触区优先级低于攀爬与基础操作；在568×320和实际安全区下需证明不遮路线，不以缩小按钮解决。若无法容纳，改为现有暂停准备入口发动持续准备效果并重测节奏，不能悄悄增加整排按钮。

新玩家只经历“看到—取得—安全试用”再进入收藏/营地；首关不展示空目录或锁住的大量物品。无声、色觉差异情况下也能辨识状态；不提供商店风险或留存的虚构分数。

## 9. 发奖与保存合同（供后续开发）

把钱、所有权、发现ID、领取ID和交易ID作为永久层；当前次数/工具效果/试用范围属于尝试层；实体位置、门和短路属于区/恢复组层。UI只表现结果，不能由动画结束回调重复加钱。

- 每个rewardId/grantId稳定，不能用数组位置或中文名。跨路线共享金币使用同一个grantId；同一箱内金币和收藏作为一笔发奖提交。
- 一个完整永久快照同时记录新余额/所有权与领取标记；加载只能恢复旧完整状态或新完整状态，禁止只加钱没记已领。保留可恢复版本；存储失败显示未保存/重试，不演成已永久获得后丢失。
- 同帧死亡/救回优先，未提交的开箱取消；此前已成功提交则保留。奖励不能使0HP立即存活，展示不冻结危险来提供开箱无敌。
- 容器开启中第二次输入忽略；领奖重试复用同一交易身份，只有首次成功播放获得反馈。
- 购买将扣款和所有权一起提交；取消/不足额/已有/重复输入都不扣款。满拥有不买重复件；商品下架保留已有所有权。
- 仅全新用户初始化钱包0。旧资产v1迁移到v2，原始JSON写archive-v1；保留余额、领取记录和所有权，观察绒球返40、鞋套返80、旧诱饵补差20，一次提交防重复；损坏主备档保留原文并禁购，未来版本只读。300不是钱包上限。老存档按已完成关卡补发主路20金币及L02教学灯，迁移使用正常领取同一个forest-NN:main及tool:lamp:first grant并记已领，不能另发一个迁移ID再让关末重复领；不赠送从未探索过的收藏与支线金币。
- 旧奖励调整不以改ID重新发全部奖励；修正或补偿另用稳定补偿ID。离线不依赖服务器时间计算工具效果。
- 本地进度不是跨设备账户；此次不承诺卸载恢复、云同步、排行榜防篡改。候选奖励层未来应沿用ForestProgress保存入口，需编码阶段确认拆分，不提前实现新服务。

## 10. 验证与准入

最小完整样板：沿用L03主题制作主路＋观察支路＋树冠挑战，先借用教学灯与一件候选工具；回营地用前两关主路已有40金币做一次选择。三路均验证无道具可达、领取、正常返程、受伤/死亡、重进及已领取提示。之后再逐关铺设，并非按成本砍方向。

| 要验证的问题 | 方法与候选判据 | 当前状态 |
|---|---|---|
| 奖励是否值得绕路 | 6–8名目标玩家初测，记录看见线索后进入/放弃的原因；不把进入率直接当留存 | UNVERIFIED |
| 用途是否清楚 | 首次发现后至少多数人能独立说明去哪用/如何补充；若超过2人反复误解，先改反馈 | UNVERIFIED |
| 是否强迫探索 | 零购买/零支线完整通主路；询问跳过支路是否担心无法通关 | UNVERIFIED |
| 是否破坏操作 | 对照工具与零工具同段；若一种工具普遍跳过核心观察/时机，改作用范围 | UNVERIFIED |
| 失败是否既可再试又有代价 | 用完次数后落水、重置、换区不补；新attempt补满且机关同步回退 | UNVERIFIED |
