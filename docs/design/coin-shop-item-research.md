# 森林冒险 · 金币兑换道具调研与设计建议

版本：v0.1 · 2026-09-22  
阶段：三工具方向已获用户批准，进入可玩原型。第2节保留调整前基线；当前生效合同见[探索奖励方向](exploration-rewards-direction.md)与[实施记录](coin-shop-v2-implementation.md)。扩展道具池仍为候选，不代表本轮全部实现。

## 1. 推荐方向

**金币优先购买“可反复带出门的探索工具”，让玩家改变环境、安排通过方式；临时补给来自关卡，独特发现来自探索，外观用于长期表达。**

目标不是让商城看起来商品很多，而是让玩家想到：“刚才那段路，如果带另一件工具，我可以换个办法。”

建议形成四层：

| 层次 | 玩家得到什么 | 获得方式 | 失败会失去什么 |
|---|---|---|---|
| 基础能力和观察信息 | 跳跃、推物、攀爬、辨认危险与风向 | 流程教学免费保证 | 不失去 |
| 探索工具 | 引导生物、固定柔茎、搬运露水等新选择 | 金币一次购买，永久拥有；购买前可安全试用 | 当前挑战已用次数和局部部署 |
| 环境补给 | 蒲公英绒毛、治疗芽等短时帮助 | 关内固定、可预期的自然补给 | 按关卡恢复合同处理 |
| 外观与见闻 | 旅人装束、装备外形、营地陈列、发现记录 | 通用装饰可购买；挑战纪念直接探索取得 | 不失去 |

暂不建议出售复活、加血上限、永久跳高、无限飞行、自动过关、金币倍率或随机装备。理由是它们容易让目前以观察、物理互动、时机为核心的关卡变成“有没有买增强”的检验。**不是其他游戏不能用，而是我们的核心体验不需要这条成长线。**

本轮采用系统策划、经济策划、视觉／交互和测试视角；下文“竞品事实”“项目现状”“设计建议”分别列明。调研以公开资料为依据，不声称本轮完整游玩了竞品，也不声称已有玩家数据证明方案有效。

| 示踪绒球 | 40金币，L03开放，观风6秒 |

“永久拥有”不等于“效果永久生效”。当前规则以挑战尝试、休息点和恢复事件管理次数，不能在商品描述中只写“永久”而省略使用限制。

### 2.2 当前商品的设计问题

1. **用途有描述，购买冲动仍弱。** 示踪绒球主要提供信息，鞋套只减少某种漂移；如果关卡本来就能清楚看风，两者容易显得价值很小。此为设计判断，需玩家验证。
2. **有价值的工具缺少足够适用场景。** 诱饵当前仅针对甲虫；联合审查记录新版十关甲虫配置少，不能因为商品存在就宣称“生物互动丰富”。
3. **鞋套还存在实现与场景不一致。** 已记录站立高度与侧风作用范围不匹配。必须修正并证明产生作用后，再讨论其价格是否合理。
4. **三条围巾主要是颜色选择。** 可保留，但不足以承担长期表达；后续应增加轮廓、材质和装备细节不同的外观。
5. **固定有限收入不适合无限买药。** 当前金币不会靠反复通关再生。若失败反复消耗付费药水，操作较弱的玩家更可能越来越缺钱。
6. **扩充商品不能沿用300余额硬上限。** 当前解析器拒绝大于300的余额，已有旧档被重置风险记录。300只是十关新档基础收入样例，绝不是合法钱包上限；该缺陷现纳入本轮v2迁移修复，验证见实施记录。

### 2.3 文档冲突的处理

旧奖励方向中“钱包仅短显”和“营地”旧描述不覆盖用户后续明确要求：**顶部金币、道具商城、图示货架，不恢复文字菜单。**

用户已批准三工具及权益迁移方向，本轮同步奖励方向、GDD、LDD和视觉规范。其他扩展条目保留候选身份，不凭本文直接覆盖当前玩法。

## 3. 同类型／相邻类型游戏调研

选择四款：两款横向平台跳跃作品，一款以关卡和小镇准备为结构的3D平台游戏，一款以自然空间和自由探索为核心的作品。比较的是**奖励如何转化为玩法选择**，不比较销量或商业成功。

### 3.1 《超级马力欧兄弟 惊奇》：购买能改变玩法的徽章

**核实事实：** Nintendo官方将徽章分为追加动作、被动辅助和高手能力，动作示例包括跳后缓降；社区商店条目记录花花金币可购买部分徽章、惊奇种子、1-Up和立牌，徽章与种子为一次性购买项目。[S1][S2]

**对我们的启发：**

- 工具应让玩家马上感受到“我能做一件不同的事”，而不只是小幅提升数值。
- 多个用途不同的选择可以共存，不必排成低级到高级。
- 辅助与高手玩法可以分层，没必要把所有奖励都设计为更容易。

**不照搬：** 买命、随机立牌、击杀赚币；也不直接销售改变基础跳跃包络的能力。我们的桥、风、蘑菇、藤蔓仍应是主要的空间解法。

**来源边界：** S1用于徽章分类；S2用于商店细节。S2同时包含2026版本内容，本文只使用上述原有通用机制，不引用新增角色或全目录数量。

### 3.2 《耀西的手工世界》：金币变成看得见的收藏

**核实事实：** 官方介绍说明金币可投入胶囊机获得随机手工服装；服装同时作为保护装甲，稀有服装能承受更多次攻击。关卡也分别设置心、金币、红币、花朵与小狗等目标。[S3]

**对我们的启发：**

- 商城商品可以延续世界材质：布、果壳、细枝、纤维，而不是通用RPG装备框。
- 装备应能直接在角色或营地上看见，购买后有可感知的变化。
- 普通货币、探索纪念和即时恢复物可以承担不同目的。

**不照搬：** 随机抽取，以及把喜欢的外观与防御高低捆绑。我们推荐外观无属性，避免“为了更耐打只能穿不喜欢的衣服”。

### 3.3 《星之卡比 探索发现》：出发准备与临时帮助

**核实事实：** 官方小镇介绍将救出的瓦豆鲁迪与设施增长联系起来。WiKirby的道具店条目记录可用星形金币购买生命提升、攻击提升和速度提升；攻击／速度效果有持续时间，暂停时计时停止。[S4][S5]

**对我们的启发：**

- 商城可以属于旅程中的安全准备空间，购买与操作挑战分开。
- 商品必须说明“带走的是什么、何时发动、多久结束”，不是只显示一个小图标。
- 暂停和看说明不消耗效果时间。

**不照搬：** 叠加增伤、加速和额外生命条。卡比的战斗结构可以容纳这些数值；我们的精确跳跃和三心生命结构未证明适合它们。

**来源边界：** 具体道具效果来自社区维护资料，不冒称官方平衡设计意图；无需把竞品价格或持续秒数移植到本项目。

### 3.4 《A Short Hike》：探索发现与购买共同推进旅程

**核实事实：** 开发者商店介绍强调自主选路、攀爬飞行、隐藏宝藏和帮助其他旅人。社区羽毛指南记录游客中心出售两片金羽毛，每片40金币；其他羽毛也来自宝箱、活动和角色任务。[S6][S7]

**对我们的启发：**

- 购买不必是成长的唯一来源，发现和帮助生物也能直接给有意义的收获。
- 奖励应连接“现在想去的地方”，避免只在商城列表里自我循环。
- 营地陈列和见闻奖励可以让玩家记得“在哪儿、怎么得到”，不只是“买齐了几件”。

**不照搬：** 用持续增加的移动能力统一覆盖所有障碍。我们的地形主路仍需在基础能力下成立；工具提供替代办法，不能以金币支付为隐藏门票。

### 3.5 结论对照

以下为本项目的分析，不是竞品开发者原话：

| 可借鉴模式 | 适配程度 | 我们的取舍 |
|---|---|---|
| 一次购买、改变行动选择 | 高 | 商城主轴，购买工具使用权 |
| 探索直接给独特奖励 | 高 | 高处与洞穴提供纪念、试用和世界发现 |
| 收藏与世界材质一致 | 高 | 图示货架、角色可见装备、营地陈列 |
| 临时帮助 | 中 | 优先关内补给；不做常态付费买药循环 |
| 永久数值叠加 | 低 | 暂不销售血量、速度、跳高 |
| 随机商品、付费买命 | 不采用 | 与当前有限经济及探索体验不匹配 |

## 4. 三种商城路线及推荐

| 路线 | 乐趣来源 | 主要代价 | 结论 |
|---|---|---|---|
| A：消耗品商店 | 每次出发选择药水、护盾、绒毛 | 失败造成金币压力；囤积舍不得用；有限收入可能耗尽 | 不作为主轴 |
| B：永久工具商店＋有限段内使用＋外观 | 观察环境、准备工具、形成不同解法 | 关卡必须真的容纳替代解法；每件工具需要适用规则 | **推荐** |
| C：永久能力升级树 | 明显成长、解锁更远空间 | 买错路线与回头补能力的门槛；更容易破坏现有跳跃和物理 | 仅未来专项研究 |

推荐B不是因为开发简单。它对物理一致性、关卡备选路径、反馈和存档要求都更高；选择它是因为更贴近“昆虫大小的冒险者利用森林生活”的乐趣。

## 5. 推荐候选道具

所有名称、价格和时长均为**原创候选、尚未实现、未经玩家测试**。微观材质是美术方向；诱导、承重和排水是可读的游戏规则，不宣称所有真实物种都具备相同行为。

### 5.1 先验证的三件主工具

| 工具 | 玩家主动做什么 | 一个清楚的场景 | 限制与失败边界 | 候选价格 |
|---|---|---|---|---:|
| 花蜜诱饵包 | 在附近合法落点放一小滴诱饵，引导会响应的生物 | 甲虫守着窄道：引向左侧后从右侧过；或引到承重叶上改变叶片位置 | 无穿墙气味；不让生物飞过坑；攻击接触仍危险；不能通吃全部昆虫 | 40 |
| 纤维扣绳 | 把已经压弯的柔茎末端固定到近处可承力点 | 把弹性植物维持在弯曲状态，腾出双手搬石头或安排另一条路线 | 必须先靠推动压弯；绳不凭空生成平台；锚点距离、承力和绳长有限 | 60 |
| 露水囊 | 把有限露水倒进可盛水物体，改变载荷 | 给杯状叶增加重量，使它降低、露出可跳的另一侧；随后排水回升 | 不是浇一下立即长树；不对普通岩石或平叶生效；过载不能无提示 | 80 |

三者分别改变**生物位置、柔茎状态、载荷分配**。即使只有一个携带槽，玩家也在选办法，而不是比较哪个加成百分比更高。

#### A. 花蜜诱饵包

- 外形：腰侧种壳小包，投放后是可见小滴，不用大范围魔法圈。
- 候选两次／新挑战尝试，每次吸引窗口6秒；这是相对现有4秒的实验提案。
- 在安全站位预览近处落点，用朝向选择前后；目标落点不得隔着实体或超出可读画面。
- 响应流程为察觉、转向、前往、停留、恢复。非响应物种给“不受这种气味吸引”，不扣次数。
- 投放前路径必须可达；有效投放后因玩家移动石头堵路，不退款，生物在障碍前停住。
- 跳过、借石阻挡等零工具方法仍可用。不能把气味做成隐身或无敌。
- 多生物会聚可能产生新风险；首个教学只放一个对象，后续才组合。

#### B. 纤维扣绳

- 外形：角色携带的纤维短绳与种壳扣；部署后有受拉方向、收紧动作和锚点。
- 候选每尝试一套，最多一个固定结构；持续到主动拆除、承力失效或恢复事件，不给它套一个无来由的倒计时。
- 靠近已弯曲柔茎末端及另一承力点时可使用。锚点包括稳固粗根、带可扣结构的岩缝等，按材质和结构统一支持，而不是只认发光按钮。
- 可手动拆除回收；同一物理物件在手上或世界里只能有一份。部署中不能远程再复制一套。
- 站在桥上不自动恢复，继续遵守用户既定要求；扣绳额外价值是**玩家离开后也能维持弯曲**。
- 危险负载先拉紧、震动示警；不可无预兆弹回。玩家正站在结构上时的失效保护需灰盒专项验证。
- 适用价值必须体现在搬运、返程或多步解法；若只是重复当前“站上去不恢复”，则删去该场景。

#### C. 露水囊

- 外形：透明薄膜包裹露珠，倒水时看见容积变化，不画成人类尺度水桶。
- 候选在出发／新休息点从露水罐装入两份，每份一次倒水。补给来源要出现在场景中；不是角色无中生有。
- 首轮不允许沿途无限取水，以免破坏段内资源决策；后续若做天然取水点，要单独重算载荷谜题的补充规则。
- 只对明确可盛水并有排水反馈的叶杯、种壳容器有效；先预览加入后的重量区间。
- 不用“浇水瞬间长高”解释平台变化。候选叶杯缓慢排水，约8秒后恢复主要载荷状态，实际时长按操作窗口验证。
- 无工具玩家可推小石头到承重叶，或走另一条跳跃路线；露水改变准备过程，不删掉核心挑战。
- 承重平台状态跨小CP保留还是回退，必须与整个恢复组一致，不能只回填囊中水量而保留已加的重量。

### 5.2 扩展候选库：先留方向，不全塞进前十关

| 候选 | 新互动／价值 | 判断与约束 |
|---|---|---|
| 苔纤抓地套 | 在湿滑表面站稳，选择释放后滑行或起跳 | 改造现有鞋套；只在“站稳还是滑行”真正有选择时保留，不能永远开启且无代价 |
| 树皮撑杆 | 站在漂浮树皮上触及水底／岸石后撑动，短暂改变位置 | 需要接触支点；不隔空划水、不给无限冲刺；有水路样板再上架 |
| 轻种壳 | 把一个轻物放到叶片上、滚进狭缝作小配重 | 需质量、体积、滚动、漂浮统一规则；若与露水囊没有独特选择就合并 |
| 遮光小篷 | 在安全位置形成局部阴影，影响明确怕光的虚构或选定物种 | 先建立光线与该物种关系；不假定所有昆虫怕光，不当万能隐身 |
| 旅途标记套 | 在地图上记下玩家自己发现的洞口、岔路和风井 | 基础标记免费；金币只买标记外观和营地展示，不收费卖基本导航 |
| 种壳背包外观 | 可见轮廓和材质变化 | 纯装饰，不扩大携带槽或负重 |
| 披肩／雨帽／扣饰 | 塑造“酷而有点可爱”的旅人形象 | 不遮脸、手脚和推物轮廓；不区分男女，不带能力加成 |
| 营地见闻陈列 | 展示已获得的落羽、蜕壳、旅途照片式插画 | 可买展架风格；见闻内容必须亲自发现，不能直接买通手记 |

这些是后续内容池，不是首批商品数量目标。没有至少两处不同有效场景的功能道具，不应因美术已经画好就上架。

### 5.3 现有道具如何处理

| 当前内容 | 推荐处理 | 原因 |
|---|---|---|
| 观察灯 | 保留免费，候选并入免费观察套件 | 不应占用稀缺槽位后才看得清主路；只增强细部见闻 |
| 示踪绒球 | 基础风向观察免费；可作为套件中的观测动作 | 风预兆始终可见，不能收费修补场景可读性 |
| 气味诱饵 | 扩展为上面的花蜜诱饵包 | 从短暂干扰变成空间安排，仍保留适用物种边界 |
| 抓地鞋套 | 暂不列入新三件首测商品，留在扩展库 | 先修实际无效风险，再判断是否值得占一个选择 |
| 蒲公英 | 保留关内限时获取，不出售永久版本 | 保住风与滑翔的关卡节奏，也尊重已确定的有效期方向 |
| 治疗芽 | 保留关内补给，不以金币反复补命 | 三心与恢复点应承担风险管理，商城不能把失败变成经济处罚 |

## 6. 携带、使用和恢复的共同规则

建议第一轮沿用一个主工具槽，不因商品增多直接做三个技能按钮。免费观察套件、外观不计入主工具槽；手掌、跳跃和上下左右仍承担基础操作。

| 事件 | 候选规则 |
|---|---|
| 查看／试用 | 商城免费演示；固定试验场可重置，不产币、不改变关卡进度 |
| 购买 | 一次扣金币，永久获得；购买与装备是两个明确动作 |
| 出发或首次确认新休息点 | 选择工具并初始化该工具物资；扣绳1套，诱饵2次，露水2份 |
| 普通小CP | 不回血、不补工具、不换装 |
| 无合法目标／取消预览 | 不扣次数，不生成物体 |
| 成功部署 | 物资扣除与世界效果同时成立；不能只播放动画 |
| 受伤／安全落地 | 不额外补物资，不撤销已购所有权 |
| 落水救回／手动恢复 | 不退已消耗物资；按恢复组还原部署和机关，不能保留收益又退物资 |
| 死亡／明确重试挑战段 | 机关、CP与工具一起重置为新尝试；金币和永久发现保留 |
| 区域切换 | 不补物资；首次样板部署不跨区携带；离区拆除局部效果且不得留下必走路线死锁 |
| 暂停／看说明／后台 | 冻结效果计时与模拟，不让玩家因阅读损失时效 |
| 退出续玩 | 从合法恢复点恢复挑战进度、剩余物资，不能用退进刷次数 |

扣绳不是消耗药剂：主动在现场拆除可回收同一套实物；触发救回／恢复时若部署物被清除，则本次尝试不返还，避免复位复制。其提示必须与诱饵的“已用掉”区分。

主路和普通结局始终零购买可达。前十关不配置“只有某个付费工具才能打开”的独占箱；工具可以改变方法、降低准备成本、形成不同返程。以后若增加工具专用收藏，必须单独评审免费借用或等价取得方式。

## 7. 金币经济：先保证有选择，再谈更多商品

### 7.1 不改变收入的首轮纸面方案

保持每关20主路＋10共享探索，十关新玩家基础总收入300。推荐三件候选工具40／60／80，共180；装饰保留20／40／60，共120。

| 玩家路径 | 十关收入 | 可以完成的购买计划 |
|---|---:|---|
| 只走主路 | 200 | 三件工具180＋一件20装饰；也可优先装饰 |
| 约一半关卡探索 | 250 | 三件工具＋部分装饰，余钱保留 |
| 每关完成一个探索目标 | 300 | 候选三工具与三装饰全部取得 |
| 零购买 | 余额200–300 | 全部主路与普通结局仍成立 |

这是新目录独立纸面账目，**不与现有三件工具叠加计算**。如果只是往旧商店再加180商品、保持收入300，买齐目标立即失衡；必须明确采用替换目录还是扩展章节，不得含糊地同时承诺。

### 7.2 购买时间示例

下表是假定零探索、按建议开放顺序并优先买工具的玩家；不是实测行为：

| 时点 | 累计主路收入 | 之前消费 | 本次决定 | 决定后余额 |
|---|---:|---:|---|---:|
| 完成L02、进入L03前 | 40 | 0 | 买诱饵40 | 0 |
| 完成L05、进入L06前 | 100 | 40 | 买扣绳60 | 0 |
| 完成L09、进入L10前 | 180 | 100 | 买露水囊80 | 0 |
| 完成L10 | 200 | 180 | 可买20外观或留存 | 20 |

缺点很明确：零探索者最后一件工具获得偏晚。因此候选露水囊在L07就提供免费当地试用，商品也可在L07开放；玩家可以跳过前一件先买它。若初测发现“只玩最后一关才买到”缺乏回报，优先调整开放、价格和取得路径，而不是要求刷钱。

首次购买也不能只按关卡编号判断快慢。地图加长后两关可能已经很久，需测量“开始游戏→首次看见有用商品→买到→真正使用”的时间。当前没有首次玩家时长证据，不给出虚假的金币／分钟结论。

### 7.3 防止有限经济变成焦虑

- 不收使用补充费、修理费、换装费，不让越常失败的人越穷。
- 不要求清空商店才算通关；收藏齐全是自选目标。
- 商品不做每日刷新、限时折扣和涨价倒计时。
- 同一金币来源只领一次；宝箱发奖前展示内容类型，不用随机空箱。
- 余额不足时说明差額和已有未完成来源，不许给已领完奖励的关卡标“去刷金币”。
- 首次购买的误选保护可测试“在首次带入挑战前允许原价撤销”；必须移除所有权且不允许保留已用效果。这是候选，不默认已有退款系统。
- 全目录已拥有时不再推销不存在的消费目标。剩余金币保留，后续章节按新增收入与商品重新核算，不靠无意义消耗清钱包。

### 7.4 旧存档不能承担改版代价

目录若替换，需先单独解决已知资产读取缺陷，然后再做版本化迁移：

1. 保留既有余额、工具、围巾和领取记录；没有可靠恢复证据时不得重建空档覆盖原档。
2. 若示踪／鞋套转免费，可按实际购买记录退原消费；没有价格记录的v1档先按已知固定原价建立明确映射，不猜测未来折扣价格。
3. 诱饵若60降到40，已购买者候选补差20；改名沿用稳定ID，不能作为新商品要求重买。
4. 补差／退款用一次性迁移记录去重，和所有权、余额一起保存。迁移可能使余额超过300，这仍是合法资产。
5. 本文提出的是权益保护要求；没有运行迁移、没有改真实用户钱包。

## 8. 前十关如何让工具有用

这是**未来样板布局建议，不是当前十关已具备的内容清单**。

| 关卡阶段 | 建议的工具体验 | 不购买的通路 | 要观察的乐趣 |
|---|---|---|---|
| L01–L02 | 先体验免费观察和奖励反馈；看见工具使用结果的环境暗示 | 基础动作完成 | 是否理解钱是为准备服务，不是门票 |
| L03 | 单生物安全借用诱饵；首次可买 | 等巡逻空档或跳跃绕过 | 是否主动选择引走方向 |
| L04–L05 | 诱饵与石块阻挡、承重叶分别组合 | 推石、等待、另一条落脚路 | 是否出现两种不同计划，而非只多一次眩晕 |
| L06 | 压弯植物→扣绳固定→搬运物体；安全返程可拆扣 | 站桥压住／另一侧绕行 | 能否看懂固定点和受力，而不是误会魔法桥 |

第一轮不让玩家同时携带三件来串连；应先证明**同一道题可用不同工具解**。若三件工具对应三个唯一钥匙孔，表面自由，实际仍是按图索骥。

## 9. 商城与使用反馈

### 9.1 商城保留货架，商品“看得懂”

整体像林间旅人的小铺，按工具与装扮分栏。点商品后，详情用一段短循环演示解释前后变化，不放整屏长说明。

商品详情固定回答五件事：

1. 这是什么：名称＋清晰轮廓。
2. 能做什么：例如“引走会响应的甲虫，腾出窄道”。
3. 不能做什么：不穿墙、不提供无敌。
4. 买到的是什么：永久工具；每次新挑战可用两次。
5. 花多少钱：价格、现有余额、购买后余额；已有状态不再提供购买。

“试用”“购买”“装备”语义分开。金币在既有顶部钱包显示，补充购买反馈，不再加一条货币HUD。

### 9.2 世界中的反馈优先于文字

| 道具状态 | 角色／物体表现 | UI补充 |
|---|---|---|
| 可使用 | 目标有与材质一致的轻微轮廓提示 | 情境工具图标与剩余次数 |
| 选择目标 | 展示落点、绳端或预计载荷 | 无效原因一句话 |
| 开始 | 真实投放、系扣、倒水动作 | 次数在效果成立时减少 |
| 生效 | 生物转向、纤维拉紧、叶杯下降 | 只显示当前工具状态 |
| 将结束 | 诱饵变小、排水滴落；扣绳看受力而非倒计时 | 临近结束才强调时间 |
| 结束 | 生物恢复、叶杯回升、物资变空 | 不遮人物的短提示 |

不能靠一个光圈代表所有工具，也不能只在角落扣次数而场景没有变化。即使静音、色觉差异或玩家没读介绍，也应能从物体行为理解结果。

触控仍用一个情境工具入口，不为每件工具增加常驻键；工具瞄准期间必须能移动取消，不能覆盖洞口向上进入、攀爬、推物和跳跃。横屏安全区、手指遮挡和中文长名称需后续真机验证，本轮不对未制作界面打可读性分数。

| 视角 | 判定 | 主要问题／结论 |
|---|---|---|
| 游戏策划 | TEST | 三种环境变量有组合潜力；必须做同题多解，避免工具钥匙化 |
| 数值策划 | WARN | 新目录180＋120可与300收入对齐；换购时间偏晚、旧档补差与未来扩品尚需验证 |
| 视觉／交互 | TEST | 三工具轮廓、动作和对象差异清楚；扣绳锚点可读性、倒水容量、触控预览尚无实物证据 |
| 开发／测试 | WARN | 扣绳载荷、局部部署恢复、诱饵路径和旧档迁移都是具体风险；不能以现有测试通过替代 |
| 玩家体验 | UNVERIFIED | “敢用、想买、愿意换方法”目前都是假设，没有真实玩家体验结果 |

本轮没有建议用金币掩盖当前物理、关卡和反馈缺陷；尤其存档与鞋套作用失配属于修复前置条件，不是可以靠商品描述解决的问题。

### 优先验证的三个样板

1. **生物窄道**：零工具跳跃／推石；诱饵改道。记录玩家是否能预判甲虫仍危险、是否有不止一个有效落点。
2. **柔茎与搬运**：零工具通路；扣绳维持路径后搬运。检验绳是否只是装饰、是否重复已有压桥能力。
3. **载荷叶杯**：石块加重／露水加重，两者时间与准备过程不同。检验重量反馈和排水窗口。

每个样板都要覆盖：无目标取消、成功、受伤、死亡、手动恢复、跨区、暂停、续玩、剩余次数、重复部署，以及空钱包主路。

### 玩家测试问题与淘汰条件

建议先邀请6–8名未接触项目的玩家做定性观察；这只能发现理解问题，不能代表留存或市场表现。

- 看完短演示能否说清“做什么／何时用／是否永久拥有”？若两人以上把永久工具误解为永久Buff，先改说明。
- 拿到后是否敢用？若多人担心花掉就要再付钱，先改补充反馈。
- 是否能指出一次工具改变了自己的计划？若只能说“好像容易一点”，重新设计用途。
- 是否存在一种工具在所有样板都明显优于其他选择？若有，收窄适用规则，而不是只涨价。
- 零购买者是否觉得漏探索就无法继续？若有，检查目录预告、主路布局和措辞。
- 首次买到后很久都找不到用途，或一件工具只在一个地方有效：调整关卡后再上架。
- 结束时是否仍想购买下一件？询问具体原因，不用兑换率代替乐趣判断。

验收状态：方向可继续讨论；数值、物理稳定性、UI和玩家乐趣均未验收。

## 11. 需要定方向的少量问题

不需要现在决定所有名字、价格与持续时间。建议只围绕下面三项评审：

| 决策 | 推荐答案 | 影响 |
|---|---|---|
| 金币主要买什么？ | 永久探索工具＋纯外观 | 保留失败后重试的自由，不形成重复药费 |
| 新工具优先改变什么？ | 生物位置、柔茎固定、载荷 | 后续关卡围绕环境互动提供多种解法 |
| 工具会不会成为通关钥匙？ | 前十关不会；普通结局和探索奖励均保留基础解法 | 需要关卡验证，不能只在文档写“可选” |

本文推荐下一步先做这三件工具的**场景演示／纸面规则评审**，确认乐趣后再同步正式设计与实现。商城扩展数量、装备槽增加、能力升级树暂不作为决定方向的前提。
