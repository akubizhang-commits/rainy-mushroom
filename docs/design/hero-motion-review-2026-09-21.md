## 检查结论

原问题不止缺跳跃素材：上升／下落各一姿，按方向落地会跳过缓冲；轻伤只有变色；部分交互只有提示／粒子；落水耗尽和地面耗尽共用侧倒。缺少统一动作优先级，使相邻状态容易覆盖彼此。

本轮新增20张关键姿态、8张携带步态，共28张；图集82→110帧，仍2048²。新动作选择器HeroMotion只读取游戏状态，不改位置、速度、碰撞、跳高、计时规则或生命。普通跳跃立即响应，不增加前摇；压身蓄力只用于既有0.14秒孢子机制。

## 全动作检查表

| 动作／状态 | 检查发现 | 本轮处理与验收边界 |
|---|---|---|
| 待机 | 已有站姿及轻呼吸 | 保留脚底锚点，不新增整身漂浮 |
| 行走／左右／坡面 | 已有距离驱动八相 | 保留，不改行走物理；携带时改用新增握柄八相 |
| 普通跳跃 | 上升一姿，不能分辨蹬地、收膝、顶点 | 加蹬地、收膝、顶点、下落探脚、快速下落；以真实vy选姿 |
| 落地／连续跳 | 按方向时走路覆盖落地 | 落地深缓冲→起身→恢复，仍能移动；缓冲跳再次腾空优先于落地姿 |
| 蘑菇弹射 | 菌盖压缩但人站着 | 增加压身蓄力，释放后用伸展／收膝；动画不延长蓄力 |
| 攀爬上／下／停挂 | 背面八相可用 | 保留高度驱动，停止不换相；顶端补撑起姿，跳离立即进入腾空 |
| 推轻物／重物／压茎 | 既有移动推、受阻撑、压茎 | 保留接触点／实际位移驱动；受伤、落地等高优先状态不继续伸手推 |
| 获取／携带蒲公英 | 有持物和粒子，手仍普通走路 | 新取用、握柄待机与八相携带；取用姿不阻止移动或跳跃 |
| 展开／滑翔／收起到期 | 稳态旧姿，缺举手过程 | 加短举手展开，滑翔手臂放帽前握点处；释放／到期立即改为实际空中姿，保留绒毛消散 |
| 藏身／离开 | 原先直接压扁 | 进入短收身后低姿，离开起身；移动立即打断起身，不扩大可穿空间 |
| 树洞／地下入口 | 原先冻结等换房，没有收身 | 收肩缩入、随0.35秒过渡淡出；到达起身显现。道具跟着隐藏，无漂浮空伞 |
| 轻伤／保护恢复 | 原先1秒整身橙色，无护身 | 0.15秒护身姿和短色差；后续恢复重心，保护期间仍实体碰撞 |
| 地面生命耗尽 | 六帧倒下可用 | 保留屈膝、撑手、侧倒、淡出，暂停时跟死亡状态冻结 |
| 空中／落水／深沟耗尽 | 错误共用地面侧倒 | 标记falling，采用失足姿淡出，不在空中横躺；尚未制作水面深度遮罩 |
| 剩余生命救回 | 缺独立身体反馈 | 失足姿随0.6秒救回淡出，到达起身；仍保留剩余HP |
| 树皮／蜗牛／甲虫／毛虫站立 | 普通站立不能表达保持平衡 | 支撑ID识别载体，补屈膝张臂；起跳马上取消平衡姿 |
| 苔窝休息 | 只有文字和状态变化 | 新坐低休息姿；移动随时取消表现，不取消已确认休息 |
| 治疗芽／轻触西瓜虫 | 只有对象变化 | 新伸手轻触姿；高优先受伤／跳跃可打断 |
| 抵达终点 | 只有结算UI | 新挥手确认姿；结算仍即时，不加动画等待 |

## 优先级与转换合同

生命耗尽 → 救回 → 进出洞 → 轻伤 → 藏身 → 攀爬 → 滑翔 → 孢子蓄力 → 空中 → 落地 → 推动 → 结算 → 短交互 → 行走 → 载具平衡 → 携带／站立。

- 短交互按状态变化触发，不因同一个音效字段未清除而每帧重播。
- 移动取消取用／休息等表现；恢复自由输入时不等待动画播完。
- 暂停／竖屏暂停不推进表现计时。换房新画面实例不继承前一空间的短动作。
- 普通跳／载具跳／攀爬跳共享腾空规则；不会套用普通起跳持续时间来延迟孢子高速上冲。
- 左右镜像遵循玩家朝向；推物仍以接触方向为准。全套继续使用脚底锚点。

## 证据

- 158项Node回归通过，包括十关主线、分路、物理与图集；新增7项动作测试检查跳跃完整相位、移动落地、优先级、暂停、载体、交互中断和只读性。
- 逐关键姿态目视检查：手脚未裁切、身份一致、跳跃双手与收膝可辨；修正上举手被帽子遮住的问题。
- 图集边界／无重叠检查通过；通过矩形装箱填充空隙保持2048²，未因新增动作翻倍纹理尺寸。新关键姿态采样1.1、携带步态1.0，实际游戏约半尺寸渲染，仍需真机检查清晰度。
- Cocos引擎新增实际帧检查：起跳→收膝→顶点→下落→缓冲→起身、护身受伤、水中耗尽不侧倒；构建与最终结果见交接文档。

## 已主动记录的精修项

这些不是待发现的空白动作，但尚未达到最终动画成片品质：

1. 压茎掌跟沿弯曲曲线的连续贴合、攀顶背转正，还需更细中间帧／接触修形。
2. 稳态滑翔可增加衣摆二次运动；收伞目前即时切空中姿加道具消散，没有独立收伞连续片段。
3. 落水已有失足与淡出，尚无逐水深遮挡、入水波纹与专门湿衣表现；不要宣称水中动画完整验收。
4. 轻伤当前为镜像护身姿，不是按左右受击部位分别绘制；足以区别受伤与死亡，方向精度仍可提高。
5. 真机清晰度、持续帧率和真人对动作节奏的感受未验收。

后续按这份清单统一精修与回归，不以“某张图存在”作为动作已完成的唯一证据，也不把新增翻滚、攻击、游泳等未实现玩法混入现有动作需求。
