# 林间探索体验优化

本轮在现有八类生境、33种菌物及收藏进度系统上完善探索循环。

## 玩法

- 每局生成10朵菌物，采满8朵自动完成，提供25%的数量余量。
- 悠闲模式没有时间上限或猛兽；食菌动物30秒后开始觅食，全局最多吃1朵。
- 挑战模式限时180秒，食菌动物最多吃2朵；50秒出现足迹预警，60秒猛兽入场。
- 猛兽先巡逻，视野、距离和地形遮挡决定是否发现玩家。发现后先警觉，再追踪；失去视线后搜索最后见到的位置，连续6秒未发现玩家便回到巡逻。未达标时触碰直接失败；已达标后的额外探索规则见 [后续玩法](stealth-and-bonus.md)。
- 部分地生菌物藏在松针或落叶下：第一次轻点拨开覆盖，第二次采集。准星显示生境线索。腐木、苔藓和宿主树帮助判断寻找位置。
- 采集和动物进食都会移除目标；拨开覆盖不计采集。失败保留已采集的收藏记录。

## 收藏与重访

- 鉴别仍先查看三条线索，再选择名称。
- 首次答错等待45秒，连续答错等待120秒，不继续累加。等待只锁定该菌物，可继续探索或学习其他菌物。
- 答错展示误选菌物与当前标本的关键结构，重试成功清除错误记录。
- 旧版5/10分钟冷却迁移为最多剩余120秒，保存版本升为5。
- 结算“林间手记”显示本图进度变化、本图新增、全局首次发现、下一层解锁所需鉴别数及收藏纪念。新增卡片每页3张。
- 首次发现和完成单个生境名录各颁发一次纪念；不通过强制广告解锁。
- 重访改变菌物位置、遮盖、动物起点和行走相位，并轮换雨后微光、薄雾清晨、暖光午后。主要地形、起点及地标保持稳定；树木会避让生成的目标。
- 菌种开放仍以全局鉴别数0/3/8/15为阈值，使用原有生境匹配和稀有度权重；天气变化目前为视觉变化，不修改物种概率。

## 操作与性能

摇杆增加小幅移动死区。中心准星检测限制为每秒10次，实际点击仍立即检测；探索HUD每秒最多刷新约20次，操作反馈可触发即时刷新。UI纹理仅在更新时上传；动物寻路缓存静态地形可通行结果。3D画面持续渲染。这些是减少计算和上传的措施，不代表已达到某个真机帧率。

## 验证与预览

2026-09-14：147项Node测试通过，语法检查通过。新增覆盖模式差异、预警和暂停、视线与追踪脱离、拨开覆盖、动物遮挡拾取、重复探索变化、冷却迁移、收藏纪念及摇杆死区。

浏览器WebGL冒烟流程通过，包含33种菌物生成、移动、采集、收藏、冷却、猛兽和结算；320×568预览检查了结算与纠错排版。微信开发者工具已编译并显示新版首页，但自动点击未观察到原生触摸回调，因此不能据此确认微信端完整操作链路；原生触摸及真机性能仍需验证。工具内另有游客模式SDK警告，不作为业务代码测试通过的依据。
