## 1. 目标与不做项

玩家第一眼能认出“雨后菌谷里的剑修”，移动时看得懂朝哪走，拥挤时仍能找到自己、危险与逃生方向。保留淡彩水墨背景、青衫月白人物、暖白飞剑、品红瘴气与青绿经验。背景有水墨质感，人物轮廓与攻击边界必须清楚。

吸取用户此前“角色丑、横走、动画不连贯”的反馈：不能用文字宣称美观，不能把一张侧面图旋转成所有方向，不能将独立生成的相似人物硬拼成动画。先验一个角色，再扩资产。体修、邪修、第二兽王、皮肤、全屏宣传插画均不进入首批制作。

## 2. 剑修造型规格

| 维度 | 设计决定 | 验收要点 |
|---|---|---|
| 身形 | 青年剑修，约 5.5 头身；窄肩不过瘦，头手简化，重心落在双脚之间 | 原始尺寸和手机实际显示尺寸都能看懂人形，无畸形手脚、脸部脏点 |
| 服装 | 青衫 `#5E8FB0`，月白交领 `#EAF2F4`，深蓝腰封；下摆开衩到小腿，露出靴与步态 | 不是一整块三角袍；侧/背面保留腰线、双腿和衣摆分层 |
| 识别点 | 高束发髻、短发带、暖金剑穗、细长剑鞘 | 四个特征各方向一致；不靠满身金边和发光遮掩造型 |
| 武器 | 剑鞘固定在身体左后侧，右手短暂捏诀；飞剑为独立物件 | 左右方向不能镜像后将剑鞘换到身体另一边；手不黏剑身 |
| 轮廓 | 外缘浅色 2u，深浅双边只在背景确实混淆时启用；脚下浅色椭圆底影 | 描边不吞掉面部/手部，底影不与碰撞圈混称 |
| 尺寸 | 战斗可见身高暂定 80u（不含飞剑），身体单帧显示盒 96×112u，制作源格 144×168px | 比旧稿 64u 提高识别度；先以实际场景确认，不通过不锁尺寸 |
| 境界差异 | 练气使用基础造型；筑基加克制腰间灵纹，金丹加短暂金线气息；使用独立叠层 | 不重做三套身体、不常驻巨大光环；同一人物各境界连续 |

场景是俯视偏斜约 35° 的三分之四视角；八方向保持同一相机高度、头身比与脚底基线。移动是轻快步行/小跑，不是悬浮滑行。五官在战斗尺寸只保留必要明暗，避免用缩小的精细肖像制造噪声。洞府立绘沿用同一设定另绘，不放大战斗帧假装正式立绘。

## 3. 朝向、落脚点和连续动画

### 3.1 方向契约

- 八方向 N/NE/E/SE/S/SW/W/NW；屏幕上为 N。N 看背面，S 看正面，E/W 明确侧面，其余是对应三分之四面。单独提交八方向接触表。
- 移动身体朝向由实际移动向量决定；输入停止保留最后有效朝向。自动索敌只影响飞剑，不能让身体一边向北走一边面向东；惊鸿剑气与 UI 方向弧跟随逻辑朝向。
- 方向分区宽 45°，边界增加约 8° 回滞防抖；待体验调整，不能造成明显转向迟滞。转向时保留当前步态归一化相位，不重播第一帧；不将两幅身体半透明叠出“双头”。
- E/W、NE/NW、SE/SW 均需独立检查并修正剑鞘、捏诀手和衣襟；不能将纯镜像直接当交付。角色贴图不随移动角度整体旋转，底影也不转成竖椭圆。
- 每格脚底中点固定为源格 (72,150)，余下 18px 保留底部余量。身体可自然上下起伏，但脚底支撑点相位必须一致；图集裁切必须保留原始格尺寸与偏移。
- 显示盒不等于碰撞盒；延用 GDD/工程既定碰撞尺寸，脚下影子和衣摆不改变可受击半径。若视觉体积与碰撞落差过大，在预览阶段调整画面而非暗改判定。

### 3.2 动画表（规划）

| 动作 | 方向 / 帧数 | 播放与衔接 | 不可接受现象 |
|---|---|---|---|
| 待机 | 8×4=32 | 4fps 循环，1秒；轻呼吸与衣摆，脚不漂 | 缩放整个身体代替呼吸，脸/服装漂移 |
| 移动 | 8×8=64 | 基准10fps；按速度适度调至8–14fps，保持位移/步幅关系 | 横向侧图向上滑、两脚始终粘地、转向重置步态 |
| 捏诀 | 8×3=24 | 独立上身层，约0.25秒；自动飞剑只用此轻动作，可省略高频重复 | 每发飞剑冻结双腿，攻击方向牵动身体 |
| 受击 | 8×2=16 | 独立上身层约0.12秒，移动腿部不断播；无敌外描边另层 | 频繁整人闪没、受击动画阻止走位 |
| 破境/凝婴 | 正面偏侧共用6帧 | 仅世界冻结时进入，0.2秒/帧组成1.2秒破境；凝婴按1.5秒另编排叠层 | 破境前后换脸换衣，演出控制逻辑奖励 |
| 暂退 | 正面偏侧4帧 | 约0.6秒至单膝退场，结束持帧至失败转场 | 血腥断肢或末帧突然站起 |

总计 146 帧（含上身叠层），元婴剪影另复用已验身体轮廓，不额外生成一个不相干的小人。移动八帧必须覆盖左右脚接触、下沉、经过、抬起共两个半周期；第8→1帧同样验收。各方向同一帧号对应同一侧脚支撑，急转不会换腿跳帧。帧间身高漂移目标≤2%，身份标志不得漂移；脚滑须在带地面网格的正常速度视频中检查，不能只交慢放 GIF。

动作优先级：失败/凝婴/破境（冻结态） > 受击上身 > 捏诀上身 > 待机/移动。运行时上身与下身若无法可靠拼接，先删去高频捏诀，用独立飞剑与手边符光表达；不能交付断腰或停腿。此降级不减少八方向移动质量。

### 5.1 图集、下载与内存目标

- 玩家图集1张2048² RGBA8，无mipmap约16MiB；146源格净面积约3.53百万像素，接近单页容量，打包仍需算padding与上身裁切。超过时先优化透明空白与重复帧，不能缩坏轮廓。
- 敌人图集最多2张2048²，共32MiB；FX最多1张1024²约4MiB；UI最多1张1024²约4MiB；场景1张1024²约4MiB。战斗纹理总目标≤60MiB（不含渲染缓冲与引擎开销）。洞府背景/立绘单独按需加载，不与战斗常驻；洞府纹理另留≤8MiB。
- 29个144²图标约0.60百万像素，UI单页剩余空间要留卡框/字形padding；若装不下，先减少装饰，不先拆新页。旧稿“全动态单图集8MiB”不再适用于完整方向动画，此变化必须由工程性能验证。
- 下载压缩体积内部目标：战斗图片≤8MiB、洞府图片≤2MiB、全部声音≤3MiB，总新增≤13MiB。透明PNG/JPEG/音频实文件出齐后记录字节数；这些并非微信包体限额，发布分包约束交工程另行核实。
- Atlas边缘外扩2px、至少2px格间距，源格安全边不小于6px；透明不出现白/绿边。交付需包含每帧rect、原格尺寸、pivot、方向、帧率、循环规则、素材版本与来源记录。
- UI目标 DrawCall≤25、战斗激活节点≤600，沿用01；新增图集可能增加批次，不能保证“+0”。性能不足先裁雨丝、粒子、数字和额外捏诀帧，保留八方向脚步、危险轮廓与前摇。

## 6. 音频风格与层级

雨声、竹木、轻金属与短弦音构成菌谷气质。飞剑利落但不刺耳，受击明确但不恐吓，破境由收束到开阔，凝婴有胜利完成感。不要用厚重低频和长混响盖住高频率的战斗判断。

| 优先级 | 事件 / 预算 | 时长与混音规则 |
|---|---|---|
| P0 生存危险 | boss_warn、charge_warn、enemy_cast、hurt（4） | 0.15–0.8秒；同类合并，受击最短间隔0.15秒，威胁提示优先于己方输出 |
| P1 进程决定 | levelup、breakthrough、win、retreat（4） | 升层≤0.4秒；破境配1.2秒、凝婴配1.5秒；高阶演出替代普通升层，不叠成巨响 |
| P2 战斗手感 | sword_launch、sword_hit、sword_gather、sword_strike、thunder、frost（6） | 命中0.06–0.18秒；预警0.6秒、落剑≤0.5秒；多剑合成一个事件音 |
| P3 操作收益 | pickup、pill、ui_focus、ui_confirm、extract_enter、extract_done（6） | 0.04–0.3秒；拾取至少80ms间隔、最多3声并发，升级时让位 |
| P4 环境/音乐 | 雨林环境1、洞府音乐1、战斗音乐1 | 环境20–30秒、音乐30–60秒无缝循环，避免每次循环出现明显撞击点 |

- 总同时发声目标≤12：事件音最多8、环境1、音乐2（交叉淡化）、余量1。事件音为P0保留2槽；满载先替换最旧P3/P2，不因拾取密集丢失危险声。最多同时2个P0，重复警报合并，不排队迟播。
- P0触发时P2/P3降低约6dB，音乐降低约8dB；约30ms进入、250ms恢复，具体听审调节。P1演出在世界冻结时可居前，但不得在战斗中压掉危险提示。
- 输出峰值目标≤−1dBFS，先消除削波再听手机小扬声器；这是制作目标而非测量结果。关键音居中，左右定位只作辅助，单声道下仍要可辨。
- 母版WAV 48kHz；短事件音单声道、音乐/环境可立体声，发布格式由当前运行平台验证后选。事件PCM解码预算≤8MiB；背景声优先流式，若不支持须重新计算解码内存，不拿3MiB压缩体积当内存。
- 音效与音乐独立开关，默认开；环境归音乐开关。后台全部暂停或停止，回前台不自动开战、不播放积压声音；用户点继续后短淡入循环音。首次音频解锁失败仍可静音游玩，后续有效手势再试。
- 音频不得独占信息：charge_warn对应条纹冲撞方向，enemy_cast对应喉囊/蓄力形状，boss_warn对应文字，breakthrough对应境界标题。减弱动态不删除危险声音；震动独立且默认关闭。
- 程序音可以作带标签的占位，但必须经历响度/疲劳度听审后才可标成正式。不得把已有生成命令运行成功写成已完成混音。
