## 1. 美术风格与色板

### 1.1 风格

“雨后菌谷 + 淡彩水墨”：在 02 的低饱和雨后林地上加东方元素（山石皴笔、云纹、竹、青苔石阶、灵菌微光），只用于背景和 UI 边框。战斗层继续执行 02 §1.1 的四条可读性规则：背景最暗最灰；每类对象“颜色家族 + 形状语言”同时成立；紫红/橙红优先给威胁，青绿/金/暖白优先给己方与收益；精英外环按下表作为例外并辅以尖角形状；不用全屏辉光与大面积粒子。

修仙元素的约束：
- 灵菌装饰的微光用月白 `#E6EEF2` α ≤ 0.3，不呼吸、不用菱形，避免与菌孢灵光（经验）混淆。
- 剑光一律细长形（菱形剑身 + 拖尾），这是“己方攻击”的签名形状；敌方弹体使用圆形/环形；冲撞预告使用条纹箭头，不与细长剑形混淆。
- UI 面板用 02 的深绿半透明底，描边加 1 道 4u 云纹角花（只在四角，九宫格切边内），不增加 DrawCall。

## 2. 720×1280 竖屏操作与安全区

- 逻辑宽度 W=720；FIXED_WIDTH 下 H 随实际视口变化，720×1280 为基准。本文屏幕坐标统一左上为原点，x 向右、y 向下；safeTop 是顶部系统区域与胶囊避让后的下边界，safeBottom 是底部系统区域高度。L/R 是左右系统安全边界再加 24u。不得混用底部向上坐标。
- 所有按钮位于安全区内；暂停热区 96×96u（最低不得低于 88u），相邻热区至少隔 16u。375px 宽时 96u≈50px，仍须真机按物理尺寸复核。按钮有按下、禁用、焦点状态，不能只变颜色。
- 浮动摇杆仅接受 y≥H/3 的世界空白区起始触点；面板、按钮及系统手势区域先截获触摸。底座半径 60u、头半径 28u；中心钳制到 [L+60,R−60] × [max(H/3,safeTop+60),H−safeBottom−72]。边缘触摸以钳制后的中心计算方向，避免零位跳动。
- 世界只跟踪首个有效 pointer；额外手指不接管摇杆。暂停按钮可作为独立系统操作中断当前移动。松手、取消、失焦、弹窗、切后台均清零全部 pointer 与移动向量；恢复必须重新按下，旧手指抬起不能选卡或触发按钮。
- 建议摇杆死区 8u，超过后连续映射；最大偏移 60u。此为待体验验证参数。左右手都可在下方空白区起摇杆，不增加常驻左右手按钮。
- 单指移动、全部功法自动施放，不设手动大招或闪避。惊鸿剑气沿逻辑朝向释放，脚下前缘 8u 方向弧表示实际逻辑朝向。人体视觉朝向规则详见 05；飞剑索敌不能拉着角色身体反复转向。
- 首局下方提示“按住下方拖动，飞剑自动攻击”，首次有效移动后淡出；首次吸收提示“靠近灵光，积累修为”。提示不截触摸，不遮住角色或危险预告。

## 3. 局内 HUD：减少常驻信息

### 3.1 信息取舍

| 信息 | 展示方式 | 原因 |
|---|---|---|
| 生命、境界与经验、计时、暂停 | 常驻 | 生存、下一次成长与 5/7 分钟威胁节奏 |
| 净化数、4 功法、御剑术、4 心法法宝、详细属性 | 暂停页与结算页 | 自动施放，无战斗中点击决策，不常驻 9 个图标 |
| 丹药 | 生效时一行，最多 3 枚，失效消失 | 可影响当下走位，不保留空槽 |
| 统领/兽王血条 | 在场时出现 | 兽王优先；统领仍存活时保留其世界血条/方向标，不显示第二条顶部血条 |
| 万剑归宗 | 世界剑影预警 0.6 秒，落剑短报 | 删除常驻冷却格；与危险横幅冲突时舍弃战报 |
| 灵石、最高一击、装备详细等级 | 暂停/结算 | 不占战斗视野 |

### 3.2 基准布局

所有 dy 从 safeTop 向下计算；下表默认 L=24、R=696，实际按安全区重排。顶部面板只承载文字与条形，不画大块装饰边框。

| 元素 | x / dy | 规格 |
|---|---|---|
| 境界·层数 | L…L+280 / 0…44 | 32u，Lv27 及以上显示“金丹·圆满” |
| 计时 | L+296…R−112 / 0…44 | 36u；不与境界或暂停相交 |
| 暂停 | R−96…R / 0…96 | 视觉 64u，热区 96u |
| 生命条与数值 | L…R−112 / 52…92 | 20u 高条，32u 的“当前/上限”配深底，低于 30% 加“生命偏低”与缺口标记 |
| 经验条 | L…R−112 / 108…124 | 高 16u；L=9/18 时上方标签改“下层破境”，不能仅变金色；L≥27 不再提示破境 |
| 丹药情境行 | L…R / 132…176 | 每枚最多 208×44u，固定爆/疾/金顺序，不按剩余秒数交换位置；名称简称+秒数 28u，完整效果进暂停 |
| 首领名称与生命条 | L+56…R−56 / 184…248 | 名称/阶段 28u，血条 20u；没有首领则整行不占位 |

世界可视边界按内容档位决定：无丹药、无首领为 safeTop+176；有丹药、无首领为 safeTop+192；有首领为 safeTop+256；不再把旧 `HUD_TOP_RESERVED=300` 当成必须保持的实现。屏外箭头、短报和数字共同使用新边界。若 safeTop+256 超过 H/3，摇杆仍从 H/3 起，UI 只截获暂停热区，其他只读元素不挡输入。世界摄像机/箭头位置由开发依据这一约束适配，本文不改代码。

短报置于 HUD 以下一行，最多一个、最长两行；优先级：危险 > 破境/升层 > 万剑战报。危险提示不得排队到危险已经发生后再显示。大字模式若放不下，先隐藏计时和丹药简行（详情仍可暂停查看），保留生命与危险；不得缩小文字或覆盖摇杆。

### 3.3 可读性底线

- 正文/卡牌效果 32u、主按钮 36u、次要标签不低于 28u；24u 仅允许非必要装饰标签，不能承载成长条件或生命信息。旧稿 24u 正文不再沿用。
- 在 375px 宽预览，32u≈16.7px；这只是布局换算，不等于已通过物理手机可读性验证。行高至少 1.35 倍，中文两端不硬挤，数字与单位不拆行。
- 普通文字目标对比度 4.5:1、大字 3:1，需在最终背景合成后测量；忙碌背景加深色底板，不能只靠细描边。
- “较大文字”按 125% 起步，允许卡片长高、面板滚动；所有确认/返回控件固定可见。未支持的语言不声称完成本地化；当前中文用最长名称和 150% 文案长度做溢出用例。

## 4. 伤害数字（“爆数”折中方案）

### 4.1 显示范围

02 不显示伤害数字的两个理由（200 敌人遮挡、性能）仍成立，所以只在“少数但关键”的命中上显示：

| 类别 | 何时显示 | 优先级 | 样式 |
|---|---|---|---|
| A 兽王 | 任何来源对瘴泽蛟王的伤害 | 3 | 暖白，字高 28u |
| B 统领 | 任何来源对裂山妖犀的伤害 | 2 | 暖白，字高 28u |
| C 万剑归宗 | 每次释放，取视口内距剑修最近的 12 个受击妖兽（同距按池内顺序，确定性） | 1 | 金色，字高 36u，出现时 1.4 → 1.0 缩放 0.1 秒 |
| 预留 暴击 | GDD 当前无暴击；若后续加入，作为优先级 2，样式“金色 + 末尾‘!’” | — | — |

爆灵丹生效期间，上述数字改为琥珀 `#F2B544` 并放大 1.15 倍，让“伤害翻倍”看得见。普通妖兽被普通功法命中不显示（继续靠受击闪白），剑修自身受伤不显示数字（靠晕影与生命条）。

配套“爆数”手段（不增加节点）：万剑归宗落剑后横幅位置显示“万剑归宗 ×N”（N = 本次受击数，HUD Label）；结算页显示“最高一击”。

### 4.2 合并、上限与淡出

- 同屏上限 24 个数字。满时：新数字优先级高于池中最低者 → 回收池中最低优先级里最旧的一个；否则丢弃新数字。
- 合并：同一目标在一个数字存活期内（距上次累加 ≤ 0.3 秒）再次受击，累加到这个数字上并重新弹一下（1.2 → 1.0，0.06 秒）；单个数字总寿命上限 1.2 秒，到上限后下一次命中另起一个。兽王的新数字在其头顶交替左右偏移 ±24u，避免叠在一起。
- 运动：出现在目标头顶（目标半径 + 12u），0.7 秒内上飘 40u，最后 0.2 秒 α 1 → 0。
- 格式：< 10 000 显示原数（最多 4 位）；≥ 10 000 显示“1.2万”（一位小数，最多 4 个字形）。
- 进入 HUD 保留区（dy < 当前 HUD 下沿）的数字下移到保留区下沿，不压 HUD。
- 性能档位（03 §7.4）降到 30fps 档时：上限降为 12，万剑归宗每次取 6 个。
- 设置关闭“伤害数字”：战斗层一个数字都不生成；战报“万剑归宗 ×N”是 HUD 文字，保留。

### 4.3 实现方式与预算

- 字形：`0–9`、`.`、`万` 共 12 个字形，按 05 放入对应 FX/UI 图集（源 30×42px，显示 20×28u，描边烘焙）。每个数字 = 1–5 个字形 Sprite，颜色用顶点色染色，不切材质。
- 节点：新增 `Damage` 层放在 World 的 FX 层之后，对象池固定 24 个数字 × 5 字形 = 120 个 Sprite 节点，构建时一次性创建，用完隐藏，不运行时 new。
- DrawCall：字形连续提交、使用同材质合批；与敌弹分层可能增加批次，须计入总25批预算，不承诺增量为0。
- 节点预算：战斗层激活节点 ≤ 600；旧稿引用 S2 峰值 321，仅作历史参考；新动画与特效加入后的峰值必须重新测量。
- 逻辑依赖：逻辑层写入有界 `DamageFeed` 记录 `{sequence,tick,uid,x,y,amount,source,targetKind}`，只对统领 / 兽王 / 万剑归宗发出（普通命中不发，避免每帧数百个事件）；事件只给表现层，不影响模拟和确定性。结算 summary 新增 `maxHit`，由逻辑独立累计，不依赖可能覆盖丢失的显示记录。
- 设置：存档 `settings.damageNumbers`，默认 true；缺省值按 true 兼容旧存档。

### 6.2 无障碍与降级

1. 色盲：§1.3 每类对象有独立形状；暂停详情三类栏位形状不同（圆角方 / 圆 / 切角方），卡面另有文字角标；丹药计时有秒数文字。验收沿用 02 §6 第 7 条：Chrome DevTools 红绿、蓝黄、全色盲模拟下，对 0:30、6:40 满屏、兽王战、万剑归宗落剑瞬间 4 张截图，能指出剑修、妖兽、瘴气弹、灵光、回春丹、伤害数字各一例。
2. 减弱闪烁（reduceFlash）的总原则：不出现任何每秒 > 3 次的明暗变化；任何大面积（> 屏幕 25%）的亮度变化只能单调渐变；精英外环常亮。万剑归宗和破境是本版新增的两个大面积效果，按 §6.1 降级。
3. 关闭震动：全程不调用 `wx.vibrateShort`，视觉与声音不变。
4. 较大文字与独立音乐开关：字体按 §3.3 重排；音乐与音效分别静音。默认震动关，开启后仍受平台支持能力限制。
5. 关闭伤害数字：§4.2；战报、结算“最高一击”保留，爆数感不完全丢失。
6. 声音不是唯一信息：万剑归宗预警有剑影与短报文字，兽王预警有横幅。
7. 全部六项设置在洞府和暂停均可改、即时生效并保存。旧存档缺失字段按 §0 默认值；不覆盖原有已保存偏好。较大文字不能依赖读屏支持；Canvas/引擎读屏可访问性尚未验证，不宣称支持。

## 7. 美术与音频交接

详细清单、剑修造型/八方向/动画、出图验收门槛、图集与音频预算统一在 `05-art-audio-design.md`。本稿 §1 配色、形状与危险层级继续生效。旧稿“把旅人帽改发髻即可”“约新增 8 帧”“正式图同占位尺寸差≤10%”不再作为制作依据：角色身份与动作先验收，再定图集；碰撞规则不能被大袖或头发暗中扩大。

## 8. 性能与开发边界

目标战斗 DrawCall≤25、激活节点≤600；伤害字形池最多 120 节点、同屏数字≤24。图集显存与音频声部见 05。以上是验收预算，不是结果；不同材质、图集拆分和排序都可能破坏合批。不得以“同图集所以必为 +0”代替实测。

低性能先减少装饰雨丝、净化光点、己方剑影、伤害数字；绝不减少敌弹可见性、危险前摇、输入反馈或生命信息。只准降表现，不改命中/时序/掉落。具体代码、字段与测试由开发文档落地，本任务不改代码。
