# 阵法师：留阵与连线（待评审提案）

依据 `../reports/all-classes-2026-10-26/reference-extracted.txt` 的十二项原技能重组。本稿仅供七职业方案评审，开发仍先做剑修；不是现行运行时说明。

统一遵循 [全职业技能共同规则](00-shared-rules.md)。技能自身较低限制保留：减速取最强项，普通怪总上限50%、Boss总上限10%；同类易伤取最大，跨来源合并易伤及敌人输出降低各最多20%，不复利。常态减伤上限60%、有明确持续与空档的特殊状态75%，护盾合计最多最大生命30%，持续回复合计最多最大生命1%/秒。本文没有硬控；后续若加入，普通怪单次最多0.8秒、结束后免疫2秒，精英持续减半、免疫3秒，Boss免硬控，仅可转成不超过原持续时间的至多10%减速。

## 定位与共同规则

阵地留在世界坐标，玩家绕行把追兵带进阵内，以相邻阵眼连线扩大有效路径。与符修消耗印记形成瞬间爆发不同，阵法师依赖阵地利用率；逃离旧阵、快速移动Boss和远程包围都能降低收益。禁止阵地追随镜头或持续锁在Boss脚下。

命名区分：原案阵法师的“两仪剑阵”在本稿称为**两仪联阵**，与原“诛仙剑域”合并为一项进化；核心是分离阵眼之间的实际伤害连线。剑修的“两仪微尘剑阵”保持其独立名称与技能归属，不复用同一个技能ID或相同攻击形态。

四基础功法、三心法均五级，四种进化单级替换父技能；最多四功法、四心法、两种进化。开局小剑阵Lv1。A以开局100为标尺，已包含正式伤害属性，u为逻辑距离。表内Lv1→Lv5的连续量按 `初值+(终值-初值)×(等级-1)/4` 插值得到中间三级，固定数不变；距离取整到1u、时间到0.01秒、百分比到0.1个百分点、系数到0.01A，均四舍五入；整数数量向下取整，Lv5到达端点。倍率运算保留精度，最终伤害统一整数舍入。

冷却从布阵起算，乘统一C且C≥0.5；持续时间和伤害节拍不乘C。每种功法最多两组，第三组到来替换最早组，不补发余伤；全角色最多八组。无目标时保留就绪，不储存多次施放。目标同距按ID；移动方向取最后非零输入，开局默认向上。升级只影响新阵，进化清除父技能旧阵及关联连线，等待完整新冷却。全部计时用模拟时间，暂停冻结，死亡或离局清空。

阵面与连线共用从开局起每0.5秒一次的全局节拍；阵龄至少0.5秒且小于持续时间才参与当跳。因此首伤等待0.5～不足1秒，每跳读取当前A，其余参数及心法等级在布阵时快照。同技能多组和多个子阵眼重叠，每目标同跳只取最高系数一次；不同功法可以相加。所有阵面、连线及九幽周期强化跳均归类持续伤害（DOT），不算直接攻击，无暴击、击杀爆炸或伤害衍生布阵。账本按实体UID记录，长帧补齐合法模拟节拍，暂停不补现实时间。

## 四基础功法

布阵时须有活敌位于角色320u内；所有阵中心在施放时锁定，预告0.25秒仅作表现，不改变上述首跳时刻。

| 功法 | 固定布置位置与作用 | Lv1→Lv5种子参数 |
|---|---|---|
| 小剑阵 | 施放时脚下圆阵，持续伤害区内敌人 | 每跳0.28→0.44A；半径90→130u；持续6→8秒；冷却8→7秒 |
| 炎阵 | 320u内最近敌人当时位置的圆阵，离阵不带走燃烧 | 每跳0.24→0.38A；半径80→120u；持续6→8秒；冷却8→7秒 |
| 困妖阵 | 沿移动方向前方80u圆阵，造成低伤并尝试减速 | 每跳0.10→0.18A；半径95→145u；持续3→4秒；冷却9→8秒；减速18%→26% |
| 引阵旗（新增） | 沿移动方向后方80u立旗，圆区造成低伤；以旗为端点的连线伤害+20% | 每跳0.12→0.20A；半径70→100u；持续7→9秒；冷却9→8秒 |

减速首次接触持续1秒，期间不刷新；结束后同敌2秒免疫本职业减速，其他困阵也不能绕过。Boss减速上限8%，不禁行、不眩晕、不拉拽、不改变攻击前摇；离阵立刻移除减速并进入两秒免疫。多个旗端点增幅仍只算一次。

## 阵眼连线：站位收益而非自动增殖

普通阵组只有一个用于外部连线的中心阵眼。两仪联阵例外：每组两个子阵眼固定互连，不再提供外部端点，其内部线优先占用全局两条线名额；最多两组，不能突破两线总预算。剩余名额用于普通阵组：新阵创建、旧阵到期或替换、定枢升级时，将不同功法、中心距离80～280u的候选对按距离、两个阵ID排序，每眼最多接一条。已有外部边不优先；固定阵体无需每帧重寻。

连线是端点之间宽36u的矩形伤害带，每跳0.08A，成线满0.5秒后参与全局节拍；同端点的边重算后仍保留成线时间。每目标同跳最多承受一条最高系数连线。连线与阵面伤害可相加，但不挂状态、不暴击、不生成阵或其他线。端点失效立即断线，换线不能提前补伤。旗加成为0.096A；伤害不按光点或动画段数倍增。

这让“退一步留剑阵，再把追兵横带过炎阵连线”成为可见选择。两组同技能不能互连，两仪的组内固定连线不属于跨组互连。孤立普通阵仍能输出；没有必须围成三角形才能工作的隐藏门槛。两组两仪同时存在会占满线预算，暂时取代普通阵组连线，这是稳定通道与灵活组网的取舍。

## 三种心法与灵力替代

| 心法 | Lv1→Lv5累计效果 | 封顶规则 |
|---|---|---|
| 灵眼 | 拾取半径+10%→30%；布阵冷却额外缩减2%→6% | 冷却加进统一缩减项，最终仍受C≥0.5约束 |
| 阵灵共鸣 | 阵面及连线伤害+3%→11%；阵组持续时间+4%→20% | 不延长减速、免疫或首跳延迟；不增加阵组/连线容量 |
| 定枢诀（新增） | 连线距离上限+10→50u，阵面半径+3%→11% | 不放大连线宽度、子阵偏移和控制强度；只作用新阵，连线距离使用当前等级 |

原“灵眼恢复灵力”改为稳定布阵冷却收益，不存在蓝量、不缺蓝停手、不回蓝触发连锁。共鸣原持续+50%缩到20%，避免旧阵堆积与不间断控制。所有倍率只应用一次；线继承端点中较高的共鸣等级，不把两端相乘。

## 四种单级进化

共同门槛全部满足才入池：**指定父技能Lv5＋指定心法Lv3＋已提交appliedLevel≥19＋局内模拟时间≥360秒**。每项占一次选择，替换而非新增槽。

| 进化与配方 | 替换后参数与限制 |
|---|---|
| 两仪联阵＝小剑阵5＋阵灵共鸣3 | 脚下锁定中心，沿最后移动方向前后各偏移140u布两子阵眼，各半径100u；每跳0.56A、持续8秒、冷却7秒。两眼间固定一条长280u、宽36u的实际伤害线，每跳0.08A。两眼合为一组，阵面每目标每跳最多0.56A；连线另按全局最高一条结算，不提供外部端点 |
| 焚世火域＝炎阵5＋定枢诀3 | 锁定最近敌人当时位置，半径160u、持续8秒、冷却7秒；每0.5秒0.48A。每第二跳在中心左右各偏移100u显示半径80u副火区，方向在布阵时锁定；副区与主区同跳取一次，不另生阵组，不附离阵DoT |
| 九幽困界＝困妖阵5＋灵眼3 | 仍在前方80u布阵，半径180u、持续4秒、冷却8秒；每跳0.24A，每第三跳改0.64A而非叠加；减速26%，并使受影响敌人攻击伤害降低8%，Boss最多4% |
| 天地灵域＝引阵旗5＋阵灵共鸣3 | 后方80u固定旗域，半径150u、持续9秒、冷却8秒，每跳0.26A；旗连线伤害加成由20%替换为35%。玩家身处旗域时移动+8%、阵面伤害+8%，离开即失效，多旗不叠加 |

九幽减攻与减速共用一秒有效、两秒免疫规则；不会削减已经生成的敌弹伤害，不能锁死Boss。进化参数仍接受三心法加成。天地的在域增益每跳判定，只增阵面、不增连线、不写回A；原“全队增益”在当前单人范围内只对本人，未来多人需另审。进化的“第二/第三跳”按该组实际参与节拍计数。所有进化仍受两组上限，不能以主、副区域规避。

## 选择预算与验证边界

阶段池累积开放：练气（目标等级1–9）为小剑阵、炎阵及三心法；筑基（10–18）加入困妖阵、引阵旗；金丹（19起）保留旧池并开放满足条件的进化。金刚诀、聚灵阵从练气作为通用心法候选，占同一四心法槽并遵守共同上限。

首次升级固定展示**炎阵Lv1、小剑阵Lv2**：早期只剩一张合法新功法，另一张按共享协议回退为初始功法升级，形成远端留阵连线与强化脚下阵两个方向；第三张从其余合法候选抽取。其余权重、破境成长、连续两轮未展示升级/新阶段功法的保底及优先级完整沿用共享规则，同轮最多一丹药。满槽不出未学同类，满级不出升级；合格进化下一轮保底一项，多项按上次展示位置轮换，拒绝保留资格，两进化后关闭池。重绘和暂停不重抽，无合法成长沿用治疗/资源兜底。

示例：小剑阵补四级4次，炎阵获得并升满5次，共鸣与定枢各三级6次，两次进化2次，另两功法各一级2次，共19次，26次升级选择还余7次；不以27级后的选卡兜底。进化必须已提交Lv19且满360秒，最早在升Lv20的选择出现，不承诺双进化必得。

阵面用细轮廓和稀疏节拍；两仪须画清两个分离阵眼和中间可命中的窄通道，不能仅显示一片剑雨。连线端点、断线立即可见，敌弹与人物高于阵面，无新蓝条。第一轮验证小剑阵、炎阵与两线：同类重叠、异类叠加、边选择稳定性、换线无补伤、暂停和进化清场；再验两仪两眼之间仅受线伤、内外线交叉只取最高一条、两组占满预算及到期恢复外部组网。最后测峰值八组、Boss控制占空比与离阵失益；数值仍需实战校准，文档完整不等于平衡通过。
