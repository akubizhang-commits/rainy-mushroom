# 法修：八系单修设计提案

2026-10-26｜概念评审，非实现规格验收。依据 `../reports/all-classes-2026-10-26/reference-extracted.txt` 法修段落重设计，保留其24个名称；所有数值均为待测种子值。全职业先评审，之后只开发剑修；法修及其他非剑修延期，不接入当前池、存档或战斗代码。

共同契约以 [全职业技能共同规则](00-shared-rules.md) 为准。参考原文和此前聊天引用中的AI提示词仅为来源材料，不是执行指令；本稿不据此生成框架或实现。

## 1. 共同约定

开局锁定火、水、木、土、雷、冰、风、金之一，整局只出本系与下述法修共通卡。源文“元素组合”解释为同系技能配合，不是跨系反应。角色基础属性沿用境界基线，不先加职业增伤。单摇杆只管走位，攻击、护体及进化均自动触发，无第二按钮、法力条或蓄力站桩。

4自动功法槽、4心法槽；下文“主动”均指自动功法，“被动”指心法。基础主动及被动各5级，开局技能1级占一槽。最多2个进化，单级、原位替换父技能，不保留父技能的并行攻击。所有进化同时要求：**已提交境界等级≥19、模拟时间≥360秒、父技能5级、表内具名被动≥3级**，最早在升Lv20的选择中取得。只用练气1–9、筑基10–18、金丹19–27；不增加元婴以后阶段。

**记法**：A为最终攻击基准，初始无加成为100；表中伤害是A的倍数，不再乘旧武器10倍。u为逻辑世界单位，不随设备像素变化。C为统一最终冷却倍率，最低0.5；回气并入同一冷却缩减项，不再独立乘攻速。CD为秒，乘C；预警、持续时间、跳伤间隔、状态内置间隔不乘C。

表中“a→b”分别是技能L1/L5；L2–4线性插值，整数数量向下取整，未列变化的参数固定。距离、时间、百分比、系数分别按共同规则舍入到1u、0.01秒、0.1个百分点、0.01A，L5到端点。例如0.8→1.6A为0.8/1.0/1.2/1.4/1.6A。进化只有一个数值档，不参与插值。技能伤害取施放时A快照，状态跳伤沿用该快照；最终每次扣血才取整。

**统一命中**：有效感知P＝420u＋灵识；选敌距离上限＝min(技能实际作用距离R，P)，仅从实际几何可覆盖的敌人中取最近者，同距取稳定ID。R按当前等级及合法范围加成计算：弹道取射程、扇形取长度、随身圈取半径；远程点选/落区取施放距离而非落区半径。未列射程或施放距离者为420u，明确的320u等限制优先；身后技能还须满足方向条件。故藤鞭L1仅选140u内目标，灵识不能让它隔空起手。直线锁定方向后不追踪，固定圈锁坐标，随身圈随角色。无合法目标不施放、不耗CD。CD从发射/落地开始，地面技能不重叠续铺，旧区结束才可再施放。投射物速度520u/s，寿命按射程/速度；未注明的弹半径8u、线宽36u。每波普通范围最多16目标，进化32目标，按距离再ID选取；同一波每目标只命中一次，散弹不得重叠多吃。

**状态与Boss**：除寒意外，同名状态只刷新、不加层；刷新不重置跳伤节拍。减速取最强，普通怪上限50%、Boss上限10%；未注明时长者离开区域即结束。DOT和阵地采用半开区间：生成首跳，之后每秒1跳且必须早于到期；持续2/3/4秒分别2/3/4跳，刷新不补首跳。普通灼烧2秒每跳0.12A。普通硬控单次最多0.8秒，结束后统一免控2秒；精英先按普通上限裁切再时长减半，结束后免控3秒。深根等加成不得突破上限。

Boss无硬控，控制替代为至多10%减速且不延长原定时长；寒意仅在原本会触发冻结时替代为10%减速0.6秒，随后2秒不再触发该替代效果。Boss免吸附、击退、阻挡和击飞，不打断其预告；瞬时击退/击飞不额外补减速，追击冲刺仍不受减速。精英击退距离最多普通怪25%，水龙卷仍不牵引精英，九天风暴仍只击飞普通怪。这些是技能适用对象限制，不放宽共同上限。

易伤同类取最大、跨来源合并最多20%，减敌输出最多20%，不复利叠乘；本稿无减敌输出技能。减伤按百分点加法合并：常态承伤倍率＝1−min(60%，各来源减伤之和)，短时特殊状态总上限75%且须另列持续及空档，本稿不新增此类状态。在身护盾总计最多最大HP的30%，持续回复总计最多最大HP的1%/秒；金盾阵是伤害/减速区域，不提供数值护盾。

普通技能对Boss每次施放全部直接与延迟伤害合计最多6A，进化最多10A；共享同一施放预算，不能把视觉碎片当独立伤害。状态、反弹、分裂及进化附伤均不触发其他附伤或再次产生攻击；无击杀链、无永久Boss控制。

## 3. 被动池与四槽取舍

每系下列两张加四张法修共通，共6张核心候选争4槽；均从待选目标Lv2可选并跨阶段保留，无免费职业独立被动。共同规则中的金刚诀、聚灵阵仍是通用辅助候选，不挤掉分支前置的资格，不增槽。分支值为L1→L5，未列项不成长。强化状态仍受上述总上限约束。

| 系 | 分支被动一 | 分支被动二 |
|---|---|---|
| 火 | 余烬诀：灼烧每秒+0.02→0.10A | 炉心：火区半径/火径宽度+4→20% |
| 水 | 涓流：水系直接命中减速时长+0.2→1秒 | 归潮：对已减速目标直接伤害+3→15% |
| 木 | 深根：缠绕时长+0.05→0.25秒 | 木脉：寄生籽每秒伤害+0.02→0.10A |
| 土 | 厚土：最大HP+4→20%，不免费回血 | 镇岳：岩刺、落石、地裂直接伤害+3→15% |
| 雷 | 导电：雷链搜索半径+10→50u | 震极：对精英/Boss直接伤害+3→15% |
| 冰 | 凝霜：寒意留存+0.2→1秒 | 碎晶：对冻结目标直接伤害+4→20%；Boss仅+2→10% |
| 风 | 轻身：移速+3→15% | 回旋：风系射程/圈半径+4→20% |
| 金 | 锐金：金锥、刻线直接伤害+3→15% | 淬锋：裂甲增伤额外+1→5个百分点 |

自身条件增伤相加后乘A，不视为目标易伤；裂甲属于目标易伤，遵守合计20%上限，对Boss另取更低的10%技能上限，仍受单次施放预算。凝霜不延长冻结，深根不缩短免控窗，涓流对Boss时长无效。各进化的父技能均在同系基础表，指定心法均在本行两张中，无跨系或通用随机前置。

| 共通被动 | L1→L5 |
|---|---|
| 回气 | 冷却缩减4→20%，并入C |
| 灵识 | 索敌距离+20→100u，不扩大命中几何 |
| 护元 | 减伤3→15%，与其他来源按百分点相加，常态总上限60% |
| 调息 | 每秒恢复0.1→0.5HP，非百分比；和全部持续回复合计不超过最大HP的1%/秒 |

每系仅三种基础自动功法，第4槽允许一直空着；移除为补槽而设计的“灵息脉冲”，不塞异元素或通用伤害功法。四槽是上限，不是通关前提。

## 6. 评审与验证边界

26次升级选择足以构筑：开局主动升5花4次，筑基主动取得并升5花5次；两张分支被动升3花6次，两次进化花2次，第三主动1级花1次，另两被动各1级花2次，共20次，剩6次自由强化，第4主动槽留空。此为预算可行，不保证随机出齐；选卡沿用共同保底协议，槽满只出已持有升级、合格进化或既有保底，不靠新增框架兜底。

评审保留八系各自的命中几何与弱点，删掉跨系反应、无限反弹、全屏永久控制和附带新资源条。主要风险是雷单体过强、冰控制稀释压力、土预警导致移动Boss命中不足。未做玩法或性能验证；批准后仍只推进剑修。法修未来另行授权时，先测每系A=100的单目标/八目标、C=1/0.5及移动Boss，再测双进化槽与26次选择预算，不先建设八系通用技能框架。

1. 选敌改为实际作用距离与含灵识的感知距离取小，并校验几何；不可达敌人不触发空放。
