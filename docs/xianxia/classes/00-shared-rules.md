# 全职业技能共同规则

设计评审稿 v1，2026-10-26。适用于本目录七职业与法修八分支。所有参数均为首次试验值，不代表平衡、性能或美术已验收。

## 1 产品边界

保留单指移动、自动攻击、升级暂停三选一。当前第一章沿用练气1–9、筑基10–18、金丹19–27，胜利凝婴；不因参考文档列出化神和渡劫而直接延长单局。现有5分钟统领、7分钟Boss的章节结构暂不改。

本轮设计所有职业，首次开发只做剑修。后续职业按独立里程碑逐个制作，法修也按元素逐个落地。没有完成的职业不在首发界面放可点击的空入口。

“主动技能”统一称“自动功法”，避免玩家误以为有额外按钮。中后期技能允许更改核心攻击形态，但不得在玩家未输入时突然强制移动角色。

## 2 槽位和成长预算

- 4自动功法槽，开局自带职业指定技能Lv1，占一槽；4心法槽。
- 普通功法、心法最高Lv5；进化单档替换原功法，不增槽、不再另升五级。
- 一局最多2种进化；所有进化必须列出基础技能和心法搭配。
- 金刚诀和聚灵阵作为通用辅助候选，不额外提供第五心法槽。职业同类防御或拾取心法与通用项可以二选一；同一加成按统一上限合并，不能因名字不同逃过上限。
- 从Lv1至Lv27按26次选择规划。2核心满级9次＋2配套心法各三级6次＋2进化2次＋2个其他功法各一级2次＝19次，余7次自由搭配。该预算证明一种合法路径，不承诺随机每局都凑齐。
- 若某元素仅提供3种基础功法，第4槽可以空着；不强行塞入异元素或通用伤害技能补齐。槽数是上限，不是通关要求。

## 3 选卡统一协议

境界池做累积解锁，不能升级后失去旧技能升级渠道。练气提供至少两个可选战斗方向，筑基加入更需要配合的技能；终极改为金丹进化，在当前章节内可见。

新技能候选先按职业/法修开局元素过滤，再按阶段、槽位和已学状态过滤。已学升级权重10、新功法8、新心法4、丹药3是初版试验值；同轮最多1丹药。

保底顺序：

1. 有合格进化且未达到2种时保底1张，多个合格进化按上次展示位置轮换。
2. 首次升级展示本职业两张指定的早期互补功法；如果只剩一张合法新功法，另一张改为初始功法升级。
3. 破境保证一张合法功法成长；进化也满足此条件。
4. 连续2轮没有展示任何已学功法升级，下一轮有候选时保证1张。
5. 新阶段连续2轮未展示该阶段新功法且槽未满，第三轮有候选时保证1张。
6. 剩余位置加权无放回抽取。不重复同技能，不同时展示同技能升级与进化；优先级低的保底可以顺延，不能挤成四张。

当前待选目标层数用于新候选阶段解锁；实际属性只在选择提交后更新。进化单独要求**已提交等级≥19、模拟时间≥360秒、基础Lv5、指定心法≥Lv3**。因此即使时间已够，最早也在升Lv20的选择中进化。

同一选卡会话只抽一次并保存结果；暂停、重绘、回到该界面不能刷新随机序列。没有合格成长时使用现有治疗/资源兜底。继续27级之后也遵守槽位与两次进化上限，不把无限升级当作前期设计补救。

## 4 统一数值与触发语义

### 基准

A为当下攻击基准，初始无外部加成为100；u为世界逻辑单位。接现有代码时A可用`10 × stats.might`，其中已有修仙10倍与境界/丹药等修正，不能再次乘同一倍率。当前原始玩家生命100，移动速度160u/秒，职业和境界已有修正要按实际代码读取，不能同时保留旧修正又叠一套同名新加成。

C为最终冷却倍率，最低0.5。表内普通冷却乘C；DOT跳伤、召唤物独立攻击间隔、触发内置冷却、护盾回复间隔均不自动乘C，除非该技能写明。不用同时缩短召唤冷却和攻击间隔把同一增益计算两遍。

每个非剑修文档的Lv1→Lv5是参数端点。未给五档时，连续值按`v(L)=v1+(v5-v1)×(L-1)/4`；距离四舍五入到1u，时间到0.01秒，百分比到0.1个百分点，系数到0.01A；整数数量取向下整，Lv5必须到端点。阶跃或非线性技能必须另列五档。不能把视觉个数当作实际命中次数。

### 伤害事件

每次伤害记录源职业、技能ID、施放ID、目标实体UID、事件种类、是否直接命中。同UID才是同一敌人，不能只用对象池槽号。伤害取最终值后统一整数舍入。

默认直接攻击可暴击，初始暴击率0、倍率1.5；召唤物攻击只有拥有明确赋予召唤暴击的心法才暴击。DOT、反伤、二次爆发不暴击、不再叠加原始状态、不再触发击杀连爆。例外必须逐项写出允许的触发边，不能用“所有伤害”默许递归。

同一敌人每次死亡只发一个击杀事件。状态到期、死亡、实体回池、离局时清理账本。选卡随机、战斗随机、刷怪随机分开；不因粒子减少而改变伤害或抽卡。

### 通用控制和生存上限

- 一般减速取最强项，不相加，普通怪最多50%，Boss最多10%。
- 普通怪硬控（冻结、麻痹、束缚、恐惧）单次不超过0.8秒；同目标硬控结束后2秒内对所有再次硬控免疫。精英持续时间减半，随后免疫3秒。Boss免硬控，用对应至多10%减速替代，持续不延长超过技能原定值。
- Boss免强制吸附、击飞与恐惧位移；精英强制位移距离至多普通怪的25%。不自动取消Boss已有危险预告。
- 同类易伤取最大，跨来源合并后最高20%；降低敌人输出最高20%。两者都不得复利叠乘。
- 所有常态减伤含职业、心法、丹药按减伤百分点相加后上限60%，最终承伤倍率=1−封顶后的减伤率；短时特殊状态最高75%，必须明确持续和空档，不能靠冷却缩减常驻。
- 所有在身护盾合并上限为最大生命的30%，不叠成无限盾；普通护盾不反伤。持续回复合计最多最大生命的1%/秒，不限制原章节破境满血和独立掉落治疗。
- “吸血”默认不基于怪物最大生命或过量伤害，须给固定每跳恢复值和每秒上限；没有可造成有效伤害的目标就没有回复。
- 此处常态减伤上限比现行Stats的0.25最低承伤更严格，是**新职业规则的待实现改动**，不是声称旧实现已经满足。旧规则存档和经典模式不跟着改。

## 5 范围 爆发与屏幕

“全屏”是演出描述，不是代码上的无限命中。每次施放必须固定世界中心与边界；常规大型区域最长边不超过760u。镜头移动不搬运已落地技能，也不多次伤害屏外无关敌人。

DOT或阵地使用半开时间区间：生成时可首跳，之后`t < expiresAt`时才跳；最后一帧不额外补一跳。长帧需结算跨过的所有合法模拟时刻，暂停不计时间。

控制目标必须在实际可命中范围内筛选。没有合法目标的主动攻击保留就绪，不生成伤害对象、不消耗周期。常驻护体、地面布阵、召唤待机按各自条目处理，不能反复重置冷却刷状态。

玩家特效在敌弹和敌方预告下方。不开全屏纯白闪光，不用一百个伤害数字对应一百把装饰飞剑。碰撞半径与巨型法相、龙影等视觉尺寸分离，明确画面不会赋予额外碰撞体积。

## 6 工程与容量

初版仍以当前敌人硬上限200、玩家弹体150、敌弹60为压力边界。解析形状、DOT账本、召唤物拥有独立预算，不能挤掉敌弹以维持玩家爽感。

建议跨职业采用同一份数据契约，而非先实现七套空基类：

`skillId / classId / branchId / unlockTier / type / ranks / targetRule / timing / hitRule / statusRule / evolution / renderBudget`。

只在剑修真实实现出现共性时抽出公共几何、施放计时和状态账本；不提前做召唤寻路、法修元素反应或联网队伍系统。

普通状态账本按敌人UID存储；同目标同状态来源合并，不为每层新建Cocos节点。阵地与召唤容量、刷新策略由职业条目明确。若表现预算不足，只减少粒子，不能丢实际伤害；若逻辑实例到上限，必须使用明确的最老替换或延后规则，不能随机吞施放。

## 7 评审与验证

设计评审分三关：玩法有差异、参数与事件规则闭合、当前版本能够承担。设计文字通过不等于数值通过。

剑修按现有17号详细稿先实现核心闭环；后续职业进入开发前必须把端点表展开为完整五档数据并补齐自动化样例。每一职业至少有：对单、密集群、快速怪、远程压力和Boss移动场景；一个明确的强项以及一个可感知弱项。

任何职业不能以“前期弱”作为前60秒无法可靠杀怪的理由。用共同怪物和同局外属性对照，分别统计击杀、受伤、走位负担、成型时刻与缺关键卡时的可玩性。

剑修新旧各600局＋300留出局的计划沿用17号稿。其他职业尚未实现，不伪造模拟胜率；正式立项后再定义各自同规模或更小探索批次。至少验证手机上能分辨角色、敌弹和下一步安全移动方向。
