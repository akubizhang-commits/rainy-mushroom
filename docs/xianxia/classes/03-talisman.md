# 符修：蓄符与引爆（待评审提案）

本稿依据 `../reports/all-classes-2026-10-26/reference-extracted.txt` 的符修十二技能重组，不代表现行能力或平衡结论。七职业均可评审，开发仍先做剑修；本稿不要求改运行时。

统一遵循 [全职业技能共同规则](00-shared-rules.md)。以下技能的较低限制保留：减速取最强项，普通怪总上限50%、Boss总上限10%；同类易伤取最大，跨来源合并易伤及敌人输出降低各最多20%，不复利。常态减伤上限60%、有明确持续与空档的特殊状态75%，护盾合计最多最大生命30%，持续回复合计最多最大生命1%/秒。本文没有硬控；后续若加入，普通怪单次最多0.8秒、结束后免疫2秒，精英持续减半、免疫3秒，Boss免硬控，仅可转成不超过原持续时间的至多10%减速。

## 定位与共同规则

玩家用移动将已挂符的敌人聚拢，再让雷击、陷阱提前兑现符印。强项是短时群体爆发，弱项是符印过期和爆发后的空档；没有手动引爆按钮、灵力条或永久阵地。原方案未规定符修耗蓝，本稿统一以冷却和有限符印控制产能，不新增消耗资源。

四种基础功法、三种心法各五级；最多装备四功法、四心法，开局火符Lv1。四种进化均单级、替换父技能，一局最多两种。基础攻击系数以开局A=100为标尺，A随正式伤害属性变化，不再重复乘境界倍率；距离用逻辑单位u。表内“甲→乙”为Lv1/Lv5，Lv2/3/4按 `甲+(乙-甲)×(等级-1)/4` 线性插值，固定项不变；距离取整到1u、时间到0.01秒、百分比到0.1个百分点、系数到0.01A，均四舍五入；整数数量向下取整，Lv5到达端点。倍率运算保留精度，最终伤害统一整数舍入。

所有冷却从施放开始计算，乘统一冷却系数C，C最低0.5；延迟、符印寿命、状态时长不乘C。无合法目标保留就绪，不积攒连发。目标按距离、实体ID排序；全部使用模拟时间，暂停冻结，离局清空。普通升级不重置计时，已有投射物保留发射时等级；进化清除父技能在途物并等待新技能完整冷却，不产生清除伤害。

## 四种基础功法

| 功法 | 自动触发与目标 | Lv1→Lv5种子参数 | 数量与命中限制 |
|---|---|---|---|
| 火符 | 320u内最近敌人，发射直线符纸，速度400u/s，行程360u；碰到首敌爆开 | 直击0.60→0.90A；冷却1.6→1.2秒；爆炸半径45→65u | 同一爆炸各敌仅一次直击伤害并尝试挂符；最多8张在途，满额保持就绪 |
| 引雷符 | 320u内优先符印最多者，再按距离；锁定敌人，0.25秒后在其当时位置落雷，死亡则取消 | 直击1.00→1.60A；冷却3.2→2.4秒 | 只击该目标，随后消耗其符印；不挂新符、不溅射直击 |
| 追踪符 | 360u内优先无印敌人，符纸速度300u/s追踪；目标死亡不转移 | 直击0.30→0.60A；冷却1.4→1.0秒 | 命中挂符；每张寿命2秒，仅命中一次，最多8张在途 |
| 符箓陷阱 | 260u内有敌人时留在施放时脚下；0.5秒后武装，敌人进入60u触发 | 爆炸1.20→2.00A；冷却6→4.8秒；伤害半径90→130u | 寿命5秒，最多2枚，满额保留就绪；各敌受伤一次，再按距爆心排序消耗最多6名存活敌人的符印 |

火符和追踪符每目标共享0.4秒挂符间隔，每次一枚，最多三枚；每枚独立存活4秒，过期直接消散。第三枚成功挂入立即消耗三枚。引雷符、陷阱可以提前消耗一至三枚。挂印之前先结算直击，已死目标不挂印；伤害事件按施放序号、目标ID处理。

消耗时先原子移除符印，再以宿主当时世界位置为爆心：每枚造成0.35A、半径60u的符爆。三枚合为一次1.05A伤害事件，不按三次触发心法；不同宿主可以重叠命中，但每目标每模拟步最多承受三处符爆，按宿主ID取前三处。符爆读取消耗时A，不暴击、不挂印、不触发其他符印、不连锁引爆陷阱。宿主死亡清除余印且不爆炸，避免击杀递归。基础与进化的直击按共享规则可暴击，初始概率0、倍率1.5，使用独立战斗随机；暴击不会增加挂印或消耗次数。账本使用实体UID，不使用可复用的对象池槽号。

## 三种心法

| 心法 | Lv1→Lv5累计效果 | 上限与作用对象 |
|---|---|---|
| 护身符 | 最大生命+4%→12%；每10秒启动一次持续2秒的恢复，合计恢复最大生命0.5%→1.5% | 匀速每秒0.25%→0.75%，与其他持续回复合计最多1%/秒，不积存溢出治疗；升级不立刻回血，暂停冻结 |
| 封魔阵符 | 符爆命中后减速12%→20%，并使所受基础/进化直击伤害+3%→7%，均持续1秒 | 先结算本次符爆再附状态；同目标效果不叠加、不刷新，结束后2秒免疫再附；Boss减速最多8%，易伤最多4% |
| 灵墨凝意（新增） | 符印寿命+0.4→1.2秒，符爆伤害+4%→12% | 不加印数、不缩挂印间隔；只放大符爆，不放大技能直击 |

封魔的减速与易伤同时开始，均只取最高值；不影响符爆伤害，因此不会自我放大。取消原封印圈常驻形态，以爆符后短暂圈线表达余效。护身恢复不能产生攻击或治疗触发链。

## 四种单级进化

每项必须同时满足：**表列父技能Lv5＋指定心法Lv3＋已提交等级appliedLevel≥19＋局内模拟时间≥360秒**。待选目标等级不等于已提交等级。

| 进化与配方 | 替换后规则 |
|---|---|
| 万火符阵＝火符5＋灵墨凝意3 | 每2.4秒向320u内最近目标施放三连符，间隔0.2秒，各0.75A、半径80u；初始锁定世界位置，0.3秒预告后第一爆。取消原火符。三爆可分别挂印但仍受0.4秒间隔限制，无额外燃烧DoT；一轮总直击2.25A |
| 天雷符海＝引雷符5＋护身符3 | 每4秒锁定320u内优先多印目标；0.25秒后先命中，再沿120u邻近敌人链跳，最多3个不同目标，每跳1.60A并消耗其符印。跳间0.1秒，死亡目标跳过、不补名额；单Boss只命中一次，无麻痹 |
| 九幽封界＝符箓陷阱5＋封魔阵符3 | 保留武装、寿命、容量规则；冷却5秒、爆炸2.60A、半径160u并消耗最多6名目标符印。爆心留2秒封圈，每0.5秒尝试施加封魔心法状态，不造成额外伤害；最多2圈，第三圈替换最早者 |
| 万符归一＝追踪符5＋灵墨凝意3 | 保留追踪符Lv5发射；另每6秒在角色周围400u搜寻带印活敌，按距离/ID选最多12名，0.3秒预告后消耗各自余印，爆心仍为各宿主当时位置。预告不冻结符印寿命，死亡或印已耗尽者跳过；无合格宿主保持就绪 |

天雷链路在首击时锁定名单，只选距上一目标位置120u内未选活敌；后续不重寻，避免无限传导。所有进化直击可用封魔易伤，只有明文挂印的技能挂印。万符归一的六秒脉冲独立于追踪发射，不受C影响，取得时等待完整周期；共振、符爆及封圈绝不再次启动脉冲。

## 选卡、可读性与验证

阶段池累积开放：练气（目标等级1–9）为火符、追踪符及三心法；筑基（10–18）加入引雷符、符箓陷阱；金丹（19起）保留旧池并开放满足条件的进化。金刚诀、聚灵阵从练气作为通用心法候选，占同一四心法槽并遵守共同上限。

首次升级固定展示**追踪符Lv1、火符Lv2**：早期只剩一张合法新功法，第二张按共享协议回退为初始功法升级，形成分散挂印与强化火符两个方向；第三张从其余合法候选抽取。其余权重、破境成长、连续两轮未展示升级/新阶段功法的保底及优先级完整沿用共享规则，同轮最多一丹药。满槽排除未学同类，满级排除升级；进化合格时下一轮保底一项，多项按上次展示位置轮换，选满两项关闭进化池。拒绝保留资格，重绘不重抽，无合法成长沿用治疗/资源兜底。

双进化示例：火符补四级4次，雷符获得并升满5次，灵墨与护身各三级6次，进化2次，追踪与陷阱各一级2次，共19次。Lv1→27的26次选择余7次；进化必须已提交Lv19且满360秒，最早在升Lv20的选择出现，不承诺每局必成。27后仍可选卡但境界属性封顶。

敌头最多三张小符，消耗前短促亮边，封圈低透明且不遮敌弹；不增加常驻灵力栏。评审后最小验证是火符＋引雷符：检查三印阈值、同帧消耗、宿主死亡、暂停、单Boss链跳、12宿主爆发的三处命中上限。数值仅为种子，需比较聚怪收益、无小怪Boss输出和四秒印损失，不能凭规则检查声称平衡通过。
