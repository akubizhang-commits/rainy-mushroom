# 手持剑换装与挥剑动作（修订方案）

本方案按用户最新要求，覆盖23号文档中“装备替换脚下御剑”的路线。

## 已确认边界

- 脚下御剑保持当前外观、比例、脚位与悬停方式，不随装备或品质变化。
- 装备切换改变手持剑。素问/青霄/镇岳的轮廓语言仍适用，但用于手持武器。
- 增加挥剑攻击表现，保留已确认角色脸、发型、服装、中性特征和比例。
- v8分离原剑仅保留为技术试验，不再作为“更换脚下剑”的后续任务。
- 当前还没有手持剑母图或挥剑帧；本次更新方案/提示词，不声称已实现动画。

## 素材是否需要补充

需要补充能看清握剑手、肩肘和衣袖关系的姿势参考。现图下垂手是张开的，另一只手结印；只往手边贴剑、旋转整条手臂会显得僵硬。先请用户用已有网页版图像工具生成一张“持剑待机母图”，视觉确认后再生成三张攻击关键姿势。不要求现在做长视频、八方向或每把剑整套人物图。

可以先用同一把简洁银白参考剑明确握持结构，制作资产时再分离该剑，补绘被遮挡的小范围手指与袖口。需要人物/手臂/近侧手指/剑的合理遮挡，不能仅把剑置于人物最上层。

若工具把脚下剑一起修改，或重新设计了脸/身材，该图不作为后续动作参考。背景编辑若影响角色，优先保留角色质量，再局部处理背景。

## 待机图确认后的三张关键姿势

以下三个追加段分别生成一张单图；每次都上传同一张认可的待机母图，使用上述身份/两把剑/背景约束，不把上一张生成结果继续传递以免累积漂移。画布、人物比例、头顶和脚位一致；手持剑挥动所需留白沿用待机画布。

### A · 蓄势

> 将同一角色改为轻度挥剑蓄势。持剑侧肩膀和手肘自然带动手持剑收向身体侧上方，剑尖斜向上，手腕保持自然，护手与手指关系不变。胸廓轻微转动，视线朝原图脸部所朝向的攻击侧；另一只手微收辅助平衡。双脚仍原位踩在同一把脚下御剑上，不抬脚、不换站姿、不倾倒。衣袖随手臂抬起，不穿过脸、头发或剑刃。单一清晰姿势，无残影。

### B · 出剑

> 将同一角色改为向原图脸部所朝向一侧的斜下方挥剑的出剑关键姿势。持剑侧肩膀带动上臂、手肘适度伸展、手腕和剑柄方向协调；手持剑位于身体前侧，剑尖指向攻击侧的斜下方，清楚表现有控制的斜劈。身体只小幅配合，不改变双脚位置和脚下御剑。不让手臂完全锁死，不让剑刃切过自己的脸、衣服或脚下剑。保留清晰手指、手腕、袖口结构，无运动模糊、剑气或光效。

### C · 收势

> 将同一角色改为挥剑之后收势的关键姿势。持剑手略低于出剑姿势，手肘自然弯曲回收，手持剑朝侧前下方，肩部逐渐放松；袖口和衣摆只有轻微跟随，形成能回到原待机姿势的自然过渡。保持同一脸型、发型、身材、双脚接触点和完全相同的脚下御剑。不要画第二个动作或残影。

四张图是动作结构参考与关键帧素材，不是自动保证流畅的最终动画。后续需对齐画布/肩肘腕、修补遮挡，再用小范围关节插值或补中间帧验证；不能只做四张图的透明度交叉淡入淡出来掩盖错位。

## 分层与接入

优先保留固定下半身/脚下剑为公共底层，选定关键帧的上半身及持剑手为动作层；手持剑独立挂在手腕握持点。最终层序按实际姿势确定：远臂/身体/手持剑/近侧手指及袖口遮挡。需要绕到身体后侧的招式暂不制作，避免过早增加前后切层。

角色只有一个装备武器ID；手持剑、整备预览和攻击飞剑可共享该ID的设计语言，但脚下御剑读取固定默认资源。已经认可的脚下剑不能被品质、试穿或自动瞄准重置替换。挥剑不增加碰撞伤害或额外攻击次数。

当前剑气斩已有前摇与锁定方向。完整挥剑优先绑定剑气斩：前摇进入蓄势，真实出手tick进入出剑，再收势回待机。攻击飞剑若一次齐射多把，只触发一次轻量起手，不每颗飞剑重播一次大幅挥砍。没有实际攻击不空播，不擅自改变当前冷却和伤害时序。

剑气斩能瞄准移动方向以外的敌人：表现朝向使用本次锁定目标方向，不能根据移动输入反向挥剑。第一版只验左右镜像；上/下方向的手臂透视不能靠整个人物任意旋转伪造，需在实际画面验证斜侧姿势的可读性，不宣称四方向动画齐全。

## 验收与下一步

先验一张持剑待机母图：原人物和脚下剑不变、手真实握柄、两剑无穿插、全身完整、小尺寸手持剑清楚。通过后才做A/B/C；再验肩肘腕连续性、握点不滑动、衣袖遮挡、左右镜像和攻击出手时序。暂不批量生成三把剑各自的人物动作。
