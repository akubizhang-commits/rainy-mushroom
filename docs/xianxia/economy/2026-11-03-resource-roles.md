# 点眷、灵石与装备分解

## 资源职责（2026-11-03 用户确认后的现行规则）

| 资源 | 来源 | 用途 |
| --- | --- | --- |
| 点眷 | 新档赠送1000；第3、6、9层首次通关各1000，总计4000 | 正式机缘抽奖：单抽100、十连1000；付费商品以后确定 |
| 灵石 | 战斗掉落、指定首通、装备分解、材料出售 | 经卷、研习、普通丹药、购买装备、炼丹和炼器 |
| 配方材料 | 掉落与抽奖 | 指定炼丹、炼器配方 |
| 功法点 | 升级、突破、指定首通、研习 | 普通功法加点 |

点眷初始为1000，自动到账，可直接进行一次正式十连，也可拆成单抽；保存和重载不会重复赠送。普通波次、Boss、重刷、分解、出售均不产出点眷；免费试玩十连已停用。两种货币不互兑，付费商品暂未接入。内部持久化字段仍叫 contribution，显示名称统一为“点眷”。

## 分解与普通商品

武器、法衣、灵戒仅返灵石，不返点眷或材料。原装备价格的灵石和贡献数字合并为灵石费用；例如凡器商店24灵石，分解9灵石；法器下品配方60灵石，分解24灵石。返还按同阶同品质标准获取费用的40%向下取整，不追踪该实例曾支付的历史金额。任何一套配装正在使用的装备不能分解；容量不足或保存失败保留装备，重复提交不会重复到账。

丹药购买价和炼丹服务费的数字保持原值，改为灵石结算；战斗内缺少突破丹药时的直接购买也使用灵石。

## 审查结果与边界

旧版开局300、单次九层波次/Boss合计1090、首通450，共1840贡献，且重复通关可无限累计；另有独立的免费试玩十连。现行首通预算为3000点眷，另按用户最新要求提供新档1000点眷，共4000。开发调试加资源功能仍保留，普通商店实例禁止该指令，不计入正式经济。

正式极品概率仍为3%，最多40抽保底；40抽预算若全部用于同一档奖池，可覆盖一次极品保底；跨档抽取分别计数。没有改动奖池概率和心愿机制。没有玩家耗时数据，本次不推断每小时收入或实战难度变化。开局赠送资源可进行一次正式十连；初期装备和突破补给仍可由灵石渠道承担。

保存格式升至59。按开发期约定，旧版本宗门通塔存档重置，不迁移旧贡献；其他模式和账户不受影响。
