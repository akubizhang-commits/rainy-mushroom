# Q版剑修与御剑滑行：替代写实步态的方案

> 后续用户提供了明确角色参考：造型改用银白高马尾、白外袍/浅蓝内衫、中性面容与参考图比例，见[当前角色基准](15-silver-character-reference.md)。本页黑发、短袍和约三头身仅保留为此前提案，已不再约束制作；御剑滑行方向继续保留。

2026-10-26 · 造型与表现原型阶段

## 这次改什么

用户否决v4人物与步态的美术质量。原有测试只证明贴图、关节、暂停和加载逻辑正确，不能证明人物好看、走路自然。停止继续扩展这套写实分层步态。

目标是让手机画面里的主角一眼可辨；学会御剑飞行后，以站剑滑行代替大部分地面步态。以用户认可的[原参考](../../design/xianxia-character-2026-10-26/index.html)为造型依据，保留宽袖、交领、蓝白袍服和黑发束髻，而不是继续沿用后来的窄袖护腕裤装。

## 造型定向

| 部位 | 本轮要求 |
|---|---|
| 比例 | 约3头身；重新设计头身和服装，不压扁原图、不只放大头 |
| 头脸 | 黑发束髻、简洁刘海、大而清楚的面部；保持少年剑修气质 |
| 服装 | 月白交领、雾蓝宽袖短袍、深蓝腰带；减少碎装饰和细线 |
| 识别点 | 发髻、宽袖轮廓、蓝白大色块、小面积暖金剑穗 |
| 腿脚 | 短靴与袍摆留出间隙，不能被衣服吞没；站剑时双脚确实踩在剑面 |
| 视角 | 首张采用三分之四视角，使脸、胸前色块和脚下剑都可见 |
| 不接受 | 多手多脚、站姿漂浮、剑从脚踝穿出、原图机械缩放、不同角色混作方向帧 |

优先审阅同一人物的站立与站剑两个姿势。手机约40–52 CSS像素高度的画面和放大图都要看，不能只在大图里验收。

## 飞行如何解锁

现有“御剑术Lv1”开局自带，作用是飞剑攻击修正；它并不是载人飞行系统。本轮提案将两者区分：

- **暂定在筑基一层解锁御剑飞行表现**，条件为已提交的`appliedLevel >= 10`，不是尚未选卡提交的经验等级。
- 结合现有破境提示展示一次“御剑飞行已领悟”，不增加常驻按钮或HUD栏位。
- 解锁后自动站剑悬停、滑行；松手停在原地悬停，不每次停下都下剑。
- 现有御剑术的穿透、剑数和进化条件保持原含义。

这是待验证的解锁提案，尚未写入游戏。若玩家在筑基前停留时间太长，应调整飞行教学的时机，而不是为了尽快展示美术偷偷改经验曲线。

## 滑行动作的最小实现

角色与脚下剑作为一组：腿和剑面保持相对稳定。地面阴影对准真实角色坐标，身体与剑可在视觉上离地约6–10u。现有受伤位置和碰撞圆仍有明确的地面投影。

| 状态 | 表现 |
|---|---|
| 悬停 | 约1–2u的缓慢起伏；衣摆与剑穗小幅随动，不上下颠簸 |
| 起步 | 剑尖和身体向移动方向轻倾，约3–5°，短暂加长剑尾气流 |
| 移动 | 主体稳定滑行；气流随速度变化，不靠腿反复摆动表达速度 |
| 转向 | 朝向带死区，细小摇杆抖动不翻转；不延迟真实角色移动 |
| 停下 | 原地约120–180ms回正，剑尾气流收短；不继续拖行真实坐标 |
| 暂停/升级 | 所有悬浮、衣摆、尾流表现一起冻结 |
| 受伤 | 保留当前变色/无敌反馈；不新增摔落、免伤或强制位移 |

飞行外观不自动附带加速、穿怪、免伤、越障或扩大拾取范围。若以后要加入这些能力，需要另立规则和数值测试，避免“看着飞起来就能躲避接触伤害”的歧义。

## 不能被飞行掩盖的工作

1. **解锁前的地面移动**仍要使用Q版自己的短步态，不再接回已被否决的v4写实人物。需要少量真正画好的关键姿势；若尚未合格，就不要宣称角色替换已经完成。
2. **朝向**先证明一个侧向滑行好看，再补正/背视角。左右镜像不能冒充八方向。
3. **施法**先让飞剑从独立特效层发出，主体维持稳定；后续增加一个短施法姿势，不用全身摇摆代替动作。
4. **造型验收**先于图集扩量、关节拆分、生产接入。姿势数和自动化通过数不是美术通过标准。

## 本轮交付与下步边界

先交独立Q版候选与站剑/滑行视觉验证。真实素材不合格就列出问题，不以程序几何人物或旧图拉伸作为成品。暂不把未经视觉确认的候选换进游戏，不改存档、伤害、角色移动或敌人规则。

进入生产前应确认：同一角色身份稳定；原尺寸可辨；双脚与剑面贴合；转向、悬停和停止不显机械；解锁前后衔接清楚。随后只接一条完整路径——地面移动 → 筑基提示 → 站剑滑行 → 停止/暂停/受伤。

## 本轮试画结果

使用本机已有ComfyUI与Counterfeit模型，未安装模型、未调用付费API。原参考用于识别配色、衣型与人物特征；本轮两张是重新生成的比例探索，不是具有身份约束的原图编辑。

- 第一张：Q版比例明显，但偏成少女形象，额外生成第二个角色，脚部不完整。拒收。
- 第二张：少年轮廓和双靴更清楚，但变成白发白衣，缺少原参考的黑发髻，背景还带有大幅特效。只能用于比例讨论，不能作为角色成品。
- 两次均未满足人物特征，因此停止该生成路线，不继续扩展动作或站剑图，不接入游戏。

原图、提示词、实际工作流和拒收理由保留在[试画目录说明](../../design/xianxia-character-2026-10-26/v5-chibi/README.md)。当前本机工具能生成一张Q版图，但尚未证明能稳定画出指定的同一角色；这一限制必须在下一轮造型生产前解决。
