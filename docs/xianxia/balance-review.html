统计口径与边界

  • 通关率 = won 局数 ÷ 该筛选下全部有效局数；败局、超时均留在分母。flee 目标为 30%–60%，spore 目标为 ≤80%。本页只判这两个指定门槛，不据此宣布整套平衡验收完成。
  • Boss 击败耗时 = bossDefeatSec − bossSpawnSec，缺少任一时刻的局不进入其中位数。胜利时长取胜局的 survivalSec；界面分钟数四舍五入到秒，判定使用原始数值。
  • >720 秒和超时是两个不同指标，可以重叠。超时以 outcome=timeout 为准，不用显示时长反推。计数为 0 也完整显示；无胜局或无 Boss 击败记录时显示“无样本”，不当作 0 秒。
  • 对局身份由版本内的 seed + move + pick 组成。重复身份只保留第一条并显式警告；报告汇总与明细不符时标记“数据待核对”，不展示达标结论。中位数、比例均从载入的明细计算。
  • 两版只读取首轮各一份报告。额外批次、复跑及 B 版留出集报告另列；不汇入本页，不把策略复用、配对版本或重新读取当成新的独立样本。本页不代表留出集验证结果，也不推断真实玩家通过率。
