# 全职业装备详细设计：整套30%预算

> **新版审阅入口：** 用户要求普通铁剑起步、每品至少3把及稀有特效，已review本稿并形成[40号武器设计稿](sect-tower-v1/40-weapon-tiers-and-traits-proposal.md)（待审，尚未接入）。本文的18%输出、禁止吸血/暴击及兑换印记等内容属于历史设计，不能直接用于当前开发；现行30%与双币寻器规则以已确认需求为准。

2026-10-26 · 详细设计评审稿v3。用户已授权展开七职业装备与数值设计，要求抑制数值膨胀。**本稿完成设计不等于批准全部职业同时开发；首个可玩实现仍为剑修。**

## 关键裁决

品质已按用户确认更新：**绿下品、蓝中品、紫上品、金极品**；“强化”对玩家统一称“淬炼”。四档普通抽概率40%/35%/20%/5%，本次新增下品不提高极品上限。教学仍赠中品基础装。


30%适合作为保守的整套预算上限。不能让武器、法衣、佩饰各加30%，也不能只统计面板攻击而漏掉攻速、召唤数量和护盾。

采用更留余量的首期方案：

| 指标 | 满品质＋满淬炼整套上限 | 比较对象 |
|---|---:|---|
| 装备基础输出 | +12% | 相同职业、境界、心法、道基、丹药，无装备修正 |
| 武器条件特性 | 同装备加法项最多+6个百分点 | 仅满足特性条件的伤害事件 |
| 合计输出 | **最多+18%** | 不新增攻击次数或频率 |
| 最大生命 | **最多+8%** | 相同条件的无装备最大生命 |
| 静态输出×有效生命预算 | **最多+27.44%** | 1.18×1.08=1.2744 |
| 冷却、攻速、暴击、弹数、宠物数、吸血、控制、范围、经验增益 | **0** | 装备不提供 |

27.44%是设计的静态预算，不是对每局胜率、清场速度或存活时间的数学保证。斩杀阈值、击杀触发和走位会造成非线性收益，仍须实战对照。不会在游戏里通过动态增怪、削减实际伤害或偷偷改变掉率“凑30%”。

## 相比20号初稿的变化

- 飞剑最大基础伤害从20%降为12%，条件特性从8%降至最多6%；它们相加，不相乘。
- 法衣统一为有限生命加成，移除装备回复、减伤、护盾；佩饰改为展示型，不提供拾取、重抽或额外伤害。
- 装备只改变已存在事件的数值，不增加触发链、宠物数量、DOT跳数、暴击或控制。
- 道基原权益保留；新装备使用单一独立受限修正入口，替代20号稿“并入旧道基加法项”的建议。这不是新增多个乘区，每次伤害最多应用一次装备修正。
- 三槽保留，但只有武器、法衣可淬炼。佩饰不卖数值、不收淬炼钱，稀有度只代表展示效果。
- 由剑修十二件扩为七职业28种武器＋4件通用法衣＋4件通用佩饰，合计36身份。共用衣佩可跨职业使用，不重复抽七套。
- 抽池按职业＋槽位选择，只展示已开放职业；不让玩家抽到尚不能使用的职业武器。法修不拆八个元素抽池。

## 为什么顶级装备仍值得拿

收藏目标来自不同武器的方向、外观和稳定的小幅成长，而非千倍伤害。中品装已有完整特性，极品装不解锁必要进化。满淬炼下，同特性的金武器相对蓝武器，在特性触发时为1.18÷1.14≈1.0351，连续模型中仅约3.51%输出差距；基础无条件连续差距约3.70%。实际整数伤害按严格出口计算，不能把该比例视作每击固定差距。

如果玩家觉得这个差距不值得追求，先改善外观、目标收藏和章节挑战，不先把加成翻倍。也接受玩家收集到喜欢的组合后阶段性毕业，后续回归靠新章节与横向装备，而非不断新增更高颜色。

## 交付与开发顺序

本轮交付是36身份设计、属性与概率计算、数据/交互规范和分工。没有替换角色或怪物，没有写入正式存档。

第一实现片段：剑修素问、青霄、镇岳三剑（`eq_sword_suwen`、`eq_sword_qingxiao`、`eq_sword_zhenyue`）＋通用基础衣佩 → 测试档抽取/兑换/淬炼 → 同种子比较伤害与存档中断 → 第二章波次实验。三件测试武器是明确标注的测试池；正式四选一池需剑修四件全部可用后才开放。其他六职业方案保留，按职业逐一实现和验收。

数值审阅后不直接宣称留存提升。验收目标是玩家看得懂装备差别、能尝试不同搭配、基础装备能通故事关、顶装不会把同章所有威胁抹掉。
