## 评审结论

采用“七职业、法修八分支、每局单职业”的结构。职业差异来自玩家如何移动、如何创造有效伤害，不靠把同一套攻击换成七种颜色。保留现有单指移动与自动攻击，把参考中的终极技能改为本章可达的进化，避免等到尚未开发的化神、渡劫阶段才体验职业高潮。

剑修沿用上一轮六功法、四心法、四进化的细化方案；本次把它放进全职业框架，补齐职业边界。尚未因本评审稿更改现有试玩技能。

## 3 七职业真正不同在哪里

| 职业 | 玩家主动创造的优势 | 伤害组织方式 | 弱项与反制 | 不应该变成 |
|---|---|---|---|---|
| 剑修 | 拉直追兵、保持剑圈距离、调好斩击方向 | 飞剑点杀＋穿透＋短爆发 | 侧后方包围、爆发空窗 | 以冰雷为主的通用法师 |
| 法修 | 按所选元素控制距离和敌人状态 | 单元素弹道＋状态＋领域 | 分支有各自短板，不能一系全能 | 八色同一个火球 |
| 符修 | 先布置或附着，再让敌群一起进入引爆条件 | 可读的储备和有限连锁 | 来不及附符的高速敌人、引爆后空档 | 无限自动连爆 |
| 御兽师 | 移动调整兽群目标与回防位置 | 有数量上限的持续协同 | 转火延迟、召唤恢复空窗 | 百只独立AI和全屏视觉噪声 |
| 阵法师 | 在可守位置建阵，把敌人引入联动区 | 固定区域与有限连线 | 不断搬场、远程逼位 | 永远跟随玩家的光环 |
| 体修 | 贴近短爆发，在护体结束前脱离 | 短距离直接攻击＋有限防御 | 远程交叉火力、长期站桩 | 永久免伤自动冲刺 |
| 邪修 | 保持状态覆盖，在积累后结算或传播 | 持续削弱＋受限爆发 | 新目标冷启动、回血有上限 | 无成本无限吸血 |

“强项”必须能在同一测试场景下看出对应收益，“弱项”必须允许玩家通过移动或选卡改善，不是随机必死。

## 4 法修八分支评审轴

| 元素 | 首要特征 | 必须限制 |
|---|---|---|
| 火 | 扩散燃烧、集中区域持续伤害 | 燃烧层数、扩散代数、过量伤害不重复传播 |
| 水 | 波动推退、移动中的范围控制 | 不击退Boss、不永久搬运怪物 |
| 木 | 布置缠绕、稳定留场 | 控制免疫窗口、不能永久束缚 |
| 土 | 延迟落点、重击封路 | 落点可以落空，不自动追着移动Boss |
| 雷 | 有限目标跳链、快爆发 | 同链不重复命中、无怪可跳时不折返刷Boss |
| 冰 | 逐步积累冻结、制造离场窗口 | Boss不冻结、普通怪有免控间隔 |
| 风 | 沿移动方向切割、机动收益 | 无强制位移，移速增益不失控 |
| 金 | 精确穿透、集中打击标记 | 无防御系统时不虚构“无视防御”收益 |

第一次开发法修时只选择一个分支做垂直切片，再逐个复用成熟机制。文档写八分支不等于一次性制作八套特效、资源与测试。

## 5 技能池与成长审阅要点

统一4功法、4心法、最多2进化；一个技能不能同时作为三个不同层次的独立卡稀释池子。原文的基础—进阶—终极名称可以落为升级形态或进化，但每个原名均需在对应职业文档说明去向。

例如体修“裂地拳”并入崩拳中期形态，开山碎岳成为进化；这样保留成长画面，又不要求玩家同时占用三个拳法槽。御兽师的狼群、兽潮也须明确是新召唤、升级形态或替换，不能把同一数量奖励重复发放。

优先评审：

1. 开局技能能否稳定打到敌人，初升两项是否带来不同打法。
2. 同一路线的基础、心法、进化能否在26次选择内达成。
3. 已学升级是否持续可抽；满槽不再抽到无用新技能。
4. 法修所选分支是否能独立完成一局，不依赖不存在的异元素配合。
5. 大招是否改变战斗节奏，同时保留敌方预告和移动意义。

## 6 首发只做剑修的任务边界

### 首发必须完成

- 新御剑术、剑气斩、万剑诀、一线天、剑影分光、两仪剑阵六种基础功法。
- 剑心通明、青萍剑意、剑骨、剑开天门四心法及对应状态/事件限制。
- 四条进化、统一进化前提和每局两种上限。
- 剑修选卡池、保底、卡片差值文案、暂停技能详情。
- 银发剑修与已通过的站剑滑行保持一致，补剑技特效的可读性。
- 不改经典技能表和旧存档，不让旧御剑被动与新御剑攻击重复加成。
- 开局、升级、暂停、死亡、重开、资源回退与手机负载验证。

### 明确不在首发开发

职业选择系统的七职业可玩入口、八元素切换或反应、召唤物AI、尸傀、阵法链接、体修护盾反伤、蓝条、联机队伍、新章节境界和全套新Boss。它们仅保留设计接口说明。

### 可并行但需明确归属

| 工作包 | 主责 | 前置 | 验收交付 |
|---|---|---|---|
| S0 冻结数据与规则 | 系统设计＋数值 | 本次评审 | 版本化剑修表、目标/命中/状态契约 |
| S1 核心战斗 | 玩法工程A | S0 | 御剑＋弧斩两技能完整路径 |
| S2 选卡与界面 | 玩法工程B＋UI | S0 | 合法候选、保底、卡片增量；先用明确测试数据 |
| S3 剑技美术 | 技术美术 | S0 | 小尺寸飞剑/弧斩/直线/阵眼样片 |
| S4 其余功法和心法 | 玩法工程A＋状态工程 | S1命中契约稳定 | 六基础＋四心法，事件归因完整 |
| S5 进化与合并 | 集成工程 | S2/S3/S4 | 四进化与完整新局，不混旧技能 |
| S6 数值与体验 | 独立QA＋数值 | S5 | 同种子比较、留出验证、实际移动体验 |

只有S1是第一段可玩验证目标，不能把它标成“剑修全量重构完成”。其他职业开发不得偷偷进入这些包。

## 7 后续职业顺序

参考文档顺序保留为建议：剑修 → 法修 → 御兽师 → 符修 → 阵法师 → 体修 → 邪修。每个箭头都是一个独立立项决定，不是本轮自动执行队列。

每个新职业开始前，先复核当前章节敌人和已经成熟的公共机制；重新校准本文试验值，不直接复制数月前参数。只有一条该职业的可玩完整路线通过，再扩另一流派。

## 8 本次评审需要决定什么

| 议题 | 本稿建议 | 确认后影响 |
|---|---|---|
| 战斗操作 | 单指移动，全技能自动 | 不新增操作栏；体修不抢玩家移动 |
| 单局可达范围 | 本章金丹进化，胜利凝婴 | 不为后期技能拉长单局 |
| 构筑规模 | 4功法＋4心法，最多2进化 | 槽位、卡池、HUD维持可控 |
| 法修元素 | 开局锁单元素，不跨系抽卡 | 八独立子池，后续逐系开发 |
| 职业强项 | 按第3节的不同空间/时序玩法 | 不以纯伤害倍率区分职业 |
| 首发范围 | 剑修全套分阶段交付 | 其他六职业不进本轮代码 |
| 数值地位 | 所有新增值视为首轮试验值 | 必须实测后才称平衡完成 |

以上是供评审的建议，不代表用户已经逐项拍板。技术性边界（不递归爆发、Boss不永久控制、实体回池清理）作为设计基线，除非提出明确替代规则不应放宽。

## 9 证据与未验证项

本轮证据应包含：原文提取和哈希、七职业及八分支覆盖表、原技能去向核对、内部矛盾复核、文档链接检查。没有改游戏，也没有跑新增技能的战斗、胜率或性能模拟。

核心未验证项：控制链是否过强、召唤物在小屏是否清晰、阵地玩法是否过度站桩、体修是否能避开远程包围、邪修在Boss阶段的冷启动是否过长，以及剑修各路线的真实收益。

评审通过后先进入剑修S0/S1；评审中的其他职业只修改设计文档，不提前实现。
