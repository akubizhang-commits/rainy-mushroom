## 1. 故事在本作中的作用

- **给重复战斗一个理由**：封印松动、妖气重聚，解释“逐层修补封印”和“同一层可以反复挑战”。
- **解释系统限制**：塔内不能服疗伤丹、三峰暂未开放、剑修不用灵兽和符箓、后六境与高阶器物未开放，都用世界内的说法讲明白。
- **用大世界撑起后续内容**：碎界七洲与人妖魔三族，为以后的新地图、新职业和高境界留出空间。
- **用悬念推动登塔**：层主旧事和塔中旧闻只给线索。

基调温和清雅（宣纸玉青），不写血腥内容。

## 2. 前提

上古神魔大战之后，苍玄界碎成七洲，由人、妖、魔三族分据：魔族三洲，人族与妖族各两洲。玩家所在的云泽洲是人族两洲之一。霁云宗位于云泽洲南部的霁云山，坐在一条大灵脉上，世代镇守锁妖塔。近年九重封印松动，玩家作为新入门的剑修，从最外层修起，逐层修补封印。上三层直通封印核心，宗门只说那里镇着“魇”。

## 3. 大世界设定

2026-11-06 用户确认的方向：
- 上古神魔大战结束后，世界碎成7块。
- 人、妖、魔三族占据这7块，魔族范围最大，人族与妖族相当。
- 玩家所在大陆由助手命名。

《雨后菌语》是项目最早的名称，现行游戏内容已与其无关，后续迁移项目时会删除相关旧代码与资料。世界观不再引用雨后菌谷、灵菌、菌孢灵光等旧设定，也不受旧 GDD（00-gdd-summary）的命名约束。

| 名称 | 设定 |
|---|---|
| 苍玄界 | 碎界之前的完整天地 |
| 神魔之战 | 神族与魔族争夺天地主宰。神族尽数陨落，魔族元气大伤；天地碎裂，至今已逾万年，称“碎界纪” |
| 劫海 | 七洲之间的灵潮与虚空乱流，只有上古传送阵与渡海楼船可以通行 |
| 魔族三洲 | 玄冥洲、赤渊洲、寂灭洲，三洲相连，占碎界近半 |
| 人族二洲 | 云泽洲（玩家所在）、天衍洲 |
| 妖族二洲 | 万灵洲（设妖庭）、苍莽洲 |
| 云泽洲 | 多山多水，雨云不散，灵脉密布。西北隔劫海与玄冥洲相望，是抗魔前沿之一；东南与天衍洲有楼船往来 |

**三族关系**：
- 人族与妖族势力相当，时战时和，边境有互市。
- 魔族与人、妖两族都为敌。

**名称区分**：
- 妖兽：未开灵智的野兽，锁妖塔中的敌人都是妖兽。
- 妖族：开了灵智、能化人形的妖修。妖族不为妖兽出头。
- 魔修：修行魔气的魔族。
- 邪修：走上邪路的人族修士。

## 5. 世界规则

**修行九境**：炼气、筑基、金丹、元婴、化神、炼虚、合体、大乘、渡劫（顺序沿用37号稿）。
- 当前只开放前三境，各分十层。
- 后六境只写境界含义，不写等级、功法、数值或开放时间。

**器物八阶**：凡器（白）、法器（绿）、宝器（蓝）、灵器（紫）、法宝（橙）、灵宝（红）、仙器（金）、神器（彩／幻金）。
- 名称、色泽、获取阶段和开放状态在运行时从 `TowerEquipmentTiers.js` 读取，典籍不另存一份。
- 世界内解释：炼成时灵光越盛，色泽越高。
- 同一品阶内分下品、中品、上品、极品；初始装备不入品。
- 古宝、本命法宝等称谓只提及，注明宗门尚无此类器物。

**七脉职业**：剑修（已开放）、法修、符修、御兽师、阵法师、体修、邪修。
- 每脉的战法摘要来自 `docs/xianxia/classes/` 下各职业设计稿，只写定位，不写技能数值。
- 邪修的傀儡沿用合规用词“魂灯傀儡”。
- 2026-11-06 用户确认：霁云宗不传邪修，藏经阁不收邪修功法；邪修之法在散修与隐秘门派间流传。

**不存在或禁止**：
- 塔内没有第十层。
- 锁妖塔中不出现八阶、九阶妖兽。
- 剑修不结契灵兽、不使用符箓。
- 疗伤丹和修为丹不能在塔内服用（回灵丹除外）。

**机制解释**：
- 层主妖身：玩家交手的是妖气借层主旧形凝成的妖身，被镇后妖气会重聚，所以可以重复挑战。
- 妖丹化修为：妖兽被镇后浊气散去，余下的灵力自行化入修为。
- 宗门回血：宗门灵气充沛，伤势会慢慢恢复。

**用词与内容禁区**：
- 用“镇妖、镇平、净化”。
- 传闻必须标注“未经证实”。
- 不写成真实宗教，不把丹药写成现实中有效的药物。

## 8. 设定决策（2026-11-06，用户授权助手决定）

### 8.1 已写入游戏（《霁云志》）

- **云泽洲是抗魔前沿**：保留。云泽洲西北隔劫海与玄冥洲相望。
- **灵菌**：不采用（用户确认：《雨后菌语》为已废弃的旧名，世界观中不出现灵菌）。
- **阵法师、体修**：霁云宗没有这两脉的传承峰，将来由藏经阁传授（与50号稿“体修等可由藏经阁承担学习入口”一致）。
- **邪修**：霁云宗不传，藏经阁不收（用户确认）。
- **三峰未开放的原因**：三年前，三峰长老率弟子赴西北抗魔前线，峰上只留守山弟子。今后开放三峰时，可以用“长老归山”作为剧情节点。
- **具名人物**：

| 人物 | 身份 | 用途与约束 |
|---|---|---|
| 云止真人 | 掌门 | 长年坐镇锁妖塔下阵眼稳住封印，所以极少露面。上三层剧情可以出场 |
| 陆归鸿 | 凌霄剑峰首座 | 剑修导师，适合做新手指引与破境提示的说话人 |
| 霞姑 | 丹霞峰长老 | 丹事 |
| 石炉长老 | 炼器峰长老 | 器事。对应游戏里已有的“长老已备好炉火” |
| 墨老 | 藏经阁守阁人 | 《霁云志》的编者，可以作为典籍旁白 |

### 8.2 只记录在设定稿中（塔顶真相，游戏内暂不揭示）

**魇**
- 碎界时，一缕上古魔神的残念坠入云泽洲，落在霁云山灵脉的节点上。
- 残念以生灵的恐惧与执念为食，能把灵兽染成狂暴的妖兽。这就是“浊气”的源头。
- 盘丝蛛后“把闯入者的梦织成回家的路”，正是魇的影响。

**白衣人**
- 他是三百年前霁云宗的剑修首座。
- 宗门当年无力斩灭魇，他便把九头大妖引入塔中，以它们的妖力为九根镇柱，再以自身补上最后一重封印。
- 当时的宗门认为他“引妖入山”，将他除名，旧名也被抹去。这就是“无人敢再提起的名字”。

**镇魇白虎**
- 白虎是白衣人当年镇服的大妖。它感念白衣人，自愿守在最后一道封印前。
- 剑修不结契灵兽，所以白虎不是他的契兽。
- 白虎身上并没有长发。“银白长发轻轻扬起”是白衣人残留在封印中的剑意。

**主角的白发**
- 主角与白衣人不是转世关系，也不是血缘关系。
- 只做“相似”：塔中的大妖会把白发白衣的主角错认成那位故人（例如二层狼王“仍在等白衣故人”）。
- 白发因此成为情感伏笔，不承担身世设定。

**九层揭示顺序**（供日后的首通剧情使用，每层一段可跳过的短剧情）

| 层 | 揭示 |
|---|---|
| 1–3 | 封印被侵蚀；狼王错认主角；蛛后的幻梦 |
| 4–6 | 层主守的都是白衣人的旧物（沉水古剑、求雨铜铃、残碑旧名）；九头大妖是镇柱而不是囚犯 |
| 7–9 | 掌门云止真人道出除名旧事；白虎让路；主角补上封印，墨老在《霁云志》中为白衣人补录姓名 |

**白衣人的姓名**暂不定，留到写第9层首通剧情时一并确定。
