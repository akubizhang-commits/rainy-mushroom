# 苍玄界与云泽洲地图：制图提示词

2026-11-06。依据 `01-world-bible-v1.md` 与藏经阁《霁云志》现有设定。按项目约定，静态图由用户出图，助手负责审核验收。

## 通用约定

- 横屏 16:9，建议 2560×1440 出图。
- 风格延续霁云宗首页的“宣纸玉青”：米白宣纸底、水墨淡彩、灰青山石、玉青林木、低饱和度。
- **图上不生成任何文字**，包括地名、图例、印章字和落款。地名由程序叠加。
- 不画网格、指北针或现代地图符号。可以有古地图常见的云纹和海浪纹作装饰。
- 每次出图上传 2–4 张候选，我按第4节的验收项逐张审核。

### 七洲关系的画面表达

- 云泽洲西北角与玄冥洲之间只隔一道窄海峡，海峡上空的魔云压向云泽洲。这是抗魔前线。

- 各洲都是“碎块”：海岸线带有断裂般的锐利边缘和崖壁，不是自然圆润的大陆轮廓。

## 2. 苍玄界全图提示词

> 为一款中国修仙游戏绘制世界全图“苍玄界”。16:9 横屏，古代山水舆图风格的俯瞰视角（略带倾斜的鸟瞰），不是现代地图。风格为宣纸玉青：米白宣纸底，水墨淡彩，灰青与玉青为主色，整体低饱和度、清雅克制，笔触细腻。
>
> 世界在上古神魔大战中碎裂，七块大陆像破碎的瓷片一样散落在灰青色的“劫海”之中。海岸线是断裂般的锐利崖壁，不是圆润的自然轮廓。大陆之间的海面有翻涌的灵潮和隐约的虚空乱流纹理。画面正中央的海上有一个巨大的暗色漩涡，周围漂浮着断裂的古陆残块与残破石柱，是神魔古战场的遗迹，气氛神秘，但不要画骷髅或血色。
>
> 北部是连成一道弧形的三块大陆，约占画面 45%，被低垂的灰紫色魔云笼罩，整体偏暗：西北一块是深青黑色的冰原与山地，正北一块是赤褐色的火山与裂谷，带有暗红色微光，东北一块是灰白色的荒漠与枯石林。
>
> 西南偏中是全图最明亮清润的一块大陆：青绿群山、雾气缭绕的大湖与河网，雨云笼罩，作为视觉重点。它的西北角与北部暗色大陆之间只隔一道窄海峡，暗紫魔云越过海峡压向这块青绿大陆，形成明暗对峙。东南是一块暖米色的平原大陆，有规整的田野与城郭，与西南大陆之间的平静海道上有几艘古代楼船的帆影。正东是一块被茂密古林与巨木覆盖的深绿色大陆。正西是一块黄绿色的草原与荒山大陆。
>
> 四周海域留有足够空白，边缘以淡墨云纹和海浪纹收束。图上不出现任何文字、地名、图例、印章、落款或水印，不画网格和指北针。避免厚重黑边、浓烈金光、满屏特效和赛博感。

## 3. 云泽洲地图提示词

> 为一款中国修仙游戏绘制大陆地图“云泽洲”。16:9 横屏，古代山水舆图风格的倾斜鸟瞰视角，不是现代地图。风格为宣纸玉青：米白宣纸底，水墨淡彩，灰青山石、玉青林木、青瓦白墙，少量低饱和暖铜点缀，整体清雅，笔触细腻。
>
> 这是一块从上古世界碎裂出来的大陆，海岸线带有断裂崖壁的锐利感，四周环绕着灰青色的海。整块大陆多山多水，雨云终年缭绕，灵气充沛。
>
> 中部是全洲最大的湖泽，湖面笼着薄雾，周围河网密布；湖畔东侧有一座体量克制的古代城郭（凡人都城）。北部有一道横贯东西的山脉，把北境与中部隔开。
>
> 南部是视觉重心：一组七八座山峰拱卫一座最高的主峰，主峰被云雾环绕，峰上有大殿楼阁；群峰侧方的台地上立着一座细高的古塔，塔周围的雾气略显阴冷，与清润的群峰形成对比。群山之间零星点缀三四处小型楼阁，表示别的修仙宗门。
>
> 西北海岸有一道沿海岸绵延的城墙与烽火台，面朝一道窄海峡；海峡对岸只露出一角深青黑色的陆地，上空压着灰紫色魔云，表现边境前线的紧张感，但不要画战斗场面。东南海岸有一座港口，停泊着几艘古代楼船。西部海岸有一座小集镇，远处海上隐约露出另一块黄绿色大陆的一角。
>
> 图上不出现任何文字、地名、图例、印章、落款或水印，不画网格和指北针。避免厚重黑边、浓烈金光、满屏特效和赛博感。

## 4. 验收项

1. 图上没有文字，也没有伪文字（类似汉字的乱码笔画）、印章和水印。
2. 苍玄界图：
   - 七块大陆数量正确，能逐块分辨。
   - 北部三洲相连，面积约占一半，色调最暗。
   - 云泽洲是全图最亮的区域，且西北角与暗色大陆隔窄海峡相望。
3. 云泽洲图：
   - 南部群峰加侧方古塔的结构，与霁云宗首页“主峰居中、侧峰拱卫、塔立台地”的关系一致。
   - 中部大湖、北部山脉、西北关墙、东南港口都能辨认。
4. 两张图中云泽洲的轮廓大体一致：苍玄界图里那块大陆，放大后应能对应云泽洲图。
5. 画风与霁云宗首页统一，不出现血腥、骷髅、真实宗教符号。
6. 地点周围留出足够空间叠加程序文字，主要地点不要被浓雾完全遮住。

## 5. 建议出图顺序

1. 先出**云泽洲图**，并确认它的轮廓。
2. 再出**苍玄界图**时，把云泽洲图作为参考附上，追加这句：

   > 西南那块青绿大陆的轮廓参照附图，保持形状一致。

   这样两张图中的云泽洲能对上，不必再手工修形。
