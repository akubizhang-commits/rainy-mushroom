## 本轮实现

- 设置、背包、技能的可见圆底及图标缩小25%，保留80×80设计单位的点击节点。浏览器以偏离中心34单位的位置实际点击，验证透明边缘仍可使用。

- 四位数气血完整显示；五位数起按万／亿显示，避免长期依靠缩小字体。角色信息浮层保留完整整数。大数值截图是纯显示夹具，不代表当前可达到的角色属性。
