# 精通标记与技能连线核对

精通标记改为浅金粗体＋深墨2px描边、无底色。Web构建及1280×720、844×390隔离浏览器检查通过，见本目录图片。技能数值和连线尚未改动。

当前三种线都是学习依赖：深色实线为普通前置；金虚线为进化母功法；青点线为进化所需被动。青点线不是可选搭配。普通前置为御剑术2→剑影分光、剑气斩2→一线天、万剑诀2→两仪剑阵。

四个进化首级分别需要母功法6级＋被动4级：御剑术/剑心通明→万剑归宗；万剑诀/剑骨→无我剑境；一线天/青萍剑意→天地一剑；两仪剑阵/剑开天门→四象剑阵。还需满足各自境界门槛、通关6层、经卷及技能点要求。

建议后续统一实线表达依赖，选中时强调关联线，并明确列出等级；双前置使用“同时满足”而不是误导为二选一。本轮仅核对解释，未修改依赖或布局。
