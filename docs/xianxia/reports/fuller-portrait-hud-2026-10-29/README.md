# 头像圆框内构图微调

头像等比放大5%，相对居中裁切上移6个设计像素；从同一角色母稿补足颈部取样，继续沿颈线去除肩胸。保持圆框和HUD布局，采用原有低饱和调色。

- 最终素材仍为704×248的RGBA PNG，头像之外的像素与整个透明度通道均保持不变。
- Cocos web-mobile构建成功，见 `build.log`。
- 现有浏览器验收在1280×720、844×390、1024×768三个横屏尺寸通过，见 `browser.json`；包含宗门／战斗画面、角色信息浮层、入口及快捷按钮点击、大血量显示。
- `portrait-comparison.png` 为调整前后实际宗门画面的等比例裁切对比；`hall-*` 和 `battle-*` 保留完整画面。
- 本轮仅修改素材生成和导出的PNG，未改交互或游戏逻辑。浏览器使用独立存储，未进行微信真机验证。
