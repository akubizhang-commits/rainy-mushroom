## pulses 与 pulseLog 时间不一致的来源

早先的 live-results.json 中，`pulses` 数组记录为 1.35 / 1.78 / 2.8，`pulseLog` 为 0.783 / 1.783 / 2.783。`pulses` 是脚本在 50 毫秒采样循环里轮询 `z.pulseIndex` 时记下的时间，经过了页面 evaluate 的往返延迟，并不是游戏内的轮次时刻。`pulseLog` 在游戏自己的 `_qinglianPulse` 调用中记录，时间取自游戏时钟，因此以它为准。两者相差约 0.5 秒，我没有完全确认偏差的全部来源，只能确定 `pulses` 不是可靠的计时依据。
