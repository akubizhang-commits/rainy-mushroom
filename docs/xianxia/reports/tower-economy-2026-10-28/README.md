## 实现

- 灵石四品阶百进一，支付自动找零；妖丹精华自动提供修为，不进入钱包。普通加点只消耗技能点。
- 寻器100下品灵石＋100贡献；特殊主动/被动经卷200/100下品，进化2400，研习800/1600/2400。现有抽取概率与保底、修为曲线保持。
- 存档schema4；不兼容旧档重置，写入失败保持旧记录并禁用修改。当前档正常保留。
- 技能页最多五列，依赖连线、境界块标题；通用标签、被动精通标记、右对齐技能点、固定操作区。真实浏览器验证后修正冷却文字与等级徽标相互遮挡。
- Growth.damageType定义物理/混合/魔法/无独立伤害；Presentation和未来技能目录同步分类。御剑、剑气、穿透与幻影等为物理；万剑和剑阵为混合；未来控制为魔法。进化继承父技能类别。

## 边界

本次攻击类型为明确的数据与展示分类；战斗当前没有物理/魔法抗性分算，不擅定混合比例，不增加一份魔法伤害。无伤害控制不因魔法标签额外造成伤害。数值回放用于预算校验，不代表真人通关难度或性能压力验收。浏览器使用隔离存档，未操作用户实际存档。
