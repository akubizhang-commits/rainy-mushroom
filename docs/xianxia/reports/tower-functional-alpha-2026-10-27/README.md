## 试玩

本地服务运行在8767时，打开：

```
http://127.0.0.1:8767/cocos-pilot/build/web-mobile/index.html?ruleset=xianxia&tower=1
```

手机在战场拖动；电脑使用WASD/方向键，自动施法。宗门先用20妖丹买一本功法，再在洞府加入出战；天工坊可抽武器及强化。出塔/换层不回满，丹鼎阁仅场外服药。暂停后可继续原战斗，主动回宗则本层重来。

新模式存档键为 `xianxia.sect-tower.campaign.v1`，入门赠礼只发一次。旧模式未导入，也未删除。`smoke=1`仅用于内存存储的自动化环境，不是正常试玩入口。

## 本轮修正

1. 旧同步器将配置键 `reserve_from` 误当成import，导致新内容无法构建；改为仅识别行首import声明。最终manifest及共享副本一致性测试通过。
2. 养成/战斗/界面对进化的配套心法要求不一致；统一为学习前置，保留装备母功法条件。
3. 场外自然回血原先只更新领域状态，界面数值没有跟随；现在局部刷新生命数字/生命条，不重置正在滚动的页面。
4. 宽屏使用居中竖屏场地；敌人攻击使用扣除HUD后的可见区域，危险预警绘制实际圆形、扇形或冲撞路径。

## 尚不能宣称完成的内容

- 美术按用户要求后置：角色、建筑、妖兽、武器与特效当前采用清楚的占位表现，不作为最终美术验收。
- 自动走位会读到危险区域，它不是普通玩家。第3/5层出现明显失败重试，带成长后的通层约5–7分钟，仍需真人校准到期望节奏；没有声称“完整平衡已完成”。
- 本轮是浏览器功能版；未做微信真机、长期存储兼容、持续性能及发布验收，新模式微信入口仍需接线。
- 存档使用本地持久化与校验，未引入云存档、服务端防作弊或付费功能。

下一步直接体验本版，优先记录首层易读性、第三/五层难度和宗门整备的操作负担，再调数值，最后逐类替换美术。不再重新询问已锁定规则。
