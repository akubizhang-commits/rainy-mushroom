# 丹霞峰庭院接入验收

用户提供的《云海仙庭炼丹院》通过美术验收：淡彩青灰画风与首页、炼器峰一致，丹炉完整，药圃、配药台和丹瓶形成明确的炼丹场景。原图 1671×941，复制到 resources/sect-scene/danxia-courtyard.png，保留下载源文件。

验证：web-mobile 编译成功；炼器/丹药界面与装备单测合计 17 项通过，含开关菜单不扣费、过期回调不重复扣费、保存失败原子性。真实浏览器 1280×720、844×390 均通过：宗门入口、点炉、两种丹药各购买一颗与五颗、关闭菜单、返回再进入、刷新后库存与贡献保持一致，无页面异常。
