# 三类装备试玩验收

本轮完成武器、防具、戒指的生成、三池炼制、配装、锁定、分解、战斗与schema6存档。强化关闭。

- 塔玩法测试：643项通过，0失败。
- 预算测试：64组品阶混搭、510300组边界取值；样本网格最高增幅27.004878%，另有连续参数保守边界验证，未越过对应份额和35%全局上限。
- TypeScript检查通过；web-mobile构建成功。
- Chromium实际点击：1280×720、844×390两尺寸通过。三类分别炼制、查看、穿戴、锁定、炼制闲置副本并分解；重复分解被拒绝。验证技能购买、暂停、携装备战斗、结算和重新读档。
- 存档回归覆盖防具回血历史回退、同刻及超出技能数量的虚构会心计数、概率累计超过总炼制次数；失败操作不写档、不扣币。
- 炼制规则：47/35/15/3；15次连续未出极品后下一次5%，每次再加2个百分点，最高33%，出极品重置。无固定必出，各池独立。
- 纯逻辑性能样本见simulation-profile.json：12000次模拟更新，最多30敌人；测试人为持续补满生命以维持负载。该报告不代表浏览器GPU性能或手机原生帧率。

复现：`node --test tests/xianxia-tower-*.test.mjs`；`npm run cocos:build`；`TOWER_UI_REPORT=docs/xianxia/reports/three-slot-equipment-browser node scripts/verify-tower-economy-ui.cjs`。
