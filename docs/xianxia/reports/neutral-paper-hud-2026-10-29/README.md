# 角色 HUD 纸底配色调整

将宗门与战斗共用纸底调为低饱和灰青色，最高不透明度约78%。保留文字下方的稳定底色，四边柔化、下缘透景；同时协调头像底色、描边、气血文字及空血槽颜色。继续使用352×124布局，保持头像与剑标识的位置、32单位右留白和152单位数字列。

`scene-comparison.png` 为两张1280×720实际浏览器截图的左上区域并排裁切，没有重绘界面或替换背景。完整画面分别为 `hall-*` 和 `battle-*`。
