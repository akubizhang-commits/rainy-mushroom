# 开发者工具精简与补给 · 2026-10-30

## 最终行为

- 仅保留速度、无敌、联合补给、提升小境界四个操作，右上角、空白遮罩及 Esc 可关闭。
- 速度循环 ×1 → ×2 → ×3 → ×1，无二级菜单。
- 使用主存档一份进度，不再加载或切换旧体验档。旧体验档记录未删除。
- 无敌只屏蔽受击扣血，不改变角色输出伤害，不回血，不秒杀。
- 联合补给每次增加999极品灵石和999贡献，任何一项容量不足或写入失败时整笔不提交。
- 境界按现有阶段（初期、中期、巅峰）逐步推进，跨越大境界仍遵循相同顺序，到金丹巅峰为止；技能点与属性按正式成长计算。已有阶段内的修为推进到下一阶段起点，不额外补满生命。
- 宗门和暂停中的塔内挑战均可操作；塔内更新永久修为与结算基数，不制造战斗掉落记录。演武中提升境界需先结束演武。
