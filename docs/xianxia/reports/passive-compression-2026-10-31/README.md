## 等级与数值

以下均为该等级的累计效果，不是每次升级额外增加的数值。

| 技能 | 新等级上限 | 各级累计效果 |
| --- | --- | --- |
| 凝神诀 | 3 | 御剑术索敌距离 +4% / +8% / +12%；拾取半径 +20% / +35% / +50% |
| 剑心通明 | 4 | 暴击率 8% / 14% / 20% / 28%；暴击额外伤害系数仍为 50% |
| 青萍剑意 | 4 | 直伤转剑痕 4% / 6% / 10% / 15% |

| 御剑飞行 | 1，保持不变 | 移速 +25%，消耗 2 点 |

压缩后的多级被动每级均消耗 1 技能点。全部被动点满的总投入从 90 点降为 25 点；自然技能点来源和总量不变。四级被动采用原第 2、4、6、8 级数值，并保持这些等级对应的境界阶段。

凝神诀每个炼气阶段开放一级。摄灵诀从当前技能目录、学习入口和技能树中移除，其拾取效果并入凝神诀；不会提高掉落数量、概率或价值。御剑术 4–6 / 7–9 / 10 级的凝神诀前置改为 1 / 2 / 3 级，退点时也按此前置校验。
