## 体验与边界

用户当前游戏页面未被自动刷新、正常存档未被测试工具修改。保存回宗后刷新现有浏览器页面，再新开一次塔层，可看到新的六边场地；旧未完成尝试继续其原场地和原掉落版本。

本轮保持美术灰盒。正常九局是阶段配置压力测试，不是自然养成或真人通过率；第5/8层失败保留，不能以无敌排空覆盖难度问题。六边形面积比旧矩形少25%，边角走位和远程压力仍需正常倍率试玩。

微信发布包、实际手机安全区/多指生命周期/性能、全职业、领域与最终美术均未在本次验收。当前交付针对浏览器宗门塔模式。
