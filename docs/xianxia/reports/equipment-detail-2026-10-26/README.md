## 唯一接受的舍入与生命模型

伤害严格采用 `n0 + floor(n0×ePct/100)`：n0直接保留原无装备整数事件，ePct=0–18；零装备逐位不变，零基线不变正数，单事件≤1.18。低伤害可能没有整数装备收益；不承诺长期贴近18%，不用最低1点补偿。无法分离原基线/防止重复乘法/保持原Golden时关闭相应装备适配并回退原事件，不能换一套舍入。

生命用普通currentHP与 `Hgear=H0+floor(H0×E)`，只舍弃装备HP增量的小数。非破境百分比治疗、盾、持续回复上限、自损、生命转伤等按H0；原破境补满Hgear明确保留。三次补满可能额外补24而非8HP，脚本包含此动态例外反例；**不作生命周期资源或真实TTK上限证明**。

小数余量账本和不可补充reserveHP是已否决的探索方案，其测试均已从接受结果删除。JSON仅保留rejected_alternatives名称，不包含其通过计数。

连续静态输出≤1.18、HP/EHP≤1.08、乘积≤1.2744。H0与承伤倍率必须有效且后者>0；无敌状态不可除零。端点跨条件金T=+6对蓝T=−3的静态连续比约1.2370413512，并非品质差距；品质比较固定同一事件T。静态结论不保证整局总伤害、胜率、TTK或治疗收益≤30%。
