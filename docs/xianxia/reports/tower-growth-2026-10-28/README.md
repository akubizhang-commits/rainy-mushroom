## 玩家路径

- 第1/3个累计完整清波永久领悟剑气斩/万剑诀1级；御剑1为初始绑定。三者不花自由点、不洗成自由点。
- 修为提升给点（普通1、筑基/金丹突破各3总计），境界累计30；3/6/9首通各1；80/160/240妖丹限三次研习再3；总36。
- 全16技能在一张分支树上，功法10、心法8、进化3（塔内只可修1/2）；学会全自动，无出战槽。特殊经卷只首次收费，技能等级按分档SP修习。
- 暂停可修基础功法和已学心法至3级；秘传、高阶、进化、免费全洗在藏经阁。洗点退实际投入，绑定与经卷保留。所有学习与存档事务一起提交。
- 六心法各有脚下光环，暂停冻结、死亡/离场消失，画在敌方攻击预警下方。没有声称触发高亮和美术已完成。

## 体验工具

游戏普通入口参数 `ruleset=xianxia&tower=1`。首页“体验工具”或战斗“暂停→体验工具”进入独立体验档；也可添加 `playtest=1` 直开。

- ×1／×2／×3只加快战斗模拟，包括移动、施法、怪物、波次；暂停与读图不推进时间，场外回血始终按真实时间。
- “无敌秒杀”一击任意妖兽、免疫伤害，开启/关闭不补血。技能射程/施法动作与正常怪物刷出流程保持，以便验技能表现。
- 首次复制普通进度，后续体验档独立保存；工具偏好也单独保存。切回普通档重新应用正常规则；体验进行中不写普通档。返回普通宗门后允许其正常场外休养，不把合法HP/restAt变化误当经验或资源污染。
- 体验档初始化失败停在只读错误，可重试或主动切回普通档；不能自动落入可写普通档。正常平衡脚本从不启用秒杀。

## 存档与旧档

Campaign schema3。同一修为/首通/研习源派生总账，最高36，不重复发放。旧schema1/2先验证checksum和原规则，再迁移；返还旧逐级升级妖丹（特殊首次经卷费用保留为已购资格），教学绑定恢复。按新预算优先旧所选技能逐级重新分配；旧进化经卷保留，需按新前置重新投入点。游戏会提示补偿/重修，迁移只发生一次。

保存失败/CAS冲突保留原始记录；在途伤害携带施放时上下文，加点不会把旧弹体变成新等级，也不抹除冷却、敌人和击杀。旧经典游戏路径保持原规则。
