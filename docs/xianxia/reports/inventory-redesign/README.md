# 背包界面调整 · 2026-10-29

- 移除背包头像 HUD、顶部资源行、底部导航和“三套配装”入口。
- 左上返回：宗门内返回宗门首页，塔战内恢复暂停的战斗。
- 左侧使用现有角色图集的全身待机帧，显示武器、防具、戒指三个当前装备槽；装备槽缩小为正方形图标，不显示名称或种类文字；点击槽位可查看装备。
- 右侧为八列小正方形物品网格，不显示物品名称，保留品质、穿戴、锁定、数量和新物品角标。分类和排序合并为一排，移除阶位、品质与状态筛选。
- 点击物品打开详情，右侧提供穿戴／解除、锁定／解锁、分解；已穿戴物品不显示分解，丹药提供服用。
- 解除后存档槽位为空，物品仍保留；战斗计算沿用既有基础配置。现有内部配装数据结构不变。
- 战斗 HUD 和暂停菜单提供背包入口。战斗中仅可查看，沿用现有规则。
