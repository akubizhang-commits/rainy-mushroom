# 第七层隼王、第八层猿王

第七层改为裂风隼王（falcon_boss），第八层改为撼岩猿王（ape_boss），均为六阶。选层名称、故事、真实Boss投放与原始设计生成器同步更新，九层各20波、普通怪混编、奖励不变。当天较早的犀牛/牦牛方案被本次决定取代。

- 隼王：使用已有远程羽刃散射与中距移动，HP约148258.90（第七层基准×0.75），移速220。原犀王为第七层基准×0.9；本次采用现有隼类属性，不声称难度完全等价。
- 猿王：使用已有近身圆形重击，HP250635.83（第八层基准×1.0），移速165。原牦牛为基准×0.9。连续前方砸地属于后续设计建议，本次未新增。
- 复用原有猿图片；妖隼由已存在的1024px图本地去底色、保留翼尖，适配为256px透明PNG，并接入共享战场素材缓存。未调用付费生成服务。
- 大卡片、正方形奖励框与已领取提示保持。犀牛/牦牛只保留原型数据及备用轮廓，不再作为塔内层主。
- 存档版本8→9：按用户授权的开发期约定重置旧锁妖塔档，以免旧的第七/八层Boss快照被当成当前波次。保存失败保留旧记录，其他游戏存储键不受影响。
