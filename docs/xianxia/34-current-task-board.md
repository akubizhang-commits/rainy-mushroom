## 并行边界

- MAP-1负责规则和空间契约；MAP-2负责资产准备，可并行。两者先统一原图坐标与世界尺度，再由MAP-3集成。
- ENEMY-1可同时进行素材检查，但本轮不和场景集成争改同一个渲染文件。
- HERO-1的素材依赖不让主线停下来；已有外观工程回归不再当作下一主任务重复执行。
- QA随交付开展；除阻塞游戏的缺陷外，不再用额外独立QA轮次替代已排定的场景工作。
