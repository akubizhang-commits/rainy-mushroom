# 炼器抽取动画：后续制作 Prompt

## 可直接复用的主 Prompt

为横屏修仙游戏《落云宗》制作一段炼器抽取演出。以现有炼器峰庭院和三足炼器炉为视觉依据，保持场景构图、炉子的外形和位置一致。画面沿用淡彩青灰、玉青、宣纸米白的中国仙侠风格，炉火使用温暖橙色。借鉴抽卡演出“蓄势—品质预告—揭晓—结果总览”的节奏，所有场景、特效和界面使用本游戏自己的设计。

玩家确认单抽或十连后，菜单隐去，镜头缓慢靠近炼器炉。少量灵石、矿石和灵材从画面两侧沿弧线飞入炉口，带有短而轻的灵气尾迹；炉口收拢灵气，炉底火焰逐渐变旺，暖光照亮炉身与附近地面。炉子先轻微颤动，再出现两到三次更明显的左右摇晃，始终保持完整，不弹跳、不倾倒。

在摇晃达到顶点时，根据本次真实抽取结果播放以下两个结尾之一：

- **本次至少一件极品**：炉身缝隙透出金色光芒，随后一道集中、明亮的金色光柱从炉口冲向天空，伴随少量向外展开的金色粒子和一圈柔和冲击波。金色预告只代表“本次包含极品”，不提前展示具体物品。
- **本次没有极品**：炉口升起柔和白色灵光，伴随白色微粒和轻薄气流。不要使用金色光柱或金色品质标记。

亮光短暂扩散后平滑过渡到结算界面。结算逐件展示真实获得的武器、法衣或戒指，只显示装备特写与名称，不展示属性说明：物品先以略小的比例出现，再柔和放大至稳定尺寸；背景放射光只衬托物品，不遮住名称。极品使用金色光晕，其余物品使用白色光晕。单抽展示一件；十连按实际抽取顺序展示十件，最后进入所有物品的总览。物品名称、品质、阶级、图标和属性均由游戏运行时绘制，动画素材中不要烘焙文字、数字、按钮或物品结果。

镜头运动轻缓，避免强烈全屏闪白、快速频闪和持续震屏。以材料、炉火和灵光的变化营造期待感，不依赖长时间等待。整个炉子演出建议约4秒，逐件展示由玩家控制节奏。

## 制作与接入约定

- 当前任务只制作结算界面；以上材料入炉、炉火、摇炉、品质光柱均留待后续，不在本次生成或接入。
- 结算中的缩放入场、金白光晕、短暂光点与卡片错峰出现已由代码实现，不需要额外生成动画。可选的后续静态分层素材见同目录 `forge-static-art-prompts.md`。
- 建议拆分交付：公共蓄势段、普通白光结尾、极品金光结尾；必要时另交透明粒子层。先确定动画工具支持的实际尺寸、帧数、时长和透明格式，再生成素材。
- 横屏16∶9母版，适配更宽屏幕时保留炉子与光柱的完整主体，不拉伸画面。
- 建议时间轴：0–1.1秒材料入炉，1.1–2.2秒炉火增强，2.2–3.1秒摇炉，3.1–4秒品质光柱与过渡。工具时长受限时按阶段分段制作。
- 右上角“跳过”由运行时绘制；跳过直接进入结果总览，不能重新抽取、改变品质或影响奖励入账。
- 抽取、扣费及奖励先作为一次事务保存成功，再开始演出。金光条件为本次结果中存在 `quality === 4`，与黄阶、玄阶无关。
- 结算中的点击物品继续、查看全部、返回总览和点击卡片外返回，只控制展示。底部“炼器1次／炼器10次”是再次购买按钮，沿用当前阶级及池子，分别消耗100／900下品灵石及100／900贡献；图标和数字分行清楚展示。
- 出炉演出期间若退出或应用中断，已经入账的装备仍在背包；演出不是领奖动作，不允许重复领取。
- 如后续加入声音：材料落炉声、渐强火焰声、轻微炉身震鸣与结尾清亮音分别提供，极品结尾略有层次，但避免尖锐爆音。

## 本次结算交互

1. 保存成功后直接揭晓第一件，不播放炉子动画。
2. 单件页只展示装备特写和名称，保留金白光效。十连点击物品推进，最后进入总览。
3. “跳过展示”直达总览。十连以两行五列展示全部结果；点击任一物品可查看其详情并返回总览。
4. 金色只强调极品，普通结果使用白光。
5. 移除关闭按钮，点击卡片外回到炼器峰。底部只放一个再次炼器按钮，显示次数，第二行以灵石及贡献图标配价格。单抽100＋100，十连900＋900；再次炼器仍须通过余额、容量和保存检查。
