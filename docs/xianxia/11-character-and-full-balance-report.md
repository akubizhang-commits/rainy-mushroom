## 3. 发现的问题与已知边界

1. **整体偏易，但弱随机构筑仍拖局。** B 的三个超长主样本都来自保守走位＋随机选卡；留出集还有四局超过12分钟。简单统一增加敌方伤害或生命可能同时恶化这些长局。本轮保留原参数，先提供完整诊断，未以修改门槛或筛掉弱局制造通过。
2. **敌弹池确实发生攻击省略。** B 的 `balance-40 / flee / prefer:dew_ring` 在约443.767秒发射时占满60槽，其中一枚泡弹剩余生命约 `5.655e-15` 秒。敌人发射早于本步敌弹清理，导致 acquire 返回 null；该次发射直接省略并重置发射计时，不会下一步补发。只读包装复现与主矩阵两遍记录相同。尚未验证如果保留该攻击会否改变胜负，不以最终获胜声称它没有影响。
3. **归因遥测仍不足。** 万剑命中数不是有效伤害贡献；没有完整的过量伤害、实际回血、破境治疗和经验溢出归因。本轮未做逐系统六层消融，因此完整平衡验收仍未关闭。
4. **经典汇总展示缺陷已绕开。** 原始 `abandoned` 字段把经典不可获得的万剑也计为“放弃”。原始文件保持不改；分析器按两版各自合法池重新统计，审阅页面不使用错误字段。该问题不影响实际对局。

## 4. 角色制作结果

沿用上一版黑发蓝白剑修身份，调整头身比例、腰带与下摆，提亮蓝灰裤靴；站姿主体遮罩已修复。有效交付仍是**一张待审站姿及尺寸/背景对照**，没有把它称为已获用户认可的最终角色。

本轮实际尝试了正面、背面、斜向、三个步态关键姿势和施法姿势：

- 同母稿图生图＋OpenPose仍出现多靴、多手、服装及发型变化，方向稿拒收。
- 同母稿像素分层保留了脸和衣服，但没有补出被遮挡的关节和肢体；局部低噪重绘仍留下膝部补丁、旧手残影和连接问题，动作稿拒收。
- 全局颜色抠图会误删灰蓝衣服，已改为保护主体、从边界泛洪识别背景；该修正不能解决动作结构问题。
- 两轮局部修复后仍未通过，停止同配方扩量，保留全部工作流、输入、遮罩、生成历史和拒收原因。没有把不同姿势自动循环成“完整动画”，也没有纯镜像冒充八方向。

详见 [美术 QA](../../design/xianxia-character-2026-10-26/v2/QA.md)。后续需要先补齐同一母稿的遮挡肢体与关节结构，再通过一个完整侧向步态；该门槛未通过前不继续批量方向或动画。
