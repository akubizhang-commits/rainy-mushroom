# 剑修 S4：四条进化与选卡闭环

2026-10-27。状态：实现及本地 web-mobile 验证完成；未完成真机性能、自然整局平衡验收。规则版本 sword-s4。

## 玩家可见变化

| 基础功法＋三级心法 | 进化 | 效果 |
|---|---|---|
| 御剑术Lv5＋剑心通明Lv3 | 万剑归宗 | 保留三柄飞剑，额外每8秒锁定600×600区域；0.25秒预告，六次剑雨伤害 |
| 万剑诀Lv5＋青萍剑意Lv3 | 无我剑境 | 外圈剑刃与70u内圈合并判定，每目标每0.5秒只在窗口末结算较高伤害 |
| 一线天Lv5＋剑骨Lv3 | 天地一剑 | 可移动蓄势0.9秒，最后0.3秒固定起点/方向；760×80范围贯穿全部目标 |
| 两仪剑阵Lv5＋剑开天门Lv3 | 四象剑阵 | 四个90u阵眼形成区域并集，4.5秒九跳；重叠不重复伤害，普通敌减速20%、首领10% |

全部要求已提交等级≥19、模拟时间≥360秒；最早升20级时出现。原槽位替换，每局最多两种进化。新剑雨等待完整八秒，进化清除同功法遗留弹体/阵地，不清除其他功法。保持御剑术无拖尾及剑气斩既有残月美术。

## 选卡与界面

合法进化保底一张，多种合法进化按上次展示位置轮换；不选择后仍有机会出现。优先级按评审文档：进化、首轮、破境功法成长、已学功法升级缺席保底、新阶段功法缺席保底、加权剩余。三张以内、无同技能重复。暂停/重复进入同会话不会推进抽卡或轮换计数，提交前再次验证资格，旧会话点击无效。

本次统一阶段候选规则为“待选目标等级”，因此升10级可出现筑基功法/剑开天门；进化仍单独使用“已提交等级”。这取代S2/S3报告中的晚一轮阶段过滤。进化卡金色边框，暂停与结果栏显示进化名称及标识，不增加常驻HUD区域。

## 表现

剑雨在固定世界区域显示六批、每批五柄完整剑影；三十柄只是装饰，不决定命中次数。无我剑境仅轻描内圈边界，不表现为护盾。天地一剑有追踪蓄势、锁向预告与收尖的宽剑光。四象剑阵绘制一次区域并集，四个阵眼清楚标示；手机尺寸检查后增强轮廓亮度/线宽，保持低透明度内部。
