## 输出约定与参考图

以下每段都可以独立复制。每次生成一件。装备的具体外观是设计建议，不改变代码里的物品属性。

- 装备：期望1024×1024原图、透明PNG；交付后整理128×128运行时版本，在40像素左右检查辨识度。实际尺寸和透明度需要下载后核查。
- 技能：期望1024×1024原图；整理256×256，与现有技能保持米白纸底、圆形裁切。方形图不等于竖屏界面，场景仍只支持横屏。
- 怪物：期望1024×1024透明PNG原图，整理256×256；身体和翼尖完整，按脚点／身体基准统一定位。
- 装备建议先上传当前灵石或已满意的新装备图作为材质与笔触参考；同类后续用首张满意图保持一致。
- 御剑飞行请上传 `cocos-pilot/assets/resources/tower-skill-icons/sj_yujian.png` 作为风格参考。
- 蝙蝠如重制，请附当前 `tower-monsters/boar.png` 或 `ape.png` 作怪物画风参考，同时附旧蝙蝠图说明动物结构。
- 透明背景必须是真实Alpha，不能画棋盘格。若得到实色底，保留原图、标记待抠图。不要把生成成功当作可直接接入的验收结果。
