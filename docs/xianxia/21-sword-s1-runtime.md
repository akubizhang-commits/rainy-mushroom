# 剑修 S1：御剑术、剑气斩与选卡闭环

2026-10-26。用户已确认设计评审；本批仅实施两个核心技能及选卡。运行时版本 `sword-s1`，不是剑修全部技能完成。

## 已接入试玩

- 开局御剑术 `sj_yujian`，五级依次1/2/2/2/3把飞剑，近敌优先、稳定UID排序、直线飞行。每把剑拥有独立命中记录，第四级起最多命中两名敌人。
- 剑气斩 `sj_arc`，五级半径140/160/180/200/220、扇形75/80/90/100/110度。自动瞄准射程内最近的活怪，不受移动方向限制；无可及目标不耗冷却。0.12秒前摇锁定方向，出手位置跟随角色，单次对每敌结算一次。
- 首轮必含剑气斩Lv1、御剑术Lv2。仅两技能、原金刚诀/聚灵阵、原三丹药和兜底进入候选。未实现技能、旧职业独立御剑被动与旧进化不进入本批。
- 重复提交、旧选卡令牌、非法卡不消费升级；暂停保留当前卡与前摇。突破保底、连续未出现技能升级的保底沿用共同规则。
- 飞剑使用独立冰蓝剑素材；剑气预警与月牙出手分开显示。卡面说明单剑与整轮伤害，五级差值由数据生成。
- 经典模式仍以孢子弹开局，原经典卡池与伤害路径保留。
