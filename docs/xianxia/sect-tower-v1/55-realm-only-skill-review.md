# 技能加点资格审查与修改

> 2026-11-01更新：金丹技能已改为继承基础功法实际等级，首次费用只收进阶增量；不再独立调用10级伤害。最新规则见 [75号记录](75-skill-inheritance.md)。下文保留当时实施记录。

2026-10-30。用户要求：学习和升级资格只取决于境界，删除通关门槛和所有技能前置依赖。本记录取代第 54 号记录中的学习门槛；技能点、经卷灵石仍为实际消耗。

## 查到的旧限制

1. 基础主动技能未获教学赠送时不能自行学习。
2. 特殊技能既要求境界，又要求通关指定楼层。
3. 筑基主动技能根据已学数量，额外要求角色 10/11/12 级。
4. 金丹技能要求通关六层/九层，以及母技能六级/八级；降低母技能会连带降低金丹技能。
5. 战斗配装和存档校验重复检查部分旧条件；只删按钮条件会导致学了不能施放，或存档被判无效。
6. 主动技能等级上限在同一境界阶段内逐级变化，界面还显示角色数字等级要求。

## 已落实的规则

- 学习要求保留各技能所属的境界阶段（炼气/筑基/金丹的初期、中期、巅峰），不再要求指定通关层数、波次、母技能或配套被动。
- 同属筑基初期的主动技能同时满足境界资格，选择顺序不再改变其他技能门槛。
- 主动技能等级上限按九个境界阶段依次为 **2/4/5/7/8/9/10/10/10**；被动仍为炼气 3、筑基 5、金丹 8，御剑飞行仍仅一级。
- 金丹技能第一级按各自所属阶段开放，第二级统一要求金丹巅峰；不再单独要求角色 27 级。
- 金丹技能独立拥有施放参数，第一级/第二级分别使用原六级/八级模板参数及对应金丹技能倍率，不读取玩家母技能投入。母技能未学或退点后仍能施放，不会并行叠放同一套基础技能。
- 降级只改变点击的技能，不连带扣除其他技能；界面删除前置连线和相关条件。
- 教学赠送仍是免费奖励：提前花点学习不受阻，到达赠送节点后相应首级不再计费；赠送进度不会重复刷取。
- 塔内需先暂停并保存战斗，之后使用与营地相同的加点资格；新增购书消费账本，保存失败整体回滚，后续检查点和结算不会返还已花灵石。
- 首通奖励和道悟研习仍可提供技能点，它们属于资源来源，不是某个技能学习或升级的资格条件。
