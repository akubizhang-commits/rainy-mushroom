# 技能等级与境界分段
> 2026-11-06：御剑术仍2级可学，但1–3/4–6/7–9/10级改为在2/7/11/14级开放，见 [85号](85-school-resonance-proposal.md) 第8节。下文御剑术分段为历史记录。

> 2026-10-31 用户确认：御剑术从炼气四层（中期，角色Lv4，累计225修为）开始学习。按技能自身起始阶段顺延：1–3级需炼气中期，4–6级需炼气巅峰，7–9级需筑基初期，10级需筑基中期。原有凝神诀升级前置保留；新档仍赠剑气斩1级，御剑术需手动学习。伤害、费用及御剑飞行的筑基初期门槛不变。本条覆盖旧文档的御剑术初期解锁/初始赠送描述。

2026-10-30 实施。每个技能从自己的学习境界开始，而非套用同一个角色等级上限。

- 十级技能：起始阶段开放1–3级，下一阶段4–6级，再下一阶段7–9级，第四阶段10级。
- 八级被动：依次开放1–3、4–6、7–8级。
- 御剑飞行仍为筑基初期开放的单级技能。
- 两级金丹技能保留各自首学境界，二级需要金丹巅峰。
- 技能伤害、效果、技能点和经卷价格不变。仍然没有通层或前置技能条件，也不自动学习。

例如剑气斩：炼气初期1–3级，中期4–6级，巅峰7–9级，筑基初期10级。一线天从筑基初期起步，筑基中期4–6级，筑基巅峰7–9级，金丹初期10级。

`TowerGrowth` 统一生成每级境界数据，实际加点和介绍页读取同一份数据。介绍页保留下一等级条件，并新增完整「境界与技能等级」列表，满级后仍可查阅。列表置于独立滚动区域，不移动固定加点按钮。

存档版本更新至14：开发期旧版爬塔档重置，当前版本不接受低于对应境界的普通技能投资；沿用原有失败原子性和独立存档范围。
