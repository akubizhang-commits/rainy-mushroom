## API

```js
import { enemyAttackSpec, enemyCombatStyle } from './TowerEnemyAttacks.js'

const spec = enemyAttackSpec(
  { family: e.family, role: e.role, radius: e.radius, damage: e.damage },
  distanceToPlayer,
  state.time,
  e.ai.cooldowns,
)
const style = enemyCombatStyle(e)
```

`distance` 为怪物中心到玩家中心的世界距离；`time` 和所有 CD 均为暂停会冻结的模拟秒数。`cooldowns` 默认 `{}`，键为攻击 `kind`，值为该招式下一次可开始的绝对模拟时间，例如 `{ charge: 15, bite: 11.2 }`。到达时间的瞬间可选，不提前放宽 CD 边界。两个函数均不修改输入，每次返回独立对象。

`enemyAttackSpec` 返回兼容旧 Run 的平铺 spec 或 `null`：

| 字段 | 含义 |
|---|---|
| `kind` | 本模块只产生 `bite / charge / shot / web / slam / sweep`；仍在 `validAI` 已有集合内 |
| `shape` | `sector / capsule / circle` |
| `windup / active / recovery / cooldown / lock` | 前摇、有效期、收招、招式 CD、锁定目标时刻，单位秒 |
| `range / radius / width / angle` | 攻击几何；`angle` 是整个扇形的角度，单位度 |
| `damage` | 原样返回输入 `e.damage`，不乘角色或阶位倍率 |
| `speed` | 猪冲刺 460、投射物 270，其余 0 |
| `cost` | 普通 1；精英/Boss 2，沿用现有危险预算 |
| `segments` | 始终 1；不在此模块生成首层 Boss 双冲 |
| `element?` | 仅 `shot` 返回：`poison / feather / sonic`，用于投射物辨识 |

Run 的 `_newAttack` 继续添加 `id / segment / dirX / dirY / x / y / targetX / targetY / startedAt / locked / hit / fired / travelled / boundary / maxRange / clipped`。`validAI` 和弹体校验已将 `element` 作为可选枚举；旧存档可以没有该字段，存在时只接受三种既定值。

近战先生成最终 spec，再用 `distance <= spec.range + 18` 判断玩家圆盘是否可触及。这里的 18 是现有玩家半径，不能再用旧 `e.radius + 54 + 18` 提前返回。猪冲刺的选择区间独立为 **130–360，包含两端**，路径 360、有效期 0.8s、速度 460，保证直线路径确实能走到选择距离上界。地形裁剪仍归 Run。

`shot / web` 在中心距离 **0–480** 可以选中；480 是发起资格范围，弹体寿命仍由 Run 管理，不声称已经把弹体最大飞行距离改成 480。近处允许开火是墙边受阻时的保底，正常走位应优先恢复下述距离带。

`enemyCombatStyle` 返回：

```js
// 蛇、蝎、隼、蝠，以及精英/Boss 蜘蛛
{ ranged: true, preferredMin: 180, preferredMax: 300 }
// 猪、狼、熊、虎、鳄、猿、蜈蚣、普通蜘蛛及未知族
{ ranged: false, preferredMin: 0, preferredMax: 0 }
```

远程偏好与 CD 独立。Run 对可见远程单位在 approach 阶段实现了小于 180 时后退、大于 300 时接近、带内保持；步长在距离带边缘截断，冷却中仍使用这一策略。退路被墙挡住时按保存的 `orbitSign` 尝试两侧，只接受合法且增加玩家距离的位置。屏外单位继续接近，可见性检查仍限制发起/继续攻击。没有使用“`spec` 存在便停止所有接近”和“`spec === null` 便无条件向玩家走”处理可见远程敌人。本模块自身不移动实体。

未知族保守返回近身 bite，距离过远或 bite CD 未好则 `null`。未知 role 按普通处理，不意外升级为精英技能。正式鳄族键为 `crocodile`，也接受 `croc` 简写。非法距离、时间、身体半径、伤害或当前招式 CD 不产生攻击。

普通、精英、Boss 的差别放在攻击范围、角度、前摇和节奏上；伤害保持原型已有值。下表写的是战斗 spec，具体动物预备姿势仍需表现层制作，不宣称新增动画已完成。

|---|---|---|---|
| 猪 | 近处咬击；中距直冲，有明显蓄势和 5s CD | 更宽身体冲撞，前摇更长，冲刺 CD 4.5s | 通用单冲 CD 4s、1.05s 前摇；首层仍走 authored 双阶段 |

苍鬃狼王、镇魇白虎使用各自真实伤害和 `role: boss`，通过 family 进入狼/虎的通用攻击。此模块没有为具名异种伪造额外阶段。隼/蝠/蝎/蜈/猿的 Boss 原型在数据中存在，不等于本期九层都投放了这些 Boss。

`element: 'poison'` 仅指直接命中的毒液弹，不附带中毒持续时间、层数或额外伤害。羽刃和声波也不附带新控制效果。蛛网复用已有 `kind: 'web'` 地面控制，模块不定义新的 DoT。核对时的 Run 蛛网已有 4 次、间隔 1s 的区域伤害采样和 0.75 倍移速；这与毒液弹是两条不同路径，不能把网的重复采样复制成所有毒液弹的持续伤害。

## 已接入行为与保留约束

1. `_attackSpec` 在首层 authored Boss/蜘蛛特例之后调用 `enemyAttackSpec(e, d, s.time, ai.cooldowns)`。第一层蜘蛛早期返回 bite，保留原 role 的危险预算和近战站位，没有把精英实体改成普通。
2. recovery 完成时写 `ai.cooldowns[a.kind] = s.time + a.cooldown`，同时 `ai.readyAt = s.time`。因此冲刺 CD 不会连带封住 bite；出生 grace、入场、前摇/收招和全局攻击预算仍独立生效。
3. 每次选择传入真实 `ai.cooldowns`。猪冲刺 CD 未好时，近处返回 ready 的 bite，远处返回 `null` 以继续接近，没有缓存无 CD 的 charge spec 反复启动。
4. approach 阶段消费 `enemyCombatStyle`，将远程的退后/接近/保持距离与攻击是否 ready 分开。执行攻击时遵守既有锁定方向，不把射击变成贴身碰撞。
5. `shot` 使用已保存的 `a.speed` 发射，并向弹体透传可选 `element`；当前弹半径均为 12，伤害使用 `a.damage`。Boss 保留 `[-.25, 0, .25]` 三发角度分布。View 已绘制绿色毒液、沿速度方向的羽刃、同心声波环；没有新增伤害 kind 或自动挂 DoT。
6. web 复用现有落点圈和减速。需要变更网持续时间、采样次数或叠网规则时单独验证，不在此纯选择器暗改伤害。
7. Run 已使用新 spec 的最终 `range/radius/angle` 生成预警与命中判定，移除了旧 bite 的距离预筛。首层 Boss 的 authored 选择距离与范围保持独立。View 的扇形竖直方向仍有零值回退缺陷，见最终审查；不能据此宣称全部预警几何已验收。

选择器只决定“当前有没有某一招可用”。真实 CD、移动、伤害、弹体、预警创建与存档恢复已纳入 Run 专项回归。当前只读审查只修改本文与审查报告，没有改生产代码或 31 号统一需求文档，也没有执行 build/sync 或重复测试。
