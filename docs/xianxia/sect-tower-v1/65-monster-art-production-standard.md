# 怪物动作制作与接入标准

2026-10-31用户确认，以已验收的妖猪动作及256px清晰版为后续默认标准。新怪物制作开始前读取本文件；不再依赖用户重复指出体型、狂暴或模糊问题。

## 外观与品阶（2026-11-01用户变更）

1–3阶沿用野兽外型；4–6阶采用直立兽形／半人形（保留兽首，蛛蛇可保留异类下身）；7–9阶采用人类头脸、躯干、四肢和手足的化形版，允许保留物种特征和背部附肢。按原型实际品阶判断，与普通／精英／Boss身份无关。仅变更美术，不改变品阶、数值、技能、奖励、碰撞或投放。没有新图的原型记录为待适配，旧图作为过渡；不得把同族低阶野兽图一起替换成高阶形态。旧图和旧prompt保留历史，七阶白虎旧虎首prompt停用。

## 体型与清晰度

- 在制作前确定普通怪、Boss、狂暴三个显示档位。Boss以已批准的妖猪基础放大2倍为对照：旧基础画布上限110，新Boss常态220，狂暴264；不是每次迭代再乘2。
- 外形瘦长、展开翅膀等物种按可见主体与玩家的实景对照调整，不能只看PNG画布数字。普通怪保持普通体型，不因共用动作而跟随Boss放大。
- 使用原生至少256px的RGBA帧；主体在画布中应占合理比例。禁止128px缩略图充当大Boss动画源，不允许把128px再插值到256px冒充高清。若最终物理显示像素超过源细节能力，应在制作前选更大母版。
- 尺寸定稿后才决定输出帧分辨率。检查真实引擎载入的帧矩形和纹理尺寸，不能仅验证磁盘源图。保留所有原始图片、视频、不满意版本和制作记录。
- 透明图集不套用物品图标98%规则。动作需要完整保留角、尾、脚与特效边界，固定画布、镜头、朝向和脚底锚点。

## 狂暴生命周期

- 仅用于已有狂暴机制的物种；不得为了复用美术擅自给其他Boss增加狂暴。
- 发动动作完成后才进入狂暴。常态颜色→暗红体色，Boss基础尺寸额外×1.2。不是仅播放一次变色动画；移动、攻击、技能、受击在有效期内全部保持狂暴状态。
- 到期或死亡立即解除。死亡使用常态颜色与Boss基础体型播放倒地，不缩回普通怪尺寸。
- 当前不增单次伤害、主要加速施压的M02持续15秒；若未来方案显著增强伤害或威胁，按用户授权选择10秒并说明强度依据，不能偷偷增加伤害。
- 时钟跟随模拟时间；暂停冻结。存读档保持剩余时长，不续期；拒绝时间篡改。不改变每只怪的既有触发次数。

## 动作与接入

- 先查真实攻击配置，再制作所需动作。移动循环、普通攻击前摇／生效／收招、机制技能、受击、死亡分别映射；未配置的技能不做成新玩法。
- 普通怪和Boss可复用动作，但按各自阶段时长播放，伤害与召唤仍由战斗逻辑决定，图帧不能产生额外伤害或奖励。
- 循环接缝需测量并目视检查。攻击必须有可读前摇；生成片段不合格要记录，不当作完成品。死亡只由真实击杀触发，不由离屏消失触发。
- Boss放大时一并检查裁剪余量、遮挡层级、头顶文字、血条、碰撞与预警的可读性。视觉放大不自动放大碰撞半径。
- 图集规划需记录展开内存；避免所有物种双份大图集无条件常驻。桌面预览通过不等于微信真机内存验收。

## 交付前必须完成

1. 记录来源、模型参数、费用、源帧→运行帧映射及实际加载尺寸；先查可复用素材。
2. 输出常态/Boss/狂暴（适用时）同场与玩家对照；原始像素、透明边缘及固定锚点检查。
3. 引擎内看完整移动、普通攻击、机制技能、连续受击、死亡。横屏1280与844宽至少各一次。
4. 狂暴测试发动前、发动完成、全程保持、到期、暂停、读档、死亡；不适用的物种明确记为不适用。
5. 相关自动测试、编译和实景截图通过后才称已接入。生成受配额限制时保留已完成准备并准确报告，不把提示词或静态缩放说成已制作动画。
