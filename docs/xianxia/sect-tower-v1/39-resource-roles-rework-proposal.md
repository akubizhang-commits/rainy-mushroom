# 灵石货币与妖丹修为：职责调整提案

日期：2026-10-28。状态：用户已批准，已接入技能、战斗、钱包与存档。

最新覆盖：开发期不兼容旧档直接重置，不做迁移；schema 4当前档正常保留。见31号需求第15节及根目录AGENTS.md。下文价格作为当前试玩基线。

## 目标与建议

灵石作为可积累、可支配的通用货币；妖丹用于战斗中即时修为成长；宗门贡献代表完成宗门任务的资格与奖励。三者不互相无限兑换。

| 资源 | 主要来源 | 主要用途 | 是否进入钱包 |
| --- | --- | --- | --- |
| 灵石 | 妖兽随机掉落、通层及首通奖励 | 藏经阁特殊技能/进化经卷、有限研习；与贡献共同寻器 | 是，四品阶 |
| 妖丹/妖丹精华 | 击杀妖兽 | 自动吸收为修为，触发原有升级、技能点、升级回血 | 否 |
| 宗门贡献 | 清波、通层、首通及后续宗门任务 | 寻器、强化、场外丹药 | 是 |

普通加点仍只花技能点。学会技能永久保留、洗点不退经卷购买费也不取消解锁。藏经阁保留购买特殊经卷、研习、洗点的职责。

## 灵石品阶

保留100下品=1中品，100中品=1上品，100上品=1极品。下品为最小记账单位，支付自动找零，无须合成按钮或四个独立的钱包操作。

例如1中品支付30下品后剩70下品。价格中的品阶是金额单位，不额外要求必须持有某种实物石头。

初期锁妖塔以 下品/少量中品 为主；上品、极品预留给后续地图和大额消费。不为了展示所有品阶而把塔内价格放大。

## 妖丹经验与战斗节奏

- 保留妖兽阶级对应妖丹阶级、一至七阶塔内可见的关系；更高阶后续开放。
- 建议撤销旧“10颗低阶兑换1颗高阶”的货币/合成规则。经验表独立设定，不采用十倍指数增长。
- 不把原先低概率妖丹掉落直接改成唯一经验来源。每次击杀都有基础修为反馈，小怪可表现为妖丹精华，精英和首领表现为更明显的妖丹。
- 首次切换先保持每种妖兽当前的经验预算及累计境界曲线，再调整品阶表现和颗数。需要先校准同阶丹的单位经验与掉落数量，使相同单位价值一致，不给相同外观任意赋值。
- 当前运行时经验为 `妖兽阶级 × 普通1/精英5/首领10`；一层完整击杀预算452修为。新版不能再叠加旧灵石经验，否则经验翻倍。
- 塔内自动吸收，不增加吃丹按钮，不作为背包七栏货币，不要求回宗炼化。
- 保留金丹封顶、溢出不储存、死亡不扣已获修为、小阶回血30%/大境界回满。回满和视觉效果继续走同一升级入口。

## 随机掉落与价格：建议初测尺度

灵石继承随机经济奖励，但控制完整通层的总价值范围，不以物件数量代替经济预算。未通层按实际击杀所得，不凭空补足完整层保底；退出/死亡不重抽同一击杀奖励。

可先以“当前妖丹值预算×10”作为灵石金额起点，仅用于平移购买力，不是最终物理掉落方案：

| 层 | 击杀灵石总值候选范围（下品） |
| --- | --- |
| 1 | 570–690 |
| 2 | 590–710 |
| 3 | 710–850 |
| 4 | 790–950 |
| 5 | 810–990 |
| 6 | 980–1180 |
| 7 | 950–1150 |
| 8 | 990–1210 |
| 9 | 1080–1300 |

表中不含清层/首通奖励。沿用既有高阶妖丹概率会造成灵石面额偏差，需要重新制定下品/中品组合与价值约束。先保留原层间预算，以免一次改动同时改变成长和经济；第6/7层不严格递增另在敌群和耗时校准时审查。

技能价格候选：特殊主动经卷200下品，特殊被动经卷100下品，进化经卷2400下品；对应当前20、10、240妖丹值。基础免费技能仍免费。三次限量研习800/1600/2400下品，继续保留通3/6/9层及总共3点限制。

寻器候选：100下品+100贡献/次。贡献费用、武器概率40/35/20/5%、20抽极品保底、三把武器、重复回贡献及无指定兑换均不改。新增灵石费用仍须用户确认。

抽取固定消耗两种资源，不按投入金额提高概率；不能用更多灵石无限替代贡献。初步每层贡献预算继续限制抽取次数。按照第一层最低570下品，购买一部200下品经卷并抽一次100下品，仍余270下品；不会一抽就耗尽全部学习资金。

该例只说明第一层总预算，不代表所有经卷在第一层就可购买；境界、前置和通层条件不变。高阶经卷需多层积累。

初始灵石与贡献、清波/首通奖励需随选择一起校准，保证前期教学和恢复可进行。不能直接将旧修为变成可消费灵石，也不能消费钱包时倒扣等级。

## 其他系统

- 回春丹、培元丹及强化本期继续花贡献，减少与功法学习争抢同一份灵石。培元丹仍是场外可选修为补充，非必需品。
- 贡献不作为小怪地面钱币，结算清波和宗门奖励时显示。
- 技能页不展示顶部货币；购买经卷控件附近仅显示实际所需金额和持有量。钱包显示的地点需结合用户暂不展示妖丹的决定处理。
- 封顶后继续掉落灵石、贡献；妖丹不改成可囤经验，也不自动转钱，防止新地图开放瞬间跳境界。
- 无付费抽取；付费设计不在本轮范围。

## 实施与验收（决策后）

1. 独立字段及存档版本：灵石钱包、永久修为、贡献分开；既有妖丹余额不能被当成新增经验重复发放。测试档是否重开另行决定，不能擅自清档。
2. 更新掉落、清波/通层奖励、支付、经卷、研习、抽取与文案，不能只替换图标和名称。
3. 原子扣除灵石与贡献，任一不足不扣另一项，保存失败不丢钱或改变保底。
4. 回放固定种子九层，核对经验/升级回血次数、经济上下限、再入塔与重复结算、各品阶找零、满级与研习上限。
5. 比较“先学习”“先抽器”“混合购买”三种路径，确认均可推进且恢复费用不会导致软锁。
