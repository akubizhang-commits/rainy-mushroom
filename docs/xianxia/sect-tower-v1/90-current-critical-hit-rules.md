# 当前暴击与持续功法结算规则

适用：当前 `growthVersion=1` 的宗门锁妖塔。2026-11-03 更新，包含武器流血和碧落剑痕转化制。

## 现行规则

|伤害类别|独立判暴击|说明|
|---|---|---|
|普攻、直接功法|是|每次有效命中按当前概率判定|
|周天／无我等环绕命中|是|按实际命中窗口，不按视觉剑数额外乘算|
|两仪／四象、万剑剑雨等持续功法|是|每次实际伤害分别判定；持续不等于禁止暴击|
|剑罡爆裂的独立伤害|是|它按自身基础伤害结算，不是复制触发命中的最终伤害|
|碧落转化出的剑痕|否|继承触发伤害中已经结算的暴击与增伤，不再判一次|
|武器流血 debuff|否|从原伤害分配50%转化额度，再乘流血增伤及当前层数增伤；3秒内扣血，不二次判暴击、不递归触发效果|
|武器附加伤害|否|按本次转化后直伤乘附伤比例，包含该命中的暴击收益，不再独立暴击|

源码中的判定边界是 `!hit.scaled` 且伤害类型不是 `none`，不是 `hit.direct`。同一次混合伤害只判一次暴击，物理与法术部分一起乘暴击倍率；不同目标、不同跳伤分别结算。

暴击率为剑心、武器和戒指的暴击率之和，上限 100%。暴击倍率为：

`1.5 + 武器暴击伤害加成 + 戒指暴击伤害加成`

加成在公式内用小数表示。例如普通命中最终为 100、额外暴伤 18%，暴击为 168；不会再将暴伤单独乘剑骨。装备与心法增伤先按当前公共属性公式结算，再乘暴击倍率。

## 暴击与派生触发分别判定

碧落与剑罡爆裂的触发要求有效直接伤害，且不是已结算的派生伤害。持续阵法和剑雨能暴击，但不因暴击就获得直接伤害的派生触发资格。剑罡爆裂自己的伤害虽然能暴击，也不会递归触发自身或碧落。

武器附伤是转化后直伤的比例，不重新放大装备／心法，不重新判暴击，也不递归触发附伤或派生效果。目标剩余气血不足时，实际扣血受剩余气血限制。

不要将历史“持续伤害不暴击／不触发会心”合并句当成当前判定。会心、派生触发与暴击是不同机制；旧版本每五次施放的规则不能据此重新加回当前暴击结算。

## 当前持续掉血分配

原伤害先结算暴击与减伤，再按武器流血50%→碧落剩余直伤50%的顺序分配。两者同时生效时，100原伤害分成25直伤、50流血基础额度、25剑痕基础额度，再分别计算异常增伤；不保留完整100直伤额外叠加两份持续伤害。

两种异常分别从1层叠到11层，第2层起每层增伤1%，最多10%，按跳伤时的层数乘一次。单次3秒6跳；重复命中合并剩余额度并刷新3秒。碧落落剑前奏保留，原60%落剑爆发取消。详见 design/balance/dot-conversion-2026-11-03.md 与 tests/xianxia-dot-conversion.test.mjs。
