# 技能依赖精简：仅保留四条进阶关系

状态：按用户要求实施。本规则覆盖38号提案及其他旧稿中的技能前置DAG；不改变双流派与通用技能的归属。

## 依赖的唯一含义

A → B 表示：B以A为基础进行升级替换，学习或提升B时必须满足A的等级要求；洗掉A的必要等级时，B随之降级并返还对应技能点。箭头指向进阶技能。

同流派、伤害相似、搭配有效、境界先后，都不构成技能依赖。境界、通塔、经卷与技能点是独立学习条件，只在详情中显示，不画成技能连线。

## 保留的四条关系

| 基础技能 | 进阶技能 | 保留原因 |
| --- | --- | --- |
| 御剑术 | 万剑归宗 | 在原御剑施法上增加剑雨，替换原施法 |
| 万剑诀 | 无我剑境 | 改造原环绕剑阵，不与原版重复施放 |
| 一线天 | 天地一剑 | 将原贯穿斩改为蓄势重斩 |
| 两仪剑阵 | 四象剑阵 | 改造原落点剑阵，沿用基础伤害预算 |

进阶1/2/3级分别要求基础技能6/8/10级。当前金丹阶段最多进阶2级；3级仍受未来境界限制。

## 删除的七条关系

| 删除的要求 | 理由 |
| --- | --- |
| 剑影分光要求御剑术2级 | 是独立落点爆发技能，不消耗或改造御剑术 |
| 一线天要求剑气斩2级 | 直线贯穿与近身扇形各自独立 |
| 两仪剑阵要求万剑诀2级 | 落点阵与环绕阵各自独立 |
| 万剑归宗要求剑心通明 | 暴击被动只是可选搭配 |
| 无我剑境要求剑骨 | 伤害/移速被动不是施法前提 |
| 天地一剑要求青萍剑意 | 剑痕被动不是施法前提 |
| 四象剑阵要求剑开天门 | 击杀爆发被动不是阵法前提 |

所有被动可按自身条件学习，不强迫投入无关被动来解锁大招。元婴、化神、炼虚预留技能尚未定义真实依赖，不添加推测连线。

## 页面与战斗一致性

- 仅一种玉青色细实线，末端小箭头表示方向；不使用虚线、点线或颜色分类。
- 基础与进阶尽量同列，连接线绕开其他图标、名称与境界标题。
- 已学和未学都显示同一关系；是否可升级由现有升级箭头与详情说明负责。
- 详情只列真实基础技能要求；取消的前置不再阻止学习或触发洗点级联。
- 进阶仍替换基础技能，不让两个版本叠加施放；取消前置不自动发放技能、技能点或经卷。
- 保留现有境界、通塔、书价、技能点成本与伤害系数。减少无关前置让搭配更自由，但不提高总技能点上限。

## 验收

验证无被动也可学习满足条件的进阶技能；洗掉可选被动不影响进阶；基础技能不足仍拒绝学习；基础降级使对应进阶降级并原子返还技能点。页面只有四条依赖关系，三种横屏尺寸下无连线穿过图标文字。

## 技能页复核修订

御剑术、一线天、两仪剑阵之间没有依赖，不连接这三个独立技能。四组基础/进阶关系各自保留独立列与走线通道，禁止不同关系共用长线造成串联假象。

- 顶部洗点入口统一为刷新图标＋“初始化”；无可退点数时仅置灰，不把禁用原因拼进按钮。
- 初始化是技能点重分配，先展示退款预览，再确认；不重置角色修为、装备或已购经卷。仍仅在藏经阁可用。
- “获取技能点”下移到技能列表底部，作为次要入口；塔内不显示。
- 技能详情正文与属性数值统一20设计像素，区分名称、标签、效果、升级条件。删除重复的伤害统计提示。
- 详情独立滚动，底部加减操作固定；列表卷轴与下方次要入口不重叠。
