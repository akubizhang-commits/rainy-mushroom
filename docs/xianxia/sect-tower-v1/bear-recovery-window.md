# 第6层撼地熊王：重招后的破绽窗口

2026-11-01。用于改善中期御剑路线Boss战斗偏长；沿用自动施法与移动操作，不增加按钮。

- 只作用于第6层Boss完成M07裂地重踏、M09撼岳掀浪后的收招。
- M07收招由2秒延至5秒，M09由2.5秒延至5.5秒；其间Boss承伤提高20%。
- 使用现有破绽状态，易伤总上限仍为20%，与其他来源取最高值，不相乘。
- 预警、攻击伤害、攻击范围、Boss生命、玩家技能伤害、装备及成长曲线不变。残留攻击预警与伤害仍按原时间结算，破绽不代表玩家无敌。
- Boss收招时停止普通行动，技能冷却仍从收招结束后开始，因此出招频率也会下降。需要把生存变化与击杀时间一起评估。
- 离开视野导致蓄力取消时不授予额外窗口；精英、其他楼层和其他招式不受此规则影响。
- 复用现有HUD及头顶“破绽”倒计时，以战斗模拟时间计时。暂停不消耗窗口，重载保留剩余时间；不新增存档字段。
- 岩甲结晶被击破后的原6秒破绽继续保留。

本轮同资源御剑三种子初筛：Boss中位158.33→141.88秒，接近但尚未达到135–140秒目标。纯延长收招的两档未稳定改善，最终选择带20%承伤收益的窗口。最终成长与跨路线结果见`design/balance/balance-check-bear-recovery-window-2026-11-01.md`。
