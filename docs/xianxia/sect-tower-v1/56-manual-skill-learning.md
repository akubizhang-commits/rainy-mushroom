# 初始剑气斩与自主学习

2026-10-30。按用户要求，将锁妖塔新角色的唯一初始技能改为一级剑气斩，其余技能手动加点。

## 行为变更

- 新档技能、战斗配装及初次进入技能页均使用剑气斩；初始等级为 1，不额外发放御剑术或环剑诀。
- 移除战斗清波时补入技能、存档检查点再次补入技能的两条自动学习路径。角色升级只增加修为对应的技能点，不学习技能。
- 第一、二层首次通关分别追加 **1 技能点**，玩家自行决定学习什么。保留现有灵石/贡献奖励；清波、失败、撤离和重复通关不发这两点。
- 第三、六、九层原有首通技能点不变。因此境界 30 点＋首通 5 点＋研习 3 点＝38 点，另有开局剑气斩一级。
- 初始化维持此前“全部技能归零”的行为，仅将初始剑气斩的一级折为 1 点，合计最多 39 点；重复初始化不能叠加此来源，也不会再次自动学会剑气斩。
- 原 tutorialWaves 字段仅为保留的快照结构字段，不再随通关增长，不再决定赠技或技能点。
- 存档版本升为 13；旧锁妖塔存档按开发期约定重置，其他模式不改。
