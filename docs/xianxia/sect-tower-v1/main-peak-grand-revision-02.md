# 云阙主庭第二轮验收

对象：《云雾山寺中央大殿.png》。

与上一版相比，主殿明显扩大，中轴和主次关系更清楚；画风一致性、功能辨识基本通过。但“宏大庄严”仍未达到目标，本轮不定稿、不接入。

问题集中在尺度线索与建筑基座：大殿仍像低台上的宽阔寺院，灯具、石兽和侧殿相对偏大；基座被台阶和花木遮掩，缺少大面积可见的厚重台壁；视点仍偏高，平视屋顶多于仰望立面；各处明度接近，檐下与门廊不够深。不能只把屋顶进一步放大。

## 可直接使用的重构 Prompt

以附图为画风、材料与功能位置参考，重新绘制落云宗主峰的宗门正殿近景。16:9横屏，保留青灰瓦顶、灰白石材、松绿色植被和细腻水墨淡彩风格。

重点重构建筑尺度与高差：中央正殿连同台基占画面高度约三分之二、宽度略超过一半。正殿立面宽阔，柱列高大而有秩序，门廊深邃，屋顶舒展厚重；保留参考中的传统重檐形制，不用密集堆叠小屋顶增加复杂度。门窗、灯具、栏杆等保持正常的小尺度，衬托殿宇巨大，不要让附属器物随主殿一起等比例放大。

正殿立于三重高台之上，清楚露出厚重整洁的石质台壁与逐级退台的栏杆。宽阔中阶贯穿中轴，辅以两侧较窄阶道。视点降低到前庭石坪，轻微仰视殿门与高台；屋顶和入口均完整可见，避免俯视庭院的效果。前景石道庄重规整，指向正殿，不安排抢眼的大型圆形花纹。

藏经阁退到左侧，庶务堂和委托榜退到右侧，侧殿的可见高度约为正殿建筑主体的三分之一。它们保留明确可点击入口和必要的书卷、榜架识别物。演武台只露出左前方一角，静修院以右侧月洞门表示。减少花丛、盆景、武器架与散乱小物，留出宽阔的礼仪空间；古松只在边缘衬景，不遮挡主殿台壁和柱列。

柔和天光照亮台阶与殿前石柱，檐下和殿内保持更深、更冷的阴影，使建筑厚重有层次。远峰和建筑淡入云雾，不能高耸醒目地压过主殿。画面应体现统领诸峰的仙门正殿，有仪式感和历史感，同时保持宗门首页的清雅配色。
