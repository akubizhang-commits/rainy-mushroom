2026-10-27｜设计初值；九层与每层至少20波是用户确定框架，其余待试玩校准。妖兽外形、名字与能力以08号稿为准。

> 首层具体编排与出生预约账本见[15号稿](15-floor01-encounter-design.md)，首领状态见[16号稿](16-boar-boss-design.md)。[17号合同](17-entry-exit-and-loot-proposal.md)已确认击杀收益与完成奖励分开保存：死亡/撤离保留当前波已击杀资源，未达成完成奖不发；恢复最后可靠战斗快照，不能保留波中钱包却复活已记奖怪物。

## 1. 层与波

一期每层20波，共180波。第5、10、15波为精英波，第20波为首领波，其余16波为普通波。精英波仍可有少量普通妖兽；首领死亡后必须清尽支援，不以净化特效回收余怪冒充击杀。

波1–3：逐种认识妖兽；4：首次混编；5：精英检验；6–9：主族＋少量已学过的妖兽；10：双精英错峰；11–14：队形变化；15：精英组合；16–19：高压但保留安全口；20：层主及有限支援。

波间自动收取本波未拾取的灵石/妖丹，避免最后一只远处资源造成拖延；随后最多4秒准备，可点击提前开始。时间不构成清波条件。塔内回血掉落保留为即时拾取效果，不是带出奖励，不允许死亡自动收取回血复活。暂停不运行敌人和预警时间，也不计算场外恢复。

## 2. 全清状态机

`准备 → 波中 → 清波待结算 → 波间 → 下一波`；第20波结算后为`清层 → 继续登塔/回宗`。第9层清层才记录九层通关，之前记录单层成功，不能沿用旧“一次Boss死亡=整局胜利”。

每波维护`planned=pending+reserved+alive+killed`，其中reserved是已预约且正在出生预警的单位；需pending=0、reserved=0、alive=0、killed=planned，玩家存活且无未登记的必需召唤任务，才提交清波。容量满时保留队列；离屏、卡住、回收与击杀不是同一事件。卡住的必杀怪安全重定位到可达处，不直接加击杀数。

首领波8只支援预先列入账本：开场4只、半血4只；若一击跨过半血乃至击杀，后4只也须加入待生成队列，不能丢任务。首领招式不可无限召唤。预警出现后再生成，落点避开玩家身边且可达；不因角落站位让预警与怪体出界。

同一tick玩家与最后妖兽同时死亡：先结清伤害和死亡，再判断存活；玩家死亡则本波失败，不解锁下一层、不发本波全清奖励。该次真实击杀掉落及此前已得收益保留，死亡回宗以1HP苏醒。保存失败冻结待结算状态并可重试，不重复击杀和发奖。

## 3. 固定原型与内容初表

按[13品阶基础表](13-rank-calibration.md)设置普通/精英/Boss属性，同名同阶跨层一致，不叠楼层、波号或分钟倍率。旧楼层成长表和普通怪逐波HP乘数已撤销。敌人属性与奖励表已获准作初测基线，具体难度仍需试玩。

各层并发容量初值依次24/28/32/36/40/44/48/52/56；首层按`alive+reserved≤24`执行，后层同样不能因满池丢掉必杀队列。第四层为伏潭鳄王，第七层为裂风隼王，虎鳄品阶以10/13号交换后的表为准。移速与攻击资格共同约束压力，不靠增大倍率填满8–12分钟。

初表普通数量基线：10、12、14、16、10、16、18、20、22、12、20、22、24、26、14、24、26、28、30、8。除Boss支援固定8只外，每升一层加2只；每层至少3族；第4波起两族约60/40混编，第11波后通常三族约50/30/20，重型比例限制优先。精英5/10/15波分别1/2/2只，错峰进入。虎与熊普通怪占比上限40%，余量由已熟悉的猪狼补足，防止把轻怪数量全部换成重怪。

data/tower-design.json 给出九层具体配置与180波计数、族群分配。它是待实施的内容账本，不是游戏已经读取的配置。

## 4. 永久成长与波内节奏

用户已确认妖丹换技能书永久学习、永久升级。撤销“19次免费清波升级”与境界突破送技能点。入塔使用宗门保存的技能等级与最多4功法＋4心法配装；基础御剑术由入门赠书学习，不每次重建技能。波间只清理拾取、提交收益、准备下一波，不再弹免费升级三选一。

妖丹带回藏经阁兑换指定书，升级后用于后续挑战。12号技能结构、价格、逐级效果已获准作试玩基线；按固定阶位原型核验各层，不把旧局内满级战力当新手起点。数值验证至少区分入门、阶段正常养成、当前上限三档技能，不只区分装备好坏。

修为永久保留，首期Lv27/10920封顶，修为攻击/最大生命增幅各最多20%，场外培元丹也受上限约束。出塔、再次入塔及直接下一层继承当前HP；死亡回宗1HP。仅场外每分钟恢复1%最大生命，含离线；新尝试技能剩余冷却归零但不跳自身前摇，暂离恢复原HP/CD。

单层8–12分钟仍是建议目标，不是实测成绩。若减少选卡后明显变短，应先观察战斗节奏，不机械用怪物血量填满时间，更不能减少20波。

## 5. 测试矩阵与验收

- 每层三套剑修路线：初始无强化、普通完整配装、顶配；至少10个固定种子，记录首通/死亡波、TTK、伤害来源和耗时。
- 自动检查180波身份唯一、各层三类怪齐全、召唤预算有限；满池、离屏、角落、一次击杀Boss、最后敌人与玩家同死、断点重载、保存失败均需专项测试。
- 熟练者无极品武器应能通每层；不要求新手第一次零装备连通9层。剑修不带灵兽、符箓或战斗丹药；需记录剩余HP、场外用药/等待恢复与再挑战体验，不擅加免费回满。
- 第一层新手测试目标：能理解预警并完成前5波；首次整层成功率目标60–80%。目标需真人样本，不能用机器人宣称达成。
- 三种路线同装备、同种子条件下，中位清层耗时差目标≤20%；超过则查技能机制与敌群分配，不直接加所有技能伤害。
- 20波中至少四种队形变化，首领有明确招式空档；每层增加一个主要挑战，晚层组合已教过机制。

最新阵容和阶位以10号稿为准：十二兽族均已进入逐波表，塔内≤七阶；第5/10/15波精英也已按多族分别编排。
