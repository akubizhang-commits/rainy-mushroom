# 七职业本命领域：元婴以后内容提案

2026-10-28｜设计稿，尚未接入游戏或通过实战平衡。领域开放境界、效果数值和升级预算均为本轮建议。

## 开放与操作

- 保留七职业：剑修、法修、符修（符师）、御兽师、阵法师、体修、邪修。法修火水木土雷冰风金是八个分支，不是新增八个职业。仅御兽师拥有灵兽。
- **建议元婴初期开启领域研习资格**。锁妖塔仍只能提升至金丹圆满，不能在塔内直接突破元婴。九层通关也不直接等于元婴，后续地图的修为与突破条件另行设计。
- 大境界突破只点亮资格；藏经阁购买本职业领域经卷，再投入首级技能点，才学会领域。购买不是抽取，可在资源齐备时用一次“解锁并修习”操作完成。领域永久拥有、等级跨局保留。
- 每职业先设计一个本命领域；法修继承原有单元素路线而呈现对应领域形态，不同时开启八系。无需新增出战槽，不需要手动开关，学会后入战自动展开。
- 领域常驻、随角色移动、无需新增蓝条和消耗品。退战或死亡结束，暂停冻结。不是短时间爆发按钮，强度靠条件、半径与升级预算控制。
- 五级境界门槛建议：元婴初期／中期／后期／圆满／化神初期。每级技能点成本4/5/6/7/8，共30点；这是[23号技能点方案](23-skill-point-budget-proposal.md)的后续预算，不挤入锁妖塔36点要求中。

## 光环与领域必须区分

[心法小光环](21-skill-tree-proposal.md#5-心法光环玩家直接看得到的被动)只是角色已学被动的标识，多项可以叠加。领域是实际范围机制，只有大的外圈边界参与判定；内部小光环继续保留。技能树中领域属于后期独立节点，不覆盖现有四个进化。

各领域以清晰的外沿和少量职业纹样表现，不使用实心大色盘。不要因特效叫“剑域”而把已有无我剑境当成新增本命领域。同样，旧法修“玄冰领域”等进化名称不自动取得新领域资格；未来实施需统一显示名称、保留不同ID与结算来源。

## 数值口径与五级表

半径建议180/195/210/225/240逻辑单位，不能随屏幕尺寸变化；是否入域按世界坐标圆判定，脚下椭圆只是透视表现。1→5级面积增加约78%，也是强度的一部分，不再同步增加攻击频率和目标上限。

A表示**不含本命领域增幅**的当前攻击标尺，已含合法境界和装备属性，不能再乘一遍装备。表内百分比均为对应等级的总效果，不逐级累加。所有表为初测基线，不代表各职业同等DPS。

## 共同结算与叠加规则

1. **领域增伤只计一次**：用不含领域的对应伤害D0，计算D=D0×(1+本领域适用增幅)。不把领域增幅写回攻击A，再由技能第二次读取。雷领域增加暴击概率，在原直伤暴击判定中一次完成；不额外复制一次伤害。装备仍独立遵守30%上限，例如合法1.30装备倍率与1.35领域倍率可得1.755，此时领域并非装备加成，也不说明未来整体强度已平衡。
2. **减速取最强而非相加**：建议所有普通/精英来源合并最多50%，Boss最多10%；不影响攻击前摇、攻击频率或已明确的冲锋/跃击轨迹，不打断Boss预警。无常驻硬控或强制吸附。
3. **降低敌人输出取强**：相同减攻效果不相乘，所有减攻合并普通/精英最多20%，Boss按一半且最多10%。状态由发起攻击的怪物是否入域决定，在攻击伤害锁定时记录；已经发出的弹体保留其发射快照，敌人离开不会追溯改写飞行中的伤害。
4. **防御领域不是回血**：厚土/金刚的领域减伤作为独立一次承伤修正，Lv5最高25%/30%。例如原承伤90，30%领域后为63，不得再减30点。减攻、常驻减伤、领域防御综合建议最高降低非无敌基准伤害50%，避免削攻×减伤叠成永久免伤；这是后续内容建议，不修改当前塔的常驻减伤上限。来自域外敌人的远程攻击不吃这类领域防御。自损生命、场景机关不被该领域减免。
5. **范围增伤看命中时目标入域**：剑、雷、风、金、符印和阵面增伤在命中/跳伤时判定实际目标。御兽增益按自有灵兽是否在域内、攻击锁定时取快照；离域后的新攻击失去增益，原有弹体不追溯，防御按受伤时灵兽位置判定。邪修短命施术媒介不算御兽师灵兽。
6. **领域DOT每0.5秒跳一次**：入域不立即补发一跳，使用连续全局半秒节拍；每次伤害=每秒系数×0.5×A，最多最近12个合法敌人，并列按稳定UID。离域立即停止未来跳伤，无残留持续毒、无进出刷首跳。暂停不推进，长帧结算合法模拟时刻，不用渲染帧数发伤害。
7. **不靠派生递归变强**：领域DOT不暴击、不吸血、不叠原有咒印、不再触发击杀连爆；正常致死仍产生一次击杀收益和掉落。领域加成部分不得再增加原有二次触发预算；普通伤害已有预算照常记。敌人回收必须清UID关联状态，不能让新刷怪继承旧减益。
8. **升级原位替换**：不同时留1级与2级领域；升级不重置原攻击冷却、不补血、不生成新首跳。未来多职业/多人同类场相交先采用同类取强，不能累乘；多人尚不在本轮开发范围。

## 领域经济与边界

领域经卷使用妖丹兑换，不新增“领域币”、随机抽取或每日碎片。升级用技能点，不再每级同时收一笔同价技能书费，避免同一成长重复收费。经卷的妖丹绝对价格待后续地图产出冻结后确定，建议以该阶段约4次标准战斗的妖丹净收入作为初值；开售后固定价格，不能根据玩家效率动态涨价。

领域强于一般单个心法，体现于明显范围机制和专长。不能声称减速45%、直伤35%、灵兽35%是同等价值；必须分别测试单体、密集群、远程压力、快速Boss、持续贴身和走位失域。需要允许某领域擅长群战，某领域擅长承压，而不是用一个攻击数值把它们做成同一种技能。

## 本轮交付与后续验收

当前同一技能预览页加入七职业与五级切换，法修可看八系，共14个领域形态。它是数值对照，未生成实际领域伤害或改变角色职业。

正式实施依赖后续地图与元婴内容；不为展示领域修改当前27级上限。最低验收包括范围边界/进出、死亡/暂停/重载、DOT节拍、减益与敌弹快照、召唤主体归属、技能点扣费与升级一次性、低帧率等价、敌弹与范围线可见性。强度通过同预算对照校准，当前仅有设计和静态检查。
