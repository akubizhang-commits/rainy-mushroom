# 剑修推荐配点与补点顺序

2026-11-04，适用当前每级2点、30级58点、双月/三才每级1点规则。以下为有限样本验证过的路线，不是唯一最优解。御剑与心法提供补伤、生存或功能，角色不必只学习同一系列。

## 使用规则

先完成所选路线的核心目标，再按下面顺序使用剩余点数。某个核心功法尚未达到学习境界时，补点阶段不会提前抢点；玩家仍可自行分配，不新增技能前置或自动代点。

全洗赠送流云折算出的额外1点不计入推荐预算。技能未买秘籍时，仍正常支付首次学习费用；不通过重复领奖或研习获取额外技能点。

## 月斩

核心终局：玄月10、逐月10、双月10、剑骨4、护体2、剑心4、御剑1，开局流云1保留，共51点。

完成核心后，剩余7点投入御剑1→8级，总计58点。三项月斩保留满级，御剑承担稳定单体补伤。御剑不需要凝神前置，因此不为此强制追加凝神点数。

首次学习节点：玄月4级、逐月14级、双月17级；剑心21级开放，27级才可修炼到4级。推荐是阶段目标，不要求到达首学等级就立即点满。

## 三才

核心终局：三才10、周天6、御剑6、流云3、剑骨4、护体2、凝神1、蚀骨4、剑心4，共43点。

剩余15点顺序：

1. 御剑6→10：4点。
2. 剑罡爆裂0→4：4点，首次正常付100灵石。
3. 御剑飞行0→1：1点。
4. 凝神1→3：2点。
5. 护体2→4：2点。
6. 流云3→5：2点。

共58点。三才和周天等级保留，补齐单体输出、触发补伤与移动/生存；不是把三才替换为两仪。

## 实现与验证边界

自然成长机器人使用 `scripts/lib/tower-natural-growth-policies.mjs` 的补点表；`planNaturalGrowth` 只有在原核心目标全部完成后才执行补点。其他六条路线默认无补点表，原策略不变。游戏没有新增自动推荐UI，这份文档供人工配点及审计复现。
