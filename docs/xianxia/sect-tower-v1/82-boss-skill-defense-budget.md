# Boss技能伤害与防御价值

2026-11-04。承接用户要求：普通装备连续吃满 Boss 主要伤害技能约3–5次死亡，好的防御装备可以多承受几次。覆盖81号文档中的旧防御参数；敌方统一命中倍率仍为2。

## 结算规范

1. 敌方基础伤害×技能系数，作为攻击、投射物或区域携带的原始伤害。
2. 同帧取最强原始命中；0.6秒受击保护期间不重复受伤。
3. 原始伤害×2×(1−金刚减伤)×对应防御倍率。
4. 护盾先吸收，剩余扣气血；致死不能被当帧回血救活。

物理防御来自防具，法术防御来自戒指；两者不串乘。混合伤害按物理、法术各半，分别减伤后相加。角色面板、实际伤害使用同一个常量：

`防御减伤 = D/(D+500)`，`承伤倍率 = 500/(D+500)`。

|防御D|旧减伤（K=1000）|现减伤（K=500）|仅由防御提供的等效生命倍率|
|---:|---:|---:|---:|
|0|0%|0%|1.00|
|100|9.09%|16.67%|1.20|
|300|23.08%|37.50%|1.60|
|500|33.33%|50.00%|2.00|

防御不依赖敌人等级暗变，也不把属性点当成百分比直接相加。固定生命下，等效生命为 `HP×(1+D/500)`；每点防御的等效生命收益恒定，不会因继续堆叠突然达到免伤。金刚与防御乘算，金刚当前最高15%，运行时安全上限18%。现有周期回血、升级治疗、掉落治疗、护盾触发和冷却保持。

以宝器中品守御防具132物防、极品255物防为例，即使锁死同样的气血，极品仍多提供约19.5%的物理等效生命；不是只靠体力撑血。法防必须看戒指，不能宣称仅换防具就能同等抵挡法术。

## 技能预算

所有系数定义于 `TowerMonsterMechanics.js` 的 `MONSTER_SKILL_DAMAGE`，以敌方基础攻击力为单位、在统一×2之前计算。不按玩家当前或最大生命反推伤害，换好装备不会触发怪物追涨。

|技能|旧单跳系数|现单跳系数|完整施放的口径|
|---|---:|---:|---|
|冲锋、重踏、尾扫、掀浪、落雷、震波、引兽冲锋|1.8|3.0|一次主要命中；第一层M06维持1.8|
|缚足蛛网|0.65|2.5|一次命中，保留定身与预警|
|寒瘴泥沼|0.12|0.55|每秒1跳、完整6跳|
|毒痕追猎|0.08|0.65|3个池各5跳，重叠同帧不叠伤；完整追踪为7次有效命中|
|摆首妖息|0.55|1.15|完整3跳|
|六门避劫／濒死绝唱|3.0|3.0|保留原预算；安全区仍可完全规避|

连环落石0.75、风刃封侧1.5、狱锁禁锢0.3沿用；召唤、回血、护甲、机关布置等非伤害技能不套用3–5次目标。引兽破阵布置阶段仍为零伤害，实际冲锋才结算。

精英使用相同技能系数；第2层起，其技能基础攻击预算不超过该层Boss基础攻击的80%，防止前期高阶精英技能反而超过Boss。此上限只作用于机制技能，第一层教学、原生普通攻击与怪物生命不变。后期低阶精英仍弱于高阶精英，没有把所有精英强行升到Boss强度。
