# 筑基丹与炼气突破

2026-10-31 初版（30%）历史记录，现行规则已由 `72-breakthrough-items.md` 覆盖：筑基丹55%，另增丹药、Boss材料和出售。

原用户要求：炼气十层满经验（炼气大圆满）后服用筑基丹，30%成功晋升筑基初期。用户确认每次消耗1颗，失败保留满经验，可重试，不设保底；丹霞峰以贡献购买，售价由本次平衡检查确定为60贡献。

## 规则与接入

- 丹霞峰购买，背包场外服用；丹药录提供药性、成功率、失败损失和获取方式。
- 炼气十层从1485修为开始，1800为满修为。击杀和培元丹最多达到1800；溢出不储存。
- 成功事务把修为推进到1801，晋升筑基初期。这个单独的境界分界点只由成功服丹发放；普通修为不能跨过它。技能、装备和战斗快照均读取同一境界函数。
- 失败：扣1颗丹药，保存新的随机状态，修为保持1800。不扣生命、不掉层、不退技能点。
- 未满修为、已经筑基、没有丹药或仍处于塔内时拒绝，库存和随机状态不变。
- 每次独立30%，无连败加成。使用独立、持久化的伪随机状态，不与炼器随机序列共用。
- 扣丹、突破结果、随机状态一次事务保存；保存失败全部回滚，重试结果相同。重载和旧窗口不能重复消耗同一颗丹药。
- 延续场外培元丹的生命规则：提升生命上限不会额外回满当前生命。
- 最后一颗用完导致详情卡消失时，背包底部仍展示突破成功或失败。

并行的“每境十层”任务已扩展为炼气、筑基、金丹各十层，筑基大圆满后的突破方式按用户最新要求暂待定，不开放免费的一键突破金丹。本文件仅定义筑基丹，不能用早期28级中间稿覆盖现行30级规则。以TowerProfile的导出阈值及对应十层测试为准。当前金丹满修为14400。
