# 数值审计修复补充规则

日期：2026-10-31。依据本次数值审计及用户“把所有发现的问题都进行修复”的指示。以下是本轮实现选择；未涉及部分继续遵守56、59、62、64号文档。

## 培元丹

- 每颗仍增加50修为，贡献价格不变。
- 累计使用上限为已首次通关楼层的修为预算总和×30%，按整颗向下取整。首层首通前无额度；重复通关、重复击杀、洗点不增加额度。
- 已有库存占用可购数量；达到修为上限后不继续购买无用丹药。
- 使用次数进入存档，并与库存、贡献、修为一起原子提交。旧档缺少消费记录时保留库存，保守扣除既有额度，后续首通继续解锁。
- 玩家界面显示首次通关解锁、剩余额度及可购数量。

## 技能与装备

- 纵横剑气采用剑气斩的同等级总伤害系数：1级1.5、2级2.1、3级起为`3×1.15^(等级−3)`；保持单次宽幅攻击，不改成剑气斩的分段形态。
- 环剑诀可见剑体角速度取`max(1.8, 2π/(剑数×0.6))`，补足低阶实际经过目标的频率；同一目标每0.6秒最多一次，保留内圈空隙及实际剑体命中范围。
- 2026-10-31用户确认环剑诀改为周期护身：发动起计6秒冷却，生效4秒，结束后2秒空档；期间仍按实际剑身碰撞、每目标0.6秒间隔结算。每轮最多7击，单击乘`10/7`以补偿原6秒最多10击的理想预算。无我剑境继续常驻且沿用原伤害，不套用该补偿。
- 环剑诀冷却受戒指缩减，持续时间和命中间隔不缩减。当前最大2.5%缩减对应5.85秒CD及1.85秒空档。界面标题下显示施放CD，详情单列持续时间及命中间隔。失效时贴图与备用剑体绘制同步隐藏；暂停冻结周期，存读档保留绝对结束时间和下次发动时间。
- 进化仍为独立高阶模板；可以按正常退点流程回收已被替代父技能的投入。测试配装必须实际支付经卷和技能点，不把父技能与替代技能当作同时输出。
- 装备沿用62号文档的35%输出总预算，不为小数面板观感而整体放大。

## 第一层首只精英

后续首层整体节奏调整见[73号文档](73-opening-pacing.md)：首只精英生命保持1391.5，旧0.22倍率已随基础生命下调改为`1210 / 3500`。以下是本轮最初的调整记录。

- 首层第5波及之前精英使用0.22生命倍率；首只妖猪实际生命由6325降至1391.5。
- 初始剑气斩1级、初始装备、移动操作、种子101/211/307，首次进入460px可见接敌范围至击杀均约38.58秒，符合64号文档20–40秒目标。该接敌代理口径不是所有技能都能立刻命中的保证。
- 第6波以后的精英、其他层与Boss不受这个倍率影响；不随玩家属性动态缩放。

## 召唤物与战斗存档

剑气允许记录真实召唤物的命中，死亡后继续保留去重与贯穿计数。机制状态保存只追加的召唤分配记录，包含主人、序号、种类、批次和时间；检查点不得删除或篡改已有记录。缺少历史的旧坏快照不通过猜测补齐，可从可靠战前存档重新开战。

召唤出生点统一使用实际怪物碰撞半径检查场地、柱子与视口；预选、预告和最终释放复查共用同一半径，避免大体型随从出生后立即成为非法快照。

## 验证口径

默认固定样本使用前面各层修为预算计算入层等级；3/6/…/27的旧终层参考等级保留为reference模式。固定配装只是受控比较，不能当作自然获得装备的证明。自然流程必须经真实Campaign支付、学习、退点、疗伤、结算和读档，并保留失败记录。
