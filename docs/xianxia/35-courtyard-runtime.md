# 古宗庭院首版试玩

2026-10-27，Alpha。MAP-1～MAP-4的交付是现有修仙试玩中的可活动庭院，不再只是静态合成。

## 空间与美术

采用用户已有的1248×1664庭院原图，保持原色，不拉伸、不重复平铺。原图1像素对应3个世界单位，原图坐标(624,900)为世界原点。背景与角色使用相同镜头平移；摄影机限制在图像覆盖范围内。

首版开放中央连通石坪：原图x=320～950、y=560～1280，世界x=-912～978、y=-1140～1020。角色出生在(0,0)。活动区边缘有淡青封界线；玩家与敌人按各自半径内缩。建筑、围墙、树木和石灯都在活动区外，无需用穿墙来省略碰撞，也没有将建筑当成可探索室内区域。图像和几何元数据分别管理。

场景资源为`cocos-pilot/assets/survivor/xianxia-courtyard.png`，原图字节不变。纹理1248×1664，按RGBA8计算约7.92MiB，不计引擎副本。资源清单及原图哈希在`design/xianxia-world-2026-10-26/runtime/`。资源缺失时仍用旧地面兜底，活动边界与规则保留。

## 玩法接入

- 普通修仙、装备测试档和固定种子试玩均传入`arena: courtyard-v1`。经典模式保留旧地面及原移动/生成规则。
- 新地图只使用一个连通矩形，没有内部障碍寻路。不是完整宗门探索地图。
- 普通、事件、精英、Boss和召唤怪都走可达刷怪约束：与玩家保持至少300单位距离，并在重定位候选中优先选择视野外位置。候选选择不额外消费随机数。
- 敌人移动、击退、分离后仍约束在场内；碰撞空间索引按最终位置重建。合法场内敌人不再因旧无限地图的距离阈值被搬走。
- 掉落物与撤离点受边界约束，角落也能拾取或完成撤离。
- 不改变技能数值、怪物外观和装备规则。有限活动空间会影响战斗压力，因此旧地图平衡结果不能直接沿用。

## 验证与范围

最终864项自动化测试、源码检查、web-mobile构建通过。独立复查发现的旧距离阈值触发二次瞬移已修复并补回归。固定种子页面内完成20秒正常生成/自动攻击烟测：仍在战斗、10只活跃敌人、御剑术记录1280有效伤害；这是自动化闲置烟测，不是真人通关。

自动化覆盖四角移动、半径限制、安全生成、事件和Boss、召唤、击退/分离、空间索引、拾取/撤离、经典模式不变、背景资源失败回退、资源释放及记录重放。构建后的浏览器覆盖390×844及1280×800、四角镜头与背景对齐、输入、暂停恢复和重开；原始结果见`reports/courtyard-runtime-2026-10-27/`。

浏览器边界检查包含直接放置的夹具，不算真人记录。固定种子记录新增地图身份，构建重算源码指纹；旧记录保留，但与新地图不直接比较。未宣称通过手机真机、完整平衡或所有怪物美术验收。
