## 逻辑与表现边界

`SwordCombat.js`统一处理直接剑技伤害、暴击、剑痕、死亡点快照和击杀爆发。伤害事件保存源技能、施放编号、目标UID、直接/持续/爆发类型与顺序号。飞剑按UID顺序结算，避免对象池交换改变暴击分配；击杀候选也按UID排序。Boss死亡取消未执行爆发，玩家死亡清理状态，实体回池不继承剑痕。

两仪减速在敌人/Boss移动阶段查询当前范围，离阵不残留。视觉采用低透明双阵眼、固定剑形残影和细剑痕刻度，不新增常驻按钮。所有表现以模拟tick驱动，暂停、选卡冻结。
