# 银发剑修：当前角色基准

2026-10-26 · 用户提供的新参考优先于此前角色设定

## 已确定的方向

用户明确认可这张图的发型、发色、服饰、中性面容与身体比例。此前“黑发发髻、短袍、严格三头身、二次元平涂”的要求不再适用。

| 项目 | 以新图为准的制作约束 |
|---|---|
| 发型 | 银白色高马尾，额前分束刘海，后方长发有清楚体积；不要改回短发或丸子头 |
| 面容 | 大而清楚的蓝眼睛、柔和中性五官、安静的表情；不强化男性肌肉、女性妆容或夸张笑脸 |
| 比例 | 沿用图中的大头、紧凑躯干与短四肢关系；不拉长腿，也不为凑三头身压扁身体 |
| 服饰 | 白色宽袖外袍、浅蓝交领内衫、银白腰封、白裤与白靴，保留衣襟和层次 |
| 配件 | 腰间浅玉色圆佩、浅蓝穗，少量银色装饰；不追加黑护腕、重甲和金色大块装饰 |
| 剑 | 银色剑柄、冰蓝剑身；和人物分清轮廓，不用强光遮住手和脚 |
| 材质与光照 | 柔和的立体渲染、细腻头发体积、布料厚度和衣褶阴影；不转成粗黑描边或硬切平涂 |

原始参考应保留原尺寸与文件哈希。小尺寸游戏适配可减少看不清的绣纹，但不能改变发型轮廓、脸部比例或白/浅蓝配色关系。

## 当前先制作的内容

1. 保存用户原图，整理透明母稿和遮罩，检查白发、冰剑、衣袖及靴边是否误删。
2. 在游戏地面和深浅两种背景上比较80u、96u、112u。页面同时展示缩到390px宽屏后的实际尺寸，避免只看大立绘。
3. 母稿素材明确标注“用户参考图抠像适配”，不是新生成的站姿；原图现有的持剑和手势保留。
4. 待这一基准成立后，再制作同一人物的自然待机、站剑悬停和侧向滑行姿势。不得通过旋转持剑图、贴一把横剑或移动脚部来假造站剑姿势。

## 动作制作约束

继续采用“学会御剑飞行后踩剑滑行”的方向，飞行解锁规则仍是上一份方案中的提案，尚未进入游戏。上剑后，双脚与剑面保持接触，身体稳定，主要动势来自小幅倾斜、马尾、袖摆和剑穗。不要把马尾做成不停甩动的硬杆。

不同方向要保持同一张脸、同一高马尾、同一衣襟与佩饰位置。二维图可以保留这张图的立体渲染观感，但不能因此称已经制作了可旋转的3D模型或骨骼。

## 工具与验收边界

现有本机生成流程此前产出的是偏二次元的平涂风格，尚未证明能稳定重现这张参考的材质与身份。本轮不再用它随机重画母稿，也不把滤镜处理称为风格复现。

本轮原图分离和场景合成只验证基准图的可读性，不证明新姿势、动画、3D建模或游戏接入完成。任何新姿势必须逐项对照上面的特征与用户原图，不能以“都是银发蓝衣”代替同一角色。
