# 跳跃与林间素材更新

2026-09-14

## 操作与规则

- 右侧“跳起”按钮位于“蹲下”上方；浏览器预览支持空格键。可同时保持左侧摇杆移动。
- 起跳初速度 5.2、重力 12，平地起跳高度约 1.1 个世界单位，约 0.86 秒落地。可越过低矮倒木、石块，也可落在其顶部。
- 空中重复点击不追加起跳速度；蹲下也可跳，保留低视角和慢速。
- 玩家脚底高度与相机视高分离，落地、走下平台、头顶碰撞分别处理；头顶有遮挡时不能从蹲下站起。
- 水域和地图边界仍不可进入。跳跃不是游泳或飞行能力。
- 打开手记等暂停界面保留腾空状态，返回后继续下落；不会重置本局或采集结果。

`js/voxel/PlayerMotion.js` 实现玩家物理，最大 10 毫秒子步。动物继续使用原来的地面导航。碰撞采用现有静态包围盒，因此圆石、倒木边缘的支撑面仍是近似形状，并非逐三角形物理。

## 素材

- 野猪：柔和身体明暗、长吻与鼻孔、獠牙、背鬃、分趾蹄。
- 牦牛：厚实肩背、分段弯角、额毛、胡须、连续垂毛和不规则毛梢。
- 两者头部单独转动，身体不随低头动作整体倾斜；渲染与射线遮挡使用相同姿态。
- 近景草叶使用弯曲的多段轮廓；混交林、橡树林和白桦林增加蕨类。远景保留简化草叶。
- `scripts/art-review.html` 增至六个近景检查卡片，展示游戏同款原创几何模型。
