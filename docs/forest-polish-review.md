# 森林冒险：整关检查与精修

> 文档状态（2026-09-21）：专项参考/实现记录。有日期的规则或实现证据，不等同当前目标全通过。 当前基线见[设计文档索引](design/design-document-index.md)。

2026-09-20。阶段：可玩原型精修。范围是当前已经接入的2D森林关卡、角色动作、交互物、环境、输入与恢复流程。没有恢复3D或男女选角。原生矢量源稿直接修改，未把它们表述为AI生成的新素材。

## 已定位并处理的问题

| 对象 | 检查发现 | 本轮处理与保留理由 |
|---|---|---|
| 跳跃输入 | 踩空一瞬间/落地前按键容易失效 | 增加100ms离边宽限和120ms落地前输入缓冲；仍不能空中二次跳跃 |
| 冒险者轮廓 | 披风横向较宽，动态状态辨识弱 | 身体披风略收窄，保留兜帽、眼睛、围巾、挎包、手部结构与已选形象 |
| 起跳/下落 | 原先共用抬臂姿势 | 下落单独绘制伸腿、放低手臂的姿势；上升保持抬臂 |
| 着地 | 姿态突然切回站立 | 新增短暂屈膝姿势和轻尘，移动立即响应，不加硬直；反馈按落地速度触发 |
| 待机/行走 | 站立过于静止 | 微幅呼吸保留脚底锚点；八帧行走保持由行走距离驱动 |
| 攀爬 | 背向动作与藤蔓已有明确对应 | 保留八帧背面交替攀爬、自动到顶和途中跳离；角色不会转回正脸攀爬 |
| 推柔茎 | 冒险者仍直立，缺少施力姿势 | 新增身体前倾、双臂向前的推姿；柔茎补节理；只有搭稳后才能行走；最新规则为承重时保持、空置5秒后预警回弹，可重复压弯 |
| 孢子蘑菇 | 主动蓄力/喷射因果明确 | 保留压缩、孢子喷射、高跳与空中控制。新输入宽限不能让弹射后额外空跳 |
| 树根/藤蔓路线 | 两种到达菌盖的方式已可用 | 保留短跳路线与攀爬路线，避免必须先爬藤才能使用蘑菇 |
| 间歇上升风 | 已有停歇/预兆/强风/减弱阶段 | 保留物理和草叶、绒毛共用周期；提示继续按所在风区实时切换 |
| 蒲公英 | 有倒计时，但临近失效反馈弱 | 最后5秒携带/展开形态渐隐闪动，补落地提示；采集点留下低矮草丛，30秒寿命和补充冷却不变 |
| 甲虫 | 上轮六足步态与跳跃碰撞已修好 | 保留按位移步态、可双向跳过、过晚起跳仍碰撞；增加碰撞后的具体原因提示 |
| 蜗牛与其他动物素材 | 蜗牛是岸边环境点缀，蚂蚁未接入玩法 | 检查锚点和风格，保留静态环境用途，不伪称它们已有移动AI或新增玩法 |
| 树皮/根石缝 | 两处藏身入口、遮身前沿已分层 | 保留靠近且落地才可藏身、移动退出、甲虫不伤隐藏者；回归验证两处遮挡 |
| 高处枝间路线 | 树冠提示仍混入前段甲虫说明 | 单独提供枝间跳跃、回地面重爬、末端路标提示；普通跳跃仍可三连跳通过 |
| 落地/失败恢复 | 普通落地与掉沟反馈容易混淆 | 落地不传送；深沟/甲虫失败区分提示；复活清除待执行跳跃和宽限，临时桥按原计时继续恢复，不因复活补满 |
| 背景/岸线 | 大片土层、直切边缘缺少接触细节 | 在碰撞范围内部补湿土暗部、根须分叉和碎石；不画虚假可走台阶，不改变岸边碰撞 |
| 植被/出口 | 层次清楚但审美仍需用户判断 | 保留不同透明度远近景、曲折木质树冠与末枝木路标，不恢复白线/椭圆传送门 |
| 手机HUD | 文字偏小、整片浅色顶栏抢眼 | 顶栏改半透明深色，提示正文16设计单位、主要动作18；窄屏去掉重复键盘说明，限制宽屏提示板宽度 |
| 触控 | 按下缺少即时反馈 | 增加按钮轻压反馈，保留触摸取消清理、暂停/后台清输入 |
| 素材包 | 增加三个动作后旧装箱让纹理升到4096高 | 复用前排剩余空间，66张精灵仍2048×2048；原始分辨率未降低，新增不重叠验证 |

## 玩法评审

- KEEP：微观森林冒险；跳跃、攀爬、借风、弹射和藏身之间的组合。
- KEEP：柔茎桥是稳妥过沟路线，窄沟仍可跳过。没有为了强迫交互擅自扩大沟宽。
- CHANGE：输入容错、动作意图、反馈与提示归属，而非新增无关系统。
- CUT：重复的小字键盘说明、宽屏整条浅色提示板的视觉重量。
- TEST：高处植物美感、甲虫遭遇节奏、30秒绒毛是否够用，依赖用户试玩，不能由自动通关证明。

最小证明是整关仍可通关，同时新增输入和动作能被独立验证。已知三项优势：普通跳跃有合理替代路线；物体外形与主要落脚面共享几何；失足恢复与已完成机关状态独立。剩余三项风险：竖屏角色仍偏小；长段落的首次说明需要玩家停读；机关串联较线性，长期重玩性未验证。

## 边界

这是一次完成的检查与精修，不代表所有素材达到最终美术品质。本轮没有新增音乐/音效、关卡存档、剧情或经济系统；没有改动已移除3D的前序工作区内容。原生素材源稿可继续迭代。下一步最有价值的是按用户的实际试玩反馈调整，而非继续无差别重画已可用物体。
