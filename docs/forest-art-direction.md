# 雨后菌语：自然森林美术说明

本轮从粗体素转为细致的低多边形自然风格。保留几何棱面的辨识度，以生态观察和菌物形态为视觉重点。

## 设计与实现记录

- **地表**：连续缓坡，半米三角网格；用空间色斑混合土壤与草地，不使用方块侧面或像素草方块贴图。
- **树木**：渐细的多边形树干、分叉树根和枝条。松树由错位的渐缩针叶层组成；阔叶树冠由不规则分布的棱面体组成；白桦保留小块树皮斑纹。
- **菌物**：18 段弧形菌盖、渐细菌柄、放射菌褶、菌环、小斑点；树生菌有连接组织与层叠菌架，猴头菌有细菌刺。地生菌簇按各菌柄实际位置采样地面高度。
- **林下**：叶片草丛、棱面碎石、小片苔藓、散落枯叶、带木质断面的倒木。清理出生点附近障碍物。
- **光照**：方向光、细颗粒材质、地表明暗色斑、距离雾及抗锯齿。色斑是风格化处理，本版没有实时树冠投影或照片级材质。
- **界面**：保留调查手册、菌物观察页和简洁悬浮控件，不采用 Minecraft 的物品栏、生命图标、标志或字体设计。

以上新模型在 `js/voxel/geometry.js`、`mushrooms.js`、`VoxelWorld.js` 中以几何参数构建，颜色与着色代码在 `biomes.js`、`VoxelRenderer.js` 中定义。没有提取或导入 Minecraft 的代码、资源包、截图、音效和模型，也没有调用图像生成 API。既有鉴定照片仍沿用项目原素材目录及其许可记录，不属于本轮新绘制资源。

对外描述使用“自然森林探索”“低多边形生态观察”等本项目表述。此设计记录说明实现来源与差异化选择，不等同于法律上的不侵权证明。

## 验证

保留八个生境的步行连通性、每处菌物可选性、多指移动和转向检查。弧形模型使用实际三角面拾取，防止点击其包围盒空角也触发观察。地表边界连续性另有测试。浏览器 `/scripts/voxel-smoke.html` 验证实际 WebGL 绘制与完整观察往返流程。尚未完成手机真机性能验证。
