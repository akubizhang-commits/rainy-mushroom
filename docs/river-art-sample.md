# 河谷美术样板

2026-09-14。本轮按“自然比例、柔和光照、细腻低多边形森林”的方向，先完成河谷、鹿和三种菌物的样板。全部为项目原创程序化几何，不需要图像API或新增外部图片。

## 已实现

- 河岸：石块大小、间距与埋入深度变化，地表加入湿泥颜色过渡，替换原来的连续等距石块排列。
- 植被：河谷草叶分段弯曲，分布形成疏密斑块；局部增加蕨类、幼树和不对称树冠。地标、可行走路线和菌物周围留有观察空间。
- 倒木：增加纵向树皮沟纹、断面年轮、碎裂木刺和不规则苔藓，保留原有碰撞主体。
- 水面：独立绘制浅水颜色和流动细纹，动画随游戏探索时间推进。是风格化着色，没有引入真实反射或流体模拟。
- 接触阴影：河谷树根和倒木使用贴合地面的柔边阴影；动物脚下及地生菌物加入接触阴影。菌物被采集／吃掉后，其阴影同步消失。
- 鹿：修正身体、四肢和口鼻比例；身体采用平滑法线，头颈独立低头，行走转向更平缓。独立头部沿用相同姿态矩阵进行点击遮挡检查。
- 云芝：同心色带、薄片边缘和波浪形轮廓；倒木上的层片贴近、交叠，树干上的层片按高度排列。
- 金顶侧耳：大小不同的偏心菌盖、凹浅中心、弯曲菌柄及下延菌褶。
- 猴头菌：相连的浅色菌体和128条不同长度的下垂菌齿。
- 校正树生菌物附着距离，使它们连接到树皮附近。

环境细节以河谷为样板；鹿和三个物种的共用模型同步更新到其他使用它们的生境。没有修改物种解锁门槛、稀有度权重和采集配额。

## 查看方式

正常游戏使用原来的河谷预览入口。运行 `npm run preview` 后，还可访问实际服务端口下的 `/scripts/art-review.html`，近距离查看四个同款模型。样板页不读写玩家存档，支持暂停／播放动作。

## 验证与范围

- 172项Node测试通过，语法检查通过。
- 浏览器完整WebGL回归通过，包括移动、蹲下、遮挡、采集、收藏、猛兽、额外探索，以及全部33种菌物绘制。
- 新增检查平滑法线、菌物面数与有限坐标、倒木菌盖高度、阴影边缘与地面贴合、鹿头动态遮挡、河道范围和树皮附着。
- 实际查看了河谷画面及四个近景模型；修正了首次检查中云芝层片间距过大的问题。

阴影是轻量近似接触阴影，没有真实投影阴影贴图。入口附近树冠使用更多细节，远处保持简化；当前没有随玩家移动动态切换的LOD系统。真机帧率和长时间运行仍需设备验证，测试通过不代表已达到特定手机性能指标。
