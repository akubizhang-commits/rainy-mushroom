# Cocos 迁移交付记录

2026-09-14，完整游戏迁移到本机 Cocos Creator 3.8.8。工程与构建说明见 `../cocos-pilot/README.md`。

## 交付范围

4个生态分区、12个生境、41种菌物；原有采集、动物、挑战、收藏鉴别、学习资料、路线与观察委托接入原生 Cocos 页面。旧数据逻辑仍为唯一来源，原入口保留在源码中，微信工程默认指向新构建。

菌物细化曲面、平滑法线与色差；树木枝冠、根部、腐木、蕨类、小花和动物形象更新。原创建模配合标准材质、6张无缝纹理、分区环境光与雾、实时阴影和动态水面。12张预览图均重新从新引擎渲染。

## 验证结果

- Node 自动测试：241项通过、0失败。覆盖存档迁移及备份恢复、全部场景通关、细化菌物几何、分包清单等。
- 全12场景步行可达性与射线选取检查通过，确保模型细化后不会让菌物无法采集。
- TypeScript 无输出检查通过；原工程语法检查通过。
- Creator 网页与微信发布构建通过。
- 编译后浏览器诊断：113项通过，包括12场景创建、移动、暂停、采集消失、达标继续探索、鉴别，以及41个物种首张实拍的分包加载。测试使用独立内存存档。
- 320×568 窄屏首页实测，无按钮或文案重叠。
- 微信开发工具实际显示新版3D场景、采集计数、蹲下/跳起及顶部操作图标。游客模式仍有 `webapi_getwxaasyncsecinfo` 平台错误，与已正常显示的游戏场景分别记录。
- 最终微信主包3,904,271字节（3.72 MiB），9个本地分包；总包13,282,994字节。构建脚本自动检查包体和资源路径。
