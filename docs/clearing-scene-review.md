# 第一段场景样板：树根旁的雨后水洼

> 文档状态（2026-09-21）：历史设计/记录。蘑菇靠枯枝方案为历史，不应恢复。 当前基线见[设计文档索引](design/design-document-index.md)。

## 当前阶段与目标
可玩原型打磨；本轮仅优化第一段环境组合。玩家是小小旅人，沿自然物件观察、攀爬、跳跃并搭桥。情绪应为安静、好奇，而不是在不明平台上猜碰撞。

## 决策
- KEEP：统一小旅人、背面攀爬、圆拱菌盖、枯枝搭桥、失误落回岸上。
- CHANGE：两岸支撑、环境连接、远近层次与视觉焦点。以既有精灵重组场景，新增程序化光、雾、水面与少量空气微粒；这些不是碰撞或新玩法。
- CUT：白色碰撞线、连续箭头、均匀铺满路线的植被。
- TEST：无需长提示能否发现攀爬点与菌盖、推枝后能否识别落地通路。

## 有证据的优势
1. 攀爬、跳菌盖、推枝与整关路径有自动验证。
2. 菌盖表面与脚下高度使用同一数学曲线。
3. 场景装饰独立于状态和碰撞，本轮不修改机关规则。

## 主要风险
1. 玩家能否独立读懂路线：UNVERIFIED，待用户试玩。
2. 移动端视野与界面占比仍影响场景表现：WARN，后续独立处理。
3. 原型素材仍未达到统一的最终美术质量：WARN，不应扩展全关卡美术量。

## 生产与无障碍
重用既有素材与静态绘制；只有6个缓慢微粒逐帧更新，无闪烁。未引入素材下载、插件、角色替换、碰撞线或新增常驻UI。真机性能未测，不声称达到最终画面或发布标准。

## 验收
确认初始区域的角色、攀爬枝、菌盖、对岸均可辨认；岩石不盖住可走表面；第一跳与机关、后续整关仍通畅。截图只验证摆放，玩家的路线理解需要另行观察。

## 菌盖与枯枝组合修订（2026-09-20）
用户否定高柄扁盖及枯枝穿插，改为中心295、顶205的短柄圆鼓菌盖，低于250的枝杈。菌盖可见宽140与碰撞225..365完全对应，同用32单位落差的抛物线。岸边枯枝支点移到380、初始85度，长度285，倒下终点665。玩家从枝杈跳向低菌盖，在右侧342..365推动枯枝。原生矢量源重绘并重打图集；本轮不是AI位图生成。11项测试和40项引擎检查通过，视觉认可待用户试玩。
