## 已接入

- 人物统一为已确认的 C「神秘小旅人」细节版，移除岚/烁和男女选择。开场仅保留人物展示与出发按钮，出发前计时暂停。
- 8帧步态、8帧交替攀爬，以及站立、跳跃、滑翔与藏身姿态。攀爬按角色高度切换，暂停时保持当前姿态。脚底锚点与站立高度保持原关卡尺度（约56世界单位）。
- 12类植物、菌类、甲虫、蜗牛、露珠、枯叶、攀爬藤、蒲公英与树根素材。
- 叶面美术按现有关卡可站立边缘重新适配；叶桥放下后可见上缘与碰撞高度一致。

第一段已改成枝杈攀爬、菌盖跳跃和枯枝搭桥，后续风口滑翔、甲虫与树根藏身保持原有玩法。

## 入口

项目根目录运行本地HTTP服务，打开 `/scripts/microforest-preview.html`。

出发：点击“出发”或按 Enter，无角色性别选择。
游戏：A/D或左右方向键移动，空格跳跃，获得绒毛后按住空格滑翔，E交互。右上角可查看提示。

## 源文件

- `scripts/microforest/export-art.py` 从原创矢量绘制源导出带锚点的透明精灵。
- `scripts/microforest/pack-art.mjs` 使用Sharp生成图集、JSON清单和TypeScript帧表；可通过 `RAINY_SHARP_PATH` 指定Sharp模块路径。
- `MicroForestSprites.ts` 负责纹理、SpriteFrame、设计尺寸与生命周期。
- `MicroForestSpriteArt.ts` 负责关卡素材布局与动态姿态。
- `MicroForestView.ts` 负责加载、出发页与关卡界面。

导出后运行 `npm run cocos:build` 更新浏览器试玩。未构建、上传或发布新的微信包。

## 攀爬朝向修正

攀爬8帧重画为背面：兜帽后部、闭合斗篷背幅、背带与后跟，不显示眼睛、正面前襟或鞋尖。抬手帧独立扩展顶部裁切范围，脚底锚点保持不变。

首段叶桥仍保留现有玩法。拟议路线为「攀爬植物枝杈 → 跳上菌盖 → 推落卡在枝杈间的枯枝搭桥」，尚未实施，等待方案讨论；颜色、轮廓、材质和前后层次共同区分可走表面。

## 首段路线试玩版

用户确认后，已将首段改为：从 x=165 攀爬至 y=250 的植物枝杈（x=140–225），向右跳到宽菌盖（x=280–375，y=265），站在 x=330 附近按交互推枯枝。枝杈和菌盖分别连接主茎、菌柄，取消这一段原先的两片悬空叶子和露珠。

枯枝下端支在左岸 x=360，上段原先斜靠菌盖侧缘。推动后松动、加速倒向右岸、轻弹落稳；1.4秒后开放 x=360–665、y=90 的行走面。落点有树根支撑和短暂碎屑反馈。顶部浅暖边缘标识可走范围，植物装饰叶片采用更暗的绿色。第一次跳跃失误会落回岸上。

验证：9项图集和关卡测试通过，覆盖完整路线、隔空/空中交互拒绝、桥落稳前不开放和跳跃失误落地；TypeScript noEmit 通过。旧 `MicroForestArt.ts` 为未使用的早期绘制原型，当前游戏只使用 `MicroForestSpriteArt.ts`。

新增美术源：`scripts/microforest/route_art.py`；首次改为枯枝机关前的描述保留为历史记录。

首段路线浏览器验证：Cocos web-mobile 构建通过；真实引擎40项检查通过，含菌盖落地、枯枝下落期间无桥面、桥落稳、整关无传送无失败通关。已检查起点画面的枝杈、菌柄、枯枝和两岸支撑，试玩页停在新路线起点。

## 场景自然轮廓与层次修正

用户指出白线、平切平台与密集堆叠违和。本轮移除首段枝杈、菌盖、枯枝和树根支撑的通长浅色描边：枝杈改为不对称的生长枝与绕藤，菌盖改为圆拱，枯枝改为不规则树皮、断口与偏置侧枝，并放到菌盖后方，避免遮住落脚面。减少全关卡背景树影密度、透明度与地面装饰，首段去掉高大的杂草和人物前方蕨叶，水面改为低对比短反光，土层减少重复竖线。

菌盖可走面不再是平面：`surfaceY` 与 SVG 冠部采用同一抛物线，角色在其上行走会贴合表面；交互检测同步采用当前脚下高度。主流程仍为攀爬、跳菌盖、推枝搭桥。10项素材与关卡测试通过，新增弧面行走不悬空、不跌穿检查，TypeScript noEmit 通过。

场景重绘版本已通过 web-mobile 构建和真实引擎40项整关检查；起点实际画面核对了去描边、圆拱菌盖、背景减量和枯枝遮挡关系。视觉检查发现的土层色带进一步改为细分渐变。

## 旧玩法退役与独立入口

2026-09-20 用户确认只保留当前森林冒险。删除旧 WebGL/3D 玩法、模型生成、第一人称输入、采集界面、旧共享模块、对应测试、材质及预览资源；同时退役未采用的早期 adventure/MicroForestArt 原型。PinePilot 现在仅创建二维相机与森林界面，默认进入出发页，退出关卡返回出发页。引擎的 3d、primitive、light-probe 模块关闭，场景不再带方向光和旧相机。

同步脚本只从 `js/microforest` 生成共享模块，不再打包图鉴照片。保留独立菌物资料、照片原件与其许可证明，公共广告/隐私工具作为未接入当前玩法的基础模块保留。清理前修改已在项目外备份，具体路径见 `legacy-3d-removal.json`。

验证：40项Node测试、源码依赖检查、TypeScript noEmit、web-mobile 和 wechatgame 本地构建通过。浏览器确认无参数默认进入新玩法；40项真实引擎检查通过，覆盖整关与退出返回出发页。本轮未上传、发布，也未执行微信真机验收。
