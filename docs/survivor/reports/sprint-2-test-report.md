## 9. 给用户的真机试玩步骤（微信开发者工具）

准备：构建产物已在 `cocos-pilot/build/wechatgame`（如有改动先跑 `npm run cocos:build:wechat`）。新玩法已是默认入口，**普通编译就能直接进游戏**，不需要任何启动参数。

1. **导入**：微信开发者工具 → 导入项目 → 目录选 `cocos-pilot/build/wechatgame`，AppID 用项目已配置的。记下开发者工具版本和基础库版本。
2. **完整一局（08 P6 验收）**：普通编译 → 营地页点“出发” → 按住屏幕下方拖动移动，攻击是自动的 → 升级时三选一。约 7:00 出现“浊雾巨蜗”（顶部有血条），把它打空后全场浊雾散去，出现“阳光点”和屏幕边缘箭头 → 走进去站满 2 秒 → 胜利结算页显示“撤离成功”“浊雾巨蜗已净化”和本局构成。一局约 8–9 分钟。第一次通关可以优先拿“雨滴坠击”，bot 数据里它对保守打法最友好。过程中留意：2:30 蚊蚋包围圈、4:30 灰蛾横穿、6:30 蜗牛围墙（有缺口）三条横幅是否出现。
3. **帧率（PF-2，S1 起一直待测）**：
   - 顶部“编译模式”→“添加编译模式”→ 启动参数填 `perf=1` → 用该模式编译。屏幕左侧、HUD 下方会出现半透明调试面板（同时确认 P5“微信端面板可见”）。
   - 面板各行：`FPS 均值 P50`、`帧 P95 毫秒`、`步耗时 均值 max ×每帧步数`、`DrawCall 战斗节点`、当前状态与秒数、各池占用、`dropped/capSkip`。
   - 点“出发”进入战斗，再点面板下方的“满屏200 关”按钮，变成“满屏200 开”：之后每帧把敌人补到 200 只并保持满血，只在战斗中生效，再点一次关闭。
   - 开启后等 5 秒稳定，连续观察 30–60 秒，记下 FPS、P50、帧 P95、DrawCall、战斗节点。门槛：开发者工具 ≥ 50 fps。同时截一张面板 + 满屏画面。
   - 不带 `perf=1` 的普通编译不会出现面板，也不会计时。
4. **触摸（UI-02/03/04）**：屏幕上 1/3 按下不出摇杆；下 2/3 任意处出摇杆，贴左 / 右 / 下边缘时底座完整可见；第二根手指不影响移动；暂停或三选一时摇杆消失，关闭后不碰屏幕角色不动；升级卡弹出后立刻点无效，约 0.4 秒后点卡片任意位置都能选中。
5. **音效与打击感（P3/P4、UI-09）**：开声音玩 1–2 分钟，听拾取、升级、受击、净化、Boss 预警、胜利是否都有声音、是否刺耳；被大群包围时拾取声不应爆音或堆叠失真。暂停页把“音效”关掉后应完全无声。受击时屏幕边缘有红色晕影和轻微震屏；暂停页开启“减弱闪烁”后不应再震屏、闪白减弱；关闭“震动”后真机不再震动。
6. **安全区与色盲（UI-07、AX-01）**：开发者工具机型依次切 iPhone 6/7/8（375×667）、iPhone 12/13（390×844）、iPhone XR/11（414×896），分别截营地页、战斗 HUD（含 4 格武器栏 + 4 格被动栏、Boss 血条）、暂停页、三选一、结算页；按钮和栏位不能被刘海 / 胶囊挡住，暂停按钮在右上胶囊下方。另在 6:40 左右（满屏）截一张，用灰度和红绿色盲模拟检查小旅人、敌人、孢子、浊雾泡、撤离点能否分清。
7. **切后台（UI-06、PF-5）**：战斗中点开发者工具“切后台”（真机按 Home 键）30 秒再回来，应停在暂停页、角色不瞬移；三选一时切后台，回来仍是原来三张卡；`perf=1` 满屏 200 时切后台再回来，帧率应恢复。
8. **真机（建议）**：开发者工具“预览”扫码，用 1 台中端安卓和 1 台 iPhone 重复步骤 2、3、4、5、7。真机预览要带面板时，在“预览”设置里同样填启动参数 `perf=1`。门槛：中端真机 200 敌人 P50 ≥ 55 fps、帧 P95 ≤ 25 ms。记下机型、系统、微信版本。如方便，打完一整局后看一下内存曲线是否持续上涨。
9. **回传**：把帧率数字、截图、哪一步不符合发给我，我回填本报告 §7.2 并给出 S2 最终结论。
