# Sprint 2 第二轮调优复核（K15–K19）

数据来源：`npm run survivor:balance`（种子 balance-0…49 × 2 走位 × 6 种选卡 = 600 局，上限 17:00）、§6 的 3 局 preview 和 OBS-4 复现局。所有数字来自真实运行。balance 同参数跑了两次，除首行耗时外逐行一致（140.9s / 140.2s）；4 局 preview 各跑两次，输出逐字节一致。原始 JSON 在 `tmp/survivor-balance.json`（不入库）。对照是 `sprint-2-tuning-report.md`（下称“上次”），口径不变：新手型 = 保守逃跑走位，熟练型 = 贴孢子走位；“同口径”= 只取 random + 偏好孢子弹 / 菌伞 / 露珠环 400 局；bot 的 `prefer:` 排序（OBS-5）不改。

本轮实现见提交 45c5364：K15 狂暴 II（11:00）起 Boss 贴近追击；K16 2:00–4:00 刷怪 +15%；K17 露珠环半径、落叶回旋镖射程上调；K18 拾取半径 100 → 140；K19 6:00–7:00 同屏上限 200 → 160。

## 结论先行

判定：有 2 项硬问题，需要用户拍板后才能继续。

1. 【硬问题】总体通关率 72%（434/600），跌出 25–70%。上次 55%。同口径 70%（278/400），上次 51%。主要来自熟练型：89%（266/300），上次 76%，五种偏好都在 96–98%。
2. 【硬问题】12:00 后仍在场 1 局（目标 0）。上次 5 局，其中 4 局到 17:00 超时；这次 0 局超时。剩下的是 balance-33（保守·偏好落叶回旋镖）：Boss 从 7:00 到 11:00 只掉到 93%，11:00 贴近追击生效后 63 秒打完，12:03 击败、12:08 撤离。原因是追击从 11:00 才开始，这时 Boss 还剩九成多生命。上次的 4 个复现种子都在 12:00 前结束（balance-15 11:36 通关、balance-43 11:49 通关、balance-39 7:08 阵亡、balance-4 7:21 阵亡）。
3. 新手型明显改善：通关率 56%（上次 33%），Boss 战中位 81 秒（上次 95 秒），回到 90 秒以内。偏好露珠环 / 落叶回旋镖分别是 62% / 38%（上次都是 14%），都达到 K17 的 ≥30%。拾取率 75.8%（上次 56.4%），净化率 87.2%（上次 81.2%）。
4. 6:30–7:30 阵亡集中有缓解：新手型这一时段阵亡 81 局，占新手型阵亡的 61%（上次 81%），占新手型局数 27%（上次 53%）。6–7 分钟平均同屏 106 只（上次 139）。
5. 构筑分化保持：通关局构筑 54 种（上次 55），通关局武器组合仍是 4 种，五把武器选取率 47–53%（上次 47–53%）。
6. 通关局时长中位 8:14（上次 8:16），434 局里 363 局在 9:00 内（84%）。
7. 质量检查全部通过：`npm test` 272/272；确定性 6/6、合规词 6/6；600 局 `diag.dropped` 全为 0，droppedTime 全为 0。本步没有发现实现缺陷。

## 4. 仍未达标项

标“需拍板”的会改变玩家能直接感知的体验，请用户决定；其余可由策划按 01 流程处理。

1. 【需拍板 · 硬问题】总体 72%、熟练型 89%，超上沿。K16 没有效果，K17/K18 对熟练型也有加成。可选：(a) Boss 生命 4500 → 5500 左右（熟练型 Boss 战中位 61 秒会到约 75 秒，新手型 81 秒会到约 99 秒，再次超过 90 秒）；(b) 加大 4:00–7:00 压力（熟练型这段受击 0.6–1.0 次/分钟），例如 4:00–6:00 刷怪或浊雾泡频率上调；(c) 只把 30–60% 用作新手型目标，熟练型另定上限（如 ≤ 80%）。建议 (b)，或 (b)+(c)；(a) 会和新手型 Boss 战时长冲突。
2. 【需拍板 · 硬问题】12:00 后仍在场 1 局。根因是追击 11:00 才开始。可选：(a) 追击提前到 10:00 狂暴 I；(b) Boss 出现后若连续 N 秒（如 60 秒）没受到伤害就开始追击，不等时间点；(c) 接受 12:08 这种“追击后很快结束”的长尾，把 K13 目标改为“0 局超时”。(b) 只作用于打不到 Boss 的局，对正常局没有影响，建议 (b)。
3. 熟练型偏好露珠环 / 落叶回旋镖 96% / 98%，超过 K17 的 93% / 87%。和第 1 条一起处理。
4. 全部 Boss 战中位 70 秒，目标 40–60 秒；>90 秒仍有 123 局。和第 1、2 条一起看，不单独改。
5. 新手型拾取率 75.8%，离 90% 假设仍差。建议等 S3 磁吸被动（孢子罗盘）再复核。
