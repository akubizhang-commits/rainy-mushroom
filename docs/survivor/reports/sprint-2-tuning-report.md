# Sprint 2 调优后平衡复核（5 武器 + K7、K9–K13）

数据来源：`npm run survivor:balance`（种子 balance-0…49 × 2 走位 × 6 种选卡 = 600 局，上限 17:00）与 3 局 `preview-run.mjs`。所有数字来自真实运行。balance 同参数跑了两次，除首行耗时外输出逐行一致；3 局 preview 各跑两次，输出逐字节一致。原始 JSON 在 `tmp/survivor-balance.json`（不入库）。对照基线是 `sprint-2-logic-preview.md`（400 局，3 武器，上限 12:00）。

口径说明：
- 新手型 = 保守逃跑走位，熟练型 = 贴孢子走位（与上次报告相同的 bot）。
- 本次新增 `prefer:raindrop`、`prefer:leaf_boomerang`，上限从 12:00 延长到 17:00（08 L12，覆盖 K13 全部阶段）。12:00 前结束的局不受上限影响。
- “同口径”= 只取上次就有的 4 种选卡（random、偏好孢子弹/菌伞/露珠环），400 局，用来排除新增两种偏好对总数的影响。

## 结论先行

1. 构筑分化：明显改善，武器维度第一次真正分化。5 选 4 后，除起手的孢子弹外，“放弃哪把”的 4 种情况都出现在通关局里（放弃落叶回旋镖 122 局、放弃菌伞旋刃 76 局、放弃露珠环 86 局、放弃雨滴坠击 43 局）。通关局的武器组合从 1 种变成 4 种，“武器+被动”构筑从 4 种变成 55 种。被动不再是固定答案：湿润苔衣出现在通关局的比例从 100% 降到 70%，宽檐菌帽从 98% 降到 50%。
2. 通关率：总体 55%，落在 30–60% 内（上次 13%）。新手型 33%，刚过下沿（上次 0%）；熟练型 76%，超过上沿（上次 27%）。熟练型 + 偏好任一武器是 84–90%，偏轻松。
3. 通关局时长：中位 8:16，327 局通关里 270 局在 9:00 以内（上次 53 局里 0 局，中位 10:16）。Boss 战中位 72 秒（上次 192 秒），熟练型 63 秒、新手型 95 秒。新手型超过 K6 的 90 秒阈值，按 L12 规则要回到策划。
4. 成长：1:00 达标（熟练型 Lv5.0、新手型 Lv4.8，上次都是 4.0）。3:00 / 5:00 / 7:00 熟练型是 10.9 / 16.9 / 23.9，和上次几乎一样，仍低于 12–14 / 18–20 / 24–26 的下沿。新手型提升很大（Lv@7:00 从 7.4–9.6 涨到 16.0）。
5. 净化与拾取：新手型 0–7:00 净化率 81%（上次 59–71%），拾取率 56%（上次 30–37%）。R11 有缓解，但还没到 90% 的假设。熟练型 95% / 95%，达标。
6. 6:30–7:30 的阵亡集中有缓解，但没解决。同口径下，新手型在这一时段阵亡 113 局 / 200 局（57%），上次是 169 / 200（85%）。不过它仍然占新手型阵亡的 81%，雨夜蜗牛仍是新手型的头号死因（70%）。
7. 被动陷阱变轻了，但随机选卡仍然吃亏。随机选卡 100 局通关 14 局（上次 1 局），到达 Boss 57%（上次 50%）。平均被动数 2.9（上次 3.2），武器等级合计 10.6（上次 7.1）。拿了 3 个及以上被动的随机局只有 51% 到达 Boss，被动少于 3 个的是 72%。新手型 + 随机选卡仍然只有 2%（1/50）。
8. 新问题：K13 的超时兜底对“打不到 Boss”的情况无效。有 5 局过了 12:00 还在场，其中 4 局到 17:00 超时（目标是 0）。复现种子 balance-15：Boss 生命从 11:20 到 17:00 一直停在 83%，角色生命也一直是 45/100。原因是保守走位离 Boss 约 375，手上没有雨滴坠击，其余武器打不到 Boss，所以雾壳剥落的受伤倍率乘的是 0。这是设计缺口，不是实现缺陷，需要拍板，见 §4。
9. 质量检查：`npm test` 257/257 通过；确定性、禁用 API、合规词扫描通过；600 局没有异常、没有 NaN，`diag.dropped` 全为 0，droppedTime 全为 0。本步没有发现实现缺陷。

实现缺陷：本步没有发现。以下是观察项，本步都没有改实现：

## 4. 仍未达标的问题与下一步建议

标“需拍板”的会改变玩家能直接感知的体验，请用户决定；其余可由策划按 01 流程（先改文档再改数据）处理。改完都要重跑 `npm run survivor:balance` 复核。

1. 【需拍板】打不到 Boss 时会无限拖延（OBS-4，12:00 后仍在场 5 局，目标 0）。可选：(a) 11:00 狂暴 II 起，Boss 改为主动贴近角色（例如移速再提高，或周期性冲撞到角色身边），逼玩家进入武器射程；(b) 孢子弹等自动锁敌武器在 Boss 战中优先锁定 Boss；(c) 加“Boss 超时判负”（K13 当时明确不做，这条等于推翻 K13）。(a) 只改 Boss 行为，最接近现有设计。

3. 新手型 Boss 战中位 95 秒，超过 K6 的 90 秒阈值，按 L12 回到策划。数据指向的原因是距离：保守走位离 Boss 约 375，露珠环、菌伞、落叶回旋镖打不到。建议和第 1 条一起处理，不单独改 Boss 生命。
