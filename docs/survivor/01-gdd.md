## 1. 一句话卖点

雨刚停，浊雾附身了森林里的小虫，你扮演小旅人撑起菌伞、撒出孢子，单指操作守住雨后森林 8 分钟，把被附身的生灵净化成漫天光点。

主题落点：雨（雨滴坠击、露珠环）、蘑菇（孢子弹、菌伞旋刃、孢子经验）、森林（落叶、蕨叶、苔衣）。蘑菇只作为武器、外观和光效，永远不是食物。

## 2. 世界观与合规口径

- 敌人不是被“杀死”，而是被“净化”：浊雾离开身体，生灵化为光点/水汽飘散。界面文案统一用“净化”“驱散”，不用“击杀”“消灭”。
- 回血来源只有：露珠拾取物、露水叶片被动、露水祝福永久强化、Boss 战后的阳光。禁止任何“吃蘑菇/采菌回血”的机制、图标和文案。
- 无血液、无肢解、无尸体；受击表现为闪白 + 轻微后退；玩家受伤为闪红边框 + 角色闪烁，不出现伤口。
- 合规自查清单（测试工程师据此写用例）：
  1. 全部文案中不出现“吃、食用、采食、美味”与蘑菇/菌的组合。
  2. 所有回血图标为水滴或阳光，不是蘑菇。
  3. 所有敌人消失特效为光点/水汽/孢子光。
  4. 结算页使用“净化数”。
- 合规扫描对象与词表以 04 §7.1 为准（裁决 D16）：扫描范围 = data/strings.js 与表现层中文 UI 字面量；“死亡/血/尸”类词仅限面向玩家文案，资源帧名/字段名/日志不在扫描范围。

## 3. 核心循环

单局循环（约 8 分钟）：

1. 移动：单指摇杆控制小旅人走位，躲避虫群包围。
2. 自动攻击：已装备的武器按各自冷却自动释放，不需要按键。
3. 拾取孢子：被净化的敌人掉落孢子（经验），走近自动吸附。
4. 升级三选一：经验满后暂停，弹出 3 张卡（新武器/武器升级/新被动/被动升级/进化），选择后继续。
5. Boss 与撤离：7:00 浊雾巨蜗出现；击败后雨停、全场剩余敌人自动净化、出现阳光撤离点，走进去即胜利。

局外循环：结算获得露晶 → 主界面购买永久强化 → 下一局更强、走得更远。

时间轴概览：

| 约 0:20 | 第一次升级 |
| 2:30 | 蚊蚋包围圈事件 |
| 5:00 | 精英圆壳甲虫出现 |
| 6:30 | 蜗牛围墙事件 |
| 7:00 | Boss 浊雾巨蜗出现，普通刷怪降至低强度 |

## 4. 操作方式

- 屏幕：竖屏，设计分辨率 720×1280（逻辑单位 = 设计像素，下文距离、速度均为此单位）。
- 移动：单指浮动摇杆。
  - 手指在屏幕下方 2/3 区域任意位置按下，摇杆底座出现在按下点；底座半径 60。
  - 死区 8；偏移在 8–60 之间速度线性从 0 增至 100%，超过 60 按 100% 处理，方向为手指相对底座的方向。
  - 松手即停止，底座隐藏。只响应第一根手指，其它触点忽略。
  - 屏幕上方 1/3 不触发摇杆（留给 HUD 与暂停按钮）。
- 攻击：全自动。角色朝向 = 最近一次非零移动方向（初始朝右），落叶回旋镖使用该朝向。
- 暂停：暂停按钮在屏幕右侧、微信胶囊下方（见 02 §4.3，裁决 D12，不与胶囊重叠）；切到后台（wx.onHide）自动暂停。
- 升级三选一：点击卡片选择，无拖拽、无确认二次弹窗；弹出后 0.4 秒内的点击忽略，防止移动中误触。
- 镜头：始终以角色为中心；地图为无限循环平铺地面，倒木、蘑菇丛等障碍 MVP 中只是装饰，不产生碰撞。

## 6. 武器（5 种）

通用规则：
- 每种武器 Lv1–Lv5，再加 1 级进化形态（共 6 档）。表中数值为基础值，实际伤害 = 基础伤害 × might，实际冷却 = 基础冷却 × cooldown，实际范围 = 基础范围 × area。
- “单敌受击间隔”：同一武器对同一敌人两次造成伤害的最短间隔，防止持续型武器每帧结算。
- 伤害取整（四舍五入，最小 1）。MVP 无暴击、无护甲。
- 击退：被击中敌人沿“角色→敌人”方向后退 击退值 ×（1 − 敌人击退抗性）。

- 熟练型（贴孢子走位）只躲间隙 < 约 70 的贴身威胁，敌人本来就大多在旧半径内，新增的 20～25 外环覆盖的是它较少停留的区域，收益小于新手型；再加上 §10 2:00–4:00 刷怪 +15%，预计熟练型整体不会更轻松。复核目标见 08 K17。

## 8. 升级、三选一与进化规则

### 8.1 经验与升级

- 敌人被净化时在原位置掉落 1 个孢子，经验值见敌人表。
- 当前等级 L 升到 L+1 所需经验：`xpToNext(L) = floor(5 + 6 × (L − 1) + 0.15 × (L − 1)²)`
- 溢出经验保留到下一级；一次拾取跨多级时，依次弹出多次三选一（每次选完再弹下一次）。
- 场上孢子不会消失。场上孢子超过 250 个时，新掉落的孢子不再生成新实体，经验累加到离掉落点最近的已有孢子上（该孢子外观变大一档：≥5 中、≥20 大）。

### 8.2 三选一抽卡

每次升级暂停游戏，从候选池中不重复抽 3 张：

1. 若有可进化武器（见 8.3），第 1 张固定为进化卡（金色边框），其余 2 张正常抽取。多把同时可进化时，只出 1 张，按获得武器的先后顺序取最早的。
2. 候选池 = 已拥有且未满级的武器/被动（升级卡）+ 武器栏未满时所有未拥有的武器（新武器卡）+ 被动栏未满时所有未拥有的被动（新被动卡）。
3. 权重（2026-09-11 用户拍板：新被动卡 6 → 4，报告 §3-4“被动陷阱”）：

   | 卡类型 | 权重 | 说明 |
   |---|---|---|
   | 升级卡（已拥有、未满级的武器或被动） | 10 | 武器升级与被动升级同权 |
   | 新武器卡 | 8 | 仅武器栏未满时进入候选池 |
   | 新被动卡 | 4 | 仅被动栏未满时进入候选池（原 6） |
   | 进化卡 | — | 不参与加权，按第 1 条固定占第 1 张（S2 不做） |
   | 兜底卡（一捧露水 / 闪亮孢子） | — | 不参与加权，仅按第 4 条补齐 |

   参考（S2 开局刚拿到孢子弹 Lv1 时）：升级 1×10 = 10，新武器 4×8 = 32，新被动 4×4 = 16，单张抽到新被动约 28%（原 4×6 = 24 / 66 ≈ 36%）。
4. 候选不足 3 张时，用以下兜底卡补齐（兜底卡可重复出现）：

### 8.3 进化

### 9.3 Boss 击败与撤离

1. Boss 生命归零：雾壳散开，雨停，阳光照入（1.5 秒演出，期间玩家无敌）。

4. 角色在撤离点内连续停留 2 秒 → 胜利结算。离开则进度清零。撤离阶段无时间限制，无敌人。
5. 撤离阶段每秒回复 5 生命（阳光意象），纯表现性奖励。

4:00–7:00 加压（2026-09-11 第三轮 用户拍板，第二轮复核报告 §4-1 (b)+(c)）：第二轮后熟练型通关率 89%，2:00–4:00 +15% 几乎无效，原因是多刷的敌人也带来更多经验。本轮不加总量、不动 Boss 生命 4500，改为提高“不给额外击杀收益”的威胁：迷途菌灵吐泡间隔 3 → 2 秒；4:00–7:00 三段菌灵占比 10/10/15 → 20/20/25，相应扣蚊蚋 35/30/30 → 25/20/20；生成速率与同屏上限不变。菌灵是远程、会在 180–250 距离停下吐泡，贴着敌人打的熟练型受影响最大，保守型的逃跑走位本来就离得远。按 25 种子试跑：熟练型 91% → 67%，新手型 59% → 53%，新手型 Boss 战中位 80 秒。经验影响：每段约 10% 的生成从蚊蚋（1 经验）换成菌灵（4 经验），4:00–7:00 理论经验约 +220（不计同屏上限），以复核实测为准。通关率口径同步调整：新手型（保守走位）30–60%，熟练型（贴孢子走位）≤ 80%，总体不再作为硬门槛。

6:00–7:00 同屏上限 200 → 160（2026-09-11 第二轮 策划裁定，调优报告 §4-5）：新手型阵亡的 81% 集中在 6:30–7:30，保守型 6–7 分钟平均同屏 139 只（熟练型 59 只），蜗牛围墙落在已经很满的场面上。上限降到 160 后，熟练型（约 59 只）不受影响，只削保守型的峰值堆积；6:30 蜗牛围墙走全局硬上限 200，160 + 14 = 174 仍能完整生成，缺口规则不变。生成速率 4.8 不变。

6:30 蜗牛围墙缺口规则（2026-09-11 策划裁定，报告 §3-6：保守型 169/196 局阵亡集中在 6:30–7:30）：
- 触发瞬间读取角色朝向 θf（§4：最近一次非零移动方向，初始朝右），以角色当前位置为圆心、半径 400，把圆周等分为 16 个槽，第 k 个槽的角度 = θf + 22.5° × (k + 0.5)，k = 0…15。
- 跳过 k = 0 和 k = 15（即 θf ± 11.25° 两个槽），其余 k = 1…14 各生成 1 只蜗牛，共 14 只。缺口正对角色前进方向，两侧最近的蜗牛位于 θf ± 33.75°，缺口张角 67.5°。
- 只依赖事件触发时的角色位置与朝向，不消耗随机数，同状态必然得到同一座围墙。
- 尺寸校验（蜗牛半径 22、角色半径 18）：开场缺口两侧蜗牛边缘间距约 2 × 400 × sin 33.75° − 44 ≈ 400；收拢到半径约 72 前缺口仍能通过角色（> 36）。其余相邻蜗牛间隔 22.5°，半径小于约 205 时就合拢，缺口是主要出路。
- 蜗牛生成后按 §9 直线追踪角色，生命按 §9.1 成长（m = 6，80 × 1.9 = 152）。
- 受全局硬上限 200 约束：按 k = 1→14 的顺序生成，到上限即停止，少生成的只会让缺口更多。

## 13. 局外成长

### 13.1 货币：露晶

结算时一次性发放：

```
露晶 = floor(存活秒数 / 10) + floor(净化数 / 50) + 精英奖励 + Boss 奖励 + 胜利奖励 + 闪亮孢子卡数 × 5
精英奖励 = 精英被击败 ? 5 : 0
Boss 奖励 = Boss 被击败 ? 30 : 0
胜利奖励 = 胜利 ? 20 : 0
```

参考：3 分钟失败约 18 + 6 = 24；胜利一局（约 8:10、净化约 1400）约 49 + 28 + 5 + 30 + 20 = 132。

## 15. 数值初稿汇总与公式

### 15.1 公式

```
实际伤害       = round(武器档位伤害 × might)，最小 1
might          = (1 + 局外晨光之力) × (1 + 晨光菌丝)
实际冷却       = 武器档位冷却 × max(0.5, 1 − 湿润苔衣)
实际范围       = 武器档位范围 × (1 + 宽檐菌帽)
移动速度       = 160 × (1 + 局外轻灵蕨步) × (1 + 蕨叶轻靴)
拾取半径       = 140 × (1 + 局外孢子亲和) × (1 + 孢子罗盘)   # 2026-09-11 用户拍板：基础 60 → 100；2026-09-11 第二轮 用户拍板：100 → 140
Boss 受到伤害  = round(武器档位伤害 × might × Boss 受到伤害倍率)，最小 1   # 2026-09-11 策划裁定，倍率见 §9.2 超时兜底
生命回复/秒    = 局外露水祝福 + 露水叶片（每 1 秒结算一次）
敌人生命       = 基础生命 × (1 + 0.15 × m)
敌人接触伤害   = 基础伤害 × (1 + 0.05 × m)
xpToNext(L)    = floor(5 + 6(L − 1) + 0.15(L − 1)²)
```

### 15.3 DPS 与 Boss 校验

7:00 典型构成（4 武器 Lv4–5、晨光菌丝 Lv3，might 1.3）对单体 Boss 的估算：孢子弹约 56、菌伞约 32、雨滴约 40、回旋镖约 45、露珠环约 17，合计约 190 × 1.3 ≈ 250/秒，进化后约 350–400/秒。Boss 10000 生命对应 25–40 秒战斗，加上走位损失约 40–60 秒，整局约 8 分钟。M2 以此为基线调 Boss 生命。

2026-09-11 用户拍板（K6 触发）：Boss 生命 10000 → 4500。依据 S2 第一批 400 局实测（reports/sprint-2-logic-preview.md）：3 武器、无进化的通关局 Boss 战中位 192 秒，有效 DPS 约 52/秒（10000 ÷ 192），远低于上面 250/秒的估算。按 52/秒，4500 生命约 87 秒，低于 K6 的 90 秒阈值，通关局时长预计从约 10:20 降到 8:30–9:00。S2 改为 5 武器后 DPS 预计还会上升，Boss 战可能进一步缩短；重跑平衡后若中位 < 40 秒再上调，S3 加入进化后按本节原估算复核。

2026-09-11 第二轮 用户拍板：Boss 生命**保持 4500**。调优后实测 Boss 战中位 72 秒（熟练型 63、新手型 95）。熟练型偏轻松改用 §10 2:00–4:00 刷怪 +15% 处理，不上调 Boss 生命，避免让新手型已超 90 秒的 Boss 战更长；新手型 Boss 战偏长由 §9.2 贴近追击与 §6.3/§6.5 露珠环、落叶回旋镖的范围调整处理。

### 15.4 难度校验

- 0–1 分钟：蚊蚋 8 生命，孢子弹 Lv1 一发净化，玩家站桩也不会死（最多每秒受 2 次 5 点伤害，但蚊蚋到达速度跟不上）。
- 6:00 起蚊蚋生命 8 × 1.9 ≈ 15，需要升级后的武器才能一击净化，形成压力。
- 受击无敌 0.5 秒意味着承受伤害上限约 2 次/秒，Boss 战最高约 40 生命/秒（狂暴后 60；2026-09-11 策划裁定的狂暴 II 起 80），站桩必死，走位可活。狂暴 II 起 Boss 贴近追击（2026-09-11 第二轮 用户拍板）后玩家无法再把 Boss 甩开，但追近停在 90（> 接触距离 74），只要躲开冲撞和浊雾泡仍可活。

## 17. 明确不做（MVP）

- 多角色、多地图、角色解锁、难度选择、无尽模式。
- 宝箱、商店、局内金币、重抽/跳过/封印卡等三选一扩展功能。
- 武器融合超过“1 武器 + 1 被动”的进化，被动自身进化。
- 暴击、护甲、元素克制、状态叠层（除露珠环减速外无其他状态效果）。
- 可碰撞地形、可破坏场景、地图事件（如倒木滚落）。
- 联网排行、好友、PVP、服务端存档、每日任务、签到、成就。
- 付费内购；MVP 核心循环不依赖广告，复活/双倍作为 M3 可选激励点（裁决 D9，接入条件见 05 §7.2）。
- 任何“吃蘑菇/采菌回血”或把蘑菇当食物的机制、道具、文案。
- 血液、肢解、尸体、惨叫等暴力表现。
- 剧情过场与配音；世界观只通过 Boss 提示文案和内容介绍呈现。

## 18. 策划假设

1. 设计分辨率**已确认 720×1280 FIXED_WIDTH**（裁决 D10，见 02 §0、03 §1），逻辑单位 = 设计像素，距离/速度数值无需换算；pt↔u 换算采用 02 §0 的 `1pt = 720/屏宽pt` 公式、最小热区 88u。原 750×1334 分支已关闭。
2. 精英复用甲虫外观放大发光，不另出素材；Boss 需要新素材（UI/UX 出规格）。
3. 敌人移动采用简单追踪 + 轻推开，具体分离算法由架构决定，策划只要求“不叠成一点、不穿过角色”。
4. 敌人上限 200 与 00 中的 M1 性能目标一致；若真机达不到，优先降低第 10 节的同屏上限，不删敌人种类。
