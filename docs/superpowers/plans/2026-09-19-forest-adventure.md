# 林风小径：已批准方向的试玩实施计划

> 文档状态（2026-09-21）：历史设计/记录。不作为本轮新增地图或角色/奖励规则来源。 当前基线见[设计文档索引](../../design/design-document-index.md)。

Goal: 一个第三人称小型森林地图，溪边出发，双路登望台，途中得到叶翼，可发现隐蔽花谷。仅本地试玩，不发布。
Architecture: 平台无关 AdventureState 负责高度、碰撞、跳跃滑翔与发现；AdventureWorld 共享同一高度生成地形；ForestAdventureView 负责 Cocos 镜头、角色动画与触屏/键盘。独立 adventure 入口，不读写旧收藏。

- [x] 先测试双路线可达、不能走穿树干、滑翔与跳跃不同、失足恢复、目标与秘密只触发一次。
- [x] 实现共享地形与状态，制作路径、溪流、倒木、望台、花谷、角色与叶翼。
- [x] 接入预览与首页；处理触屏取消、失焦、重开和退出释放。
- [x] Node测试、TypeScript检查、Web构建；实际浏览器试玩并检查窄屏。

验收：无采集数量/背篓/鉴别门槛；目标始终明确；两条路都能到达；滑翔可以控制；秘密是可选；完成后可继续探索或重开。
