# 横屏游戏 UI 精修 Implementation Plan

> 按已获用户批准的六项建议，在当前会话逐项实施与验证。

**Goal:** 统一精修技能、背包、战斗 HUD 和宗门界面，提高横屏可读性。
**Architecture:** 保留 Cocos 现有组件与视觉资源，只改呈现和显示文案。技能数值继续来自 skillPresentation，条件继续来自 skillRequirement。
**Tech Stack:** Cocos Creator 3.8.8 / TypeScript / Playwright。
**Spec:** 当前聊天中用户批准的六项 UI 建议。

## Constraints
- 仅横屏；宣纸、青玉、墨色和旧金风格不变。
- 技能升级不增加通关门槛；物品图标与格子尺寸不变。
- 不覆盖其他开发中的修改，不重置用户存档。

## Review Focus
- 小横屏：详情滚动到末尾后提示与滚动条同步。
- 长技能说明：数值、条件不丢失，正文不遮住底栏。
- 背包筛选和排序：文字与实际状态一致，按钮仍可点击。
- 密集战斗：HUD 不挡住目标名牌或小地图，资源大数值不溢出。
- 宗门：建筑和文字入口均保持可点，未开放地点仍可识别。

- [x] TowerSectScene.ts：已开放/未开放文字主次层级。
