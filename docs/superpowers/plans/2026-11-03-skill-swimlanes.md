# 功法小境界泳道实施计划

> 使用 executing-plans 在当前会话落实已获用户确认的方案，保持现有工作区修改。

**Goal:** 六列固定分类、九个当前小境界泳道、未来大境界默认折叠，并接入用户随后提供的剑破虚空图标。

**Architecture:** Catalog提供显示列；Layout输出纯几何、泳道、折叠和选中进阶连线；TowerMenu渲染并保留滚动/展开状态。学习数据、事务和战斗保持原样。

**Tech Stack:** Cocos Creator 3.8.8 / TypeScript / Node测试 / Playwright实机Web检查 / Pillow。

**Spec:** 本会话用户确认的六列九行排布及后续图标附件。

## 约束

- 固定列依次为御剑、剑气、剑阵、剑影与附伤、增益心法、护体与身法。
- 空位留白，不自动压缩；每个技能仅出现在首次学习小境界。
- 当前炼气/筑基/金丹共9行；元婴之后保持预告，默认折叠。
- 选中节点仅突出真实基础/进阶关系；同列不代表前置。
- 图标保留用户原图和旧图；不使用付费生成，不套用物品98%规则。

## Review Focus

- 学习后位置和滚动不变；图标、名字均可查看详情。
- 折叠不隐藏当前18技能，不改变存档或未来技能可学性。
- 横屏844×390及1280×720可横纵滚动，不压缩字号强行塞满。
- 进阶线避开同列无关节点，选择基础或进阶均能显示关系。
- 新图标在88/64像素圆形下主体完整清楚。
