# 微观森林第一关：雨后的归途

> 文档状态（2026-09-21）：历史设计/记录。不作为本轮新增地图或角色/奖励规则来源。 当前基线见[设计文档索引](../../design/design-document-index.md)。

Goal: 原创2D侧视平台解谜单关，三段连续内容：攀草茎推露珠压叶桥、取得绒毛拨开枯叶借风升空、树根藏身观察甲虫并爬高滑翔抵达出口。
Architecture: MicroForestState.js 为纯逻辑，包含共享平台数据、固定步长物理、交互/检查点/危险。Cocos MicroForestArt.ts 用矢量 Graphics 分层绘制原创美术；MicroForestView.ts 处理摄像机、键盘与触屏、暂停与菜单。新增 microforest 入口，首页现有森林试玩指向新关卡，原版收藏不参与。

- [x] 用可执行测试验证跳跃不能绕过第一二关、攀爬与露珠触发、风场与滑翔组合可到平台、甲虫碰撞/躲藏/检查点、完整流程及重开。
- [x] 绘制大尺度叶片、草茎、水洼、蒲公英、树根、甲虫与小人；移动时不重建静态资源。
- [x] 接入键盘A/D或方向键、空格跳跃/滑翔、E交互，以及屏幕按钮。页面销毁清空引用；后台暂停。
- [x] Web构建、类型检查、Node回归、真实浏览器操作与跨帧按钮回归。提供横向试玩入口和操作说明。

验收：3道谜题均可解，未解决不能靠一直向右走通过；死亡不重复解旧谜题；提示可主动查看；无广告或采集数量门槛；只本地试玩，不发布。

验证结果：280项Node测试通过（含6项新增），TypeScript检查与web-mobile构建通过。实际引擎29项回归通过，路线以固定步长输入推进、无传送；菜单切换跨帧验证。鼠标实测提示与暂停继续成功。仅本地Web试玩，尚未验证微信真机触屏和性能。
