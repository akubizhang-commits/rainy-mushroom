# 武器基础攻击与动作调度实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox syntax for tracking.

**Goal:** 接入独立普攻、互斥动作调度、固定武器攻击范围、攻速、独立附伤及宝器起的元素强化。

**Architecture:** 武器纯数据生成固定属性；独立动作模块管理普攻就绪和施法占用；TowerRun负责真实命中、随机攻击快照、伤害与存档。已有飞剑、落地阵法继续运行，启动技能才占用动作通道。

**Tech Stack:** ES modules / node:test / Cocos Creator 3.8.8。

**Spec:** 本对话2026-11-01用户批准的建议及追加限制：元素强化仅宝器、灵器出现。用户已要求实施，继续在当前工作目录执行。

## Global Constraints

- 横屏；复用现有动作及程序绘制，不消费静态图额度。
- 同名同属性，炼制只随机身份。武器攻击范围在施放时随机一次，多段共享。
- 普攻独立于御剑术；近身单目标，1秒基础间隔，0.2秒动作。已就绪最多让一个新自动技能抢先；等待不积攒多刀。
- 普攻、技能前摇、多次主动挥击互斥；飞行、阵法持续不占动作。读条不被普攻中断。
- 攻速只缩短普攻间隔和动作，不缩短技能冷却、读条或持续效果间隔。
- 新元素轴独立于物理/法术；风归剑气斩与纵横剑气，雷归长虹贯日与剑阵，火归剑影分光；进化继承母技能。御剑术与普通挥剑为无属性。
- 宝器/灵器的通用武器全元素，剑气偏风，剑阵偏雷，极品全元素；凡器/法器无元素强化。
- 独立附伤按施放攻击快照计算，每次直接施放对同目标至多一次，不暴击、不触发被动与自身，不给持续阵法每跳附伤。前期为无属性；后期可带元素。
- 新属性从原百分比预算挪出小部分，不宣称旧平衡报告覆盖本版。新增普攻与串行技能改变绝对输出，需记录实际影响。
- 仅重置本模式旧开发存档；正常保存、失败原子性、重复领奖须回归。
- 工作树有大量现有改动，先保留本轮触及文件的before副本，不整树提交或覆盖。

## Review Focus

- 高频技能排队不能饿死普攻；普攻目标出界或死亡不能产生幽灵伤害。
- 长读条、暂停、恢复、多段施放共享动作与攻击样本，不能重复补刀。
- 御剑术自动发射、万剑归宗和周天剑阵的启动不能绕过通道；已发出的持续效果可以继续。
- 附伤不递归、不重复多段领取；元素只对匹配伤害一次加算。
- 新属性在详情、图鉴、技能面板与战斗一致；当前快照非法字段必须拒绝。
