# 剑气斩动画接入计划

用户已审核 Scenario 动画并要求接入。直接使用已批准视频，不重新生成。

**目标：** 锁妖塔及修仙生存战斗播放同一套透明剑气序列帧；伤害、冷却、范围和存档逻辑不变。

**实现：** 从原始视频有效动作导出 16 帧 256px RGBA 图集；黑底亮度转柔透明，保留原视频。`SwordArcArt.ts` 负责资源缓存、有界节点池、按模拟时间取帧与释放。锁妖塔从已有 arc effect 的过期时间推导出手时间，并在视图内保留短暂消散；旧战斗沿用原来的 28 tick 生命周期。

- [ ] 1. 保存原素材、检查所有有效帧、导出带透明留白的图集。
- [ ] 2. 先写渲染回归测试：方向与范围、固定出手坐标、暂停、迟到加载、重复 effect、清理与销毁。
- [ ] 3. 接入两套渲染；失败回退现有矢量表现，敌方预警层不变。
- [ ] 4. 定向测试、Cocos 构建、横屏实际渲染检查与截图；记录文件尺寸及局限。

实施约定：当前目录包含大量用户已有改动，直接做最小增量，不切分支或提交。使用 writing-plans、test-driven-development 和 verification-before-completion 工作流；在当前会话顺序实现。
