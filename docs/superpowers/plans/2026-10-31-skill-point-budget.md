# 技能点预算接入 Implementation Plan

> 使用 superpowers:executing-plans 逐项接入与验证；不需要新建工作树或覆盖当前未提交工作。

**Goal:** 接入用户确认的高阶技能费用与68免费/12购买/1教学点预算，并验证自然成长。
**Architecture:** TowerGrowth统一成本、奖励和研习定义；Campaign负责事务及存档版本；Menu消费同一份数值；自然流程走真实Campaign与TowerRun。
**Tech Stack:** JavaScript纯逻辑、Cocos TypeScript、node:test、现有自然成长模拟器。
**Spec:** design/balance/balance-check-skill-points-2026-10-31.md（本轮已获用户确认）

## 约束与关注点

- 不改战斗伤害、境界门槛，不重新增加条件段中的“技能点”行。
- 不兼容旧存档只重置本游戏模式；新档正常存读、购买失败原子性、重复领奖必须验证。
- 突破奖励在塔内保存后立即可用，不等首通；退点、重置不能刷点。
- 研习从共享表读取费用与点数，奖励UI显示真实数量，横屏按钮显示学习/升阶价格。
- 自然流程从新档开始，不能修改HP、XP、装备或赠送资源；失败也保存。
