# 四页布局修正

用户的六张截图是交互和布局依据。保持项目宣纸、青玉配色及现有业务规则。

1. 购买页：左分类、右三列商品卡片（图标/名称/价格）；点击卡片显示购买弹窗，显示属性、数量、总价、购买操作。购买页不显示配方材料。
2. 炼制页：左分类、中部配方图标网格、右成品/材料拥有与需要数量、底部数量与费用/炼制。成品可查看详情，材料可查看来源，装备心愿规则保留。
3. 炼制确认不扣资源；确认后成功才出现获得物品弹窗。保存失败不弹成功，保留原 request receipt 以便安全重试。取消不扣费。购买和炼制入口相互独立。
4. 使用明确尺寸的专用按钮，禁用原因单独展示；不用旧按钮的 72px 强制最小高度挤压紧凑布局。
5. 现有资源复用；缺图材料保留文字卡片，不付费生成静态素材。
6. 验证真实业务的取消/成功/失败/防重复，再在 844×390 与 1280×720 构建预览中逐页截图，验证弹窗、滚动和点击。
