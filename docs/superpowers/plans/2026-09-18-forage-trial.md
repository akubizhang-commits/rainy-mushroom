# 林间寻宝A原型实施计划

目标：固定俯视3D森林、单击拨叶/采集、六格背篓可放回、展览目标、独立试验收藏。依据：用户已确认research报告A方向，先试原型。
架构：独立ForageTrial纯状态类 + TrialWorld几何 + Cocos TrialView。PinePilot仅处理进入/退出和生命周期；原版GameSession存档不写入试验收获。
技术：现有Cocos3.8.8、原生JS/TS、已有菌物模型与照片，无新依赖。非Git工作目录，直接在用户授权项目开发，保留原版入口；不上传发布。

1. 先编写状态测试：拨叶不入篓、重复点击不重复计数、容量不足无副作用、放回能重新采、收获只结算一次、每个布局目标可达、旧收藏不变。运行看到模块缺失后实现js/trial/ForageTrial.js。
2. TrialWorld复用makeMushroom/BotanicalMesh/speciesSculpture创建紧凑3D林地，含倒木、树木、落叶遮挡，目标在可点击区域。每轮变化目标/布局。无计时、动物竞争、广告。
3. TrialView显示顶部目标、下方背篓、点击目标和放回按钮、带回与再来一局、退出。首轮3种，后续指定3种。独立storage key rainy-mushroom-forage-trial-v1记录试验展柜，不迁移或清空旧存档。
4. 首页加入“试玩·林间寻宝”；浏览器?trial=1直达。切换时清除旧输入，暂停原版状态，销毁临时网格和UI，恢复透视相机；退出需确认以免误丢当局。
5. 运行状态/全套测试、TS、双平台构建，实际320/375宽点击完整一局、背篓容量/放回、第二局目标、退出回首页。原版迁移冒烟也运行。记录实际结果与原型限制，打开预览供用户试玩。
