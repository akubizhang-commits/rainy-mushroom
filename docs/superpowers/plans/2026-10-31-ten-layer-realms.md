# 十层境界 Implementation Plan

**Goal:** 炼气、筑基、金丹各十层，十层满经验才显示“境界 · 大圆满”，突破方式按境界另定；金丹仍封顶。
**Architecture:** TowerProfile提供唯一层级、满修为与经验条边界。TowerGrowth跟随阶段并保留80点总预算；Campaign原子提交突破；Cocos菜单复用同一显示信息。
**Tech Stack:** JavaScript纯逻辑，Cocos Creator TypeScript，Node test。
**Spec:** 当前用户确认；炼气服筑基丹机制保留，筑基满修为显示突破条件待定（用户最新覆盖：不实现通用手动突破），金丹不开放元婴。

## Constraints and review focus
- 仅本模式旧档按开发约定重置；保存失败、过期写入、重复突破、在塔内请求不能改变进度。
- 十层未满不得提前显示大圆满；两道修为门槛不可通过击杀、丹药越过。
- 原境界阶段技能和装备门槛顺延；十层不增加技能点，保持80点总预算。
- 满修为经验条100%，金丹十层尚未满继续收经验。
- 不改经验掉落与怪物数值；量化经验缺口、满级属性变化，实际通关难度无新试玩数据不作健康结论。
