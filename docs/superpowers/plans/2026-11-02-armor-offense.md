# 防具输出取舍 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在已有两件同档防具之间建立物理／术法选择，力量、智力、普攻速度、施法速度真实生效。

**Architecture:** 保持物品ID、图片、固定词条校验和两件候选不变。guard/graduate对应守御武斗，recovery/master对应回复术法；master不再表示全面升级。属性从装备汇总至角色，普攻统一按配装计算动作时序，存档校验使用施放快照中的同一计算。

**Tech Stack:** 原生JavaScript、node:test、现有Cocos共享生成器。

**Spec:** 本聊天已批准的四项防具属性及生存代价方案；以下具体数值由助手实施选定。

## Global Constraints

- 仅现有法器／宝器／灵器防具加入输出，凡器不变；不调整戒指、武器或静态素材。
- 固定属性点（下／中／上／极品）：法器3/5/7/9，宝器8/12/16/20，灵器20/28/36/44。武斗只加力量，术法只加智力。
- 普攻速度（%）：法器2/3/4/5，宝器3/4/5/6，灵器4/5/6/8。术法施法速度为对应数值的2倍，不增加普攻速度。
- 保留原防御预算表，去除极品1%全面加强。双防换算后乘0.95；武斗物／法系数1.10/0.90，术法0.85/1.05；武斗沿用守御预算微调。
- 武斗HP在原基础表上加守御预算再减品质×0.5个百分点；术法减品质×1个百分点。武斗装备回复降为原通用品质回复的75%；术法保持原回复身份回复。术法保留品质×0.3%冷却，武斗无冷却。
- 速度同类加算后换算动作时长，力量／智力加在境界基础值之后，仅一次，不放大固定词条。
- 不缩短持续效果跳伤或独立飞行时钟。暂停、途中施放存读档使用冻结配装。
- 存档schema49→50，按已有开发政策只重置本游戏模式旧档，失败原子性不变。
- 已有大量用户改动：按本轮开始的文件备份比较，不打包或提交其他改动。

## Review Focus

- 普攻中途保存后重放时序一致，伪造时长拒绝。
- 角色面板、实际技能与普攻使用相同主属性，摘下装备后撤销加成。
- 装备攻速和武器攻速相加一次，未装备武器不发起普攻。
- 同阶品质升高，同路线的攻击、生存、速度不倒退；极品各有独占输出与防御优势。
- 当前档保存和重载、旧档重置、写盘失败均不影响其他键。
