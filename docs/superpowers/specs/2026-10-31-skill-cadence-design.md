## 结论与范围

CONCERNS：节奏同质化可直接由相同CD及伤害曲线证明。对绝对强弱的目标区间判定为 NOT ASSESSED — NO DATA：未找到为当前每项技能规定的目标DPS范围。不能据此宣布全技能平衡；若建立统一目标注册表可使用 /design-system。

1. 剑气斩、纵横剑气所有10级伤害完全相同，均2.5秒CD，近距离实测1级0.600A/s、10级3.192A/s。形状不同，但节奏与预算缺少区别。
2. 长虹贯日、剑影分光都是4秒。前者1→10级实测2.000→4.716A/s，后者1.200→6.192A/s；后者成长更快，且固定落点、延迟伤害存在落空风险。没有移动目标证据，不判断谁全面占优。
3. 两仪8秒CD、持续3秒，10级5.629A/s；四象也是8秒/3秒，进化更像扩范围加数值，缺乏新的持续节奏。
4. 御剑已是0.5秒生成一剑，周天已是6秒CD/4秒持续，无我常驻，天地实际6秒。并非所有技能真的按境界统一2/4/8秒；问题集中在几组重叠。
5. 不能把每剑、每跳、多段整招混为一谈。周天10级每次接触约2.211A，一轮最多7次；两仪10级整阵45.029A；长虹10级整招18.864A，三段共用此预算。
6. 距离200时低级剑气斩/纵横及周天不命中；无我外圈10级母版一阶探针仅0.279A/s（80距离3.096A/s）。几何覆盖影响远大于部分面板差值，不能把近身满命中DPS宣传为全距离表现。

未证明某技能在所有成本、阶段、距离和目标数条件下严格支配其他技能；本轮不出具无敌或必胜流派结论。未做当前版本全流程TTK及多目标实战，对这些项目为 NOT ASSESSED — NO DATA。

### 阵法驻留与Boss输出

- 两仪保持等级对应6/7跳，首跳0.5秒、末跳5秒、中间均分；10级7跳，每跳6.433A。
- 四象保持一阶7跳/二阶9跳，首跳0.5秒、末跳6秒；二阶9跳，每跳10.788A。整阵伤害增加50%对应周期8→12秒，吃满秒伤不变。伤害保持均分，不新增末跳伤害加成。
- 两仪10级命中7/4/1跳时，每8秒贡献45.029/25.731/6.433A，周期秒伤5.629/3.216/0.804A/s。
- 四象二阶命中9/5/1跳时，每12秒贡献97.093/53.941/10.788A，周期秒伤8.091/4.495/0.899A/s。
- “约一半”指上述整数跳数，不假装Boss恰好吃50%；也不能直接用50%时间推出50%命中。首跳延迟、移动轨迹与每跳时刻共同决定收益。
- 吃满时两仪约为长虹秒伤的99.5%，四象二阶约为天地二阶的92.8%。这是风险回报比较，不是合法同点数组合排名；进化前置、解锁与成本仍须单独计入。
- 持续更长会让移动Boss更容易漏跳，允许这个弱点；阵法不自动追踪，不增减速、定身或嘲讽。通过走位引导敌人留阵，由玩家换取完整输出。

### 清杂血线复核

enemy-budget.json 从当前怪物、波次与经验表提取1—9层血量及一次通关的入层等级；无吃丹/刷层。proposal.json 计算当前阶段等级上限的单技能基准，配初始武器、无心法；不代表能同时点满所有技能，不保证新解锁1级就秒本层所有怪。

- 第4层入层9级、初始攻击190.093，3级纵横一击约712.85；本层普通怪最高690，满足命中即可清杂的基准。
- 第9层入层24级、初始攻击922.416，10级纵横约9201，普通怪最高4140。虽有溢出，但周期秒伤仅1.995A/s，低于长虹5.659；没有用清杂溢出换Boss强度。
- 两仪第5层3级对最高1012血普通怪，每跳约836.40，需要2跳；第9层10级每跳約5933.62，对最高4140血普通怪一跳。持续阵可分跳清杂，不要求所有阶段首跳秒杀。
- 以上是无临时护甲、完整命中的血量比较；护甲/易伤、移动、空间分布与目标上限另测，不能宣称实战必清全屏。

### 实现必须保持的特殊规则

御剑内部cooldown=1是预算基准，实际每0.5秒生成一把半预算飞剑，不可把两者混淆。周天保留10/7周期补偿，无我不能继承该补偿。天地整击=新长虹10级伤害×10/新长虹CD×进化倍率，0.45秒前摇、释放后9.55秒；一阶79.227A，二阶87.150A。四象整阵=两仪10级damage×6×进化倍率×(四象CD/两仪CD)，避免漏乘周期比例。万剑保留现有普通飞剑/剑雨独占与停火补偿；这轮不改它的8秒剑雨周期。

剑影保留0.65秒首段延迟及0.16秒后续间隔，固定落点；纵横两刃共用同敌账本；长虹和剑气斩保留总预算分段，不让增加段数偷偷翻倍。伤害类型、目标上限、碰撞宽度和范围全部不变。

流派搭配方向（不是把所有技能满级塞进38点，也不改变进化前置）：
- 高频触发：御剑/万剑 + 剑影分光 + 剑气爆裂；底火稳定触发，影剑补小爆发。
- 贯穿爆发：剑气斩作底火 + 长虹/天地 + 碧落斩；轻重节奏互补，走位拉直线。
- 贴身剑阵：周天/无我 + 不灭剑体 + 剑骨；近身收益与危险并存。进化替换母版，不同时叠算。
- 阵地清场：两仪/四象 + 纵横 + 御剑飞行；长阵驻留、十字清漏怪、移动调整敌群。阵伤不是直接攻击，不依赖阵伤触发剑心/碧落/爆裂。

## 实现边界与验收

1. Growth是数值源，统一实际CD/持续时间访问；当前四象调度跟母版CD走、形态持续时间硬编码3秒，只改进化表不会生效。一起更新运行、形态、面板与快照校验。伤害多段分摊保持单目标总预算，尤其剑气斩首段锚定逻辑不能套旧倍率。
2. 同步规则文字、面板伤害单位（每剑/整招/整阵）、持续时间与冷却。沿用所有现有视觉素材，不覆盖/删除原图视频；阵法延长表现用现有循环，不拉伸单次打击动画。
3. 本轮不调角色成长、装备预算、怪物HP、技能成本/门槛、全局冷却缩减，也不新增手动施法、控制或连携乘区。
4. 先做所有等级定点预算回归、0CDR/最大合法CDR周期、距离80/200、无目标再入场、进化替换与存读档恢复。新运行结果与上表提案理论DPS偏差目标≤5%（不是相对旧版≤5%）；周期边缘采用至少600秒窗口。阵法比较整阵总量及完整驻留DPS；移出阵法时损失属于设计，须单列。
5. 补移动单目标、密集多目标、精英/Boss及合法同点数配装测试；记录前10秒爆发、总DPS、溢出伤害、落空比例、爆裂触发次数和通关耗时。尚无证据，不预先填“通过”。万剑本轮保持原逻辑，以基线回归为准；发现原有调度差异应单列，不为凑理论值擅自改动。
6. 重技能必须在实际游戏里显著重于轻技能，阵法持续视觉与伤害结束一致，暂停/死亡/存档恢复不额外跳伤。新12秒周期应纳入快照合法范围，不放松任意冷却注入检查。
