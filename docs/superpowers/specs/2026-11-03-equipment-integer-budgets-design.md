# 装备整数基础属性与固定词条区间设计

日期：2026-11-03。版本：第二版，提高实际属性收益。状态：设计提案，未接入游戏，未通过实战平衡验收。

## 1. 已确认需求与本次决定

用户确认：每件装备保持固定数值。本文的区间是同品阶、同品质不同装备的设计边界，不是掉落、打造或每次攻击时重新随机装备属性。同名装备始终相同；不增加洗词条、随机属性或极品数值追刷。

用户要求：解决大量基础属性只有零点几的问题；为每个品阶的基础属性、词条制定范围；必要时可以同步调整技能和怪物。

第二版反馈：第一版整体数值偏低，需要提高；U范围不直观，改为直接展示武器物攻/法攻范围。本版相对第一版将固定攻击约提高到2倍、力量/智力额度提高到3倍、防御提高到1.5倍、体力提高到2倍；神识和百分比效果分项上调。换算系数不变，实际收益也提高，不是仅扩大显示单位。

以下为助手提出、尚待确认的具体方案：

- 基础攻击、防御、力量、智力、神识、体力均为整数。出现的力量/智力单项至少3，神识至少2，体力至少2；不分配的项目省略，不用小数凑行数。
- 武器承担固定攻击，防具承担物防与体力，戒指承担法防。武器、戒指不再普遍附带体力；三槽仍可提供力量、智力、神识。
- 将部分武器百分比增伤预算转移至基础攻击、力量、智力。并非在现有百分比增伤之上叠加整张新表。
- 防具取消常规气血百分比词条，改用明确的整数体力。1体力仍为10气血，1力量仍为1物攻，1智力仍为1法攻。
- 保留当前装备名称、图标、获取方式、流派和特殊身份。普通铁剑、粗布道袍、素银戒保留初始过渡定位。
- 本次可执行范围是已开放凡器、法器、宝器、灵器。法宝、灵宝、仙器、神器目前没有合法等级和战斗基线，暂不虚构正式上线数值。

## 3. 如何读数值表

所有区间均包含端点，只能选整数；回复百分比是单独列明的例外。品质依次为下、中、上、极。缺省词条为不存在，不代表可以生成越界的0值。

每件装备在范围内固定取值，不能把所有列上限同时塞给一件装备。基础值、普通词条、特殊效果共同占用同一战斗强度预算。最终必须产出逐件清单，列出所取数值及选择原因；工厂只读取该固定清单，区间用于校验。

“力量+智力总量”是二者共享的最终总额，不是每一项都加这么多。本版撤销第一版“2点力量/智力换1神识”的未验证换算。神识单独列范围；带神识的装备将力量/智力总额选在本档区间下半段（上界为区间中点向下取整），不带神识可以选完整区间。是否等价由实际战斗验证，不宣称固定比例换算。

物攻型将额度给力量，法攻型给智力；均衡型平分，两项差最多1。允许上品及以上专精装备拨出至少3点给副属性，但必须从同一总量扣除。不强制所有装备都带神识。

分配约束：

1. 武器不再每把都附一条极小暴击率/暴伤，暴击收益主要交给爆发戒指。
2. 爆发戒选暴击率+暴伤，节奏戒选冷却缩减；不同时拿满两套。通用功法伤害适用于两类，但带专属特效的戒指需要从普通收益中扣预算。

4. 普通双通道增伤的最终值等于总预算减去流派与元素分配，必须非负。同件武器物理/法术普通增伤相同；定向优势由固定双攻、主属性及流派词条表达。
5. 表中全部上限是单项合法性边界，不是同件装备的预期值。若完成技能等级/特殊伤害核算后预算不足，先在合法区间降低普通增伤、速度和基础取值；仍不足则必须修改提案及证据，不静默突破整套上限。
6. 技能等级+1有独立交换区间：照胆剑的武器增伤总预算为12–25%，太衡剑为24–42%，替代各自品质的普通武器预算行，基础属性仍遵循原表。这为技能等级收益留出空间，不把特殊效果白送。最终是否足够仍须实测；例如剑气斩训练2→装备3的伤害系数比为1.4286，不能统一只预留10%。

## 9. 技能、怪物如何联调

1. 先保存当前源码、身份数据和同种子战斗基线；只在离线设计数据中生成新固定清单，做静态可行性检查。
2. 接入后先调整装备内部预算。把百分比收益转为固定点数后，技能基础倍率、冷却和怪物基础生命默认先保留，以测量净变化。
3. 若单一技能异常，确认是否为主属性重复计入、混合通道重复加成、附伤递归、技能等级重复加成、神识加速或攻击整数波动导致，再调整该技能的实际问题。不得给全部技能统一补偿。
4. 怪物按自然可获得的下/中品装备校准，不能按极品满配统一抬血抵消装备价值。同物种、同品阶普通怪保持固定基础，不随玩家装备实时缩放。
5. 普通怪保持清群差异，精英验证其机制与压迫性，Boss用合理标准构筑100–140秒作参照；优秀配装可以更快。需要改动时列出具体怪物/技能的旧值、新值和同种子原因。
6. 装备变强允许缩短旧有卡点，不强求改前改后通关时间完全一致。不得改变素材制作、怪物视觉尺寸或狂暴时长来“修数值”。
