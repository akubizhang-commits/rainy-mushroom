# 操作按钮图标化检查 · 2026-09-20

> 文档状态（2026-09-21）：专项参考/实现记录。有日期的规则或实现证据，不等同当前目标全通过。 当前基线见[设计文档索引](design/design-document-index.md)。

阶段：原型交互打磨。范围：右侧手掌与跳跃图标；沿用按键位置、触控区域和输入规则。

## 问题与处理
- P1：“交互”无法说明当前动作。手掌保留固定位置，靠近对象才附带攀附、松手、压弯、躲藏、出来、推动等短词；常态无文字。未改成攻击拳头，也未移除手机主动操作。
- P2：图标化容易丢失长按滑翔与期限信息。保留长按提示和秒数，实际滑翔时换成伞形人物。
- P3：半透明分件图形叠色。改为不透明的低强调颜色；无目标仍可点按获取说明，不是假禁用。

## 证据与限制
94项浏览器引擎检查通过，包含真实触控事件抓取、按键取消、滑翔计时提示、完整通关。TS检查、源码检查和最终Web构建通过。最终320×568预览截图确认图标不裁切、按键不重叠；62设计单位高在此预览约53像素。图标首版亦查看窄窗口自适应画面。
未测试720×1280、1080×2400、手机刘海/手势安全区和六英寸真机；项目本页只有中文，未测试其他语言。未做新玩家识别率或留存实验。优先级顺序为场景与角色、邻近动作提示、底部操作；此轮不增加HUD条目。
