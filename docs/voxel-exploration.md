# 自然低多边形 3D 生境探索

当前 `game.js` 入口为 `VoxelGame`。屏幕主 Canvas 使用 WebGL 1；第二个离屏 Canvas 绘制原有菜单、观察、鉴定、图鉴及透明 HUD，再上传为界面纹理。无需外部引擎、在线资产或图像 API。

## 环境与寻找

| 一级生态分区 | 二级生境 | 立体环境 |
| --- | --- | --- |
| 暖湿山地 | 暖湿针阔混交林 | 松林、落叶、树根与局部草丛 |
| 暖湿山地 | 高寒草甸 | 无乔木、连续坡地、矮草和岩石 |
| 寒温带森林 | 红松白桦混交林 | 白桦黑色树皮斑块与松树混生 |
| 寒温带森林 | 冷湿针阔混交林 | 较密林冠、深绿色地表和倒木 |
| 冷湿过渡带 | 林缘湿草地 | 草地空隙与边缘树林 |
| 冷湿过渡带 | 冷湿河谷 | 蜿蜒水带、河岸树林与倒木 |
| 温带丘陵林地 | 落叶阔叶林 | 黄绿色阔叶树冠与褐色落叶 |
| 温带丘陵林地 | 山脚林缘 | 稀疏树木、开放草地与丘陵远景 |

菌物由旋转曲面菌盖、渐细菌柄、层叠菌架和细菌刺构成，保留可见棱面。地表用半米三角网格和连续高度插值，树干、树根和倒木使用多边形截面，草丛由细叶片组成。树生菌绑定树干或倒木高度；地生菌位于地表，部分由矮草遮挡。它们与环境共用光照、距离雾和深度缓冲，不使用朝向相机的照片贴片。场景固定且有限，所有目标可步行接近；不能跳跃、攀树、建造或挖掘。

## 操作与规则

- 左下摇杆连续行走；另一个手指可同时在右侧滑动改变朝向和俯仰。支持绕树，树干、岩石、倒木、水带和地图边界会阻挡移动。
- 进入 4.8 世界单位内可轻点采集可见菌物。拾取射线先检测包围盒，再检测实际三角面和环境遮挡，不能穿过树干点选。
- 右上角放大镜仅缩小视野角、方便观察，不改变目标可见性或发现距离。
- 首次移动或转向后隐藏提示；顶部进度可以查看本局采集，采满8朵自动完成。进入本局采集列表再返回保留位置。
- 当前采集规则由 ForagingState 管理：所有菌物可直接采集，鉴别移到收藏并支持按物种冷却。后台切换清空移动输入并暂停计时与动物行动。

## 验证与限制

`npm test` 覆盖八个场景从入口连通的步行区域、每个目标至少一个无遮挡可选位置、多点触控和射线。`npm run check` 检查入口及所有 3D 模块语法。

`/scripts/voxel-smoke.html` 在实际浏览器 WebGL 上验证首页、八个场景绘制、输入驱动移动、转向、隐藏提示、直接点击菌物、观察往返、焦距切换和 GL 错误状态。

微信开发者工具已实际显示 3D 环境。当前游客模式仍有基础库 `webapi_getwxaasyncsecinfo:fail` 提示；这不属于场景着色器错误。尚未用手机真机验证性能和兼容性，不能据浏览器或模拟器测试宣称已完成真机验证。

最新关卡参数和动物行为见 [生态采集与收藏鉴别](ecological-foraging.md)。
