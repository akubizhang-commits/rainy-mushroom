# 装备详情展示规范

2026-11-02，适用于武器、防具、戒指，以及背包、已装备对比、商店和炼器成品预览。

## 属性文案

- 每项一行，格式为 `属性名 空格 带符号数值`，不用冒号、全角加号和“增加”等重复措辞。
- 示例：`智力 +11`、`施法速度 +5%`、`所有技能冷却时间 -5%`。示例不代表新增装备属性。
- 百分比不留多余小数；保留实际精度。攻击区间为 `基础物理攻击 +4～6`。
- 冷却缩减统一为 `所有技能冷却时间 -数值%`，不出现 CD、主动功法冷却缩短等其他写法。
- 属性区不显示公式、上限、作用机制等解释，不添加感叹号或解释入口。
- 必须保留数值的作用范围：普攻速度、物理／法术暴击率、指定功法及其进化伤害等。
- 气血回复写作 `气血回复 +数值%/3秒`，数值仍表示每三秒额外恢复最大气血的百分比。
- 防御只列装备提供的物理防御、法术防御；由防御换算的角色减伤留在角色属性页。
- 无属性的初始戒指显示 `无属性加成`，不虚构零值词条。

## 布局和窗口

- 三类装备共用一个详情卡组件；已装备和待穿戴装备使用同样的尺寸和结构。
- 顺序固定：状态 → 图标、名称、品阶、境界要求 → 装备属性 → 背景描述。
- 属性统一放入一个列表，基础攻击／防御在前，其余加成在后；戒指按功法伤害、暴击率、暴击伤害、冷却排序。
- 正文统一左对齐，边距20设计像素；图标96设计像素，不修改素材或物品格子。
- 标准卡片380×540设计像素；横屏空间不足时按可用空间统一约束，同一入口不因装备类别、词条数量或是否已装备改变尺寸。购买窗口为交易控件留空间，详情卡复用同一字体和内部结构。
- 超长内容在正文区域滚动，属性数值不截断、不挤占操作区。返回、穿戴等按钮保留在固定操作区。

## 字体与颜色

- 详情卡统一使用系统无衬线字体，不按装备类别切换字体。
- 名称26、品阶和境界21、属性标题和属性正文24、背景描述22设计像素。
- 行高统一为字号的1.35倍向上取整；同级属性同字号、同颜色、同行距。
- 复用已有不透明浅色卡底、品阶边框；属性为深色，背景描述使用次级文字色。境界不足以明确文字和警示色共同表达。

## 实现与验收

- 武器、防具和戒指的公共描述函数输出统一文案，图鉴等复用入口一并生效。
- `inventoryDetail` 不再通过匹配属性文案决定布局，所有装备共享属性列表。
- 仅改展示，不改装备数值、冷却适用范围、战斗计算、交易和存档逻辑。
- 验收横屏844×390、1280×720、1024×768，覆盖三类装备、初始装备、长词条、对比、滚动、穿戴和商店预览。
