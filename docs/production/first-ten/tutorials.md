2026-09-21。对应[重设计LDD](../../prd/level-design-prd.md)A/B/C/X/Y/D/E/F，不是现有运行位置提示。使用动作事件与真实到达，不以必须看完字幕、必须按某次E锁门。成功先于提示就直接跳过；未知动作在后关安全处补教。
