# 十关长地图试玩版 · 2026-09-22

当前正常 Cocos 入口已切换至 `ForestLongCampaign.js` 的十关，旧 `ForestLevels.js` 保留作物理回归样例。它们共用原关卡 ID、奖励、永久道具与通关记录；不会因换地图重复发金币。

本轮交付是可体验节奏的地图原型，不是 LDD 全部空间、美术和分钟指标的最终验收。具名段落已展开为连续可玩空间；部分关卡仍采用重复的机关组合，树冠垂直层次和探索路线的差异还需通过试玩继续打磨。不能把脚本的通关时间当成人类首次游玩时间。

## 续玩

- 苔窝首次启用恢复生命、刷新本次工具次数；已经启用的旧苔窝不能反复补满。
- 退出后恢复到最近已记录苔窝；保留当时剩余生命、工具次数、累计时间与返回次数。局部物体重新生成。
- 地下苔窝可直接恢复到地下，不必从地表重新走完整关。
- 通关清除该关的局部续玩记录；主动“重新开始”从关首开始。
- 使用独立版本化键，不读取旧布局坐标、不改金币存储。存储失败会在暂停界面提示。

## 下一轮试玩关注

1. 石阶、蕨梯连续段是否重复；优先重排选择和落点，不继续单纯加长。
2. 探索宝箱是否值得绕行，树内／地下路线是否形成明显的不同体验。
3. 苔窝间距是否合适、失败回退是否过长。
4. 树冠的连续高差、场景宿主连接、美术变化尚需进一步细化；本版保留可测试的主路与支路。
5. iPad Pro、小米 13、iPhone 17 Pro 的真实触控、性能、安全区尚未验收。
