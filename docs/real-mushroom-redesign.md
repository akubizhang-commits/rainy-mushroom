# 《雨后菌语》真实菌物科普玩法改版研究

> 版本：2026-09-11
>
> 定位：菌物调查训练游戏，不是野生蘑菇食用鉴定工具。

## 1. 改版结论

当前原型用矢量图和虚构物种，能验证页面流程，但不能承担真实物种教育。下一版应从“看抽象造型猜名字”改为：

**写实生境观察 → 补齐关键角度 → 建立候选 → 与危险相似种逐项比较 → 允许证据不足 → 专家报告揭示毒性风险。**

不得改成“看一张照片判断能不能吃”。中国疾控资料及菌物识别产品的共同结论是：单张照片、颜色、气味、虫食、伤变色、银器/大蒜、是否有菌环菌托及充分加热，都不能证明野生蘑菇可食。专业鉴定需要完整标本、生境、宏观与显微特征，必要时还需 DNA、毒素及临床证据。

## 2. 新的一局（4—6分钟）

### 2.1 调查简报（20秒）

玩家收到一宗虚拟调查任务，例如“城郊草坪出现大型白色伞菌”或“同一篮中混入灰褐色鹅膏”。简报只给地点、季节、天气和一张远景照片，不预告毒性。

固定提示：

> 图片与游戏结论仅用于风险教育，不能作为现实采食依据。不采、不食不明野生菌。

### 2.2 选择补充证据（60—90秒）

玩家每局有 **4个调查行动点**。生境、菌盖、产孢面、菌柄基部及不同成熟阶段各消耗1点，孢子印或实验室资料消耗2点；玩家无法在一局内点完所有证据，必须根据当前候选选择最有诊断价值的补充材料。

1. 生境及附近树种；
2. 菌盖顶面；
3. 菌褶、菌孔或菌刺等产孢面；
4. 菌柄全长和基部；
5. 不同成熟阶段；
6. 孢子印或实验室资料。

首版使用预制案例，不调用摄像头，也不识别玩家现实照片。每次选择打开同一标本或同一菌落的对应写实照片，并标注“这是组合证据之一”。不能设置“舔尝”或仅凭气味确认的操作。

### 2.3 候选板（60秒）

系统给出 3 个候选，但不显示未经校准的“准确率”：

- 较吻合；
- 尚有冲突；
- 缺少决定性证据。

玩家可提交到“种”“属/类群”或“证据不足”。证据不足不是失败答案。

### 2.4 危险相似种对比（60—90秒）

候选按以下字段并排，而不是只放三张头像：

| 对比项 | 当前标本 | 候选A | 候选B |
| --- | --- | --- | --- |
| 生境/基质 | 已观察或缺失 | 典型记录 | 典型记录 |
| 菌盖 | 已观察或缺失 | 特征 | 特征 |
| 产孢面 | 已观察或缺失 | 特征 | 特征 |
| 菌柄与基部 | 已观察或缺失 | 特征 | 特征 |
| 季节/分布 | 是否吻合 | 资料记录 | 资料记录 |
| 危险近似种 | 固定置顶 | 风险说明 | 风险说明 |

决定性部位没有拍到时，界面明确写“当前证据不能排除此危险候选”。

### 2.5 提交调查结论（20秒）

玩家可选：

- 暂定到种；
- 暂定到属/风险类群；
- 证据不足；
- 送专家复核。

过早确定扣“严谨度”，谨慎结论不会断连胜。

### 2.6 本预制案例的审校报告与毒性科普（60秒）

完成调查后才显示**仅适用于本预制案例素材**的审校结论，不使用“你已掌握鉴定”“权威认证能力”等措辞：

- 本案例可支持的物种或分类层级；
- 证据为何足够或不足；
- 已知毒性综合征；
- 危险潜伏期或“假愈期”等重点；
- 若现实中发生误食：停止进食、立即联系120或前往急诊；所有同餐者均应向急救人员说明共同暴露情况并接受专业评估；保留剩余样本、剩菜与现场照片；
- 不自行使用偏方，不把症状暂时缓解当作安全。

不提供治疗药物剂量，不将自行催吐写成通用指令。**以上整段急救文案及其展示条件必须由临床毒理/急诊专家逐字复核，并记录来源、审校人、版本和日期；未完成审校不得进入发布内容包。**结算页再次说明：高分只代表完成这宗预制案例，不代表能够鉴定、采摘或决定食用现实野生菌。

## 3. 评分与长期循环

### 3.1 单局100分

- 证据完整度：40分；
- 相似种对比：25分；
- 结论严谨度：20分；
- 安全处置：15分。

惩罚项：

- 只有正面照就确定到种：-20；
- 把颜色、虫食、银器等民间方法当依据：-15；
- 证据不足时选择“确认可食”：该按钮不应存在，而不是简单扣分。

### 3.2 成长目标

奖励以下行为：

- 补齐生境、菌盖、产孢面、菌柄基部四类证据；
- 正确选择“证据不足”；
- 找到决定性冲突；
- 完成危险相似种辨析；
- 识别一条民间误区；
- 完成同一类群不同生命阶段的案例。

可保留当前原型的等级、研究点和图鉴，但图鉴状态改为：

`未观察 → 候选记录 → 案例确认 → 专家审校内容已解锁`

任何状态都不等于现实标本已被确认可食。

## 4. 首版内容结构

首版不追求物种数量，先围绕六个中国中毒风险组制作 6—8 宗完整案例。下表物种名和中文名均为内容候选，上线前必须由大型真菌分类专家复核现行分类名称，再由临床毒理专家复核风险标签。

| 教学模块 | 代表候选 | 游戏内风险标签 | 教学重点 |
| --- | --- | --- | --- |
| 致命鹅膏毒肽组 | *Amanita exitialis*、*A. fuliginea* | 与致命肝损害相关 | 白色、灰褐色并不安全；长潜伏期和假愈期 |
| 亚稀褶红菇组 | *Russula subnigricans* | 与横纹肌溶解相关，可致死 | 受伤变红/变黑不是食用判断 |
| 大青褶伞组 | *Chlorophyllum molybdites* | 与胃肠炎型中毒相关 | 草坪大型白色伞菌及近似种不能只看正面 |
| 急性肾损害鹅膏组 | 以 *Amanita pseudoporphyria* 等为候选 | 与急性肾损害相关 | 鹅膏风险不只“伤肝”；淡色不安全 |
| 牛肝菌风险组 | 以 *Lanmaoa asiatica* 等中国事件材料为候选 | 与神经精神症状相关 | “见手青”是集合俗名；发蓝不是毒性开关 |
| 木耳状易混淆组 | *Cordierites frondosus* | 与光敏性皮炎相关 | 长得像常见食用菌也不代表同属同种 |

### 4.1 标签规则

允许：

- `已知与致命肝损害相关`
- `已知与横纹肌溶解相关`
- `已知与急性肾损害相关`
- `已知与胃肠炎型中毒相关`
- `毒性不能由当前证据判断`

禁止：

- `放心吃`
- `无毒`
- `低风险，可少量尝试`
- 绿色对勾式“野外可食”标签
- “记住这几个特点就能采食”

如需加入香菇、平菇等，只能作为“来源明确的栽培物种”独立课程，不能用于推导外观相似的野生标本可食。

## 5. 写实视觉方案

### 5.1 场景层级

1. **实景远景**：林型、草坪、倒木、落叶层等；
2. **同一标本多角度**：菌盖、产孢面、菌柄全长和基部；
3. **对比标本**：危险相似种、幼体和老熟体；
4. **科学标注层**：热点、比例尺、缺失证据和对比箭头；
5. **原矢量风格**：只保留在按钮、研究站、转场和进度界面，不再承担物种识别。

### 5.2 素材要求

每宗案例至少需要：

- 1张生境图；
- 1张菌盖顶面；
- 1张产孢面；
- 1张菌柄及基部；
- 1张危险相似种对应角度；
- 专家确认的图片说明。

优先顺序：

1. 与国内菌物专家、自然摄影师合作，委托拍摄同一标本的成套照片；
2. Wikimedia Commons 中逐文件核实的 CC0 或 CC BY 素材；
3. iNaturalist 中摄影者明确选择 CC0/CC BY 的素材，或取得单独书面授权。

不能因为图片出现在 Wikimedia/iNaturalist 就默认可商用。iNaturalist图片默认常为 CC BY-NC，不适合商业化小游戏；CC BY-SA 的衍生和同许可要求需单独评估。每个文件记录作者、来源URL、许可证版本、修改方式、下载日期及物种鉴定状态。

推荐项目结构：

```text
assets/species/{caseId}/habitat.jpg
assets/species/{caseId}/cap.jpg
assets/species/{caseId}/underside.jpg
assets/species/{caseId}/base.jpg
assets/species/{caseId}/lookalike.jpg
assets/ATTRIBUTION.json
```

照片建议压缩为 960—1280px JPEG/WebP，每张约150—300KB；首版30—40张约6—10MB，按教学模块分包加载。

## 7. 当前原型改造优先级

### 两周唯一交付目标

完成**一宗**图片权利清楚、分类与毒理双审、可完整游玩且通过现实能力误解测试的垂直切片。另两宗只建立内部草稿或数据占位，不作为两周发布承诺。

### 第1—2天：先锁外部依赖

- 确定一宗风险案例、同标本多角度图片及危险相似种素材；
- 完成图片许可初审和授权凭证归档；
- 确认大型真菌分类专家与临床毒理/急诊专家可用时间；
- 依赖未到位时只开发界面和虚构占位数据，不把未审内容当正式科普。

### 第3—5天：写实取证纵切

- 保留当前首页、存档和矢量UI；
- 实现授权图片加载、缩放、热点和署名入口；
- 将“观察三条文字”改为4点行动预算下主动选择生境、菌盖、产孢面、菌柄基部等证据；
- 加入“证据不足”和“暂定到属”；
- 全页面固定安全提示。

### 第6—7天：相似种与审校报告

- 实现候选对比矩阵，危险近似种置顶；
- 结算改为证据完整度、结论严谨度和安全处置；
- 毒性信息只在本预制案例的审校报告后解锁；
- 加入颜色、虫食、银器、大蒜、煮熟等无效民间判断题；
- 实现内容双审与图片授权构建门禁。

### 第8天：目标用户误解测试

至少测试以下问题：

- 玩家是否认为高分代表能鉴定现实标本；
- 玩家是否认为可以据游戏决定采摘或食用；
- 玩家是否会只看颜色或一张正面照；
- 玩家能否主动说出需要补看的关键部位；
- 行动点选择是否产生推理，而不是固定顺序点完。

任何玩家形成“我可以凭游戏判断现实野生菌能否食用”的理解，都必须记录并修改对应文案或机制；若该误解在目标用户中反复出现，则发布不通过。

### 第9—10天：修订与验收

- 根据测试调整措辞、信息层级和行动点成本；
- 完成专家逐字复核、授权审计、真机布局和包体检查；
- 只将 `approved` 案例装入候选发布包。

### 后续P1：扩充内部案例

专家与素材条件具备后，再制作大青褶伞风险、致命鹅膏风险、木耳状易混淆等案例。每宗都重复授权、双审、误解测试和验收流程，不能通过复制文字快速扩量。

### 后续P2：六个风险组和长期成长

- 6—8宗案例；
- 生命阶段变化；
- 同地区同季节候选；
- 图鉴与风险综合征课程；
- Seek式徽章，但奖励完整观察与谨慎结论，不奖励采摘数量。

暂不做：玩家上传照片AI识别、真实定位推荐、野外可食判断、现实食谱、UGC鉴定和未经审核的社区投票。

## 8. 原型验收标准

1. 玩家不能只看第一张照片拿满分；
2. 至少一宗案例的正确结论必须是“证据不足”；
3. 危险相似种在首屏可见；
4. 不存在“可食/放心吃”按钮；
5. 玩家能说出至少两个需要补看的部位；
6. 玩家能识别至少三种无效民间判断；
7. 每张图片能追溯作者、来源和许可证；
8. 每个物种名和毒性标签能追溯审校人、时间与权威来源；
9. 完全不采摘也能完成课程并获得最高安全分；
10. 启动页、结果页和分享图均明确“不作为现实食用依据”；
11. 测试后玩家不认为分数、等级或图鉴代表现实鉴定资质，反复出现该误解则发布不通过；
12. 全部急救文案有临床审校人、来源、版本与日期；
13. 缺少分类/毒理双审或图片权利批准字段时，构建门禁会自动排除案例。
