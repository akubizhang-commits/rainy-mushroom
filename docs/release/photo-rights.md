# 照片许可处理记录

核验日期：2026-09-14。范围：当前 Cocos 游戏中41种菌物使用的82个实拍照片位。

原先21张 CC BY-NC 照片已退出正式游戏资源。为统一来源与署名，旧版26个照片位整体换为有明确公开许可记录的照片；另56个照片位逐一重新核对了 iNaturalist 的公开照片元数据。

## 当前许可

| 许可 | 照片位数量 | 项目处理 |
| --- | ---: | --- |

| CC BY-SA 3.0 | 2 | 干巴菌原图与局部裁剪图继续采用相同许可 |

这些照片按各自公开许可使用，可用于广告游戏，须持续保留对应条件。此次未购买独占许可，也未向作者发送授权请求。此记录覆盖照片许可整理，不代替整个游戏、引擎及其他依赖的发布审查。

## 两种难以替换的物种

- 干巴菌：使用 Wikimedia Commons 收录的 wombata / Mushroom Observer 实拍。第二张明确标为同一照片的局部特写，不冒充另一视角；原图与裁剪图均保持 CC BY-SA 3.0。
- 致命鹅膏：使用论文 *Diversity, Dispersal and Mode of Reproduction of Amanita exitialis in Southern China*（Juan Zhong、Jianping Xu、Ping Zhang，2021，PMC8701279）的 Figure 1，分别裁剪左右实拍图版。论文许可为 CC BY 4.0，图注明确物种；未用相似鹅膏替代。

## 证据与玩家展示

- `photo-license-audit.json`：82个照片位的许可、来源、修改记录、哈希和证据文件索引。
- `photo-evidence/`：公开照片元数据、原始图版及许可摘录。
- `PHOTO-LICENSES.txt`：完整逐图版权说明，另随 Cocos resources 包分发。
- 游戏首页 → 资料与图片来源 → 查看全部照片版权与许可；图鉴详情也可进入对应照片版权页。
- iNaturalist 的许可版本依据其官方开源代码固定提交 `fd15d0946025509431be9a94152a3f98264f94c0` 中的许可映射核实，并保留证据；并非逐个通过照片网页人工确认。

## 构建与验收

`npm run check:photo-rights` 校验许可白名单、唯一记录、物种对应、必填署名、证据文件及图片 SHA256。Cocos 构建会自动执行检查并生成版权资源；混入非商业许可、证据缺失或图片字节改变会中止构建。

本次验收：246项自动测试通过；浏览器实际运行154项检查通过，包括12个场景流程和全部82张照片加载。网页与微信版本均构建成功，微信主包3.72 MiB。

`built-photo-rights-check.json` 记录最终产物核验：两个包都包含82个照片位对应的文件哈希；旧 CC BY-NC 图片哈希命中数均为0。旧原型照片仅保留在项目历史素材目录中，不进入本次 Cocos 微信发布包。不要把整个旧原型目录作为商业版本另行发布。

照片替换不改变物种ID、收藏与进度存储结构。后续更换图片必须同时更新许可证据与署名记录。
