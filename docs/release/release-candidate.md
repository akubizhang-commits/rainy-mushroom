## 配置与构建

唯一发布配置：`release/settings.json`。版本、AppID、公开联系方式在此填写，verification 仅在实际核验后更新。构建脚本同步到工程；不要手改生成的 releaseInfo.js 或构建产物。

```sh
npm run cocos:build:wechat  # 生成体验候选版，允许游客配置
npm run release:check      # 严格检查，当前预期因待办事项退出1
npm run release:build      # 正式候选构建＋严格检查
```

微信开发者工具可打开项目根目录，由 project.config.json 指向 Cocos 微信构建目录。压缩包中也提供独立 wechatgame 目录。换正式 AppID 后必须重新构建；不能假设游客存档自动迁移到正式账号。
