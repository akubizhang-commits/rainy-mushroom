# 审核材料草稿：雨后菌语

候选版本：1.0.0-rc.7。名称可用性、主体、正式 AppID、公开联系方式、适龄结果和备案号均以正式后台核验为准；本文件不是备案或审核通过凭证。

## 简介草稿

在不同生态环境中漫步，寻找藏在林地与倒木旁的菌物。收集标本、观察实拍照片和形态线索，逐步丰富自己的菌物收藏，了解它们的生长环境与自然知识。

## 本版功能说明

游戏包含4个生态分区、12处探索场景及41种菌物。玩家可移动、转向、蹲下和跳跃，靠近菌物后采集；在收藏中查看照片与线索并进行名称鉴别。林间手记提供探索线索和进度记录。场景中的生态分布、概率、动物行为均为游戏设计，不能用于现实采食判断。

当前候选版无内购、无广告。已实现限时挑战暂停页自愿激励视频加时60秒（每局一次），但当前包没有真实广告位，广告默认关闭。正式广告版启用后应更新材料并真机验收。

## 版本说明草稿

首个体验版本：提供生态场景探索、菌物采集与收藏鉴别、林间手记及照片来源说明。优化收藏列表和返回体验，增加加载失败重试、隐私与存档说明，并精简引擎模块以减少下载体积。

## 审核体验路径

1. 首页选择生态分区，进入场景，选择悠闲模式。首次出发阅读健康游戏忠告及三步指引，可跳过指引开始探索。
2. 移动并接近菌物，按采集提示收集；采集目标以当局界面显示为准。
3. 返回首页进入菌物收藏，查看已采集标本，观察照片与线索，选择名称进行鉴别。
4. 鉴别成功后可查看完整图鉴信息与照片来源；答错后按界面倒计时再次尝试（当前冷却45秒，重复失败120秒）。
5. 查看林间手记；体验从详情页返回收藏时的列表位置恢复。
6. 可另开挑战模式，体验动物竞争与危险提示；世界时间和完成条件以该模式界面为准。
7. 首页底部打开隐私与存档、帮助与反馈；资料页查看逐图署名。

正式提交时应使用同一正式构建验证上述路径，不使用游客账号历史进度作为审核必备条件。
