# UI与交互复查（2026-09-14）

本轮沿用森林绿与纸张色，调整 Cocos 界面组件、收藏导航和反馈展示。

- 长段说明左对齐，正文默认18设计像素，说明文字下限14；标题、按钮及页码保持清晰层级。
- 普通按钮与图标的触控高度至少52设计像素，在320px宽预览中约44px；浅色按钮增加描边。
- 取消滚动边缘弹性并提高减速，恢复阅读位置时限制在内容范围内。
- 收藏、场景名录、照片版权页上下均可翻页，分页按钮位置固定，首尾页有明确不可用文案。主动翻页从顶部开始；详情返回保留筛选、页码及阅读位置。
- 鉴别的查看线索按钮移到相应线索卡片中，逐条阅读；收藏空状态根据筛选显示不同提示。
- 操作结果改为短暂浮层，提示消失不再重建整页；放大镜开启有选中状态。复制能力不可用时显示说明。
- 暂停页通过“带回收获”进入结算，移除跳过结算的重复首页入口。
- 照片版权每页展示一种菌物的两张照片，详情跳转不会先展示其他物种。

验收：247项自动测试通过；TypeScript检查通过；浏览器运行154项场景、采集、鉴别与照片加载检查通过。320×568浏览器预览中人工检查了首页、收藏筛选与翻页、鉴别线索卡片、版权页及详情返回位置。微信真机触控、安全区和低端机性能仍应在发布前单独验收。
