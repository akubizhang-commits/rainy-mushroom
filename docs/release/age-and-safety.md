# 新手、适龄与安全说明（1.0.0-rc.7）

## 已接入游戏

首次出发时显示三步指引：移动与观察、靠近采集、收藏中查看三条线索并选择名称。可跳过；看过或主动跳过后本机记住，不重复打断。退出指引不会改变原来的探索模式。玩法手册可重看。

首页增加“适龄与健康游戏”“野生菌安全”入口，指引和图鉴详情也可进入安全说明。首次指引支持320宽的小屏滚动。

安全说明明确：游戏鉴别不是现实鉴定服务；模型、照片、动物行为和场景分布不能作为采食判断；不随意采食无法确认的菌物，不相信颜色、虫食或大蒜验毒；疑似误食或食后不适立即联系120或就医。页面不提供自行治疗、催吐或所谓解毒操作。

## 微信后台适龄说明草稿

本游戏是一款自然探索与菌物知识学习游戏，包含三维森林、动物和菌物模型以及菌物实拍照片。玩家通过移动、观察和采集完成目标，在收藏中依据图示线索选择名称，了解物种知识。悠闲模式没有倒计时和猛兽；限时挑战有倒计时、猛兽追逐及接触后失败提示。游戏中的鉴别结果不能用于现实野生菌采食。建议玩家合理安排游戏时间，未成年人在监护人指导下依据正式适龄等级选择体验。

当前构建未启用广告；后续启用后，应补充“玩家可自愿观看激励视频获得一次本局60秒加时，不观看也可正常进行游戏”，并重新核验适龄与隐私材料。

该段为内容说明，不代表已取得任何年龄评级。请在微信公众平台“设置→基础设置→基本信息→适龄提示”依据实际画面和玩法选择、提交审核。微信指引将3D写实或近写实列为16+参考之一，不应仅因游戏含科普内容而直接填8+；最终按实际素材与平台审核结果确定。

2026-09-14开发者确认已在后台提交12+、正在审核。当前ageRating=12+，游戏展示建议年龄；verification.ageRatingApproved仍为false。审核通过后据实更新该标记；如最终等级变化，同步修改ageRating并重新构建。游戏内说明和平台启动页标识应保持一致；未核验时本地严格发布检查仍会阻止通过。

新安装或此前未看过指引的存档：选择场景与模式→出现指引→可进入安全/适龄页后返回→开始原选模式。再次出发不重复弹出，原收藏不丢失。查看图鉴、阅读安全说明、返回后保持所选菌物。小屏上下滚动确认全部按钮可到达。12+仍审核中，不标记为已完成平台审核。
