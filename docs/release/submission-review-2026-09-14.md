# 提审复核 · 1.0.0-rc.6

日期：2026-09-14。范围：当前源码、微信构建产物、本地配置、公开官方文档；未进入正式账号后台、未进行本轮安卓/iOS真机验收。结论：尚不能判定符合全部提审要求，不建议原样提交。配置未核验不代表用户一定尚未办理。

## 发现与优先级

1. **P1 隐私依赖尚未闭环**：js/services/PrivacyService.js 依赖 requirePrivacyAuthorize + 微信官方弹窗，项目没有自定义 onNeedPrivacyAuthorization 实现。release/settings.json 的 privacyConfigured=false。如果后台未启用组件或未声明剪切板，复制接口无法完成。应确认公开隐私指引声明 setClipboardData 的目的，并在正式账号真机验证同意、拒绝、拒绝间隔后再次请求、openPrivacyContract。不能选择“未处理任何信息”，官方接口表同时列出写入与读取剪切板。
2. **P1 适龄结果未确认**：ageRating=null、ageRatingApproved=false；游戏年龄页显示待核验。版本审核官方流程要求完成适龄设置。按实际三维探索、实拍照片及挑战追逐内容审核，后台通过后同步游戏展示，不自行猜测等级。
3. **P1 公开反馈入口不可用**：supportContact 为空，GameScreens.help() 显示项目内部沟通渠道占位文案，公开玩家无法反馈。补充真实公开邮箱后重新构建。
4. **P1 账号/资质证据缺失**：新 AppID 已在包内，但 accountType=unverified。需确认正式小游戏账号、个人主体、实际三级类目和资质提交结果。IAA文档要求按实际类目提交资质；不能由 AppID 格式推断已具备资格。
5. **P2 审核材料与构建不一致**：submission-draft.md 顶部仍写 rc.5，包为 rc.6。补充新加载视觉、首启指引体验路径，并用拟提交的同一构建采集截图。当前广告关闭，材料应明确首版无广告，不能宣传正在提供激励广告。
6. **P2 发布门禁混合了不同阶段**：check-release.mjs 是本项目发布门禁，不是微信提审资格判定器。官方允许版本审核与小程序备案并行；工信备案未完成会阻止正式发布，不等于不能提交版本审核。文化互动类的资质审核先后顺序另有要求，需按后台实际类目核对。
7. **P2 真机证据缺失**：androidDevicePassed/iosDevicePassed=false。既往浏览器回归不能代替手机实测。重点检查首次三条线索后的答案、复制授权、切后台恢复、断网资源、存档与低端机帧率。
8. **待核验/建议：健康忠告**。代码中有适龄、休息和野生菌安全说明，但未找到完整《健康游戏忠告》。本次未取得其在当前微信具体审核规范中必须展示的原文，不将其作为已证实的硬性违规。建议补齐开始前可读的健康提醒，并结合后台审核要求确认标准忠告展示。
