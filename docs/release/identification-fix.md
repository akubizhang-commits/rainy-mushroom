# 真机鉴别入口修复（1.0.0-rc.3）

症状：新采集标本进入收藏后，线索区域不能进入名称选择。

已复现原因：新建收藏项的 studiedClues 为 undefined，UI 使用严格数字比较决定是否显示线索解锁按钮，导致第一步无按钮。重新载入的存档由迁移逻辑填充0，因此之前只测状态方法及已有收藏没有覆盖这个问题。

修复：新收藏初始化0条线索、0次失败、无锁定；详情页兼容缺失进度；查看线索后明确触发刷新，第三条后提示向下选择名称。

验证：新增回归测试修复前失败（undefined !== 0）、修复后通过；全套262项自动测试、TypeScript检查及双平台构建通过；实际构建238项浏览器检查通过，包含12个场景的新标本三次线索按钮点击、名称按钮创建和答案提交。该验证仍不能替代手机触屏复测。

真机复测：开发者工具重新编译并生成新的预览/调试二维码，确认首页底部版本1.0.0-rc.3；进入收藏，选待鉴别标本，依次点击三条线索按钮，再向下滑动选择名称。分别检查旧未鉴别收藏与刚采到的新种类。无需删除存档。
