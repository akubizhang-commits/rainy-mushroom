## 本次已实现的广告方案

限时挑战暂停页提供“观看视频广告 · 加时60秒”，每局一次。广告期间世界、动物和倒计时暂停，观看结束回到暂停页，由玩家主动继续。只在完整观看成功关闭时加时；无广告、失败、提前关闭不扣收获、不消耗加时机会。不会在探索中弹出插屏，也不会自动改成分享奖励。

广告开关和广告位现统一放在release/settings.json的advertising字段；未配置正式AppID或广告位不能启用构建。无广告位的当前体验包不显示广告入口。

正式广告验收必须覆盖：真广告展示、完整观看、提前关闭、无填充、弱网、返回前后台、重复点击和回调、下一局不接收上一局奖励；通过后才能标记advertisingDevicePassed。模拟广告测试不能替代该项。

## 隐私后台填写草稿

用途：用户主动点击“复制资料链接”时，向剪切板写入用户选中的公开科普来源链接，便于稍后查阅。游戏不读取剪切板。拒绝授权不影响探索、收藏或鉴别。

本地存储：保存收藏、鉴别进度、探索记录、画面设置；暂无云端同步。

广告：启用后使用微信提供的激励视频广告。请根据正式版本实际平台组件和后台要求完成数据处理声明；不要沿用“本版本无广告”的无广告版本说明。

公开联系方式：填写用户提供的真实反馈邮箱。

参考：微信官方隐私开发指引 https://developers.weixin.qq.com/minigame/introduction/guide/privacy.html 。

## 发布门禁

release/settings.json中的verification字段只记录实际已核验结果，不会因代码测试通过自动改为true。构建后运行npm run release:check。正式AppID、反馈邮箱、隐私、适龄、内容备案、工信备案、安卓/iOS未核验时仍会阻止正式发布检查通过。
