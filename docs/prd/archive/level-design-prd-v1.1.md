### 1.2 单关基本节奏

安全看见目标 → 无惩罚演示 → 一次单机制验证 → 一次变化／组合 → 缓冲区和出口。

每关约4–5个有意义区域；区域不是一屏的固定长度。玩家能从安全处看见下一次起跳的目的地。探索分路最多一条，回到主路，不放强制收集钥匙。每个危险动作前留稳定站立区，动作成功后留恢复区，不能落地立刻遇到另一种未知机制。

## 2. 通用关卡规格

### 2.1 单位与可达性

H为当前角色碰撞高度44单位；V为可见高度，约56单位。表中的空间约束使用H。当前普通跳理论上升约1.52H、同高最大水平距离约3.09H，只能用于初筛，最终用真实控制器验证。

- 首次普通跳：同高有效空隙建议≤1.6H，上升≤0.7H；落地区宽≥1.5H。
- 熟练普通跳：同高空隙先按≤2.2H，上升≤1.0H；如同时上升，水平距离必须进一步缩短。不能同时套用两个最大值。
- 基础关卡不得要求连续像素级踩边；高处落点建议宽1.5–2H，离边还留可站稳距离。
- 首次攀爬从地面可抓处开始，顶部安全轴面≥1.5H；爬至顶部后镜头显示下一落点。
- 蘑菇／风场跨越按实际发射、升力、滑翔测试建立可达包络，落点位于包络中间区；不可只按数学极限摆放。
- 需要柔茎的正式验证沟可先取3.4–3.8H，有效桥长覆盖沟宽及两岸接头，各至少0.25H。现有150单位茎长不足以直接套用某些目标沟宽，必须随灰盒调整。
- 沟宽、起跳面高度和弹力一起决定能否绕过。存在合理跳过解法时可以接受，但首个教学区域应确保玩家看见并尝试本关机制。
- 所有可攀高处下方：有明确地面就安全落地；没有地面时必须显示深沟／水域，不使用假安全装饰。

### 2.2 地形、镜头与安全区

安全区可站宽建议≥2H，首次新机制的等待区≥3H。落点不被HUD、前景草或粒子遮住。视口边缘不隐藏必须精确落脚的平台；需要跨屏时用镜头提前量显示目标，并提供明确的前进方向。

横向镜头以玩家偏左构图，纵向跟随只在离开当前路线高度时移动，落地平缓回落。不能把镜头拉到高处后让地面跳跃变成盲操作。死亡镜头先保留失败位置，再过渡到安全处，深沟失败不让玩家一直盯空画面。

安全复活点必须经过“什么也不按”测试：角色不会滑入沟、被甲虫立即碰撞、随浮物漂走或因桥回弹掉落。每关入口也是有效检查点。

|---|---|
| 01 | CP0/CP1→全关固定路线组；仅恢复人物，安全落地不触发 |
| 02 | CP0→干地练习；CP1→水洼弹射段；CP2→远岸 |
| 03 | CP0/CP1→补给与风段；CP2→高岸 |
| 04 | CP0→练习A；CP1→桥B；CP2→岛C与桥D |
| 05 | CP0→A/B；CP1/CP2→C观察回路与D；B石头跨入C发生接触则按关联规则扩展 |
| 06 | CP0→A演示；CP1→B/C/D承重组；CP2→E高岸 |
| 07 | CP0/CP1→唯一树皮及水段；CP2→远岸 |
| 08 | CP0→树皮段；CP1→补给与风段；CP2→高岸；风段恢复不移动无关联的前段树皮 |

## 3. 逐关详细设计

图中的箭头表示路线关系，不是几何比例。每个区域需有明确落点和真实支撑，不能用漂浮箭头或亮线代替场景设计。

### L01 · 苔间起步（forest-01）

**体验目标：** 玩家在安全环境中学会“粗柄可抓、叶轴可站、摔下来还能自己爬”。不借文本强迫读教程。

**路线：** `A苔地入口 → B低根脊 → C粗蕨柄↑ → D两段叶轴 → E较高出口`；`D失足↓安全地面 → C重新攀爬`。

| 区域 | 布置与玩家动作 | 反馈／教学 | 制作约束 |
|---|---|---|---|
| A | 3H以上安全苔地，远处看见粗蕨柄与路标 | 只显示移动提示；行动后退场 | 无水、无甲虫、无推物 |
| B | 两个露根高度约0.4H、0.65H，短间距 | 第一个普通跳成功后才提示可攀柄 | 根脊从地表长出，不能画成小树桩 |
| C | 起点地面可抓，粗蕨柄爬升约2.5–3H | 近柄出现手掌语义；抓住后才显示上下 | 顶部轴面留站稳区，不到顶就弹出 |
| D | 两条不同生长方向的轴，首跳空隙≤1.4H，上升≤0.5H | 玩家在叶轴上行走，再跳向下一株 | 下方完整安全地面；只一次必经跨轴跳 |
| E | 出口位于第二轴后的稳定土肩，直接从地面跳不到 | 路标与透光方向形成目标 | 不用隐形锁；靠实际高度引导攀爬 |

检查点：CP0入口，CP1=C底部安全地面。重置：无关键可动物，返回最近已激活CP；尚未到C时回CP0，到C后回CP1。替代解：可以在任意合适位置跳离粗柄；不要求爬到脚本指定点。可选分路：D下方稍远处有幼卷芽景观，沿地面自然回C，无奖励弹窗。

资产：CHAR-01、PLT-01、ENV-03、ENV-04、ENV-05、ENV-06、DEC-01。首关最多两株可玩蕨叶、一组远景蕨丛，避免可玩／装饰混淆。

**验收 L01-A：** 无指导玩家能完成移动、跳跃、抓柄；至少从D左右两端各跌落一次并原地落地重爬；正常流程不触发死亡。通过视野可辨“高出口为什么要攀爬”。

**现状差距：** 当前01几乎能沿地面直接到终点；目标版要补真实高低空间与教学顺序，不能只延长平地。

### L02 · 孢子轻跳（forest-02）

**体验目标：** 区分“跳上蘑菇”与“在蘑菇上再跳”，理解主动弹射和空中修正。

**路线：** `A露根踏点 → B低菌盖／干地练习 → C宽水洼弹射 → D对岸缓冲 → E林间出口`。

A、B先无水：低根脊帮助登上菌盖，登冠前不出现空中操作长提示。第一次站稳时显示“再跳一次”；弹射后仍落在宽干地，允许原地试几次。C使用第二个同规则菌盖跨水，起跳点与对岸同时可见。水洼普通跳不可稳定跨越，但孢子轨迹至少留20%可达余量；用实际控制器录出允许左右修正的落点区。D宽≥3H，无立即追击或第二种机关；E用一段普通跳把节奏降下来。

检查点：CP0入口；CP1=C起跳前干地；CP2=D安全岸。重置：菌盖压缩／弹射状态清空，水洼保持，CP1可再次登冠。替代解：直接跳登菌盖、借侧根登冠均可；本关不放蒲公英或柔茎。

资产：PLT-03两株（可同规则不同冠形）、ENV-04、ENV-05、ENV-03、FX-01。禁止菌盖旁斜插断树枝，禁止蘑菇必须与攀藤组合。

**验收 L02-A：** 第一次落冠不自动弹飞；主动跳才压缩喷射；菌盖左右边缘可站；从包络中部起跳能落对岸；落水先有失败反馈再返回CP1，不反复重做A、B。

**现状差距：** 当前02一个危险跨水段过早承担教学与测试；补一个干地弹射练习区。

### L03 · 借一阵风（forest-03）

**体验目标：** 玩家先看见周期变化，再决定起跳；蒲公英是可见且有时限的能力。

**路线：** `A蒲公英 → B安全小坡滑翔 → C根石缝风口／安全等待 → D高岸落点 → E出口`。

A植株在必经安全路旁，获取时有飘絮与身侧携带模型。B只需从低坡跳下，长按展开，在宽地面落下，没有死亡惩罚。C风口放在天然根石缝，上扬草絮从缝隙出现；等待区不受侧向滑落影响。D高岸超出普通跳高度，低路为清楚水域，主路径是“等预兆→跳→展开→上升→向右滑出”。第一次有效上升后再提示横向离风，不提前堆一屏说明。E提供宽缓冲落地与普通步行。

检查点：CP0入口；CP1=C风口左边干地，附近固定蒲公英；CP2=D高岸。重置：风回平静起点，再经过预兆进入强风；清携带效果、补给冷却归零。建议CP1到风口步行≤2秒，使等待和反复学习不消耗大量有效期。

替代解：可以早展开或入风后展开；离开风柱的高度可以不同，只要真实落地。可选小凹地展示水面反光，不能误画成通向出口的低路。

资产：PLT-04、ENV-01、ENV-04、ENV-06、FX-02、ENV-03。无枯叶开关，无白色直线风柱。

**验收 L03-A：** 关闭声音仍能识别平静、预兆、强风、减弱；错过一个周期可安全等；效果中途到期确实收起；重新获取后可完整再试。

**现状差距：** 已有风＋绒毛，缺少安全滑翔练习和风源外观明确化。

### L04 · 压弯小径（forest-04）

**体验目标：** 植物朝受力方向弯曲，站上去会保持；离开一段时间会恢复。

**路线：** `A浅凹地双向练习 → B第一深沟桥 → C中间安全岛 → D第二桥／自然回路 → E出口`。

A柔茎根部可从两边接近，下面是可走回来的浅凹地。先让玩家自由试左右施力，错误方向也不死亡。B柔茎位于沟边内侧，玩家必须从近岸一侧压向远岸，桥长覆盖沟与接头。C可站着观察身后空桥先抖动后恢复；若玩家停在桥上，计时不推进。D不简单复制B：从稍低的根脊接近第二柔茎，根部位置让施力方向需要再判断，保持相同物理规则。E为安全土肩。

检查点：CP0入口；CP1=B近岸；CP2=C中岛。重置：对应本段柔茎恢复直立，人物回同段近岸；不可让桥恢复时把人夹入岛体。可选回路只跨A练习凹地，回主路无需等待桥。

资产：PLT-02两处危险用株＋一株安全练习株、ENV-04／05、ENV-03。三株冠叶略有变体，根部都完整扎土，不是截断树枝。

**验收 L04-A：** 两个方向都能压弯；人物站桥10秒不恢复；离开5秒后恢复；倒下或重置不让计时翻倍；错误压向近岸可以再操作纠正。

**现状差距：** 当前04两个相似桥段；目标版增加安全双向练习，把第二段变成方向判断而不是机械重复。

### L05 · 石头的用处（forest-05）

**体验目标：** 轻石能搬、重石固定；同一个轻石可垫脚或作为植物载荷，而非只触发专用开关。

**路线：** `A轻重石对照 → B推石至根坎垫脚 → C柔茎＋配重回看区 → D蜗牛缓冲区 → E出口`。

A让两种石头轮廓、埋土程度不同；重石不挡唯一道路。B目标土肩高度在普通跳上限之外，轻石放在较远干地，需要推到肩边，再站石起跳；这一次让推物有真实用途。B的高度按“直接不可达、站石可达”双回放验证，不凭目测。

C采用上桥、下根脊的闭合观察回路，详见下图；远岸等到空桥恢复，也能沿下层干地返回近岸根部。若把小石留在桥上，可直接走上层回程，省去下绕。桥保持是便利解法，不强制压石才能让出口判定有效。明确接受“先通过、不回头”的主线解法，避免用拿钥匙制造无理由折返。D蜗牛缓慢经过两个低根肩之间，可踩壳走短捷径，也能沿地面绕行；等待时间建议≤5秒。

检查点：CP0入口；CP1=B完成后的宽土肩；CP2=C后安全岸。重置B必须让石头回可推位置而非高肩另一边；C组恢复柔茎与配重石；B过后另供独立小石，不要求跨检查点搬运，但允许带入，涉及B石则按5.4扩展其出生组。


**C区闭合回程（上下两路都双向可走）：**

```text
B土肩／CP1 → N近岸：根部＋小石 ──可压弯桥── W远岸等待／CP2 → D蜗牛 → E
                   │                             │
             低根阶（可跳回）               低根阶（可跳回）
                   └──── R连续干地露根回路 ──────┘
```

W宽≥3H，离桥恢复扫掠区至少一个角色身宽；N可从两侧接近施力点。R为明显可走的干燥根脊，最长一段根阶上升≤0.65H、水平间隔≤1H，出口回到N地面而非桥尖。上下层净空≥1.5H，不使人夹在桥与根之间。R绕行目标6–10秒，计时仅用试玩调节，不复制台阶拖时长。此处是可选练习凹地，不画成无底沟；第4关才承担危险桥的考验。

回放L05-B：不放石过桥→远岸等待完整恢复（≥5.8秒）→走R回N→重新压桥；L05-C：放石过桥→远岸等≥5.8秒→走保持的桥回N。二者都不得死亡、重置或调用远程交互。主线一直向D走也有效。CP1/CP2共用C组，返回观察不会使菜单目标退回B垫脚区。

资产：OBJ-01至少两块、OBJ-02一块、PLT-02、BIO-02、ENV-05、ENV-03。不能把重石画成和小石一样大却无理由推不动。

**验收 L05-A：** B用动作可证明必须借高且能稳定完成；轻石受根壳阻挡；单独石头压桥超过5秒保持；玩家离开不带走支撑效果；不等蜗牛也可前进。

**现状差距：** 当前05主要可以绕开推石；目标版让垫脚成为核心判断，配重保留为有价值的可选玩法。

### L06 · 叶片的重量（forest-06）

**体验目标：** 读懂“载荷改变高度”，分清承重叶的垂直变化和柔茎桥的横向弯曲。

**路线：** `A空载叶演示 → B已有小石压叶 → C卸重登叶／叶面回升 → D双高度跳离 → E高岸`；`C/D失足↓低地 → B`。

A是一株完整植物，粗叶柄接地，玩家从露根小阶能上叶，踩上可见下降，跳离后看到回升。B第二片叶上放小石，叶片起始比空载低；叶侧有干地接物区，推开石头不会坠入不可恢复深沟。C玩家可先登叶再推石，看见叶面回升；也可卸石后跳回入口根阶，观察叶面复原，再登叶；此时叶面会因角色重量重新下降，最终到同一载人高度。第二种是观察／重试路线，不包装成另一套独立谜题。D的高岸放在载人平衡高度可跳范围内，低地有返回B的路径。两种操作顺序都必须验证。

检查点：CP0入口；CP1=B根阶；CP2=E高岸。重置对象为本段叶片位移、石头及支撑关系，先清支撑再放回初态，不能把石头留在旧悬空位置。无风场、无甲虫，不混入反应压力。


**L06-B/C/D候选灰盒参数（逻辑单位，Y向上；尚未经控制器验证）：**

| 项目 | 候选值／约束 | 需要验证的接触 |
|---|---|---|
| 叶空载面 | Y₀=172，主承重宽140；下降52、容量2 | 四状态面高172／153.8／146／127.8，见母文档6.2 |
| 入口／观察根阶 | 顶面Y=136，宽≥2H；与叶入口平面间隙≤0.25H | 初始石底153.8、高25；先登叶再推，不要求手臂从根阶够完整个叶宽；石到接物侧需留推行空间 |
| 低地接物区 | 顶面Y=90，宽≥3H，接物侧有止石土肩 | 石头可向入口反侧推离；落下后可从低地返回根阶，不落水；不得挡唯一回路 |
| 出口E | 顶面Y=200，宽≥2H；与叶有效右缘间隙先取≤0.5H | 载人稳态起跳上升54；同载叶面起跳需72.2，超过当前理论66.7；只作初筛 |

顺序A：登叶→同载127.8→推石入接物区→载人146→跳E。顺序B：登叶卸石→跳回根阶→叶回升接近172→重新登叶后降到146→跳E。取消v1.0“站在外侧根阶就能推完整片叶”的假设：普通推物需要人物跟随，首批不新增拉物或远程推物。B允许再登叶后等待稳定，也允许回升中跳；不承诺所有时刻都可达，但不能把可达窗口做成唯一瞬间。至少稳态路线在键盘、触控均稳定成立，且覆盖0.25／0.5／1秒等待后的尝试与安全失败恢复。

**允许第三解：** 站石顶部借高、推动过程中提前跳E，只要真实接触就算通关。石高25意味着“同载叶面不能直接跳到E”不等于“同载状态绝对不能通关”；不为教学禁踩石、不检测卸石次数。测试分别记录两种主顺序和发现的借高捷径。若几何不成立，优先缩小间隙／下调出口并重验教学，不改单关跳跃能力。参数是候选夹具，不直接覆盖当前forest-06坐标。

资产：PLT-05一套两株、OBJ-01、ENV-04／05、PLT-01背景或出口附近缓冲。叶片不是悬浮平台，空载与载荷状态都能看见接柄。

**验收 L06-A：** 空载、载人、载石、人与石同载四种状态都稳定；随叶上下时人物不滑出、不穿地；卸重后回升可把人带起；把石头推到接物区仍能通关；掉低地不死亡。

**现状差距：** 已有叶面下沉机制和两片叶，但正式版要将载荷改变高度变成可理解的解题过程，补接物区与两种顺序的验证。

### L07 · 浅水渡口（forest-07）

**体验目标：** 学会把一个干地物体变成移动支撑，并从移动平台主动跳离。

**路线：** `A岸上树皮观察 → B低岸推入水／登乘 → C短缓流 → D宽低岸离船 → E出口`。

A薄树皮躺在水边，底部与地面接触，旁边碎皮只作中远景，不与关键物同形同层。B岸高与树皮浮高差先控制在普通跳易达范围内，推入水后有一段短缓流登乘窗口；不能一入水就迅速漂离。C是方向清楚的短水段，水纹跟随流向，玩家可在树皮上略移动；此关没有风、石头装船或甲虫。D宽≥3H，树皮会靠岸停住，不要求第一次就边漂边极限跳。

检查点：CP0入口；CP1=B近岸；CP2=D远岸。重置明确取回唯一树皮。错过船后在安全岸能暂停重置；不得让玩家为了触发恢复必须先自杀。若树皮载人卡在岸边，仍有直接跳上岸路径。

替代解：可以在入水前站上边缘后调整，也可以入水后跳上；若玩法不支持站着推动，不能提示这种做法。正式必经解是从岸侧推、再跳上。可选路线只设在D上岸后的景观小岔路，避免绕开整条学习段。

资产：OBJ-03、ENV-04湿岸、FX-02水纹、ENV-06、ENV-03。不能画成扎好的木筏。

**验收 L07-A：** 相同输入下可稳定推入、登乘、随流和上岸；人物随树皮移动；岸边不穿透；静止水纹不会误导流向；错过／落水／重置三种路径都能再次尝试。

**现状差距：** 基础漂浮已实现；目标版主要补登乘窗口、湿痕与流向、明确重置集合。

### L08 · 顺流上岸（forest-08）

**体验目标：** 两个已学机制连续出现，玩家必须在中途安全区重新观察，而不是全程按住一个按钮。

**路线：** `A树皮渡流 → B中间宽岸与检查点 → C蒲公英补给 → D间歇风上高岸 → E出口`。

A复用07但水段略弯曲的视觉岸线，不改变真实流向规则；目的地从起点可见。B宽≥4H，与风的作用区隔开，站在岸上不会被误托起，玩家可以停下。C补给从B到风口2秒左右可达，植株不能靠近水缘造成误落。D风相位与03相同，变化是高岸略偏右且需在空中早一点横移；落区仍宽，不同时收紧所有参数。E以低草和远景空隙呈现安静缓冲。

检查点：CP0近岸；CP1=B中岛；CP2=E高岸。最关键合同：D失败必须回CP1，不必重做A。CP1重置只处理风段的补给状态和局部物件，不把角色送回树皮起点。

替代解：高一点再侧滑或提前移出风区都可以；不同输入方式保持同样可达。不要让A的树皮承载石头去解决D，首批不引入跨段运输依赖。

资产：OBJ-03、PLT-04、ENV-01、ENV-04、FX-02、ENV-03。与03和07共用单体，以水岸构图、距离和高度变化区分场景。

**验收 L08-A：** 连续三次风段失败均不重做漂流；蒲公英到期后在CP1附近可补；两个机制的提示分别在B前后出现；玩家不会把B当作最终出口。

**现状差距：** 当前组合已存在，正式版重点是分段恢复、镜头与缓冲，不再新增第三种机关。

### L09 · 甲虫的领地（forest-09）

**体验目标：** 从“只看地形”转向“观察活体节奏”，同时提供至少两条真实可行路线。

**路线：**

```text
A安全观察 → B根缝入口 → C巡逻区 → E汇合安全区 → F出口
                         ↘ D高处蕨轴 ↗
            低路：提前跳过／近侧小石挡虫／适时进根缝
            高路：攀粗柄、跨叶轴，避开头侧碰撞
```

A与甲虫隔开足够安全距离，先看到至少一次转向；不是靠突然弹字幕暂停敌人。B根缝出入口面对安全等待位，进入后可观察虫走远。C首段跳越给予至少约0.7秒可读反应窗口，此为灰盒起点，要用巡逻速度和镜头实际验证；先演示再通过。近侧提供OBJ-01，让玩家看见推石会改变甲虫转向位置，不把唯一石头放在虫后方。

D入口位于危险区之前，高路只用已学普通跳和蕨柄攀爬。落点下方可有虫，所以必须提前看清巡逻；至少一处纯安全下落区域，避免失足必死。E在巡逻边界之外，角色可恢复，无虫追过来。F普通步行到出口。

检查点：CP0入口；CP1=B附近但不在虫碰撞范围；CP2=E。重置恢复小石与巡逻安全初态，不能在玩家出生点生成甲虫。死亡播放倒下；虫背站立不判伤害，头和身体侧接触才失败，规则与母文档一致。

资产：BIO-01一只、OBJ-01一块、ENV-02两处根缝、PLT-01两至三株、ENV-04／05／06、ENV-03。首批不靠两只虫夹击提升难度。

**验收 L09-A：** 高路、提前跳越两条方案各自零传送通关；小石与根壳都挡虫；甲虫转向、脚步和碰撞同步；出生静止2秒快速检查及6.4完整巡逻周期检查均不受伤；藏身可进可退，不锁死输入。

**现状差距：** 现有巡逻和高路基础保留；需把阻挡石放到观察侧，增强安全观察区与危险边界。

### L10 · 回家的光（forest-10）

**体验目标：** 玩家用掌握的规则选择路线，完成一次有起伏而非机关清单式的归途。

**路线：**

```text
A孢子跨小水洼 → B安全根际 → C分流 → D汇合休息处 → E蕨轴上行 → F林缘出口
                                 ├ 低路：轻石＋柔茎桥 ┤
                                 └ 高路：攀附＋蒲公英滑行 ┘
                                              可选承重叶短径 ↗
```

A只复习一次弹射，不再显示整段新手教程，失败点就在菌盖前。B清楚显示两条路共通的远处目标。C低路更稳，需要推石垫脚和压茎；高路较快，需攀附、获得绒毛后从高处滑过。两条路各自必须能完成，不能低路拿了某物高路才开放。不给出口加“必须使用三种机关”的隐形条件。

D为宽安全区和检查点，可放蜗牛作为节奏缓冲，绕行也可继续。E回到01的蕨轴语言，但增加到三株不同方向生长的蕨叶；每次跳仍处于普通跳包络内，下方安全地面可回入口重爬。承重叶作为E前的一条短捷径，不是失败就重做A的陷阱。F在第三轴连到的真实林缘土肩，暖光从远景透入，旅人停稳后结算十关完成。

检查点：CP0起点；CP1=B；CP2=D；CP3=E攀爬基部。CP1的恢复范围为C两条分路共同组；换路不改变归属。到D后以D/E组为起点，带入物形成接触则按关联规则扩展；人物仍回最新CP。两路通关各自独立，不等于恢复时需要猜选择。F没有突然出现的甲虫或末秒落水，高潮来自到达。

资产：PLT-01/02/03/04/05、OBJ-01、BIO-02、ENV-03终局变体、ENV-04／05／06、FX-01/02。这里允许共用多种资产，但同一视口最多突出一项当前决策，背景让路。

**验收 L10-A：** 低路、高路分别从新状态独立通关；D以后死亡不重做A；E落地可返回CP3附近攀爬而不传送；到F下方不结算；完成标记只写一次并可重玩。

**现状差距：** 当前10是短组合路线，缺少真正分流与汇合；正式制作优先补两个相互独立的解法，再做终局光景。

### 6.3 新玩家测试与修改判据

首轮建议至少5名未玩过项目的玩家；先不解释规则，记录构建号、设备、输入方式与各区域耗时。看不懂与操作做不到分别记录。开发者熟练回放仅证明可达，不计入新手时长。

初始验收建议：至少4/5玩家能在不口头提示下完成01；首次关键机制至少4/5能从场景和情境提示判断下一动作；每关连续三次失败后仍能找到恢复办法。样本小，只用于找设计问题，不推出留存率或市场结论。

按原因改动：

- 多人把背景当平台：先调层次、轮廓和摆放，不给所有平台加白线。
- 多人不知道植物能推：先展示完整柔茎、受力和手掌上下文，不加新按钮。
- 多人总差一点跳不到：检查真实可达包络、坡面、镜头，再调间距；不要偷偷给某关加跳跃能力。
- 多人忘记蒲公英已过期：加强携带和消散表现、补给位置，不永久延长所有道具时间。
- 多人只觉得在等：缩短船程／蜗牛窗口，给安全观察内容；不把等待当关卡长度。
- 大多数人走了意外但合理的捷径：先判断是否保留，不立即放隐形墙封掉。


### 6.4 检查点全周期安全与时钟用例

2秒是快速冒烟，不是完整安全证明。每个入口／CP分别在首次进入、死亡复活、手动恢复后无输入等待。记录初始位置、初相位、实际配置、观测时长、结果和构建号；CP不得依赖临时无敌、移动支撑或持续按键才安全。

| 对象 | 最少观测范围 | 初态覆盖与成功条件 |
|---|---|---|
| 间歇风 | 实际周期T＋一个物理步；当前T=8秒 | 平静、预兆、强风、衰减起点及各边界前后一物理步；等待位不被吹走，视觉与力场同相 |
| 柔茎 | 空置5秒＋恢复0.8秒＋一个物理步 | 两弯曲方向、载人10秒、载石10秒、途中重新加载、恢复受阻后移开；受阻时不强求5.8秒内恢复，解除后记录实际完成 |
| 甲虫 | 至少一次完整往返和两次转向停顿 | 无障碍理论T=2×巡逻距离/速度＋2×停顿；以实际到端事件确认。例距离490、速92、停0.38得约11.41秒，非统一硬编码值 |
| 甲虫被石改变巡逻 | 当前有效区间完整往返＋转向 | 石在两端／中段都测；若虫被永久夹住，记录夹住状态及其安全性，不等不存在的往返；超过理论周期两倍仍无预期端点事件则报异常，不能自动PASS |
| 组合环境 | 各对象完整周期，加不利相位组合 | 风起／落、虫向CP走、桥开始回弹的配对边界；固定种子重复。不是只跑最短周期，也不宣称有限样本覆盖一切连续相位 |

恢复默认将组内风置平静、生物置安全初态，测试仍要通过合法初态夹具覆盖其他相位及组外继续的时钟。暂停或死亡冻结阶段不计入观测时长；前后台／旋转后继续原相位，所有按下状态清除。桥有人永久不回弹是正确规则，不能为结束测试强迫恢复。
