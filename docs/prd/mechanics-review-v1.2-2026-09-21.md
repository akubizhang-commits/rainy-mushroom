## 1. 对五项需求的处理

| 用户方向 | 评审意见 | 写入方案 |
|---|---|---|
| 树洞进入树内 | 采纳，入口必须有返回与清楚的内部尺度 | L02可逆树内短路，在蘑菇教学前汇合；ENV-07/12与zone/portal合同 |
| 上树冠，再汇回地面 | 采纳，不能靠缩小巨树或一阵风直上树顶 | L03低枝冠预演，L08高树冠；分段藤蔓、镜头随升、侧风、毛虫载具、蜻蜓定线危险，沿粗藤回地表 |
| 地下洞穴 | 采纳，先做有出口的根际／旧洞旁支 | L04可选地下回路与滴水窗口，L06采光井；洞顶根须和土壁说明地下，绿叶只在可见采光处 |
| 更多常见生物 | 采纳生物库，分批制作；不能按物种名称统一定伤害 | 首批新增蚂蚁、西瓜虫、蜻蜓、光滑毛虫；25类库含现有与候选，非昆虫标明；最多另选两类背景 |
| 血量限制无代价重试 | 推荐3格生命＋临时CP＋休息点；不把总命数锁死作为默认 | 轻伤扣血；落水扣血救回；归零回R并重做挑战段；CP／切区／手动恢复不回血，治疗不能刷 |

树内／地下的过渡借鉴“进入另一处空间”的通用设计目的，所有入口外形、环境、路径和动作保持本项目原创；不复制参考游戏的管道、美术或关卡。

## 2. 合理性审核

### 策划

通过为**待验证提案**。新增空间应改变路线选择，而不是在原关末尾无限追加房间：树内走支撑和光孔，枝冠看落点和风，地下看净空与滴水。L02/03/04即能见到新内容，危险行为在后续安全演示后再考验。

生物以动作／部位定义危险，首批不做“全身触碰即死”。否则3格生命对大部分风险没有意义。西瓜虫蜷球可推、毛虫能承人、固定预告掠过都是游戏化设定；查到真实习性不等于证明这些玩法的物理承载真实。

生命不是为了让玩家最终无游戏可玩。默认仍能重试，但一段只给3格，耗尽须从更早R重做；保留探索和学习机会，同时取消每个CP无限满血硬闯。若用户以后希望严格有限总命数，可做独立挑战模式，不能悄悄改变默认存档与进度规则。

### 视觉／交互

有条件通过出样。最需要先辨认的是“藏身根缝”和“进入洞道”，其次是CP与可治疗R点。差异必须来自深度、开口、苔窝、姿态和短上下文词，不靠颜色或新增专用按钮。

巨树只画局部，兔洞画大空间的旁支，不把树和兔子缩成盆景。连续升降镜头提前显示握点及下落承接面；竖屏和横屏各自验证。生命整合原关卡名位置，关名入场短显，不在常驻HUD再叠生命、命数、氧气、耐力。

需要动作样板：蚂蚁拐弯排队、西瓜虫蜷球与载人、毛虫腹足和顶面、蜻蜓预兆／掠过，以及人物轻伤／救回／耗尽倒下三种反馈。都不能用静图滑移代替。

### 产品

范围扩展成立，但**v1.1的原成本和准入结论不自动适用**。新增三类空间、四类互动生物、两类周期环境与生命恢复合同，已经超出纯美术补充。25类是需求库，不是本批生产清单；保留四类互动和最多两类背景的上限，先测样板再估排期。

生命设计的假设是“有代价但不阻断探索”，没有新玩家证据前不承诺提高留存或趣味。关键观察为玩家主动探索是否减少、是否更倾向受伤硬闯、归零后是否愿意再试，而不是只看死亡次数变少。

### 开发

方案有明确合同，但实现风险高于v1.1。需要全关共享HP／CP／R状态、稳定zone/portal、冻结区数据、治疗取用记录与challenge恢复范围。先沿现有状态与关卡配置加最小字段；不因为多空间就改成3D、全局生态模拟或新编辑器。

跨门只携带旅人与蒲公英；以有体积约束的窄入口解释，石头停在源区且必须松手再进。连续树冠边界仍按现有物理搬运，不设跨区隐形墙。多区状态离开后冻结，回访不重建，因此不能用进出门回血或刷机关。

必须先通过HP/R与双向入口小夹具，再接四种生物；否则一次性加完后难以区分支撑、空间转换和生命状态的问题。

### 测试

方案可拆成具体用例，**尚无运行通过结论**。LDD新增HP-01…08、ZONE-01…04、CREATURE-01…04、RHYTHM-01，并保留原地面、桥、石、甲虫、蒲公英回归。

每条主解必须有无伤回放；HP规则还需失败路径证明。不同相位受伤、无敌期间落水、同帧入洞／通关、跨区HP归零、跳过R、重新加载旧存档、载人变形与超载都是必测项。生命系统不能拿受伤保护替代安全CP验证。

## 4. 仍需验证的风险与制作顺序

1. **高风险：** HP与跨区恢复优先级。先做一块地、一个水坑、两个房间、两个CP和一个R的小夹具，验证归零／加载失败／重置去重；不用最终美术。
2. **高风险：** 相机与多层落点。做L03低枝冠来回，确保横竖屏看得见握点和下层地面，再扩高树冠。
3. **中风险：** 活体载具。分别做西瓜虫载人变形、毛虫承载与超载、队列挡石、蜻蜓预告，不把四类一起塞进关卡后才调试。
4. **中风险：** 失败成本。确认R后的正常回退候选30–90秒、约2分钟内；故意跳过R可能更长，提示需明确。若主要时间用于重走已掌握内容，优先调整R位置。
5. **待决策：** 平台／设备范围沿用v1.1规划，尚未真机确认；生物具体物种与最终造型待选定，未核验条目不得当生态事实或终稿。

建议实施顺序：生命／恢复＋入口夹具 → L02树内 → L03低枝冠与安全毛虫 → L04地下 → L05队列／蜷球 → L08侧风与蜻蜓 → L10多层汇合。固定地形、载荷和浮树皮样板继续穿插回归，未验收不量产素材。

本轮只完成文件修订、来源核对与文档一致性检查；没有新增可玩版本、真机结果、用户审美确认或试玩统计。
