# 御剑术 · 双翼藏锋 v1

已按用户同意的方向制作；本包为横屏美术动画预演，待视觉审核，不是游戏实录或已接入技能。

## 本版设计

每升一级增加一个御剑槽位，最高10柄。槽位固定，不因每轮施法累计增加。
凝神诀2/4/6级分别作为御剑术4–6/7–9/10级前置；保留原有境界条件。
上述成长与前置记录为后续接入契约，本包不修改成长数据。

按用户最新“多余飞剑悬停”的要求，本预演采用一敌一剑，单怪时一剑出击、九剑待命。
这取代前一提案的少敌合击；用户未单独选择合击数量，故该项明确记录为制作假设。

青白剑体从角色两侧肩外向上展开，左右各5个稳定槽位；外侧更高且向外倾斜。
中间保留头部轮廓，剑阵轻微浮动，待命不播放长拖尾、不旋转成环。
发射先从侧翼沿身体轮廓外收至正前方，再先行一小段、沿弧线追踪目标。
飞行叠加青色渐细尾光、亮白芯和4道剑形残影，命中以短亮点与碎光收束。
命中消散后原槽位重新凝剑；重新凝剑属于同一个槽位，不是额外飞剑。
移动时槽位稍滞后跟随，不重新排序或穿过身体。静态角色图用于位置参照，不代表新增人物动作。

## 预演

`preview/yujian-twin-wings-v1-polished.mp4`：当前主审片，20秒，1280×720，30fps。
依次展示十剑悬停、单怪九剑待命、四目标分流、十剑出击、移动跟随。
`preview/rank-layouts-polished.png`：1/3/6/10级悬停排布比较。
`source/make_preview.py`：可复现运动、拖尾、残影及预演的源脚本。

运动由本地程序按目标位置绘制。动态寻敌不可烘焙成固定视频后作为实际战斗飞剑使用；
正式接入时应以战斗槽位、目标位置和碰撞事件驱动相同美术参数。
视频中的靶标与冲击是美术示意，未验证游戏伤害、障碍、敌人死亡换靶及学习消费。
