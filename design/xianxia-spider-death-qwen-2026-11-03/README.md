# 蜘蛛死亡动作：本地 Qwen 试制

## 范围

用户要求使用本地已部署 Qwen 尝试死亡动作，其他动作已接入。
本目录只存放独立试制与审核材料，不修改现有运行资源。
生成仅用本地模型，未调用 Scenario 或 Meowa 生成接口。

## 参考与动作要求

复用 2026-11-01 已验收的蜘蛛母图，原样复制到 source/reference-green.png。
现有动作资源为 spider-v1，低阶普通及精英适用，高阶蛛姬不适用。
当前形态没有 Boss 或狂暴配置。

死亡要求：足关节失力、胸腹落地、八足明显向内蜷缩，最终保持倒伏尸体；
不翻滚、不恢复站姿，不用缩小整张图、淡出或交叉溶解代替关节运动。
现有 Scenario 死亡失败版本及源视频不覆盖。

## 实验方法

1. 先生成最终倒伏姿态，检查动作语义、八足、身份和视角。
2. 末姿合格才继续补过渡姿态，再评估能否组成连续死亡序列。
3. 不把单张姿态图当作动画，不把逐帧独立生成默认当作连贯动作。
4. 原生输出 256×256；审核另看普通 77px、精英 86px 画布。
5. 绿幕抠图采用已有动作审核的同类算法；原始生成图完整保留。

## 当前状态

第一轮已完成，**死亡末姿未通过，未产出可用死亡动画、未接入游戏**。

- 实测：256×256、8 步、4bit，生成耗时 1028.3 秒（17 分 8 秒），
  日志报告 Peak MLX memory 17.86GB。
- 姿态失败：八足仍张开，未明显内收，没有明确倒伏。
- 身份失败：红色甲纹明显丢失，头胸腹外观与比例发生变化。
- 背景失败：纯绿背景出现横线、矩形和噪声；简单抠图后仍残留杂物。
- 边界 alpha 检查为零，但这不能覆盖上述视觉失败。
- 因末姿失败，不继续批量生成中间帧，不用插值、缩放或淡出伪造动画。
- 此结果只针对本机这一 checkpoint、量化、尺寸与步数组合，
  不能外推为所有 Qwen 版本或更高配置均无法完成任务。

参数与来源见 production.json，实际运行日志、提示词、原图及元数据存放在 generated/。
审核脚本 review.py 只输出本地 QA 文件，不写运行图集。
对照图 review/comparison.png 左为母图，右为本轮输出；下方为77px和86px实际画布预览。
全部输出均为未通过样本或审核材料，不属于运行素材交付。

## 工具与约束

沿用用户指定的 game-assets、scenario-game-assets 中素材契约、复用、
风格一致性与实际尺度验收要求；图像/视频生成服务调用由本地 Qwen 替代。
进一步参考 scenario-sprite-animation 的序列帧一致性与验收原则。
本地模型是 Qwen-Image-Edit 社区全量化版本，不是视频模型。
模型卡标注旧版 Edit，MFLUX 的默认模型别名运行标签为 2509；不标为 2511。
社区模型卡许可标注 other；本轮仅做本地试制，不直接发布为游戏素材。
