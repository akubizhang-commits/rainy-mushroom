# 月牙与十字剑气 · 本地素材接入

2026-10-30。月牙复用用户批准的飞行形态预演单体；十字将既有一线天刃光作为两条交叉线进行本地合成。本轮模型调用0、新增生成费用0 CU、上传0。

## 素材

- `sword-qi-crescent-v1.png`：160×512，与已批准的 `body-approved-frame006-rgba.png` 字节相同。以x=138为前缘，参考纵向跨度474。
- `sword-qi-cross-v1.png`：512×512，将 `sword-line-v1.png` 第0格沿两条对角线重采样合成；不改旧图集。参考线段从x=64至448，y=64至448，交会中心为(256,256)。
- 两资源均为真正RGBA、完整透明边界、固定前缘锚点；十字的大形态统一放大1.5倍，保留同样的一发。
- `source-and-runtime-contract.json` 记录原路径、原SHA-256、导出SHA-256、透明范围与锚点。旧源文件已重新校验，保持原字节。
- `prepare_sword_qi.py` 保存生成脚本快照；脚本遇到已有输出会拒绝覆盖，后续版本应另定路径。

## 渲染

`SwordQiArt` 根据真实投射物的位置、方向、宽度与结束时间绘制，不计算命中或改写战斗状态。主锋外加三层低亮短尾迹。碰到边界后的消散只读取战斗终止时刻；人物移动、镜头移动及暂停不会重新播放飞行。

近身十字同样使用一次整体X图。月牙近斩继续由既有 `SwordArcArt` 绘制。三发月牙只启动一次人物动作；后两发的通知不会让身体动作倒回出手帧。

节点按技能实例复用，最多24个活动绑定，结束后转入复用池。缺图、加载失败或超过容量时，只对未绘制的具体实例使用 `TowerSwordQi.swordQiSegments` 的程序轮廓回退，不退成小圆弹，不重复绘制已成功的图。

`renderer-tests.txt` 记录43项本地测试通过：包括两图的世界锚点、朝向、1.5倍大小变化、暂停／重建、结束消散、近斩与三发动作调度、资源404／尺寸错误、逐实例回退、池复用、资源释放，以及原月牙／一线天／天地一剑渲染回归。该文件只证明本地渲染测试，正式构建与实景验收由同轮集成记录提供。
