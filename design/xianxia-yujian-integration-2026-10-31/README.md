# 御剑术 v3 正式接入

已将批准的御剑术效果接入 Cocos：1–10级对应1–10柄真实飞剑；每柄锁定一个目标，空闲飞剑在肩膀外侧错落悬停。阵形以18秒周期平滑轮换，双翼只短暂出现，换位没有瞬移。

悬停剑尖跟随角色可见左右朝向，转身用0.32秒平滑转锋，快速反向从当前角度继续。飞剑先汇聚到角色正面，向前飞出后沿弧线追敌；已出击的剑不随人物转身。青色拖尾、白色内芯和4道残影均使用模拟时间，暂停时冻结；命中、丢失目标、触墙或寿命结束后消散0.25秒，不重复伤害。

凝神诀共6级：2级允许御剑术升至4–6级，4级允许7–9级，6级允许10级；原有境界门槛仍有效。每级凝神诀增加2%御剑术寻敌范围。不能通过退点使已学御剑术失去必要前置。主剑伤害保留，副剑按原总预算分配；2级第二柄飞剑新增0.3主剑预算。
