# 试玩页面卡在加载界面：排查记录（2026-11-14）

## 现象
用户本机的浏览器一直停在加载页，重启浏览器也无效。

## 已确认
- 构建产物完整：`index.html` 引用的 polyfills、system bundle、import-map 都存在（HTTP 200）。
- 无头浏览器下，新环境能正常进入主界面，无脚本报错、无资源 404。
- 带存档的情形也能进入游戏：
  - 版本 94 的旧档会被自动重置；
  - 第 1、3、6 层战斗中的存档刷新后显示战斗暂停界面（预期行为）。
  - 截图见 `load-saves.png`。
- 旧的本地服务器没有禁止缓存，已改为 `nocache_server.py`（只用于本机试玩，不影响游戏）。

## 未确认
- 用户本机卡住的具体原因。目前没有在同样条件下复现。
- 卡在加载流程的哪一步：HTML 启动遮罩、引擎资源加载、还是素材准备。

## 需要用户提供
1. 试玩地址：`http://localhost:8741/?smoke=1`（不读取真实存档）能否进入。
2. 浏览器类型与版本，以及地址栏的完整地址。
3. 开发者工具 Console 的红色报错内容。
4. 加载页进度文字（如有"正在准备画面 · x / y"）停在哪一步。

## 脚本
- `load-check.cjs`：新环境加载并记录控制台错误。
- `mksaves.mjs`：生成几种存档（新档、版本94旧档、战斗中存档）。
- `save-load.cjs`：用上面的存档分别加载游戏，检查启动遮罩是否移除。
- `nocache_server.py`：禁止缓存的静态服务器。
