# 缚剑煞灵素材

源：用户已有的 `绿色背景上的幽灵匕首怪物.png`，原图副本为 `source.png`，哈希及原尺寸见 `manifest.json`。未重新生成造型。

`prepare.py` 去除绿色背景，仅对半透明边缘进行背景颜色反混合，裁切后等比放入256×512单元。运行时图集 `cocos-pilot/assets/survivor/bound-sword-gnat.png` 为512×512：左侧原色，右侧同alpha的白色受击轮廓。图片meta使用独立UUID。

显示尺寸28×56世界单位，脸部主体作为逻辑圆心（原图640,700处）。原gnat碰撞半径10不变，柄、刃和尾部属于装饰延伸，不扩大攻击或接触判定。`scale-review.png` 为28/56/96像素高度的辨识对照，放大展示以便检查。

动画采用模拟时间驱动的微幅悬浮与倾摆，不拉伸躯体；这不是逐帧尾部动画或石傀儡步态。仅修仙模式替换gnat，含相同类型的首领召唤物。缺失/错误尺寸素材仍显示旧gnat。

本轮与“小游戏 - 技能优化”会话发生同目标并行，后者负责去重及统一运行时验证；本目录保留最终选用资产的源与复现脚本。游戏集成结果以项目交接及其运行时报告为准。
