# 十个技能的分级命中反馈优化

按 2026-10-31 用户确认的 review 建议，依次完成高优先级、持续技能与精修三批，并接入正式 Tower 战斗绘制。应用 game-feel：以真实正伤害事件驱动局部闪光、碎芒与受击形变，强度随技能分级，反馈自动消退，不将视觉反冲写入碰撞坐标。

## 每项完成内容

| 顺序 | 技能 | 本轮实际调整 |
|---|---|---|
| 1 | 御剑术 | 使用飞剑真实入射方向，短促白芯刺痕、碎芒、局部后仰；同目标密集命中合并 |
| 2 | 剑气斩 | 单向斜切痕、接触白芯及短促身体压缩/恢复，近身与飞行形态共用正伤害事件 |
| 3 | 纵横剑气 | 双向切痕，强度高于普通月牙；只响应真实结算，不新增第二次伤害 |
| 4 | 环剑诀 | 沿环绕切线的短弧与轻量反冲，不给常驻攻击添加震屏或全局顿帧 |

| 7 | 四象剑阵 | 继承落剑节拍，普通脉冲较轻、终击更重，终击局部反馈用金白色 |

## 共用约束

- 事件携带技能、目标ID、入射方向、段次及施放/投射物标识；只有实际正伤害产生反馈。
- 同一目标80ms内命中共用起始时刻，较强响应优先，避免每一把剑重置身体反冲。每帧最多24个目标显示增强反馈。
- 闪光核心约50ms，局部反馈110–180ms；无长期发白，无新增全屏闪光/镜头震动，不引入全局hit-stop。
- 通用小火花、旧无我/剑影前景效果对已被新版覆盖的事件不重复绘制；旧事件仍保留回退。
- Body renderer 每次绘制恢复基础位置/缩放，再附加本帧反馈。攻击状态、怪物AI、碰撞位置、伤害与技能主动画不被更改。
- 本轮完成视觉反馈优化，未增加音频系统或音效资产。
