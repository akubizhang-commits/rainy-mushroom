# 藏经阁 UI / UX 布局与交互评审稿

日期：2026-10-30。版本：v0.2。用途：本轮风格、布局与交互评审；不是已接入游戏的功能说明。

视觉纠偏：v0.1 两张视觉稿与游戏不符，已撤下其美术方向。当前原型使用主峰原画作明示代用背景，四入口仅定位；它不是已制作的藏经阁内景。场景、封面与自然展开书原画按修订后的 Prompt 制作后再验收。

上游方案：[藏经阁需求评审稿](../../docs/xianxia/2026-10-30-library-reading-review.md)。

## 1. 已确认方向与本轮边界

用户已确认：知识免费全量开放；知识使用书册、功法使用玉简；首期覆盖丹药、武器、装备；典籍只读，不在书页里服药、购买、穿戴或分解。

本轮交付固定视角馆内、分类目录、双页阅读三类界面的可点击评审原型与静态图片制作需求。原型使用代表性条目验证布局，不代表正式目录已经覆盖全部游戏数据；功法区域只演示入口，不执行加点、重修或存档操作。

正式开发仍需完整接入当前版本可获得的物品定义、现有功法系统及权限。本轮原型不得读写游戏存档。若记忆原型阅读位置，只能使用独立的原型偏好键。

设计依据是 game-ui-design 的场景化界面、渐进披露、安全区、清晰焦点与触控尺寸模式。当前产品仅横屏、以触控为主要使用场景；保留鼠标和键盘操作，暂不把手柄适配扩大为本期新增平台需求。

## 2. 三层界面

### A. 馆内：选书，不在这里读长文

画面采用木架、书卷、玉简和案台构成的固定视角内景。入口在同一视觉平面排布：

| 区域 | 入口 | 进入后 |
| --- | --- | --- |
| 左侧书架 | 丹药录 | 首次到丹药目录，以后恢复本册最后条目 |
| 中左书架 | 兵器谱 | 首次到兵器目录，以后恢复本册最后条目 |
| 中右书架 | 百器鉴 | 首次到防具/戒指目录，以后恢复本册最后条目 |
| 右侧玉简架 | 功法修习 | 正式版进入现有功法系统；本轮仅展示衔接说明 |

装饰书不做与入口相同的描边、标签或点击反馈。可交互书册必须具有常显书名，不要求玩家悬停才知道类别。

顶栏左侧为“返回主峰”与“藏经阁”标题组，右侧“典籍目录”。“典籍目录”始终能通过文字清单选择四本典籍，作为场景点击的等价操作路径。

底部可以保留一句操作提示，例如“选取典籍，查阅万物”，但不放资源余额、阅读完成度、连续签到或红点任务。

### B. 目录：快速定位

目录在当前场景或书页上方打开，背景压暗。目录打开时，背景控件不可点击、不可通过键盘聚焦。

目录结构从上到下：

1. 目录标题、关闭按钮。
2. 四本典籍的文字标签：丹药录、兵器谱、百器鉴、材料录。
3. 当前典籍章节。百器鉴包含“防具篇”“戒指篇”；其他典籍按实际条目分类，避免为少量数据创建空章。
4. 兵器/装备名称搜索框；只有两条的丹药录可省略搜索。
5. 条目列表：图标、名称、类别/品阶或用途；整行可点击。

目录只显示当前发布版本的可查条目。未拥有和境界不足不隐藏内容；境界要求在条目正文中解释。

行内不展示“已拥有/未拥有”、收藏、阅读打勾或概率推荐。不要将知识库视觉化成玩家背包。

### C. 双页：一个对开介绍一个物品

书本整体展开，左页负责“认识它”，右页负责“怎么用”。双页用纸张色与书脊形成物理书本感，文字由界面渲染，不能烘焙在图片里。

| 左页 | 右页 |
| --- | --- |
| 条目名 | 实际效果 / 属性范围 |
| 类别、品阶、用途 | 使用要求 / 生效条件 |
| 物品插画 | 适用场景 |
| 一句话定位 | 获取途径 |
| 简短背景小记 | 关键限制与注意事项 |

右页第一屏必须优先出现核心效果和限制。长背景故事不得把“只能非战斗使用”等关键信息挤到不可见处。

顶部固定：目录、当前书名/章节、合卷。底部固定：上一条、条目序号、下一条。序号显示“1 / 2”，含义是章节内条目，不是两张纸的物理页码。

装备存在品质差异时，可在右页提供明确标注的“品质”选择；下方标题必须注明“可出现的属性范围”。它只切换图鉴解释，不表示更换了玩家装备。原型可用代表性品质展示这一状态。

## 3. 布局与尺寸约束

以下为设计基准，不是将画面锁死在固定像素的位置。实现应以可用视口和设备安全区计算。

| 项目 | 1280×720参考 | 844×390参考 |
| --- | --- | --- |
| 外侧安全区 | 左右约32px，上下约20px | 左右至少16px，上下至少12px，并叠加设备安全区 |
| 顶栏 | 约52px | 48px |
| 阅读底栏 | 约52px | 48px |
| 双页比例 | 左右各50% | 保持双页，左右各50% |
| 正文 | 18px左右，行距约1.55 | 不低于16px，行距约1.45 |
| 次要辅助文字 | 不低于14px | 不低于14px |
| 按钮点击范围 | 推荐48px高 | 至少44×44px |
| 相邻点击范围间隔 | 8px以上 | 8px以上 |

在844×390上首先减少纸边、插画尺寸和空白；不会把1280版整体等比缩成小字。128px物品图标不进行大幅放大，详情大图仅在有高清源时使用。

页内正文允许独立纵向滚动。工具栏、翻页按钮和合卷按钮不可被滚走。滚动页尾未到达时显示细渐隐或“向下查看更多”提示，滚至末尾后去掉提示。

设备安全区保护的是按钮和正文；馆内背景可以铺满。装饰不参与点击命中，避免透明覆盖层拦截操作。

## 4. 状态与导航规则

| 当前状态 | 操作 | 结果 |
| --- | --- | --- |
| 馆内 | 点击书册，无阅读记忆 | 打开对应目录 |
| 馆内 | 点击书册，有有效记忆 | 恢复该册条目，页内滚动回顶部 |
| 馆内 | 点击典籍目录 | 打开三册总目录 |
| 目录 | 切换典籍/章节 | 更新列表并滚至顶部 |
| 目录 | 选择条目 | 关闭目录，进入双页，记录条目 |
| 目录 | 关闭/返回，有先前阅读页 | 回到原阅读页 |
| 目录 | 关闭/返回，无先前阅读页 | 回馆内 |
| 双页 | 点击目录 | 打开当前册、当前章节目录 |
| 双页 | 上一条/下一条 | 同章前后切换，两页正文滚至顶部 |
| 双页 | 合卷/返回 | 回馆内，保留该册最后条目 |
| 功法入口演示 | 返回 | 回馆内 |
| 馆内 | 返回主峰 | 原型给出衔接说明；正式版返回原主峰 |

每册记忆独立。记忆使用稳定条目标识；如果条目已移除，打开该册目录，不沿用旧序号。书页关闭不清空其他册的记忆。

同次访问目录时保留搜索词及筛选章节。离开馆内或刷新可清空搜索词；重新打开某本书仍可恢复条目。

## 5. 搜索、章节和边界

- 搜索目标仅为名称、类别，结果随输入更新。输入过程中不抢走输入框焦点。
- 搜索结果打开后，前后翻阅使用条目所在章节的完整序列，不使用筛选结果序列。
- 从条目返回目录，恢复本次搜索词和结果，便于继续查找。
- 搜索无结果：显示“没有找到相关条目”，保留搜索框和“清空搜索”按钮；不只显示空白。
- 空章节原则上不上线。原型若缺少示例，用“本原型未列出该类示例”解释，不能让用户以为游戏内没有内容。
- 第一条的上一条禁用，最后一条的下一条禁用；既不循环，也不悄悄跨章节。
- 禁用态同时使用低强调样式、不可执行状态和可读标签，不仅换颜色。
- 目录滚动位置可在本次打开中保留；改变章节或搜索词则重置到顶部。

## 6. 输入与反馈

触控：整本前景书册连同书名牌是同一个大点击区。翻页按钮为主，左右轻扫为辅；轻扫需明确水平位移大于垂直位移，纵向阅读滚动不触发翻页。

鼠标：书册、条目、按钮具有悬停反馈；不以悬停作为必经信息层。点击按钮后立刻给出按下反馈。

键盘：Tab/Shift+Tab按视觉顺序移动焦点，Enter/Space触发。阅读页左右方向键前后翻阅；搜索框聚焦时方向键只移动光标。Escape逐层关闭目录、合卷、离开入口说明，不穿透到背景。

目录打开后焦点进入目录；关闭后回到触发它的按钮。选择条目后将可访问焦点放到包含标题的左页阅读区，方便确认内容已变化。所有焦点必须用高对比边框或下划线表现，不能只变成另一种绿色。

翻页动效建议220ms以内，以纸面轻位移和书脊明暗变化表达切换；不需要真实3D翻卷。每次切换只处理一次导航，忙碌期间最多保留一次下一次输入，避免连点连续跨过多项。

减少动效模式下取消翻页位移，直接切换或短淡入；保留页面状态变化。原型支持系统减少动效设置，正式版沿用游戏对应偏好。

## 7. 美术与内容配合

以 `style-reference.html` 的项目实图为准：环境延续主峰与丹霞院落的高明度雾蓝、灰青空气感，木构与器物具有细致工笔、矿物水彩肌理和可信体积。不要将“国风”简化成暗绿大色块、几何书架或粗描边图标。

界面沿用 `TowerMenu.ts` 的配色：浅纸面 `#FBF9F1`、浅灰青 `#E5EBE1`、墨绿文字 `#263F39`、主操作 `#35685C`、细边框 `#BCC7B6`。标题、正文和操作文字采用现有无衬线字体；减少装饰字距、印章与不必要的金色。书页使用浅灰暖白纸、自然中缝与薄页厚度，文字区纹理低对比。当前程序容器只验证阅读层级，不能代替最终书页原画。

三册封面可分别以草叶、剑形、器物纹样区别；必须同时有文字标签，不以颜色作为唯一类别区分。封面标题、章节、页码、按钮标签均由运行时绘制。

书页底图只提供纸张、书脊、边缘厚度；不包含物品插图和任何正文。这保证新增条目、长文字和不同屏幕不会与底图冲突。

正式内容的名称、效果、品阶、使用要求应对齐玩法数据。世界观小记与数值效果分层呈现，不暗示尚未实现的配方、合成或交易能力。

## 8. 原型评审方式

评审可点击原型时建议依次完成：

1. 从馆内进入丹药录，找到回春丹的使用限制，再翻到培元丹。
2. 合卷后重新打开丹药录，确认恢复位置符合预期。
3. 进入百器鉴，切到戒指篇，搜索指定戒指，打开后翻阅，再返回目录。
4. 输入不存在的名称，体验无结果与清空搜索。
5. 只用键盘完成选书、选条目、翻页、合卷；确认焦点始终清楚。
6. 切到844×390，检查正文和按钮，尝试页内纵向滚动以及横向翻页。
7. 点击功法玉简入口，确认它和典籍阅览易于区分。

本轮优先确认：馆内入口是否一眼可发现；双页信息分工是否自然；小屏阅读是否舒适；目录与返回是否符合直觉。完整数据覆盖、正式存档、真实功法执行和设备性能属于批准布局后的开发验收。

## 9. 可验证标准

- 所有可交互控件的有效范围至少44×44px；正文不低于16px。
- 两个参考横屏尺寸没有书页外溢、按钮重叠或正文被固定栏遮挡。
- 目录与书页背景不能同时响应输入；焦点不会落进被遮挡内容。
- 首尾翻页、搜索空态、清空搜索、章节切换、位置恢复和逐层返回均有确定结果。
- 阅读原型不修改游戏角色、背包、资源、技能或任何正式存档。
- 画面提供书本感，但没有强制等待的开场动画、自动跳页或晃动文字。
- 缺少正式场景与封面时明确告知是结构占位；不把原型书架外观描述成最终美术。

后续评审通过后，再把本规范与确认的静态素材交付给正式游戏开发。

## 后续开发调整：无纵向滚动阅读

按用户最新要求，正式阅读页取消上下翻页栏，改为书页左右箭头；顶部仅保留书名、目录与合卷，底部为简洁序号。正文按横屏尺寸适度缩小。左页完整展示物品、定位与小记；右页长内容拆为连续书页，全部保留，通过左右箭头或方向键阅读，不再使用纵向滚动与渐隐提示。

翻页先遍历当前物品的内容页，再进入同章下一件物品；逆向进入前一件时显示其最后一页。底部同时显示物品序号及当前内容页数。品质切换回到第1页；从目录关闭返回时保留当前内容页。目录列表仍可纵向滚动。这一调整取代上文阅读页滚动和每个物品仅一个对开的约定。


## 材料录接入（2026-11-02）

材料录独立收录当前24种材料：炼丹材料9种、炼器材料13种、突破灵材2种；丹药录仅收录丹药。馆内新增材料录入口，目录支持名称／类别搜索与章节筛选，沿用现有高清材料图。

左页展示材料图和介绍，右页展示用途、使用条件、配方用量、掉落来源和出售价格。内容按书页左右翻阅，不需要纵向滚动。用途与用量从实际炼丹、炼器配方读取；铁精当前只作为可出售战利品介绍。

### 目录入口修正（2026-11-02）

从馆内选择典籍、从书页打开目录、在左栏切换典籍，均默认显示该卷全部条目并清空搜索；不自动按上次阅读条目的章节过滤。上次阅读标记仍保留，“返回书页”恢复原条目及页码。材料录显示“全部／突破灵材篇／炼丹材料篇／炼器材料篇”四个筛选按钮。搜索框仅保留框内一套深色输入文字与灰绿色提示文字。
