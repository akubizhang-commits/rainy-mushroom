# 藏经阁静态素材制作清单与详细 Prompt

版本：v0.2 · 2026-10-30。用途：依据现有《落云宗》美术修订的出图说明。本轮只修订提示词，没有生成或接入新图片。旧稿里泛称“玉青、深木色”的方向已收紧为项目实图所呈现的明亮雾蓝、灰青和浅纸色。

## 先给制图模型什么参考

| 参考图 | 使用范围 | 必须保留的视觉特征 |
| --- | --- | --- |

| [丹霞院落干净场景](references/danxia-courtyard.png) | 场景与全部物件；书页材质优先看它 | 灰白石材、灰褐木构、自然器物体积、轻柔日光；纸与布面的细腻肌理 |

**场景与物件优先附前两张干净背景图。第三张是 UI 规则参考，不是要临摹的画面：不能让模型把截图里的按钮、文字、装备、弹窗或状态画进新素材。** 每段 Prompt 已说明参考图用途；把对应文件作为图片参考上传，再复制文字。不要只输入“国风”“仙侠”“暗绿书房”等宽泛风格词。

## 修订后的视觉锚点

- 场景保持白昼下的高明度，灰白墙、灰青反射光和灰褐木架属于同一宗门建筑。允许局部木架阴影，不能整屋压成棕黑、墨绿。
- 书架和物件有可信的三维体积，轮廓细致、材质有矿物水彩的自然变化；不使用卡通大色块、扁平矢量或粗黑描边。
- 纸书采用浅灰暖白纸张、自然中缝和薄页厚度，封皮为灰青布料。不要黄褐羊皮纸、厚皮魔法书、金属护角或欧式符文。
- 文字、边框和交互由程序画：浅纸色与浅灰青底、墨绿无衬线字、克制圆角和边框。制图模型只提供材质与物件，不能决定排版或画文字。

## 分层、布局与复用约定

背景表现很多书，但只叠加三本功能书册和一套功法玉简。前景物件独立透明导出，四处落脚点以左上为原点，大致为`(20%,70%)`、`(42%,70%)`、`(64%,70%)`、`(85%,70%)`；围绕物件底部中心锚点摆放。书架背景预留空位，书名标签位于下方，由程序叠加。

书名、分类入口、目录、搜索框、上一条、下一条、合卷、章节书签、焦点框与禁用态由程序绘制，不另行生成。入口的图形与文字同时区分类别，不只用颜色。书册与玉简架属于导航前景，不套用128px物品图标98%规则；书页中复用的丹药、武器、装备图标仍遵守该规则。

场景以16:9母版制作；超宽横屏完整保留四处功能位，装饰区可受控延展，不能裁掉入口。三本书的原图占比、视角、装订和签条位置须一致。

双页底板2:1是绘制母版比例，不要求把所有屏幕的文字强塞进同比例框。接入时可从原图拆分左页、右页、中缝、页边；中缝与页边保持厚度，空白纸面延展，正文独立排版。若纹理拉伸可见，使用可选平铺纸纹。保留未切分原图。844×390小横屏先收缩装饰和插画面积，不能缩小或裁掉正文。

## 建议出图顺序

1. 先制作室内背景，和主峰、丹霞院落并排查看，确认像同一游戏、同一白昼宗门。
2. 制作丹药录书册；通过后把它也附作参考，制作另外两本，只变封皮配色和识别纹样。
3. 制作玉简架，检查放在背景展示位上时光照、木材和玉质是否一致。
4. 制作空白双页；叠加真实正文，与现有游戏UI并排看。纸纹仅在需要延展时制作。

## 验收重点

- **先验风格，再验尺寸**：与附带的两张干净场景并排比较明度、体积、笔触和材质。暗棕图书馆、暗绿矢量场景、卡通道具，即使构图正确也不能视为通过。
- 白底或棋盘格不等于透明；所有独立前景需检查Alpha，玉简间隙和架内空洞也应透明。书页内部为不透明浅纸色，书外透明。
- 四个展示位不被柱子、帘幕或强光遮挡；背景装饰不抢过入口，四个位置不呈现四格拼图感。
- 书册、玉简和页角保留完整轮廓及安全边缘；三本书视角和占比一致。没有文字、假字、印章、页码、水印或UI截图残留。
- 阅读底板保持自然纸页体积，但正文区不能有强纹理、深阴影或脏旧斑块。最终叠加16px及以上正文检查，而非只看空白图。
- 在844×390与1280×720叠加UI复验。缩小时轮廓可辨、文字清楚、点击区完整；点击和焦点反馈不烘焙进素材。

以下每段可独立复制，每次只出指定的一张素材，不生成拼板。

## 5. 功法玉简架前景

