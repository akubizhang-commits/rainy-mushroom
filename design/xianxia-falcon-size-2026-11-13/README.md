# 低阶妖隼飞行和悬停时体型不一致（2026-11-13）

## 原因
- 悬停和放羽刃（射击）的前摇阶段显示的是立绘 `tower-monsters/falcon.png`，主体翼展占画布宽度的 91.8%。
- 飞行（move）和扑咬（bite）用的是动作图集 `falcon-v1`，最大翼展只占格子宽度的 63%。原来 move 帧不缩放，bite 帧只有补画布用的 1.0729。
- 两者按同一个体型尺寸绘制，所以飞行时看起来只有悬停时的三分之二左右。

## 修改
- 只改 `falcon-v1.json`：所有帧的 `displayScale` 乘以 1.4566（立绘翼展 ÷ 飞行最大翼展）。move 帧变为 1.4566，bite 帧变为 1.5628（1.0729 × 1.4566）。贴图本身没有动，锚点和脚底位置也不变。改前文件是 `falcon-v1.before.json`，系数记录在 `scale.json`。
- 动画测试里扑咬帧的尺寸断言从 275×1.0729 改为 275×1.5628；“标签高度不跳”的断言照样通过。

## 验证
- 怪物动画相关测试 102/102 通过，web-mobile 构建成功。
- `shot.cjs` 在真实构建里并排放了两只低阶妖隼：一只在飞（move-010），一只在放羽刃前摇（显示立绘）。截图 `after-full.png`、`after-zoom.png` 里两只的体型已经相近。`compare.png` 是立绘和飞行帧在 1.0/1.3/1.45/1.6 倍下的对比。

## 说明
- 隼妖精英（falcon-humanoid）是另一套美术，不受影响。
- 低阶妖蝠（bat）也有类似差距（立绘翼展 0.918，飞行帧 0.51–0.92），但飞行帧最宽时已经接近立绘，这次没有改。
