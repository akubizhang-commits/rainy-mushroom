# 两仪剑阵：黑白云气阵面

2026-11-02，用户要求参照黑白阴阳图替换两仪原青蓝阵面。用户补正上方白色鱼眼后，助手验收母图并按既定授权接入；最终游戏观感等待用户查看。

## 实现

- `source/approved.png` 是用户修正原图；初版双黑眼图及两张参考图一并保留。
- 本地解算绿幕 alpha、去绿溢色并转为中性黑白灰；原始尺寸透明图保存在 `source/approved-transparent.png`。`prepare.py` 记录可复现处理。
- 运行图 `tower-skill-fx/liangyi-monochrome-v1.png` 为512×512。阵面使用正常透明混合，基础透明度68%，脉冲最高76%，保留黑鱼而非加色抹掉黑色。
- 运行时以4秒周期、小于约1.4纹理像素的横向条带位移表现轻微云纹流动；鱼眼附近衰减位移，整体轮廓不旋转。不是新生成的视频，也不是流体模拟。
- 阵眼标记移至原图鱼眼位置，随原有真实脉冲交替亮起。中性银灰取代阵面蓝线和金色合鸣；双剑及落剑素材、动作继续沿用。
- 两仪范围、伤害、次数、冷却不变。四象使用原有独立绘制器及旧素材。
- `before/` 保存修改前源码，`integration/` 保存本次接入源码及运行图。未覆盖或删除旧阵图。
