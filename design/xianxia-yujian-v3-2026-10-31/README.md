# 御剑术 v3 · 随身转锋

本版按用户要求将待命剑尖改为与角色朝向一致，并补齐转身与连续反向预演。
主审片 `preview/yujian-facing-turn-v3.mp4`：30秒，1280×720，30fps。尚未接入游戏。

## 朝向与转身

- 待命时所有剑尖严格同向：人物向右，剑尖向右；人物向左，剑尖向左。排布仍错落轮换，不再用倾角打破同向。
- 角色转身后，飞剑原位用0.32秒沿最短角度平滑转锋，转完严格对齐；这0.32秒是有意保留的转身过渡。
- 肩外悬停位置继续原来的连续换位，不整组镜像，不穿过人物去交换左右槽位。
- 连续快速反向从已经转到的角度重新求最短转角，不从0度或180度重新开始。
- 同一组待命剑共享朝向，不在转身时逐柄延迟。原有0.1秒错峰仅用于位置轮换。
- 出击时冻结这柄剑的发射朝向，先经过当时人物的正面，再弧线追敌。人物随后转身，不扭转已出击剑的轨迹。
- 命中后原槽位重新凝剑，按当下人物朝向待命。

当前角色渲染仅有左右朝向：`TowerCharacterArt.ts` 中攻击动作使用锁定的 `attack.face`，
普通动作使用 `player.faceX`。正式接入应跟随该可见朝向，而不是另算一个摇杆方向；
松开摇杆保持最后朝向。未来如引入多方向人物动作，可沿用最短角度转向，但不属于本轮。
本片左右人物使用既有立绘镜像，仅示意左右朝向，未生成新的转身人物动作。

## 看点

0–5秒向右待命；5秒向左转；9秒转回右；
12–13.5秒快速连续反向；
18.5秒向右出剑，18.95秒人物转左，已出击剑继续向原目标；
22.5秒向左出剑，23秒人物转右，已出击剑继续向左；
最后展示移动跟随与左右转身。

`preview/facing-layouts.png` 是向右、向左、转身中及快速反向中的静态比较。
剑体、拖尾、白芯、残影和命中碎光复用v2，侧向发射通过冻结方向支持左右两边。
