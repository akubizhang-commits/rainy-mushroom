## 短基准的含义

短基准默认 320×320、17 帧 latent、40 步时间表中的**第 1 个采样步**，CFG 3.5、shift 5、Euler/simple、seed 20261103。仅使用高噪声专家执行一步；低噪声专家先做文件完整性验证。不会对未完整去噪的 latent 解码或把它包装为动画。

它验证模型加载、图像条件传递、一次采样计算、数值有限性和耗时/内存，**不验证死亡动作、完整双专家切换或模型最终画质**。320px 短基准耗时不能直接线性外推完整 624px/81 帧试片。完整试片须另行决定。

预处理与采样分进程，CPU 路径；服务只监听 `127.0.0.1:8192`，使用独立数据库，禁用付费 API 节点。每阶段默认 600 秒上限，14GiB 进程 RSS 保护，系统交换空间较阶段开始增加超过 4GiB 也停止。只停止本脚本启动的服务，不提高系统/GPU 内存上限，不自动重试采样。
