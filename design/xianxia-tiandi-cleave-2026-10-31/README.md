# 天地一剑 · 凝聚巨剑、由上重劈

按2026-10-31用户要求制作。复用现有青白实体飞剑与天地一剑剑气图集，不发起新生成。此轮效果已在本地运行时代码实现并录制，视觉满意度待用户查看。

## 动作与尺寸

支点位于角色胸前沿释放方向32游戏单位（短距离裁断时收敛至距离的15%）。胸高来自角色腰部锚点上移18单位，缺少角色素材时回退70单位。蓄势阶段遵循原有目标锁定；释放后支点固定。

巨剑在蓄势前0.18秒显形，最后0.14秒加速由上往下劈落。用垂直挥劈平面的投影表达举剑时的透视缩短：举起时的投影高度上限240单位，落下后剑尖精确对齐实际伤害终点；最大可见宽度按实际命中宽度80/112单位映射。遇柱体或边界时采用实际裁短终点。

蓄势和释放共用一把剑；不存在第二把重播。原下方宽锋剑气的图集与0.75秒尾光保持不变。

## 打击反馈

- 落地姿势保持0.07秒后消散，表现短促的视觉停顿。
- 地面出现短闪、向两侧扩散的冲击线；真实正伤害追加碎芒。
- 真实正伤害触发一次0.14秒衰减震屏，最大横向3、纵向6单位。只偏移画面，HUD、输入、碰撞、伤害和战斗时间均不修改。
- 落空不会触发命中震屏；反馈在暂停中固定，退出时清理。
