# 惊鸿剑特效重做（2026-11-09）

用户要求：
- 剑改成外形好看但不复杂的重剑。
- 重剑显形后先停顿，让玩家看清。
- 显形方位随机，不总在怪物头顶。
- 重剑穿过身体后立即消失，留下一道明显、锐利的剑痕，剑痕稍后再消散。

## 剑体
复用已验收的断流剑手持图 `tower-held-weapons-v2/eq_sword_duanliu.png`：宽剑身、弯护手、深色缠柄。`prepare.py` 只把它裁成透明运行图 `tower-skill-fx/jinghong-sword-v1.png`（691×154），没有改动原图，也没有生成费用。显示长度为 176px。候选对比图在 `../xianxia-hit-feel-2026-11-09/sword-candidates.png` 和 `heavy-candidates.png`。

## 时序（`js/xianxia/TowerJinghong.js`，战斗和画面共用）

| 阶段 | 时长 | 表现 |
|---|---|---|
| 显形 | 0.12 秒内 | 白色闪光，剑体带轻微回弹（ease-out-back）放大到位，同时出现一条淡淡的瞄准线 |
| 停顿 | 0.35 秒 | 重剑静止，指向目标 |
| 刺入 | 0.08 秒 | 冲向目标，带速度残影；**冲过身体中心的瞬间结算伤害** |
| 穿出 | 0.04 秒 | 穿到另一侧后立即消失 |
| 剑痕 | 0.6 秒 | 沿整条穿刺路径留下两端尖、中间宽的剑痕，由青色外光、亮边和白芯三层组成；前 0.15 秒保持满亮度，之后渐隐 |

- 首刺从 0.18 秒推迟到 0.43 秒，因为要先看到剑显形和停顿。后面每 0.22 秒刺一次，所以停顿期间画面上会同时出现两三把剑。总伤害、冷却时间、刺数都没变。
- 显形方位由施放 ID 和第几刺决定，看起来随机，但同一刺在快照恢复或暂停重绘时位置不变。相邻两刺至少相隔约 70°。施法者一侧 ±55° 的范围不会出剑，避免挡住人物。
- 命中反馈和镜头震动的方向取自真实的穿刺方向。
