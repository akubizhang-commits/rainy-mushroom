# 金白多形连斩 · 动态预演

用户要求依照所提供的连斩GIF继续制作看效果。本次仅制作动画预演，未修改游戏代码、资源引用、伤害次数或碰撞。

当前推荐查看 `attempt-02/gold-multislash-normal.mp4`（1280×720、60fps、4.5秒，原速循环三遍）及 `attempt-02/gold-multislash-half-speed.mp4`（放大黑底半速，约6秒）。游戏背景和角色为静帧，剑气为本地合成动画，片内已明确标注，不能当作实机录像。

## 动作

三道独立轮廓依次出现：长斜斩、较扁横扫、较高上挑。使用不同贝塞尔轮廓与不同刃腹厚度，不是旋转同一张贴图。沿弧线快速显形，小幅向前推出，后道出现时前道留少量余光。最后整体柔和淡出，始终保留开口。

每个循环1.5秒，三道起始时刻为0.25、0.37、0.49秒，每道持续0.31秒。这是本次预演拟定的节奏，不是对参考游戏实际帧数据的还原，也未改变现行游戏的三连间隔。
