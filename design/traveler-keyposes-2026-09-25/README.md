# 雨后旅人：站姿与四种步态关键姿势

2026-09-25。交付阶段：静态姿势审阅，等待用户确认画面。

## 查看

- `index.html`：五张图同屏、森林/浅色背景、单张大图和缩小轮廓。
- `comparison.png`：2000×1040总对照板。
- `poses/`：5张640×850透明PNG；共同地面Y=795。
- `traveler-keyposes.zip`：五张透明PNG与对照板。

姿势顺序为：站立、前脚接触、承重下沉、经过支撑脚、后脚蹬离。这是步态中的四个姿势节点，尚未包含对侧半循环和过渡帧，不能直接当作完整走路动画循环播放。

## 画面来源与编辑方式

使用项目中已有的用户参考原稿：

- `../traveler-reference-vector-2026-09-24/work/run.png`：统一帽脸、上衣、雨披与腿部绘画质感。
- `../traveler-reference-vector-2026-09-24/work/side.png`：完整的放松手臂、手掌与鞋。

本轮是原稿分层编辑：保留原有绘画像素，单独摆放手臂和鞋、调整腿部关节，修补移开原手臂后露出的衣料。工作文件为 `layers/`、`build_keyposes.py`、`landmarks.json`。JSON记录初始姿势控制点；实际支撑鞋高度由生成器按透明轮廓校准。没有调用ComfyUI或其他图像生成服务，没有重跑上一轮AnimateDiff配方。

实际制作中修正了衣料被手臂裁切、膝盖变形残片、手指在变形中拉伸、裤脚与大腿连接、遮挡层次等问题。完整手掌采用原稿刚性摆放，腿部沿连续中心线变形，鞋按各自支撑状态落到共同地面。全部原文件保持不变，游戏图集未修改。

## 本轮审阅范围

先判断五张静态姿势的角色一致性、朝向、轮廓和承重关系。帽脸与衣服沿用同一来源，人体朝向右侧；承重姿势降低髋部，经过姿势使摆动脚离地，蹬离抬起后脚跟。

保留的限制：雨披仍沿用迈步参考中的展开形状；近侧手臂在部分姿势被前襟遮挡。它们需要结合用户对画面的反馈再定，尚未验证连续动画的衣料跟随或步幅。当前不是Spine工程，也不声称完整循环或游戏动作已经验收。
