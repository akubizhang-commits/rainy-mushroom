# 震岳犀王 · 常态母图 prompt

为中国仙侠俯视动作游戏绘制一只“震岳犀王”的完整角色母图，单只犀牛妖兽，常态警戒站姿，用于后续行走、冲锋和重踏动画。

外形首先是一只厚重有力的犀牛：宽厚桶状躯干，高大隆起的肩背，短粗脖颈，宽钝吻部，四条短而粗壮的承重腿，短尾。鼻梁前方一根粗壮主角，根部厚、尖端略向上；后方一根明显较小的副角，两角前后排列，不长在额头两侧。两只小耳朵自然竖起。不要画成野猪、牛、恐龙或龙。

妖化风格克制：低饱和岩灰和深褐皮肤，肩背有少量与皮肤自然融合的厚实岩甲，形成几块清楚的大形；甲缝少量暗朱红纹路，眼睛为克制的暗红小亮点。保留犀牛皮肤褶皱和关节活动空间，不用密集尖刺覆盖全身。不穿人形盔甲，不添加鞍具、锁链、武器、翅膀或额外肢体。

高位三分之四俯视、近似正交视角，头朝画面左下，身体延伸至右上。镜头能展示主角、厚重肩背与腿部连接。四腿自然支撑，前后腿略微错开，尽量露出远侧脚掌；允许合理透视遮挡，不能出现肢体融合或腿根错位，不为展示四腿而扭曲身体。蹄趾短钝，不是猫科尖爪。

头部略低，主角朝前，保持静止警戒姿态；不奔跑、不冲撞、不抬腿重踏、不张大嘴。四足落在同一地面，腹部与地面留出合理间隙。完整保留角尖、耳尖、脚掌和短尾。

半写实手绘游戏美术，清晰轮廓，厚重体积，简洁的大块明暗与适量材质细节；缩小后仍能一眼识别犀角、肩背和四足。不要Q版、大头萌化、照片或塑料玩具质感。

输出1024×1024或更高分辨率PNG，单只、单姿势、单视图。完整主体最长边占画布约75%至78%，四周至少10%留白。背景完全均匀的纯鲜绿#00FF00，主体不含鲜绿色；柔和均匀照明。

不要地面、投影、石块、机关柱、烟尘、碎石、冲击波、光环、发光描边、运动模糊、文字、水印、边框或多视图。所有技能特效与场景物件都不画进这张身体母图。
