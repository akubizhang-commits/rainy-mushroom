# 剑气爆裂 · 四次命中重做版

2026-10-31。用户批准从技能设定重做，替代成长模式的「剑意余震」，本版本为待视觉审核原型。旧余震和原始素材全部保留。

## 机制

- 保留技能ID sj_gate，名称改为「剑气爆裂」。同一敌人累计4次不同的直接攻击，触发四剑内刺，再于0.06秒后爆裂。
- 同一攻击对同目标最多叠一层；判定使用攻击/弹体ID，并保存8秒去重记录。4秒没有新命中，未满层剑气清空。
- 每目标伤害为攻击力×50%/70%/90%/120%，半径80/90/100/110，含主目标最多6个目标。不暴击、不再叠层，不复制持续伤害或其他伤害预算。
- 第四击杀死敌人也会从其位置爆裂；独立待爆队列可存读档，结算后立即出队。当前数值是原型起点，尚未进行全流派最终平衡调优。

## 动画与打击感

前三击依次点亮朝内的青白短剑；三层显示短电弧。第四击四剑内刺，随后白金星形爆心、破碎冲击环和12枚碎刃向外炸散，0.42秒消散。爆心按目标体型高度定位。

真实正伤害通过共享命中系统产生身体顿挫，近处有0.16秒衰减震屏；不暂停战斗模拟。爆裂声音包含金属瞬态与低频冲击，限频播放，暂停/退场停止。音效由prepare-audio.py确定性生成，并非付费生成。

复用已批准的tiandi-solid-sword-v2.png，附加光刃和爆心使用现有Graphics。Scenario生成0、上传0、费用0。before/保存改动前的战斗、技能表、说明与渲染源码。
