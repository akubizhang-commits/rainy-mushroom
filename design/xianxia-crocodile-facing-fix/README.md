# 鳄鱼朝向试修与怪物方向审计

## 修改

- 鳄鱼原近正面图头朝下，渲染器将它与妖蛛一起固定为 scaleX=1，因此玩家位于其上方时会看到尾部朝向玩家。
- 复用 `design/xianxia-monster-demonic-2026-10-28/crocodile-demonic.png` 的侧向外形。`scripts/art/prepare-tower-crocodile.py` 从原生512px图本地抠图，放入512px透明画布，没有使用256px旧图放大。最长边470px仅作为怪物留白选择，不套用物品图标98%规则。
- 近正面运行图保存在 `crocodile-front-before.png`；原母图、付费源文件和旧版本均保留。没有使用Scenario额度。
- 取消鳄鱼固定朝向，源图朝左，向右时镜像。脚底参考点为画布高度0.84，保持原有普通、精英和Boss体型计算。
- 所有静态怪物现在与动画怪物一样读取当前普通攻击的方向；攻击期间不因位移/玩家绕背改朝向，回到approach后忽略旧攻击方向。
- 没有改变攻击几何、机制、伤害、数值、掉落或存档。

这是侧向素材的试修，不是完整多方向素材交付。正上方/正下方目标仍由两向画面近似表示；没有通过旋转图片制造倒挂效果。旧图的纸底抠图仍有少量浅色边缘与腹下阴影，不能宣称美术最终验收。

## 其他怪物检查

审计依据：当前全部19张运行PNG（`monster-directions.png`）、`TowerMonsterArt`资源选择/翻转逻辑及已接入的妖猪/妖狼动画配置。以下是素材与代码审计，不代表19种怪物均已完成实战验收。

|运行资源|发现|
|---|---|
|crocodile|本次修正固定朝向，替换为侧向图；仍只有左右两向|
|spider|确认同类问题：近正面素材且代码固定朝向；需要匹配侧向或多方向素材。旧棕色蜘蛛参考与当前红黑妖蛛外形不同，本次未擅自替换|
|rhino、yak、tiger-humanoid、white-tiger|正面/近正面站姿；镜像能改变少量细节，不能表现可靠的转身，列为方向素材缺口|
|spider-lady、spider-queen、snake-lady|正面/近正面人物；存在相同的方向表现限制。spider-queen是预留资源，不等于当前关卡投放|
|ape|近正面偏左，侧向辨识较弱，后续需要实战视觉复核|
|boar、wolf|侧向动画与源朝向约定相符，没有发现固定朝向分支；仍是两向动画|
|bear、tiger、snake、scorpion、centipede、bat、falcon|当前源图可辨识偏左方向，走通左右镜像分支，没有发现鳄鱼式固定朝向；静态攻击方向读取缺口已统一修正|

以上所有单套侧向图/动画都不能提供真正的朝上/朝下视角，不应把左右镜像测试通过写成完整方向验收。
