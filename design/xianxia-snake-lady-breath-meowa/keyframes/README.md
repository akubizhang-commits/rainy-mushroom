## 使用方法

两次分别上传同一张已验收母图 `design/xianxia-snake-lady-2026-11-01/reference-alpha.png`，各使用下面一条完整提示词。不要把第一张生成结果作为第二张唯一参考，避免累积身份偏移。

每次只输出一张1024×1024全身PNG，角色位置、大小、尾部落地点与原参考一致。优先透明背景；工具不能输出透明时使用纯色背景，后续本地处理。不要拼成左右对照图，不要把头部单独裁成新画布。原母图直接作为闭嘴待机及收招参考，无须重画第三张。

## 收图后验收

- 对照原图检查脸型、发髻、头饰及身体；尾部不因全画布镜像而换边。局部遮挡不自动判废。
- 1024px原尺寸逐张检查轮廓，再等比缩至220px画布做离线对照；必须看得出两个相反朝向及嘴部开合。不能把放大截图当作小尺寸可读性证据。
- 检查透明边缘、头顶和尾尖裁切。位置或背景问题先本地整理，只有无法修复的形体问题才重画。
- 两张均合格后再选择关键帧动画参数，提交前重新读取额度；本包不承诺之前记录的20积分足够，也不创建自动付费脚本。

## 接入约束

当前 `js/xianxia/TowerMonsterMechanics.js` 中 M16 主动吐息持续3秒，判定朝向在此期间扫过 `sweepHeading ± 0.35π`；动画应跟随现有阶段，不能按旧草案另改战斗时序。画面左右关键帧仅定义美术姿态，不等于世界空间判定角度。

`TowerMonsterArt.ts` 当前 snake-lady 的口部挂点是静态UV `[0.426, 0.258]`。未来接入转头帧必须同时标记逐帧口部挂点，并验证吐息连在移动的嘴上，不能直接沿用静态挂点宣称完成。
