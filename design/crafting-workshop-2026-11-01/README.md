# 丹房与器坊交互设计稿

2026-11-01。配套设计：`docs/superpowers/specs/2026-11-01-crafting-workshop-ui-design.md`。

打开 `index.html`，体验领域与用途分类、配方网格、材料来源、数量／费用联动、模拟制作和背包。也可从项目根目录启动本地HTTP服务后访问本目录。无需安装依赖，不访问外部服务。

这是独立设计稿，未接入Cocos正式界面，也不读写游戏存档。配方数据来自当前13张丹方和141条装备品质配方；模拟库存和钱包刷新即复原。境界、服用额度、背包容量、失败重试等正式规则以设计文档为准，原型未完整模拟。导航返回院落及材料来源只展示交互说明，不切换真实游戏页面。

用户已确认保留宣纸、青玉风格。当前推荐布局为：左侧领域／用途，中间图录与筛选，右侧成品与材料，右底固定数量、费用和唯一提交按钮。

## 已检查

- 1280×720与844×390：无横向溢出，底部提交按钮可见；正文独立滚动。
- 13张丹方、器坊下品47张配方可选择；购买筛选为23张可购买下品配方，隐藏材料区。
- 回春丹模拟制作2炉：贡献300→296，产出2颗；保存中点击领域和数量不改变已提交请求。
- 仅可制作筛选中耗尽资源后保留原配方；更改筛选后按新条件更新。
- 筑基筛选保留疗伤丹、筑基修为丹、以筑基为目标的突破丹。
- 材料来源面板返回后仍选中原配方。
- 已显示图片均成功加载；缺少资源明确使用文字占位。
- 独立设计审阅完成，无必须补问用户的设计缺口。

原型未验收项目：真实微信设备、手柄、生产事务、全部容量／额度边界、窄于三栏最小宽度时的分类弹出式布局。当前用于比较和确认流程，不代表已完成生产开发。

## 美术接入

未调用Scenario或Meowa付费服务。现有图标只引用，不改原图；按钮、纸底、青玉选中态和边框由CSS绘制。正式Cocos实现可使用Graphics与现有图片缓存重现。

尚缺静态图的配方使用文字占位；没有把其他游戏截图当素材。六种关键材料可在方向确认后补图：灵玉、铁精、寒晶砂、赤铜精、紫晶髓、凝灵晶。每张独立透明PNG，建议512×512母图，单物体居中，保留完整轮廓，无文字、边框、背景与烘焙光圈。风格参照项目已验收的玄铁和灵木图标，柔和手绘、左上光、低饱和青玉与矿物色。
