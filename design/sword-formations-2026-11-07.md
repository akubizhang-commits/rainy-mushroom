# 周天剑阵迁移与青莲剑阵：设计与验收文档（2026-11-07）

范围：仙侠锁妖塔（sect-tower-v1）。周天剑阵（sj_wanjian）从炼气巅峰迁到炼气中期。新增青莲剑阵（sj_qinglian），放在炼气巅峰。两者都属于剑阵流派，使炼气境界的每个大阶段各有两个剑阵技能。

## 1. 已确认决定

以下内容为用户原文，逐条照录。

1. 周天剑阵（技能 ID sj_wanjian，当前在“炼气巅峰”阶段，解锁 7 级）迁移到“炼气中期”（4 级解锁）。数值与机制不变（冷却 6 秒、持续 4 秒、剑数 4–8、0.6 秒同目标间隔）。
2. 新增“青莲剑阵”（建议技能 ID sj_qinglian，名称“青莲剑阵”），放在“炼气巅峰”（7 级）。它是主动技能，属于剑阵流派，与周天剑阵一起构成炼气境界的两个剑阵。
3. 青莲剑阵数值（已确认）：冷却 9 秒；法力 8；判定为三层环，内 4 剑、中 6 剑、外 8 剑，共用 0.5 秒同目标间隔；伤害分配内 20%、中 35%、外 45%，整招预算不随层数增加；作用范围内 0.6m、中 1.2m、外 2.0m，换算像素约 90、150、200；目标上限 6；时长起阵 0.3 秒、成阵 0.5 秒、爆发 0.8–1.2 秒、收势 0.4 秒。
4. 视觉瓣数按 8/12/16 绘制（内/中/外），只有判定剑参与伤害，外层透明度低于内层。接受 8–16 瓣的视觉密度。
5. 青莲剑阵的视觉语义：剑气先凝成莲瓣形光刃，再层层展开。瓣是半透明剑刃，有锋利边缘和金属冷光，不是柔软花瓣。主色青白、淡青、银青，中心月白微光，避免高饱和荧光绿。三阶段：起阵、成阵、发阵。不要加水波、荷叶、露珠等水系元素，不要复杂法阵纹样。割草场景要保证角色清晰可见。

其他已记录的决定（来源：既有文档 `design/sect-tower-sword-formations-2026-11-07.md` 第 6 节，以及实现记录）：
- 伤害系数采用 `damageCurve(8, 1.15)`，阶 1 为 8，阶 10 约 28.1。
- 平衡验证按 8 层 × 3 流派执行，并注明对比局限。
- 青莲剑阵不减速敌人。

实现时的选择（用户未指定具体数值）：
- 爆发阶段取 1 秒，落在用户给出的 0.8–1.2 秒之间。
- 蜘蛛死亡姿势保持 1.5 秒（见第 9 节）。

## 3. 青莲剑阵设计

### 3.1 数值

| 项 | 数值 |
| --- | --- |
| 技能 ID / 流派 | sj_qinglian / 剑阵，主动 |
| 解锁 | 炼气巅峰，7 级 |
| 冷却 / 法力 | 9 秒 / 8 |
| 判定层 | 内 4 剑、中 6 剑、外 8 剑（三层环） |
| 作用半径 | 内 90 像素（约 0.6m）、中 150 像素（约 1.2m）、外 200 像素（约 2.0m） |
| 伤害份额 | 内 20%、中 35%、外 45%，整招预算不随层数增加 |
| 同目标间隔 | 0.5 秒 |
| 目标上限 | 6 |
| 时长 | 起阵 0.3 秒、成阵 0.5 秒、爆发 1 秒、收势 0.4 秒 |
| 视觉瓣数 | 内 8、中 12、外 16；判定剑只在判定层参与伤害 |
| 外层透明度 | 内 0.80、中 0.70、外 0.60 |
| 减速 | 无 |

### 3.2 判断

- 三层环的判定剑数量（4/6/8）与视觉瓣数（8/12/16）不同。视觉上每片瓣都是一柄剑，但只有判定剑会造成伤害。这样做是为了让画面密度与判定分开：视觉更密，判定量仍由表中的剑数控制。
- 整招伤害预算固定。层数增加只改变分配，不增加总伤害。
- 不减速：减速会改变割草节奏，本次决定不加入。
- 0.5 秒间隔与周天剑阵的 0.6 秒接近，使两个剑阵在同一炼气境界内有相近的判定节奏。

### 3.3 视觉语义

- 莲瓣是半透明剑刃，前端收尖，两侧有轻微弧刃和细窄高光。
- 主色青白、淡青、银青；中心月白微光。避免高饱和荧光绿。
- 不加水波、荷叶、露珠等水系元素，不加复杂法阵纹样。中心只保留一枚简洁的剑印或莲心光点。
- 割草场景中特效数量需受控，保证角色清晰可见。

### 3.4 阶段

1. **起阵（0.3 秒）**：角色脚下或目标位置出现淡青色剑痕，呈圆形扩散。剑痕上浮起莲瓣轮廓，中心出现阵眼光点。此阶段尚未判定。
2. **成阵（0.5 秒）**：内、中、外三层依次展开，层与层之间错开角度形成旋转感。内层快、外层慢。
3. **发阵（约 1 秒）**：环形判定，判定脉冲按 0.5 秒间隔进行，每次脉冲按层分配伤害。
4. **收势（0.4 秒）**：莲瓣变淡，化为细碎剑光回到阵眼，地面留下短暂剑痕。
