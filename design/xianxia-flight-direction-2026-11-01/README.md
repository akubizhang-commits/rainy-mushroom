# 御剑飞行 · 方向统一与流光波动

用户指出固定左侧发射点无法区分向左飞行时的剑首剑尾，上下飞行视觉不佳；随后指出原尾流只有亮度变化、缺少流动。此版本合并处理两项反馈，保留所有原图与前两版实现。

## 实现

- 剑身与尾流共用模拟时间驱动的方向，剑尖始终领先、剑柄始终在后；新增明确剑尖、护手、柄和尾饰。
- 剑尾位置随剑身共同旋转，取消固定左侧发射点。投影纵向压缩为0.42，上下飞行不再带长达两百像素的竖直尾流；横向宽度单独补偿，保留流光层次。
- 复用原图本地生成 `flight-stream-v2.png`，32帧、1.6秒循环。对光带进行空间波动变形，向尾端逐渐增大，亮头固定；叠加沿尾流传播的亮度波。旧版图集保留。不是调用模型生成的视频。
- 角色本体仍采用既有角色素材和站姿；本次调整飞剑及尾流，不制作新角色方向动作。

## 验证记录

- `tests.log`：暂停、死亡、状态替换、移动/收尾、四方向及斜向的剑尖领先与剑尾落后约束。
- `animation-check.json`：固定列光带重心在帧间变化超过32像素，确认空间位置在动；图集每帧画布边缘全透明。
- `browser-thin-attempt` 保留首次实机版本，发现透视缩放令左右尾流偏细，随后补偿宽度。
- `browser` 为最终双横屏四方向实机验证；`build-final.log` 为最终构建日志。
