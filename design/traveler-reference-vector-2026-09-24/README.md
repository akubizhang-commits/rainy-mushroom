# 雨后旅人：参考稿矢量重建

2026-09-24。用户提供两张造型/动作参考，明确要求用代码/工具按参考重画矢量版。本轮交付参考图的彩色轮廓描摹重建，不沿用被否定的旧几何人物。

## 已交付

- `svg/front.svg`：正面。
- `svg/three-quarter.svg`：三分之四。
- `svg/side.svg`：侧面。
- `svg/run.svg`：奔跑关键姿势。
- `svg/crawl.svg`：手掌与膝盖支撑、上身离地的侧向爬行。
- `svg/takeoff.svg`、`airborne.svg`、`landing.svg`：起跳、腾空、落下关键姿势；文件名landing在这里是参考稿的“落下”，不是完整落地吸收动画。
- `preview/`：单图透明PNG、三视图和动作对照板。
- `index.html`：可切换森林底色、查看56/80/112像素高度效果、下载独立文件的评审页。
- `manifest.json`：源图哈希、裁切窗口、SVG尺寸和路径计数。

## 制作方法

1. 保留用户提供的两张原图于`references/`，不改变原文件。
2. 分离八个人物，排除背景、说明文字及相邻人物。原图的水印完整保留在参考副本中，导出的人物不包含版面背景。
3. OpenCV GrabCut分离轮廓；低饱和纸底作为背景提示，回填眼睛高光等微小闭合孔洞，保留手臂/双腿间的真实空隙。
4. 轻度双边平滑后，用VTracer按颜色和轮廓重建样条曲线路径。保留较细的面部和衣褶色块，避免简化掉嘴角、鼻尖。
5. SVG路径带颜色类别ID并保持叠放次序，可修改曲线和颜色。ID只是颜色分类，**不是身体部位分层或骨骼绑定**。每张约1100–3200条路径，总SVG约6.1MB，适合作为详细编辑源。

全部SVG为真实路径，无`image`节点、无base64位图、无外部资源依赖。没有调用图像生成API；这是对参考图的工具描摹矢量化，不是宣称手工逐笔原画。

## 复现

在独立Python3.12环境安装`requirements.txt`后：

```sh
python build_vectors.py
node render.mjs
```

`render.mjs`使用Sharp；可通过`RAINY_SHARP_PATH`指定安装目录。当前机器独立环境为`/tmp/rainy-vector-venv`。安装未改游戏依赖。
