## 运行行为

`TowerMonsterArt` 为犀王建立独立、按需加载的动作缓存。只有实际位移、AI为approach且不在机制前摇/生效/收招时播放。停止、普通横扫/冲锋以及M06/M07/M20各机制阶段保持原静态形象和既有技能特效。使用模拟时钟，暂停冻结；确认死亡后正常清理并只记录一次击杀。

Boss保持220px显示画布；不改碰撞、攻击时序、数值、掉落或关底配置。犀王没有狂暴机制，本轮也没有增加。牛魔王仍使用自己的静态直立母图，不加载犀王动画。
