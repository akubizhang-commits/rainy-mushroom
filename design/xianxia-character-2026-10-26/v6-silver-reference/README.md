使用本机macOS Vision前景分割，再用已安装的PyMatting作有限边缘alpha与去底色估计；不启动ComfyUI，不调用图像生成，不下载模型。无约束细化会带回灰雾，因此最终限制在原分割支持区域内，优先保留头发、白衣和冰剑，未用全图“删除白色”等颜色阈值。
