# 原剑拆分重组样片

2026-10-26。仅技术美术预览，没有更新Cocos运行时素材。

- review.html：原图/分层重组并排，可暂停、镜像、深浅背景和单层查看。80/96/112像素尺寸展示是样片观察尺寸，不声称是所有设备的实际角色像素高度。
- body.png / sword.png：1248×1664同画布透明图；共同锚点(650,1409)，继承原母图接触点(482,1422)/(818,1396)。*-312.png为四分之一导出。
- separate.py：可重复运行的原像素分离/局部去蓝边脚本；使用原生人物mask和原剑trace，从原剑x650干净截面补被脚遮挡处。不调用图像生成，也不重绘人物身份。
- checks.json：上部1200行重组与原图逐像素一致；脚底交叠像素局部去色污染，不能声称整图完全无差异。全画布预乘RGB平均差约0.007/255，只作技术参考，不能替代脚部目视检查。
- browser-static/mirror/mobile.png：真实浏览器截图；browser-checks.json记录控件、浏览器错误和移动端横向溢出检查。

已目视检查脚底放大、深浅背景图层板和镜像对照。人物双脚和剑共用一个变换，避免分层相对漂移。仍存在原mask软边、鞋底局部边缘细节损失；隐藏剑面为邻近像素补纹理而非真实原始内容。此样片不等于新武器已经适配。
