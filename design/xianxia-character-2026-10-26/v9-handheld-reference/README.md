# 手持剑待机参考与蓄势生成准备

状态：参考已裁出并目视检查；蓄势新图尚未生成。当前会话没有内置image_gen能力，用户此前说明无图像编辑API。本包供现有网页版工具使用，不冒称已经完成新姿势。

- idle-reference.png：原文件上半部(0,0,1248,832)，无缩放、无绘制，像素与源裁切一致。仅保留上方可用人物，排除三张有脚位、比例及武器方向问题的小图。完整人物、手持剑和脚下御剑可见。
- anticipation-prompt.txt：只制作一张蓄势，锁人物/脚位/原御剑/3:2画布；手从腰侧收抬至胸外侧，剑向左上抬，不挡脸。
- reference-checks.json：源文件哈希、尺寸与裁切范围。

操作：上传idle-reference.png并粘贴anticipation-prompt.txt全文。使用局部编辑（若网页版提供），不要再上传四人物整版；拿到结果先验收，再做出剑/收势。

验收重点：人物身份与比例不漂移；腰部以下、鞋底和脚下剑对齐；手指环握剑柄、肘腕关系自然；手持剑长度/护手一致；肩袖形态可以连接待机；两把剑完整且无穿插。若工具无法严格锁定原像素，需在导入前以原图做局部合成复核，不能仅凭提示词视为通过。

不使用上一版左下穿腿的御剑动作，也不靠旋转整个人物伪造蓄势。此阶段无Cocos集成或新动画测试。
