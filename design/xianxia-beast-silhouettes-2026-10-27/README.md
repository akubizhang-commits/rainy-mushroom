# 十二族可编辑矢量剪影校样

本目录是独立轮廓设计样板，**不代表正式美术、sprites、动画或动作完成**。姿态混用侧面、轻 3/4、俯视和展开，优先展示形状差异；**不是最终战场镜头验收**，也没有接入游戏运行时。

## 打开与编辑

直接打开 `review.html`，可以对照十二族大图和实际 64 × 64 CSS 像素小图。点击大图打开独立 SVG；“隐藏族名”可进行非正式盲看。页面无需联网或构建工具。手机宽度下改为单列。

十二份 SVG：`boar.svg`、`wolf.svg`、`spider.svg`、`tiger.svg`、`snake.svg`、`bear.svg`、`falcon.svg`、`bat.svg`、`scorpion.svg`、`centipede.svg`、`ape.svg`、`crocodile.svg`。

所有 SVG 使用 `viewBox="0 0 320 240"`、透明背景和纯黑填充。路径按身体、头部、肢体、尾部等命名，可在矢量编辑器中逐部件选择和调整；重叠部件未合并，方便修改。蜘蛛右侧腿使用镜像变换。没有位图嵌入、外部字体、下载素材、付费 API 或图像生成服务。

`build.py` 是可复现源文件。若希望修改在下次构建后保留，请修改其中相应族的 paths；直接编辑导出的 SVG 会被重建覆盖。小图保持原画布比例，在 64 × 64 内居中显示 64 × 48 的 SVG，因此细长的鳄、翼类不会被拉伸。

## 重建与验证

在本目录执行：

```sh
python3 build.py
node verify.cjs
python3 check_svg.py
```

`verify.cjs` 使用指定本机 Playwright `/Users/zhangnu/.npm/_npx/9833c18b2d85bc59/node_modules/playwright` 及 Chromium，无需下载。它临时启动仅监听本机的 HTTP 服务，完成后关闭；输出都保存在本目录。

- `contact-sheet.png`：1500 × 1937，全页真实浏览器截图，设备缩放 1。
- `review-mobile.png`：390px 宽的真实浏览器截图。
- `*-64.png`：十二份透明背景 64 × 64 栅格预览，作为审阅参考，不是正式 sprites。
- `verification.json`：每族在 320 × 240 和 64 × 64 下的非透明像素边界、小图元素尺寸、页面错误、移动端溢出和按钮状态检查。
- `svg-validation.json`：XML、路径合法字符、命名路径、无嵌入图片、蜘蛛八足、蜈蚣十四节及十四对足的结构检查。
