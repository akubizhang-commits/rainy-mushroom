# 三种角色风格候选

> 文档状态（2026-09-21）：专项参考/实现记录。有日期的规则或实现证据，不等同当前目标全通过。 当前基线见[设计文档索引](../../docs/design/design-document-index.md)。

2026-09-20。用户不满意当前冒险者，要求先出三种不同风格挑选，有合适方向后再逐步打磨。本目录为独立候选稿，不覆盖当前游戏或前轮人物设计。

- A 自然绘本：圆润比例、柔和明暗、针织帽与雨披，面部简化。
- B 动画冒险者：修长比例、清楚的色块明暗、短外套与长围巾，眉眼偏利落。
- C 神秘小旅人：紧凑比例、大兜帽、极简面部，重轮廓与肢体表达。面部抽象化是本候选的有意取舍。

三稿都是重新绘制的矢量造型方向，PNG用于审阅，不是完整动画素材。用户已选择 C，并要求打磨手部、身体轮廓等细节；本轮完成细节设计稿，不替换游戏。造型确认后扩展不同可选角色；能力差异仍以后再设计。

## C 细节稿

保留大兜帽、暗色面部与浅色双眼。重画垂手与抓握手形，区分拇指、手指和袖口；梳理肩肘转折、两片斗篷前襟、内衫与弧形下摆；增加少量兜帽缝线、背带扣、侧包与靴底细节。初稿留存为 `assets/style-c-v1.svg/png`。

`assets/style-c-detail.svg/png` 为整体及手部、服装放大图。`tools/polish_c.py` 提供 C 的独立绘制源，运行 `tools/draw.py` 同时更新角色、对比图和细节稿 SVG。

## 攀爬缺项

用户指出当前攀爬没有动作。已确认：当前运行版只有一张抬手静态姿态，角色沿藤茎上移，没有手脚交替动画。此前“动作已完成”的表述不准确。

后续制作需覆盖抓握→身体上移→换手换脚的连续循环，手脚贴合藤茎、登顶过渡和暂停保持；不能把静态姿态切换或测试通关作为动画完成的证据。
