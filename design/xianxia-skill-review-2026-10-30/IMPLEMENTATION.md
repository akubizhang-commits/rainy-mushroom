## 现行形态

下表基础技能按1／3／6／10级列出；次数是同一敌人在全部有效剑路内最多承受的独立命中。剑数、阵眼数不自动乘算命中次数。

| 技能 | 已实现形态与成长 | 实际定位规则 |
|---|---|---|
| 御剑术 | 1／2／3／4把真实追踪飞剑；敌人较少时可以集中攻击 | 每剑追踪选中的目标，命中或消散后结束 |
| 剑气斩 | 1／2／3／3次开口月牙扇斩，前方90°扇区 | 整招方向固定；每一斩从人物当时位置释放 |
| 环剑诀 | 4／5／6／8把飞剑实际绕身扫碰，近身有空隙 | 随人物移动；同敌每0.6秒最多命中1次 |
| 一线天 | 1／1／2／3次狭长直线穿刺 | 首刺固定起点与方向，后续沿原剑路发出 |
| 剑影分光 | 1／2／3／4道交错方向的短线斩击 | 落点固定；首斩延迟0.65秒，后续剑痕不追敌 |
| 两仪剑阵 | 双眼圆阵；6／6／6／7次脉冲，10级末段双眼合鸣 | 阵地固定；首次脉冲延迟0.5秒，3秒内完成 |
| 万剑归宗 | 进化1级为6次向心穿刺＋1记终剑；2级为8次＋1记，共7／9击 | 固定落点；穿刺分别沿真实剑路向心，终剑由施法起点贯穿。特殊招式期间暂停普通御剑，结束后不补发积压剑轮 |
| 无我剑境 | 8／12剑外环＋内圈剑意，填补近身空隙 | 随人物移动；内外圈同敌共用0.6秒间隔，不叠成两击 |
| 天地一剑 | 两阶均为一次宽长重斩；二阶增加宽度与纵深 | 蓄势末段同时固定起点与方向；人物随后移动不改变剑路，地面余光不追加伤害 |
| 四象剑阵 | 四眼菱形区域；6次轮转＋1次合鸣／8次轮转＋1次合鸣，共7／9击 | 固定完整菱形内部；四个阵眼不乘四倍命中 |

其余7项被动保持原作用，补齐准确说明：剑心通明显示真实暴击反馈；青萍剑意在受击敌人身上留下持续剑痕；剑骨提高攻击与移速；剑意余震在击杀位置消耗已有剑意触发一次局部爆发且不连锁；金刚诀是被动减伤；摄灵诀扩大地面治疗物拾取范围；御剑飞行提高移速但仍受地形阻挡。删除了把这些被动误画成持续攻击圈的表现。御剑飞行保留脚下飞剑，实际主动攻击仍会播放角色出招动作。

## 伤害总额、目标上限与时间

`TowerSkillForms.js` 提供共享 `skillForm()` 与 `orbitSwordPose()`；战斗、详情和程序表现共用形态数据。成长、伤害、冷却、经济数据仍由原表管理。

- 剑气斩、一线天、剑影分光将原单次整招伤害分摊到实际段数。
- 两仪、四象沿用原6次基础伤害的整招总额，分别分摊到6／7／9次有效脉冲。
- 归宗沿用原特殊剑雨总额，分摊到7／9次真实剑击；终剑没有隐藏额外倍率。
- 普通御剑一轮总额按实际剑数分摊。环剑与无我保持按同敌间隔结算，内外圈不重复叠算。
- 总额对比以相同等级、装备、目标及完整命中为条件。归宗期间普通御剑停发、不同几何带来的命中率变化属于本次效果方案；不以全战斗DPS完全相同为验收结论。

每击目标上限保持原规则：御剑随等级为1／2／3／4；剑气斩6；环剑及无我6；一线天及天地随母技能为3／4／5／6；剑影3；两仪及四象8；归宗特殊剑击6；剑意余震4。UI明确将其称为每击目标上限，避免与整招同敌次数混淆。

所有段数和区域都由固定步长模拟时间驱动。已开始的招式保存等级、装备、被动与修为快照；暂停修习不会追溯改变尚未完成的旧招式。暂停不消耗段数，JSON恢复继续剩余段数。

## 技能详情与未来节点
