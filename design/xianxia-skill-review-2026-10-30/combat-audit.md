# 技能行为与表现审计

审计日期：2026-10-30。只读分析；没有修改生产代码、技能参数或素材。

本报告以当前锁妖塔 `growthVersion=1` 为准。旧修仙生存模式单列，不能把旧版较丰富的行为当成锁妖塔已经实现。文中范围和次数是核对现状的证据，不是伤害、冷却或成长平衡建议。

## 主要结论

1. **可见升级目前主要是“更大范围”，很少是“新打法”。** 除御剑术增加实体飞剑、万剑归宗增加剑雨外，其他主动技能没有新增射线、斩击、印记或脉冲。四个进阶的等级 1→2 只改预算倍率，没有新的数量或形态。
2. **万剑诀的“剑数”、四象剑阵的“阵眼数”没有兑现为现行战斗画面。** 万剑诀表里有 4→8 剑，但锁妖塔逻辑不采样剑体运动，画面也不绘制这些剑。四象在状态里写 `eyes=4`，判定和渲染都没用这个字段。
3. **一线天→天地一剑没有“开天辟地”的空间跃迁。** 现行进阶仍沿用母技能的长度、宽度和目标上限，只改变起手节奏及伤害预算，释放图形也是相同的细矩形。
4. **新剑气斩样片有审美认可，但还存在范围语义问题。** 视频从残月收成整圆后消散；新贴图渲染不接收扇形角度，固定方形贴图放在前方。真实伤害仍是从起手位置出发的 90° 扇区，不能靠“使用批准素材”证明范围匹配。
5. **剑影分光、两仪/四象剑阵、万剑归宗的剑雨、万剑诀/无我剑境、剑开天门当前大多归并为同色圆形。** 脉冲没有独立表现相位；玩家难以识别是哪种技能、在哪一次落剑时造成命中。
6. **角色出招动作目前只响应御剑术。** 剑气斩、一线天等的战斗伤害和特效可以发生，但没有各自匹配的出手动作。

## 判定术语与公共规则

- **发射数量**：一轮生成多少实体剑、射线、落剑等。
- **单目标命中次数**：同一个敌人在该轮最多挨多少次，不能用目标上限替代。
- **目标上限**：一次斩击或一次脉冲最多处理多少个不同敌人，不能当成连击数。
- **脉冲数**：持续区域在时间上结算几次，不能乘以装饰剑数或阵眼数。
- 锁妖塔统一以每秒 60 次模拟更新。所有普通技能自动选择可达范围内最近活敌人；同距按 ID 排序，六边形塔场景另检查柱体视线。没有“一线天优先精英”的现行锁妖塔规则。
- 除御剑术在释放时从玩家当前位置重新选敌外，剑气斩/一线天锁定起手位置和朝向，剑影/剑阵锁定目标起手时的位置。移动或敌人移动不会让这些技能在释放前持续重新瞄准。

## 特效与判定对齐问题

### 1. 新剑气斩：圆环和 90° 扇区语义相撞

来源样片 `design/xianxia-sword-arc-2026-10-30/source/scenario-approved.mp4` 的全段接触表 `review/contact.jpg` 显示：首段是 C 形月刃，中间形成接近闭合的圆，然后熄灭。新运行时固定把这张 16 帧贴图缩为 `1.2×半径` 的正方形，中心朝攻击方向移 `0.5×半径`。

这种贴图在视觉上可以作为冲击波，但不是从玩家出发覆盖 90° 的扇形。它的明亮圆周会暗示周向受击，扇形两侧和近身区域却没有清晰被覆盖提示。旧模式扇角还会随级别从 75° 到 110°，而新渲染函数连 `angle` 参数都没有，角度成长也不可能反映出来。

审计建议：保留用户批准的青蓝材质、发光与消散风格；另制能在真实扇区上播放的单弧切割版，或者明确将圆环转作剑阵/冲击类素材。不要未经决定就把扇区伤害改成圆形来迁就动画。

证据：[源图集转换](/Users/zhangnu/WeChatProjects/rainy-mushroom/scripts/art/prepare_sword_arc.py:25)、[运行时空间变换](/Users/zhangnu/WeChatProjects/rainy-mushroom/cocos-pilot/assets/scripts/SwordArcArt.ts:35)、[真实扇区判定](/Users/zhangnu/WeChatProjects/rainy-mushroom/js/xianxia/TowerRun.js:952)。

### 2. 一线天与天地一剑应区分“准、快”与“汇聚、终结”

新一线天样片的创作要求包含“大光柱、猛烈爆发、冲击环”，但目前已存在上位的天地一剑。若基础招就占尽屏幕、画出开天裂缝，上位招只能继续放大白光，层次会倒置。优先为两个阶段确定轮廓和时序，再批准不同级别的素材。

现行锁妖塔两者的基础形状相同，仍是一次直线结算；不应把光焰纹理的多条细线描述成多次命中。

### 3. 多数区域技能缺少“预备—有效命中—退场”同步

`TowerView` 统一画区域圆形，而且己方 `phase='active'` 不改变颜色/填充强度。两仪每跳、剑雨每落一轮都没有明确的独立亮起相位。玩家会看到圆一直在，但不能知道哪一帧正在打击。剑影延时更需要印记凝聚与一次爆开的明确转换。

### 4. 表现密度比单个特效更需要先定规则

六种被动同时存在时，玩家脚下最多叠六圈相似图形；再叠万剑诀、剑阵、剑雨后，进阶差异和敌方预警会被覆盖。建议被动默认只保留一种低频主体表现，其他通过触发闪光、敌方状态标记、武器流光区分。此为呈现设计建议，不涉及数值改动。

### 5. 招式发射姿势缺失

`TowerCharacterArt.observeCast()` 只接 `sj_yujian`，因此“横挥月刃”“直刺一线”“立剑开天”“结印布阵”没有对应独立动作。特效的气势不能只靠放大纹理，应由角色蓄势、锋面出现、命中停顿和退场共同建立。

## 进入下一轮方案前应先确定

1. 万剑诀究竟是“真实转剑护体”还是“剑域持续侵蚀”：两者的站位、判定、表现完全不同。
2. 剑气斩与一线天是否属于同一剑气流：若属于，可用扇形近身清扫→多道交错剑气→凝成终极一剑的阶段差别；若保持独立技能，避免两者都演成通用光柱。
3. 剑影分光是“多处剑影连斩”还是“一个延迟剑印”：先定动作语义再定名称，不能只给圆形爆破换一个分身名。
4. 两仪/四象是否有真实不同的空间布局：即使每轮只打一次，也可以两个核心对斩→四方交叉，关键是明确阵眼数量与命中轮数的关系。
5. 每次升级显示“本次改变了什么”：单道变多道、平行变汇聚、移动追踪变定点、短切变终结，至少在关键节点出现一种行为变化；不必要求每级都新增机制。
6. 最终技能描述固定写清“起手/瞄准方式＋空间形状＋每轮刀数/脉冲数＋同敌能否重复命中”。不向玩家公开实现中的预算倍率或账本术语。
