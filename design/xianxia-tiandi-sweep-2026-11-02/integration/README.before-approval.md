# 天地一剑 · 下劈残影与柔和剑尖

2026-11-02 用户反馈：上一版仅包裹剑身，剑尖过于锋锐，下劈需要剑身的剑气/刃光残影。本版已用于开发预览，最终视觉待用户审核。

- 天地一剑独立改用既有圆缓版冰蓝纹理 convergence-ice-aura-v1，收窄贴刃光，取消尖锋增强版引用。实体剑和其他技能的素材不变。
- 旧版25/50毫秒追随残影会在下劈结束后快速重合。本版改为8个固定挥剑阶段的剑气残影，在经过的位置与角度停留并各自衰减，约0.28秒消散。
- 沿实际剑身扫过的区域连接半透明冰蓝光面，覆盖剑身20%到100%区间。第二轮柔化内外边缘与透明度，保留第一轮分带较明显版本及实录。
- 动画由游戏时间驱动，暂停冻结；原有单次伤害、蓄势/下劈速度、实际范围、地面剑气不变。无生成、上传或新增费用。
