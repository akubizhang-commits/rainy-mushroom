# 剑气斩冰蓝三连：正式接入

2026-11-02，用户确认“挺好，接入吧”。已将获批的近身剑气和斜劈、横扫、下劈三种飞行轮廓接入正式 Tower 战斗。

## 接入内容

- 三张512px运行图与获批预览逐字节一致，近身与第三道共用原下劈图。尺寸、锚点、透明度保持获批试装效果，关闭飞行月牙的重复尾影。
- 1—3级保持近身释放；4级起飞行，7级起三连依次为斜劈、横扫、下劈。真实挥剑、原伤害、间隔、目标上限和每发去重保持。
- 飞行碰撞沿原母图的明亮刃缘取点，应用与两张派生图相同的投影；命中、连续扫掠、地形停止和缺图回退使用同一套轮廓。中空部分不作为整块矩形判定。近身仍沿用原扇形判定。
- 新图为静态材质，由现有战斗驱动飞行与消散；没有新增内部能量动画。旧静态图、动态图集、母图、原片及失败尝试均保留。本轮模型生成、上传和费用均为0。
