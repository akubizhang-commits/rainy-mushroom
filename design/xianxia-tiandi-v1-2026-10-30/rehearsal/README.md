# 天地一剑候选 · Cocos 游戏内预演

日期：2026-10-30。素材来源为 `../attempt-03/tiandi-candidate-atlas.png`。这份预演在已构建的 Cocos 游戏浏览器会话中临时创建候选精灵层，替代天地一剑的程序主击图形；没有修改游戏源码、正式资源或构建文件，不代表正式接入。

## 结果

`attempt-03/browser.json` 为 PASS。18 个战斗夹具（9 类 × 1280×720、844×390 两种横屏）及两次退出清理通过，页面错误为零。验证的生产源码和构建入口前后 SHA-256 相同。

- 一阶母技能 6/10 级、二阶母技能 8/10 级均沿真实范围释放。
- 水平、反向、竖直、斜向、柱体截断、边界截断与锁定前后移动通过。
- 使用真实 `TowerRun.advance()` 产生效果，单轮仅一份重斩效果，目标生命仅下降一次。
- 蓄势 0.45 秒，前 0.30 秒允许重瞄准，最后 0.15 秒同时锁定起点与方向；锁定后移动不会改变剑路。
- 候选播放 0.5 秒，战斗源效果仍在 0.25 秒结束；额外尾光没有增加伤害。
- 暂停时游戏状态、人物帧和候选特效帧不变化；重复 draw 不改变战斗状态。
- 人物使用现有通用挥砍动作，锁定与释放未引起帧倒退；本次没有新增专用人物动作。

`attempt-03/tiandi-ranks-realtime-review.mp4` 是两段原生 Canvas 录像的顺序拼接：一阶、二阶各一次完整蓄势、主击和收势，总长 4.733 秒，1280×720、30fps。只增加审核文字标识并统一输出帧率，没有改变播放速度。原始 WebM 和单段 MP4 同时保留。录制由生产 `TowerView.update(dt)` 驱动，开始前人物、场景及候选图集均已就绪；没有通过逐帧推进伪造实时录像。

正常游戏摄像机保持人物居中，满级 670/770 长剑路可能越过右侧视口。候选仍按完整真实终点绘制，未按屏幕边缘缩短。可在独立素材审片中检查完整剑尖，游戏截图中检查角色、环境遮挡和实际尺度。
