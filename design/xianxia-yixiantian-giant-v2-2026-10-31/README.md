# 一线天巨剑第二版：胸前单剑

按2026-10-31用户反馈修订，上版每贯重复出剑的表现不被采用，但所有原素材和录像继续保留。

- 每次完整施法只在首贯生成一把巨剑，二、三贯仅播放原白色剑气。
- 巨剑按首贯释放时角色腰部锚点加18单位定位胸前，包含角色动作倾斜和飞行高度。世界垂直抬升经逆旋转转换到局部坐标，左右、上下和斜向均保持在角色胸前，不会转到脚下。
- 前25毫秒短促蓄势，然后快速前冲，0.22秒完成前飞，0.30秒淡出。位置单调向前，不折返、不重播。
- 首贯真实正伤害记录触发定向短闪和六道碎芒，最长0.12秒；反馈跟随剑尖到达时刻，落空、免疫和后续剑气不重复触发该巨剑反馈。
- 下方剑气的原图集、位置、16帧播放曲线、0.33秒尾迹和连贯节奏保持原样。未修改战斗伤害与命中次数。
