## 处理

对黑底发光图作alpha反解，保留低亮度蓝色薄层；仅去除近黑底噪。右侧少量低强度辉光接触文件边缘，在最后12像素柔化，并给四周补64像素留白；明亮刃口与主体未裁切。未重绘或用程序噪声替代用户纹理。母图原分辨率保留，试装为512px单帧。
