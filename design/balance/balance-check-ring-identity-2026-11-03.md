# 戒指独立review

结论：**CONCERNS；三类中同档雷同最严重，极品路线取舍应优先处理。**

## 级别与基础属性

26种身份。法／宝／灵每阶每品质2枚；基础法防，力量或智力方向，部分神识与第三属性，另有体力。主属性预算为法器2/3/4/5，宝器4/5/6/7，灵器6/8/10/12，与武器一致。同路线品质提高时基础法防递增。

不同阶位数值提高，允许旧极品胜新下品，不存在“新颜色必然每项更高”的规则。单件没有独立EHP成长硬阈值，不能套用三槽1.25–1.40目标。

## 雷同与路线反转

25枚非初始戒指全部带暴击率、暴伤、冷却缩减，其中24枚还带功法增伤；特殊效果栏全部为空。12组同阶同品质戒指的效果类型完全相同，主要改变百分比和力量／智力方向。

下／中／上品原本存在burst（偏暴击）与cadence（偏冷却）取舍，但早期差距很小。例如法器下品锐意石戒／追锋灵戒：暴击0.5%／0.3%，冷却0.1%／0.2%，暴伤均0.1%，功法增伤均2%。对1.8秒基础冷却，0.1个百分点差异仅1.8毫秒（理论连续时间；是否形成帧差尚未实测），很难让玩家感到两个节奏。

极品却使用同一份graduate效果表，master额外＋1.5个百分点暴击、＋0.3个百分点暴伤。两者冷却与功法增伤相同，同时master法防更高。这使原本的冷却路线变成“暴击也更高”的偏智力装备。

具体对照：

| 灵器极品 | 决锋宝戒 | 天锋灵戒 |
| --- | ---: | ---: |
| 主属性 | 力量10.8 | 智力10.8 |
| 法防 | 164.678 | 190 |
| 暴击率 | 7.5% | 9% |
| 暴伤 | 2.5% | 2.8% |
| 冷却缩减 | 2.5% | 2.5% |
| 功法增伤 | 9% | 9% |

法器明心／破妄、宝器剑鸣／照玄也遵循同样结构。仍有力量与智力取舍，所以不是所有原始属性轴上的严格支配；不能声称天锋对一切物理配装必然更强。

隔离戒指、同角色等级、初始武器，采样无剑心及合法满级剑心：三阶master戒的混合期望技能伤害比同档graduate高约0.74%–0.78%，法防也更高。纯物理收益会随角色成长发生交叉，例如天锋／决锋的纯物理比约0.99295–1.00044；可见旧爆发方向优势很薄且并不稳定。该测试没有覆盖所有武器、元素、暴击封顶或实际施法调度。

## 建议

P1：先恢复两条路线的互斥取舍：暴击型在暴击收益上领先，冷却型在冷却收益上领先，避免极品把暴击优势也给冷却路线。检查基础法防／主属性是否已经提供补偿。

P2：将早期两条路线的有效收益差做成可感知的区别，在总预算内集中词条，避免四项都给一点点。P2：之后只为少量上品／极品加入有搭配要求的专属效果；持续伤害支持等仅为候选设计，不代表本轮已实现。不要通过给所有戒指叠一条特殊效果掩盖取舍问题。

2026-11-03。只做独立类别review，本轮不改运行时装备数据。太衡剑保持用户确认的当前强度及全技能＋1，不再列入本轮削弱建议；这一决定也不等于把所有装备的3倍预算一并放宽。

## 输入与边界

FOUND：TowerEquipmentRoster、TowerEquipmentBases、TowerWeaponBases、TowerWeaponTuning、TowerWeapons、TowerEquipment、TowerEquipmentTiers、TowerRun、TowerAttributeRules；equipment-rebalance-targets-2026-11-02.md；本轮 review.json、progression.json。

ABSENT：design/registry/entities.yaml、design/gdd；每个单槽的逐项绝对属性范围、同档辨识度量化阈值、完整人类通关时长和获取时间目标。相应绝对数值、胜率及获取时间判断为 NOT ASSESSED — NO DATA，需要 /design-system 汇总目标。三槽EHP 1.25–1.40不能直接移作单件防具或戒指的阈值。

阶位开放：凡器1级、法器4级、宝器11级、灵器21级；法宝等后续阶位未开放。阶位与品质分开：法／宝／灵均有下、中、上、极品；旧阶极品胜过新阶下、中品符合现有设计方向。

区别三种重复：同路线提升品质沿用机制是正常成长；同档两件完全相同是重复装备；同档只有很小的百分比差异、缺少用途取舍是设计雷同。不能只凭“原始属性没有严格支配”判定玩法差异已经充分。

本轮脚本 review-equipment-slots.mjs 导出全部87件当前属性；检查三类共18条同阶品质路径的基础主输出／防御单调性；戒指单槽期望输出对照和防具跨阶单槽无回复EHP取样。未跑完整新档成长，未宣称全仓库测试通过。
