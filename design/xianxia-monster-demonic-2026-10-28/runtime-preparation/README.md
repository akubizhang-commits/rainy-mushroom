# 妖化静态素材的游戏预览准备

用户已确认妖化方向并要求接入体验。原始生成图保持不变；本地脚本 `scripts/art/prepare-tower-monsters.py` 去掉纸底，输出九张256×256 RGBA到游戏资源目录 `tower-monsters/`。

这是确定性的图像处理，不调用Scenario或其他生成模型，不消耗生成额度。统一留边、居中和缩放，保留原有颜色。深色背景检查见 `dark-background-contact.png`；蛇/鳄腹部原有浅色绘画仍保留，边缘不是人工逐像素精修。

游戏首轮只使用静态怪物形象与水平朝向翻转，仍由原有行为系统控制移动、攻击、预警与受击。无需等待动作帧才能验形象，但这不能作为爬行或攻击动画的验收。三种未生成的妖兽继续使用原有矢量形象。
