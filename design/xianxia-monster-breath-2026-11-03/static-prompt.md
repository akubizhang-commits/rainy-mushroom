# 下一张：M16摆首妖息母图

第五层Boss已配置M16，运行时生效阶段为90度扇形，3秒内扫过方向。当前只有几何区域，没有专用喷息图。已查库：毒液是离散液滴、泥沼是贴地圆斑，都不适合作为连续扇形喷息主体；可继续复用它们的配色，不重画已有素材。只替换表现，不改变扇形或伤害。

## Prompt

中国仙侠游戏怪物技能特效，赤鳞蟒王喷出的连续妖息，单个完整的扇形气流素材，手绘游戏风格，略俯视但不画地面。

气流从画面左侧一个明确、狭窄的喷口起点向右扩散，形成约90度张角的短宽扇形。整体是低饱和灰青、暗橄榄绿色的半透明妖雾，内部有向右流动的层状丝缕，少量浅黄绿亮边。靠近起点较集中，远端逐渐变薄、碎散并消失。保留清晰流向和透空层次，轮廓自然，不能画成实心三角形、液滴、地面毒池或火焰。完整保留喷息起点和远端雾丝。

1024×1024 PNG，主体居中，宽度约占画布75%，四周留足空间。均匀纯品红背景#FF00FF，所有透空间隙同为品红，主体不含品红。单一气流，不要多帧或多角度。

不要蛇头、怪物、人物、嘴、牙齿、地面、场景、法阵、圆环、文字、图标、闪电、独立弹丸、浓黑烟柱、大片强光、边框或水印。
