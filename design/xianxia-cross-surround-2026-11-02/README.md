# 纵横剑气 · 周身错落大月牙

用户确认伤害为周围360度后，要求视觉恢复主要集中在角色周围，并将月牙至少放大1.5倍。本开发版按上一版每道月牙的宽、高各乘1.5，保留冰蓝/红色素材、错时释放和非均匀曲线。

六道剑气分配到非等距的周身方向，带施放级别的微小变化；直线剑光随之旋转至周围。放大后缩短外移，使主体仍集中在角色附近。按放大后的完整旋转画布保留身体78单位净空。

伤害规则未变：以角色为中心的360度范围，1–3级半径180、4–6级220、7–10级270，最多6个可见目标，每次施放同敌一次结算。
