2026-10-28。仅独立设计原型和预算检查，不是正式塔战、真实存档、真人平衡或真机验收。

## 当前结果

`verify.cjs`在隔离Chrome上下文中执行，1440×900、1280×800、390×844、360×640共40组检查通过，页面异常0。结果见`verification.json`。`verify-plans.mjs`验证技能点总量、三套样例前置/点数与领域五档数据，结果见`design-budget-checks.json`。本轮未跑全游戏回归或重构正式Cocos构建，因为没有改运行时。

覆盖内容：

- 16节点同页（6功法、6心法、4进化），无技能/心法分类页签、无手机流派隐藏切换；4个母技能与4个心法前置连线。
- 旧5级交互基线的购书前置、塔内禁买、已购不重扣、教学优先与低阶研修；改为学会自动生效，无装备按钮/槽位，第五第六功法及三种已学进化可同时生效。
- 进化替换母功法、重修退款一次、保留所有权、重新升阶后自动恢复。仅内存模拟，不证明战斗里没有重复伤害。
- 六心法光环按已学显示、领悟即时增加；六种单项/叠加样式；回宗/死亡消失；暂停与系统减少动态效果下连续截图像素稳定。
- 七职业、法修八系共14个领域形态，1/5级切换有对应数值；没有改变玩家职业或战斗状态。
- 新技能点预算独立标注提案：1/9/10/18/19/27级点数，境界30＋额外6总36，三套36点样例。逐级成本校验总树240点，御剑路线去掉剑影3级为30点。
- 无横向溢出，16节点字体≥16px/触控≥44px；同页dialog可键盘打开、Esc关闭返回原节点；无localStorage写入。

外观光环短亮由预览按钮触发，非实际战斗事件。采用既有v7站剑抠图，未替换角色美术。当前只静态对照敌方预警，不证明密集弹幕下可读性已经过真机验收。
