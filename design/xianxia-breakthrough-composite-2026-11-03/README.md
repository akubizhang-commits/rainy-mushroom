## 编排与处理

聚气0–1.65秒，凝气1.65–2秒，突破2–2.65秒，退光2.65–3.5秒，3.5秒后显示“筑基已成”。前3.5秒沿用当前仪式时间，后1秒仅为预演结果展示。失败分支尚未实现于本预演。

道基先旋转再压缩为地面椭圆，角色保持静止。光柱位于人物后方，本地加宽以显示两侧光丝；淡金冲击环与聚气粒子用Canvas编排。不是新生成的角色或特效序列动画。未添加镜头晃动和全屏闪白。

黑底图以最大RGB通道计算alpha并反预乘，普通透明合成还原黑底亮度。角落完全透明，黑底还原单通道最大误差2/255。人物派生版本进一步抑制残留品红，原母图及前次透明版本均未改动。
