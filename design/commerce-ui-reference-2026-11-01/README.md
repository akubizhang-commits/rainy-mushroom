# 购买与炼制页面的布局依据

2026-11-01 用户再次明确：这六张图片是四个页面的交互与UI布局依据。后续移动入口不得把这些页面还原成旧的长文本列表。

- reference-1：购买目录，分类 + 三列商品卡片，图标/名称/价格。
- reference-2：点击商品后的购买弹窗，数量与总价，取消不扣费。
- reference-3：炼器，分类 + 配方图标 + 成品/材料 + 固定操作区。
- reference-4：炼丹，图标配方网格，成品、材料拥有/需求、数量、费用。
- reference-5：炼制确认，确认前不扣材料。

静态素材优先复用，不调用付费静态生成。缺少图片的材料使用明确名称卡片，不伪造另一件材料的图标。
