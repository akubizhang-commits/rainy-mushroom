# 长虹贯日：裂缝由中线张开再合拢

2026-11-03。用户要求裂缝“从中间裂开，然后再合拢”。

沿用用户提供的蓝白裂口纹理，围绕飞行轨迹的中线向两侧展开，再收回同一中线：

- 施法后约0.07秒出现细缝，0.35秒完全张开；
- 保持张开至0.72秒，随后逐渐合拢，1.22秒结束；
- 合拢期间保持亮度，最后0.08秒才淡去细线，使闭合动作清楚可见；
- 裂缝的长度继续跟随飞剑，闭合只收窄宽度，不回缩飞行距离；飞剑出屏、伤害和命中范围均保持。

使用单张原纹理的缩放开合，未生成新的逐帧动画，新增Scenario费用0。旧代码与测试保存在 `before/`，之前的参考原图、纹理和历次录像保持。
