# 已接入技能的打击感审查 · 2026-10-31

范围：当前 Tower 已接入动画的10个技能，包括基础与进化形态。依据正式运行时代码、素材库接入记录、既有真实施放录像的抽帧检查。不是本轮重新操作全部技能的实机验收，也未做音频试听和满屏混战性能测试。本轮只审查，不修改已批准表现、伤害或素材。录像清单在 recordings.json，抽帧在本目录；抽帧不能验证几十毫秒的细节，短时序判断以代码为依据。

## 结论与排序

最值得先补的是御剑术、剑气斩、纵横剑气、环剑诀的“接触敌人”反馈。共用一套受击视觉响应后，再分别调整其斩击/刺击方向、大小和节奏，比重新制作飞行动画更有价值。

| 技能 | 现有表现 | 优先级与具体建议 |
|---|---|---|
| 御剑术 | 肩侧待命、转锋、弧线寻敌、四道残影、结束消散；命中使用通用火花 | 高。真实命中点增加沿入射方向的短促白芯、窄刺痕、敌人轻微后仰；首剑清楚，后续剑减弱。多剑同击合并反馈，不能十剑连续震屏。 |

## 横向问题

1. **通用受击响应覆盖不足。** TowerView 当前只对 shadowBodyReactions 的结果调用 monsterArt.applyImpact。其他技能虽可触发怪物受击动画，但主动攻击/特殊动作在选帧中优先于受击，不能依赖受击动画覆盖所有命中。建议独立的短时身体视觉偏移/形变层，与AI、碰撞位置分离，复用剑影现有能力；不要打断怪物预警与攻击逻辑。
2. **多数命中使用同一种很小的叉形火花。** 普通半径6、暴击半径15，难以区分刺、斩、重劈。先做三种方向明确的命中形状，再按技能分级；火花应随敌人可见身体锚点放置，避免落在脚底或被遮挡。
3. **音效事件链待补。** 本轮搜索 Tower 宿主、特效及战斗模块，未发现专属播放/音频接入调用；不能用项目里存在 SurvivorAudio 推断 Tower 已有技能命中音效。后续单独核查平台实际播放路径，再加入短促切割/刺入/重击声音、少量变体与并发限额。本轮未试听，不评价现有音质。
4. **需要统一强度与并发上限。** 常驻环剑/无我用轻量局部反馈；月牙、御剑用中等局部反馈；天地与剑阵终击才考虑重反馈。同一敌人密集命中取最强或限频，镜头冲击合并封顶，避免高等级越打越看不清。
5. **伤害与视觉事件要明确关联。** 通用正伤害事件应带目标ID、施放ID、命中方向、段次和等级，便于精确驱动一次反馈；不能仅按“同一时间存在某种hit”就扩散到整个技能范围。剑阵/剑影已有较好的目标关联，可作为参考。

## 建议实施顺序

第一批：共用受击层 + 御剑术、剑气斩、纵横剑气、环剑诀，各做普通/暴击/落空对比。第二批：无我、两仪、四象的连续命中节奏和同屏抑制。第三批：一线天视觉到达同步、天地与剑影的精修。各批保留原批准版作对照，不重做主动画。

初始调参建议：轻量闪光约40–60ms、身体反馈约60–100ms，重击回弹约100–160ms；这些只是实验起点。全局顿帧不作为第一批默认项，若试验必须使用独立实时时钟恢复，移动输入持续采样，暂停/退出清理，并限制连续触发。

后续验收：单敌/多敌、空挥/命中、普通/暴击、低级/满级、敌人处于攻击动作时、重叠多技能、两种横屏尺寸；检查输入持续响应、碰撞位置不变、特效正常归零和性能峰值。没有这些实测，不声称“满屏不会抖”或“所有机型都流畅”。
