# 无我剑境 · 可见曲线拖尾

用户反馈上一版拖尾几乎不可见。本版将拖尾起点从剑身中部移到剑尾，避免短尾被剑身遮盖；留痕延长到约0.65–0.9秒，并提高冰蓝外层和浅色亮芯的宽度、透明度，末端渐细渐隐。

保持飞剑独立变速和脚下光环，不恢复已移除的剑身刃光，不改动伤害规则。原素材、上一版实现和录像继续保留，无新增生成费用。本版待用户视觉确认。
