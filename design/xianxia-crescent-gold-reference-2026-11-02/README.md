# 金白扫斩 · 用户参考图轮廓草案

用户提供横版战斗截图，要求参考剑气形状，颜色也可参考。本草案采用下侧舒展、右侧上挑、两端不对称收尖的宽刃扫斩轮廓，并以金黄色过渡到浅金白色刃芯。

复用原批准剑气素材的纹理，使用两段贝塞尔曲线重映射及本地调色。未从参考截图提取人物、场景或界面。`user-reference.png`保留用户原图，`provenance.json`记录来源，`make_preview.py`保留制作过程。
