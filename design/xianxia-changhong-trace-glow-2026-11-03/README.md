# 长虹贯日：先留细痕后张开，剑身蓝色描边

2026-11-03，根据用户最新反馈调整时序，并强化飞剑可见性。视觉效果待用户审核。

## 时序

- 飞剑沿原轨迹飞出屏幕，路径上先留下细裂痕。
- 至0.8秒前始终保持细线；飞剑于0.72秒结束显示。
- 0.8–1.08秒，完整路径上的细痕向两侧张开；保持至1.3秒。
- 1.3–1.72秒向中线合拢，保持原路径长度。
- 1.72–1.82秒，合拢后的细线淡去。

相较上版，张开延后至飞剑出屏之后，总视觉时长延长至1.82秒。伤害、命中范围、施法节奏不变；多段释放仍只有一把实体剑。
