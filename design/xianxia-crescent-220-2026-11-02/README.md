## 实现

复用已批准 `sword-qi-crescent-v1.png`，定位其白色刃芯后做平滑曲线重映射，导出独立 `sword-qi-crescent-220-v2.png`（384×512）。参考跨度440像素，圆心(130,256)，半径220像素，前缘锚点(350,256)。在保留原色与透明度的基础上重采样，避免直接拉宽造成的扁弧。

`TowerSwordQi.js` 仅为 crescent 增加44段220°圆弧；碰撞、连续扫掠、地形停止和资源失败回退共用该曲线。圆弧后方的140°缺口与中央空白不自动造成伤害。横向跨度、飞行速度、发射位置、三连间隔、伤害预算和每发去重规则不变；刃面向后的深度随曲率增加，因此真实命中/地形轮廓也随图像更新。cross仍使用原12段基础曲线。

动画继续由正式战斗推进，保留起手淡入、飞行、短尾与到达地形后的消散，不在任何阶段补画闭环。原图与新图集均没有付费生成、上传或云端调用。
