# 下一张：妖隼飞羽弹体母图

用途：对应现有隼类 feather 物理飞行攻击。仅制作一根羽刃主体，飞行、旋转与拖尾由游戏控制。现有资源文件名及特效库索引未找到专属飞羽母图；不使用Scenario静态生成额度。

## 可直接复制的prompt

中国仙侠游戏怪物远程攻击素材，单根妖隼射出的锋利飞羽，仙侠手绘风格，清晰的游戏道具轮廓。

只画一根完整羽毛，平放横向展示，尖端朝右，羽根朝左。形态细长，右端自然收成锐利羽尖；中间一条清楚坚韧的羽轴，两侧羽片紧密排列，略不对称，有少量自然缺口，但整体连贯。它是坚硬锋利的真实妖禽羽毛，不是金属飞刀、箭矢或能量剑。

羽片以玄青灰为主，银灰羽轴和灰白锋缘，羽根附近少量暗赭红纹理。用清楚的大色块和适量羽片纹理表现层次，避免过密毛丝，缩小后仍能辨认一根锋利飞羽。光照柔和，无强反光、无发光包边。

输出1024×1024 PNG，单物体、单视图。飞羽完整居中，长度约占画布80%，最宽处约占画布20%至25%，四边均留白。背景为均匀纯绿#00FF00，主体不含绿色。

不要鸟、翅膀、人物、手、场景、地面、投影、尾迹、烟雾、火焰、粒子、运动模糊、额外羽毛、文字、水印、边框或多格图。
