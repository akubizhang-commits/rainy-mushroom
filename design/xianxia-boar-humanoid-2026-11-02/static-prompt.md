# 四阶赤鬃猪妖 · 半人形母图

现行boar_normal_r4为四阶普通怪，仍缺半人形母图。已有boar-demonic.png为四足野兽，可复用长吻、双獠牙、粗毛、黑纹和短尾设计；不替换低阶妖猪与其已验收动画。

为中国仙侠俯视动作游戏绘制“四阶·赤鬃猪妖”的完整角色母图。半写实手绘游戏美术，与已完成的猿王和狼王保持同一画风。

成年男性气质的半化形野猪妖，保留完整野猪头部，厚长吻部、宽大鼻盘、三角兽耳、两根由下颌向上弯曲的象牙色獠牙，眼神凶悍。额头与肩背有简洁黑色妖纹。脸部不能画成人脸或家猪圆脸。

双足稳定直立，脖颈粗短，肩背宽厚，胸腹粗壮，腰部保留体积。躯干覆盖深灰褐色粗毛，后颈沿脊背生长一条暗赤褐色硬鬃，毛束坚硬、方向清楚。双臂粗壮，前臂尤其厚重，双手为覆盖粗毛、具有五根粗短手指和深色短指甲的兽形大手；双手空手，略微半握，手臂与身体之间留出间隙。双腿结实，以宽大分趾猪蹄承重；双脚自然错开。腰后保留短小、末端有毛簇的猪尾，避免变成狼尾。

穿简洁深褐皮革护腰和短战裙，少量旧铜扣件，护具不遮住主要关节。不持武器，不戴头盔，不披披风。静止警戒姿态，略微前倾但不奔跑、不冲撞、不咆哮。

高位三分之四视角，适度俯视，面朝画面左下。单个角色、单一视图、完整全身。主体占画布约80%至85%，双耳、獠牙、双手、猪蹄及尾尖完整入画。纯中灰背景，柔和均匀照明，无地面、投影、烟尘、碎石、法阵、文字、水印。输出2048×2048高清PNG，常态配色。
