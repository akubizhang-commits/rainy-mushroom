## 实现和范围

复用已有刃光纹理，以新曲线重映射并重新调色，生成三套16帧、512px单帧、2048px图集。每道用0.12秒沿弧线显形，之后沿真实技能的飞行及消散时钟显示。技能单发/三连次数和伤害机制未改；现有三连间隔仍由游戏决定。

使用上轮已验证的固定构建。`scripts/preview-jinqing-crescent.cjs`只在浏览器预览页临时替换剑气绘制，加载本目录图集；未修改正式资源引用、角色代码或伤害判定。新形状的碰撞对齐尚未正式接入，不能将此预览当成新形状生产验收。现有动作规则是一轮三连配合一次完整挥剑，后续两道不会强制倒带人物姿势。

`runtime-02`六个场景均确认真实角色至少四个不同挥剑帧；三连确实使用三个变体，单发只用第一变体；真实伤害次数仍分别为3/1。双横屏尺寸为1280×720和844×390。
