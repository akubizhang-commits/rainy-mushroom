# 啸月狼王 / 青风妖狼动作制作

下一只按第二层Boss顺序选妖狼。复用已批准的青风妖狼外形，不新画一个物种。

## 动作范围

| 动作 | 用途 | 接入约束 |
|---|---|---|
| 移动 | 普通怪、Boss追击 | 原地步态、固定相机，可无缝循环 |
| 撕咬 | 当前扇形普通攻击 | 普通/Boss前摇0.7/0.9秒，生效0.16秒，收招0.65/0.85秒；不增加扑击位移 |
| 召唤长嚎 | M01镜魄分身、M05号令群妖 | 共用起手长嚎，按实际机制时长播放；分身/召狼由逻辑生成 |
| 受击 | 生命减少 | 短促回缩，保持脚底锚点；不循环、不引入额外控制 |
| 死亡 | 击杀后倒地 | 倒地后保持末帧；保留Boss基础尺寸 |

狼王现有技能没有M02，不擅自添加狂暴。未来拥有狂暴的物种自动遵守统一生命周期标准。
