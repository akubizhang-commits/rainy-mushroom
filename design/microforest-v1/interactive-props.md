# 微观森林互动道具设计规范

> 文档状态（2026-09-21）：历史设计/记录。旧枯枝桥/枯叶开风/自动归位不用于当前设计。 当前基线见[设计文档索引](../../docs/design/design-document-index.md)。

2026-09-20 · V1 提案。美术原型与交互分镜，尚未加入游戏。H为同景深人物站立高度；原型图采用同一人物尺寸，素材目录为排版单独缩放。

## 借鉴依据与本项目取舍

- EA《Unravel》开发者文章 **A World of Challenges and Obstacles**：推拉物体、物理关系与可操作外观保持一致。参考：https://www.ea.com/games/unravel/news/unravel-game-puzzles 。本项目取“看得懂受力与结果”，不照搬毛线能力、角色和关卡。
- Nintendo《Pikmin 4》官方探索指南 **Explorez sans limite avec ces conseils pour Pikmin 4 !**：先观察敌人反应，再选择策略。参考：https://www.nintendo.com/fr-fr/News/2023/Juillet/Explorez-sans-limite-avec-ces-conseils-pour-Pikmin-4--2420212.html 。本项目取可观察预警和危险绕行，不引入群体指挥系统。
- Nintendo《Yoku’s Island Express》官方介绍：弹球、平台动作与开放探索相结合。参考：https://www.nintendo.com/us/store/products/yokus-island-express-switch/ 。本项目取少量核心操作的组合潜力，不增加一套弹球控制。

下面的操作、比例和阈值均是本游戏的设计提案，不是参考游戏的数据或自然科学结论。

## 通用要求

1. 每个物体只有一个主要操作，结果可见。首次在安全位置单独教学，再与熟悉道具组合；每个小谜题最多引入一种新规则。
2. 操作优先沿用移动、跳跃/按住滑翔、一个情境操作键。靠近后显示具体动词“推”“攀爬”“进入”“拨开”，不显示泛化的“互动”。一时只选一个最近且可达的目标，不穿墙选中。
3. 目标进入约0.5H可达范围才显示提示；离开约0.7H消失，减少边缘闪烁。提示不得盖住脚底、抓点或敌人。
4. 按住操作并移动用于推动；持续推动速度建议为步行的40%–55%。推物时手掌接触物体侧面，脚底有支撑；松开即停止。拒绝推动时用短促受力反馈，不让按钮无响应。
5. 攀爬由操作键进入，方向输入移动，跳跃可脱离；上下端都要有安全着陆。不可攀爬的相似背景面不画连续抓点。
6. 尺寸是规则的视觉提示：可推动石头高0.6–1H；攀爬石高2.5–4H；洞口净高≥1.2H、宽≥0.8H；枝桥有效跨距2–4H。数字最终由关卡物理验证，不视为已实现。
7. 颜色分工：背景灰绿/灰褐；可操作部位局部暖黄绿或琥珀浅边；危险荆棘灰紫褐、尖刺明确。岩石不整体刷成金色，树洞暗部不发光。颜色之外还必须有形状、表面、动作区别。
8. 地面、支点、抓点和接触面必须连贯，碰撞轮廓与可见表面吻合；枝桥两端有支撑。大岩石不能被角色推着走，小石不能自由抬过头。
9. 交互反馈分四步：可达提示→动作受力→结果变化→结果保持。视觉状态改变必须对应碰撞状态；禁止图像倒下而碰撞仍竖直。
10. 失败不制造软锁。每段有安全点和重置入口；物体落入不可达区域自动归位或允许重置；完成的永久通路保留，不能把唯一工具永久丢掉。
11. 不强制双人合作；小男孩和小女孩能力、碰撞体与可达范围一致。
12. 美术分层：底部阴影/背面、主体、可动部位、前景遮挡、低频效果分开；锚点标在脚底、支点或附着点。动作3–5关键姿态先验证，再决定动画帧数。只保留稀疏灰尘/气流，不常驻高亮光圈。

## 物体与功能映射

| 物体 | 操作及结果 | 明确外观 | 状态 | 风险与取舍 |
|---|---|---|---|---|
| 小岩石 | 推入浅槽或抵住轻物，形成踏脚点 | 低矮圆钝，有接地面与擦痕 | 自由→受力→入槽稳定 | 首选；滚入危险区可恢复，不能当背包物品 |
| 大岩石 | 攀有抓点一侧，到达高平台 | 大体块、连续台阶裂缝、宽顶部 | 靠近→攀爬→登顶 | 首选；另一光滑面不可攀，不能全表面吸附 |
| 枯枝桥 | 围绕固定根端推倒，搭住对岸 | 枝端支点、断口、可见另一岸 | 斜靠→旋转→双端承重 | 优先验证；用受控旋转，首轮不做任意杠杆物理 |
| 穿根树洞 | 左侧进入，沿通道走到右侧 | 巨树基部、双端洞口、连续地面、出口透光 | 靠近左口→穿行→右侧离开 | 允许原路返回；不传送、不切场景，出口留安全地面 |
| 荆棘 | 观察后绕行、跨越或走上方通道 | 暴露尖刺、灰紫茎、危险轮廓清楚 | 静止→靠近预警→接触受伤 | 优先验证；不提供“推”或“攀”提示，不引入砍伐 |
| 攀爬藤 | 沿固定藤茎升降 | 连续茎、根端/上端固定，亮侧抓握面 | 靠近→攀爬→脱离 | 延续原型；可脱离返回地面 |
| 露珠 | 推向叶片承重位置 | 通透体积、接触阴影 | 静止→滚动→承重 | 延续原型；不用于食用/饮水系统 |
| 承重叶桥 | 承重后弯下，成为路面 | 叶柄支点、叶脉、连续站立上缘 | 翘起→弯折→稳定 | 延续原型；叶片和碰撞共同改变 |
| 绒毛滑翔器 | 拾取后在空中按住跳跃展开 | 细丝、轻轴、可收拢 | 地面→携带→展开→收起 | 延续原型；不得强迫反复拾取 |
| 枯叶风口 | 拨开枯叶，让上升气流显露 | 卷边枯叶、背后缝隙、稀疏漂浮碎屑 | 遮挡→拨动→敞开 | 延续原型；风始终来自可解释的缝隙区域 |
| 树皮浮台 | 随水升降或短程漂动 | 翘边厚树皮、水线、载重轻压 | 空载→登上→受载→离开 | 储备；依赖水流、移动平台与重置，暂不加首关 |
| 种子配重 | 推上支点，压住轻叶 | 大种子、圆钝接地、可见受力处 | 静止→推移→配重 | 储备；与石头功能重叠，等新谜题确有需要再加 |

## 优先验证的两个小谜题

A. 小岩石→浅槽→登上低台→攀大岩石→从荆棘上方绕行。先学推，再学攀，最后组合；每一步提前看见目标与落脚面。

B. 推倒枯枝→搭桥越缝→从左侧进入穿根树洞→穿过树根→从右侧回到林间。通路搭好后保持；躲避失败从桥后安全点恢复。

这两段只作为下一轮试玩候选，不是同时塞进现有第一关的开发承诺。现有露珠/叶桥、风口/滑翔谜题保留作比较。

## 原型图与验收

新增12类道具目录、5组三态分镜（小岩石、大岩石、树枝、树洞、荆棘），使用统一人物参照。原型页面可切换分镜类别；它是设计查看器，不是可玩的物理原型。

验收：无文案重叠；小屏能分辨推物/抓点/洞口/刺区；手脚接触合理；桥落下后两端支撑；穿洞时遮挡不丢失移动反馈；同一物体三态体量不变；不能仅靠颜色传达危险。程序接入后追加真机触控、重置、碰撞、帧率与存档检查。


## 穿根树洞修订
用户确认树洞为一棵巨大树木根部的贯穿通道，左入右出。树干延伸出画面，不画完整小树或独立小拱门。保持方向移动自然进入；不要求按键切入藏身模式，不做瞬移。通道净高至少1.2H，地面连续，左右端各留不少于1.5H安全落脚区；可中途停下或回头。概念图用半剖视展示内部，实际渲染拆成通道后壁、角色层和前沿根皮，中段保留弱剪影或局部淡出以免失去人物位置。尚未改动现有游戏藏身代码。

## 道具造型修订：自然材质

2026-09-20。玩法与蒲公英保持，另外11类道具的美术已更新到目录和现有分镜。

| 道具 | 本轮造型修订 |
| --- | --- |
| 小岩石 / 大岩石 | 风化圆钝边缘、连续明暗、零星矿物斑与苔藓；攀爬抓点融入裂隙，不再画人工梯子 |
| 枯枝桥 | 粗细变化、分叉节、断口纤维和侧面木纹；保留原支点与跨距 |
| 穿根树洞 | 不对称板根交叠形成通道，洞顶起伏，树干仍向画外延伸 |
| 荆棘 | 刺根按茎线定位，刺的朝向随茎变化，保留清晰危险轮廓 |
| 攀爬藤 | 不等间距交替着叶，叶柄连接藤茎，辅以少量卷须 |
| 露珠 | 去掉尖头水滴图标，改为圆润水珠、略扁接触面与克制的透光反射 |
| 承重叶桥 | 有连接的叶柄、中脉及侧脉，用上下表面明暗表现厚薄 |
| 枯叶风口 | 单独重画不齐叶缘、卷折与浅色背面，不再复用鲜叶换色 |
| 树皮浮台 | 厚薄不齐、两端破损、内外表面及纵向裂纹 |
| 种子配重 | 壳面纵纹、杯托鳞片、短柄与接地暗部 |

验收范围：SVG结构与资源引用、目录与分镜的静态渲染。未改动玩法状态、游戏碰撞或动画；不视为实机验收。原环境方向稿尚未换用这组新造型。
