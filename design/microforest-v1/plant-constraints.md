# 背景植物素材约束与检查记录

> 文档状态（2026-09-21）：历史设计/记录。材质经验可参考；旧H指视觉高度，当前统一V可见/H碰撞。 当前基线见[设计文档索引](../../docs/design/design-document-index.md)。

2026-09-20 · 适用于当前24种原创形态设计。用户确认：**人物 > 植物 > 动物指关注度，不是尺寸**。以下比例与阈值是本项目美术约束，不是生物学尺度或已完成的真机测试结果。

## 1. 尺度、关注度与摆放

以同一景深人物站立高度 H 为基准；人物含头发、不含绒毛。

| 对象 | 同一景深的设计范围 | 限制 |
| --- | --- | --- |
| 人物 | 1H；正式实机目标高32–40屏幕像素 | 轮廓完整，脸、衣身与四肢不被背景吞没 |
| 中景草丛、草叶 | 高2–5H | 基部落在地表；近处叶片可跨出屏幕 |
| 花茎、成熟蕨叶 | 高3–7H | 不等距排成栅栏；花朵朝向随支撑枝变化 |
| 普通菌丛 | 高1.5–4H，成熟菌盖宽1–3H | 幼体可更小；不能把所有菌都缩成装饰点 |
| 苔藓、贴地小叶 | 高0.2–1H | 低矮层用于衬托高大植物，不强行放大每个物体 |
| 树木 | 同景深树干宽至少4H，树冠通常在画外 | 整棵小树仅用于远景，不与人物共用同一地面尺度 |
| 昆虫 | 身长1–3H；本关甲虫约2.8H | 体量大但颜色克制；接近危险时才增强动作反馈 |

素材画册为适配卡片会缩放单体，**不用于推断关卡中的比例**。新增统一比例板 `assets/plant-review.svg` 用于比较。远景与同景深不混用上述比例。

视觉关注度：人物保持清晰边缘、可辨肤色面部、领巾与动态；植物靠体量、层次和材质表现；动物平时降低对比，不常驻闪光。危险预警、互动提示可短暂提升优先级，不能为了“动物排第三”而隐藏危险。

每屏中景选4–6类背景形态，聚成2–3组，保留路径与空隙。同一素材不得连续三次以相同尺寸和方向排列；变体缩放控制在0.85–1.15，不能将树干拉扁、菌盖任意拉长。前景不得覆盖人物面部、落脚点或危险物关键轮廓。

## 2. 结构合理性

- 所有叶片有可追溯的生长连接：叶片→叶柄→主茎/叶轴→地面。不能靠近但不相接。
- 先明确互生、成对或轮生的设计规律，再允许轻微错位；不把随机旋转当自然生长。
- 草叶基部较宽、叶尖收细；中间直立叶仍有面积，不能退化为一条线。平行细脉顺着草叶长度走。
- 蕨叶两侧小叶连接叶轴，朝叶尖方向展开，上部逐渐变短，叶尖连续。
- 穗草小枝从弯曲主茎的实际位置长出，末端穗粒随重力下垂；不能悬空排列。
- 莲座叶从共同基部放射，前后叶有遮挡，叶脉由基部指向叶尖。圆叶与细草不复用同一种叶脉。
- 树干向上收细，枝条承接树干；树皮纹理不等距；针叶树保留可见枝条与针束，避免五片三角形叠成图标。
- 菌盖、菌柄、基质之间结构相接；菌褶只出现在菌盖下表面。木生菌具有木面基质与附着部位；杯状菌有杯口厚度，球状菌保持体积，胶质菌不用金属高光。
- 所有名称仅描述原创形态。若未来标注真实物种名称，需要另做权威资料核对。

## 3. 光色与精细度

- 单体光从左上方来；新增柔和三段材质渐变，上亮下暗，亮部不泛白，暗部不变成黑色描边。
- 背景主色维持灰绿、灰青、灰紫、灰褐；互动叶片保留暖黄绿，风口和洞口保留琥珀边，露珠保留通透青蓝。人物采用 V2 雾蓝／赤陶衣装，保留肤色面部与暖色领巾。
- 中景表现两级细节：先读出轮廓，再看到叶脉、木纹或菌盖结构。远景减少细节，不把中景细纹原封不动缩小。
- 不靠噪声滤镜伪装精细度；纹理沿生长/表面方向，密度有留白。高光面积小于所在物体可见面积的15%作为生产目标。
- 缩至实机尺寸后，小于约1屏幕像素的细纹允许合并或删除，避免闪烁；不能为保留细纹加粗所有轮廓。
- 1倍看轮廓、对比、接地；2倍看枝叶连接、渐变、重复纹理和透明边缘。320px宽与正常桌面宽分别检查。

## 4. 本轮逐项检查与处置

| 素材 | 检查结果与本轮处置 |
| --- | --- |
| 垂铃花 | 增补叶片连接主茎及叶脉；保留向下开口的花形，材质统一 |
| 林下小花 | 保留五瓣与花心，增补叶片支撑茎、叶脉，统一柔和光色 |
| 伞状花序 | 保留分枝与团簇，增补叶片连接和材质层次 |
| 细叶草丛 | 修复中间叶片面积退化；添加顺生长方向细脉 |
| 羽状蕨叶 | 重画叶轴和小叶连接；左右错位、上部收短；添加尖端和小叶脉 |
| 苔藓垫 | 重画连续贴地苔毯，使用短茎小叶簇形成前后遮挡，边缘散开；移除圆石块状团簇 |
| 浅皮阔叶树 | 树皮短纹改为不等长度、粗细；补充细小木纹；树冠仍为概括形，后续精绘可继续细化 |
| 层枝针叶树 | 移除规则三角层片，改成枝条、针束和短针纹 |
| 老树板根 | 重绘不对称板根和前后根脊，以凹槽、侧面、接地阴影表现体积；木纹沿树干和根脊连续弯曲 |
| 伞状菌丛 | 补充菌盖下侧菌褶与柄部细光，仍保持灰褐低对比 |
| 木生层孔菌 | 重绘宽扇菌盖、厚浅边、环带及下侧孔点；增加断木基质和贴合阴影，去掉尖叶感 |
| 珊瑚状菌 | 检查分叉连接，保留分枝轮廓，统一材质，未新增密集点纹 |
| 挺叶莎草 | 修复中央叶片，增加纵脉，保留直立感 |
| 垂穗草 | 按二次曲线计算真实着生点，重画下垂小枝与穗粒中线 |
| 卷芽蕨 | 保留卷曲生长姿态，补充顺茎亮侧细线 |
| 莲座叶丛 | 添加由中脉分出的侧脉，保留共同基部 |
| 节枝草 | 检查节点/分枝关系，统一细茎明暗 |
| 三叶地被 | 保留三片共同着生的叶形，统一材质与叶片前后关系 |
| 马勃状菌 | 保留球形、细点和顶孔，统一上亮下暗，避免平面圆片感 |
| 杯状菌 | 保留杯口外缘与内腔，统一材质，内腔较暗 |
| 长钟形菌 | 保留纵向盖纹与不齐盖缘，统一菌柄及盖部材质 |
| 耳状木生菌 | 保留卷边与暗褶，增加基质木纹 |
| 蜂窝菌盖 | 调整网穴边长与角度，削弱重复菱形的机械感 |
| 胶质菌簇 | 保留褶皱团块，柔化明暗，避免高亮硬壳效果 |

## 5. 验收边界

本轮交付为矢量美术设计优化、结构检查和统一比例示意。脚本校验覆盖SVG结构、引用完整性、重复ID、页面脚本语法；视觉检查针对设计板。未替换游戏资源，也不能声称完成真机像素尺寸、动作、遮挡或性能验收。个别树冠、花瓣和菌类仍是概念级概括形，需要在画风确认后继续精绘。
