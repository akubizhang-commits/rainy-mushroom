# 怪物动作图集 ASTC 压缩试样（2026-11-27，只试样，未改构建配置）
工具：Cocos Creator 自带 `astcenc v5.2.0`（`/Applications/CocosCreator.app/Contents/Resources/tools/astc-encoder/astcenc`），`-cl -medium`。样本：白虎（3840×3968，有半透明拖影和白色毛发）、蛛女（头发、细长腿）。压缩后解压回 PNG 对比，正式素材未动。
| 块大小 | 每像素 | 相对 RGBA8 | 白虎 RGB / Alpha PSNR | 蛛女 RGB / Alpha PSNR | 观感 |
|---|---|---|---|---|---|
| 4×4 | 8 bit | 1/4 | 38.3 / 46.1 dB | 38.7 / 45.6 dB | 与原图无差别 |
| **6×6** | 3.56 bit | **1/9** | 32.1 / 38.9 dB | 33.3 / 38.5 dB | 显示大小下看不出差别；放大 4 倍时毛发边缘略软 |
| 8×8 | 2 bit | 1/16 | 29.0 / 35.3 dB | 30.5 / 35.0 dB | 放大后白虎头顶毛发出现明显色块，不建议 |
对比图：`compare.png`（显示大小）、`zoom.png`（头部放大，最近邻）。
## 结论
- 建议 iOS 用 ASTC 6×6。第 8 层怪物贴图约 412 MiB → 约 46 MiB；最大的第 8 层之外，各层都降到 30 MiB 以下。
- 安卓：较新的机型基本支持 ASTC；不支持的机型需要 ETC2 RGBA 兜底（8 bit/像素，约 1/4，第 8 层约 103 MiB）。
- 下载体积：白虎 6×6 文件 6.8 MB，和 PNG（6.8 MB）相当；gzip 后只有 1.3 MB（图集里透明区域多）。远程服务器开 gzip 能明显省流量。
- 编码很快：单张约 0.6–0.9 秒，20 张全量重编一分钟内完成。
