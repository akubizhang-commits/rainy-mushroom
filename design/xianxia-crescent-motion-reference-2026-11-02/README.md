# 用户剑气连斩动画参考

用户指出慢放能看见快速多道剑气，且每道外形略有差异。完整附件 `reference-02.gif` 共16帧，每帧100毫秒，总长1.6秒。第一份附件实际仅1帧，原样保留为 `reference.gif`。

## 逐帧观察

- 0帧：斜向长弧，右侧宽亮，末端沿左下方向拉长。
- 1–3帧：人物连续改变挥斩姿势，剑气随之出现高度、倾角和刃腹变化；2帧的上方弧边明显比0帧高。
- 4–7帧：能看到更扁、更接近横扫的长弧，右侧仍有宽亮的刃腹，余光和后续斩击有重叠。
- 8–9帧：近竖向、高挑的弧刃，内外层光痕分离。
- 10–15帧：强终击及消散，白色核心和命中爆光混合，不宜把整个白色区域当成剑气实体。

GIF是每100毫秒取样，无法仅凭它精确还原原游戏的每一道起止时刻；连击UI数字也不是新剑气数量的可靠统计依据。

## 后续制作约束

以长斜斩、扁横扫、上挑斩为变化基底，保留统一金白色刃芯和金黄外缘。每道轮廓的开口、刃腹宽度、尖端长短和倾角应有差异，不能仅复制旋转同一张圆弧。短促亮起、扫出、余光重叠、快速消散共同形成连斩感。

游戏实际命中次数与视觉子层分开：当前每发只按既有规则结算，不能因为叠加多层视觉刃光而重复伤害。现有三连的三道实际飞行体可各用一套变体；额外残影只作表现。
