# 环剑诀周期调整（sj_wanjian）

2026-10-31，用户确认采用“持续4秒，发动起计算6秒CD”的方案。仅调整当前成长版环绕技能；无我剑境维持常驻与原伤害，原始贴图及付费素材未改动。

## 规则

- 每轮持续4秒，默认2秒空档；到期停止伤害，同时隐藏贴图及备用剑体绘制。
- 同目标命中间隔仍为0.6秒，剑身碰撞、剑数、半径与近身空隙保持原规则。
- 原6秒最多10次命中，新每轮最多7次。生效期间单击乘10/7（约+42.9%），保持理想完整周期预算。最初考虑的+50%会令理想总输出多约5%，因此未采用。
- CD接受戒指缩减，持续时间和命中间隔不变。当前最大2.5%缩减：5.85秒CD，1.85秒空档。
- 保存绝对结束时间orbitUntil及既有冷却时间；暂停不推进，恢复不重新获得一轮持续时间。死亡立即隐藏。
- 技能节点显示6秒（装备缩减后显示实际值）；详情列出持续4秒和同目标命中间隔0.6秒。
