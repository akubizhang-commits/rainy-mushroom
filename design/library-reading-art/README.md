# 藏经阁阅读插画

复用21张已接入物品的高清母图，通过 scripts/art/prepare-library-items.py 调用 item_icon.py --size 512 输出到 tower-library-items。源图与背包128px图标不变；manifest.json记录输入输出哈希。统一98%主体、居中、保留透明边缘。

阅读展示：长剑目标为正文宽60%，其他物品54%，常规目标280～360布局单位；矮横屏160～200。首屏剩余高度进一步限制大图尺寸，以免物品被卷页边缘截断。物品小记在图下，可独立滚动。缺少高清素材的条目保持原128px图或占位，不冒用其他物品。

验证：item_icon.py --check覆盖128px图标及512px阅读插画；verify-library-integration.cjs检查高清资源实际帧尺寸、完整首屏展示、两种宽度和三种横屏比例、键盘/搜索/翻页/存档隔离。正式馆内与展开书美术仍按原交接等待素材。

## 阅读页精修

已补中文行首标点避让和连续数值范围断行保护；物品背景说明加“典籍小记”层级；双页底部渐隐与居中阅读提示在滚到底时隐藏，并排除段末空白造成的多余滚动。回归扩展为21张实际高清插画×3种横屏，核验资源帧512px、首屏完整主体、页尾提示消失以及现有键盘/搜索路径。未生成新素材，源图不变。
