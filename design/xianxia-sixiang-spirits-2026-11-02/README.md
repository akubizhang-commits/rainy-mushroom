# 四象剑阵：四灵阵印版

## 当前表现

- 上朱雀（火红）、右白虎（银白）、下玄武（水蓝）、左青龙（青绿）。四灵纹样保持正向，外圈光弧20秒一圈；不旋转整个布局。
- 四阵印中心距阵心0.59R，最大绘制半径0.28R；圆形印章及外圈均位于真实菱形伤害区域内。菱形边界保留较淡金线。
- 同色细流连接中央阵心。当前真实伤害脉冲对应的阵印提亮，落剑使用对应属性剑体；最终一击四象合鸣，九个落剑位置分配四种属性外观。
- 朱雀附火羽形尾迹和落地短芒，青龙为盘绕细流，白虎为直线锋芒，玄武为水纹和局部龟甲形波纹。
- 这些仅为视觉语言，没有新增缠绕控制、护盾、反弹或额外伤害。原菱形范围、7/9次攻击及固定落点规则不变。
- 原图拆分为4张512px阵印，合入1024px图集；原高分辨率切片与透明图均保留。四柄剑由已有剑体做本地着色，分别合入两个1088×128图集。
