# 御剑术 v2 · 游剑换位

本版只修订用户不满意的固定双翼悬停。用户已满意的剑体、正面出击、弧线追敌、长拖尾及残影沿用v1。新视频为30秒横屏美术预演，尚未接入游戏。

## 当前主审片

`preview/yujian-changing-hover-v2.mp4`（1280×720，30fps）：

- 0–18秒完整展示一次「肩外错落 → 疏密交错 → 短暂双翼 → 回到错落」。
- 18–22秒展示换位状态下的单剑出击，其他九剑继续悬停。
- 22–26秒展示四剑分流，其余六剑继续悬停换位。
- 26–30秒展示角色移动时的跟随。

两种错落造型均使用手工安排的高低、间距和倾角，不逐帧随机改位置。
每柄剑保留身份与肩侧，在2.5秒内沿微弧连续移动到目标位置；相邻剑延迟0.1秒出发。
位移与转角均缓入缓出，无淡出切换或瞬移。头部与身体中间保持留白。
18秒轮换中，双翼仅短暂停留约1秒，随后再散开；错落造型是主要待命状态。
「散乱」指位置有自然疏密，并非让剑相互穿插、遮挡人物或绕成一圈。

`preview/formation-layouts.png` 对比两种错落、双翼和换位中四个时刻。
`source/make_preview.py` 是可复现动画源脚本。

## 范围与保留

新剑体、角色图直接从v1归档按原字节复制。所有v1素材、脚本和视频均保留。
本轮模型调用0、新增生成费用0 CU、上传0；历史来源ID与费用未知仍为null。
每级一剑、凝神诀前置、伤害及存档逻辑尚未接入，不以此美术预演代替战斗验证。
视频靶标为人工编排示意，不是游戏运行录像；人物继续使用同一静态立绘。

位置范围、身体留白和历史源文件核验结果见 `verification-summary.json`。
