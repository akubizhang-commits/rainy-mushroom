# 纵横剑气：冰蓝月牙向外释放

用户要求以《冰蓝幻刃能量弧.png》替换月牙，蓝色保留参考色、红色对应改色，并向外释放、避开角色身体。已修改开发版，待视觉验收。

## 素材与动画

原图保留在source；本地去黑底后导出768×768透明图，蓝色用原图色彩，红色重排色彩通道。处理脚本prepare.py与provenance.json记录来源和哈希；没有生成、上传或费用。旧素材及上一版预览全部保留。

四蓝两红六道月牙采用内侧锚点，完整画布从身体中心76单位之外开始，沿各自刃面朝向向外平移，无自转穿身。约0.55秒完成外移，整体0.9秒淡出。直线剑光的最内侧偏移至少96单位，碎光也移至外围。原有180/220/270伤害半径、伤害倍率、6目标上限与单次结算规则不变。
