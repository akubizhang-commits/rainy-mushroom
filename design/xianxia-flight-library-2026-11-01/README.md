# 御剑飞行 · 守山剑原画

用户要求从武器素材库挑选造型不复杂的剑作为母图。比较10把现有剑后选用守山剑：剑身朴厚、短护手、无复杂悬饰，原画自带旧金属质感。

使用 design/equipment-swords-intake/eq_sword_shoushan-master.png 原画，经主轴旋转、透明裁剪导出512×128御剑用图。原图及哈希记录保留，未重新生成、没有模型费用。FlightSwordArt跟随与尾流相同的方向和投影，独立加载、隐藏和销毁。最终显示宽100、高64再经纵向0.42投影，补偿首轮过细的显示。

browser-first保留首轮试验，browser为最终双横屏四方向检查，同时确认四个被动光环已按用户新要求停用。旧程序剑仅作为资源加载前回退。母图、候选总览和旧源码均保留。
