## 第一张：剑破虚空

复制以下prompt：

> 国风仙侠游戏的单枚技能图标，技能意象为“一柄飞剑划破虚空”。正方形1024×1024，温暖浅米白宣纸底色，细腻水彩与工笔融合，轮廓清楚，与传统仙侠功法图标风格一致。画面中央只有一柄完整的银白色实体长剑，少量浅金色剑柄细节，剑尖朝右上方，整体接近横向、微微上扬，正在向前穿出。剑身有窄而明亮的青蓝色轮廓光。在长剑经过的后方，空间沿同一飞行轨迹被撕开一道狭长裂口：内部是清晰的深黑虚空，边缘不规则、两端尖细，包裹白色亮芯与克制的青蓝辉光，呈现“空间被切开”的感觉。裂口和飞剑是一个连贯的动作，剑尖清晰露在裂口右端之外，剑身保持实体可辨，不能被辉光吞没。以一柄剑和一道黑色裂口作为唯一视觉重点，缩小为64像素后仍能辨认。主体集中于画布中央约75%的范围，四角留白，确保圆形裁剪时剑尖、剑柄及裂口完整保留。无文字、无边框、无圆形外框、无人物、无山峰、无建筑、无太阳、无星空背景、无竖直光柱、无圆形传送门、无冰晶、无繁密法阵、无多把飞剑，避免大面积光雾和细碎粒子。

## 验收

- 先看图标是否能独立读出“实体飞剑＋空间裂口”，而不是雷电、冰剑、山谷或传送门。
- 检查256px、88px、64px和圆形裁剪，主剑与黑色裂口仍须分明。
- 空间裂口内部黑色为画面内容，不应去黑底。
- 沿用当前技能图标浅米色底；不要求透明背景，不套用物品图标98%占比规则。
- 用户原图原样归档，输出新的运行图；已有原图与历史运行版本均保留。
