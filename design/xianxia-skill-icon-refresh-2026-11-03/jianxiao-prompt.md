# 下一张：剑啸八方

先前图标为双月牙十字。新图应表达六道剑气从周身向外爆发。可把已有图作为水彩风格参考，构图按以下要求调整。

> 国风仙侠游戏单枚技能图标，正方形1024×1024，浅米白宣纸背景，细腻水彩与工笔融合。画面中央留有小块空白，六道锋利的月牙剑气在空白周围错落交织，并向四周外放：四道青蓝色剑气为主，两道低饱和暗红色剑气为辅。剑气有清楚的锐利外缘和简洁拖尾，弧刃朝外，前后交叠但轮廓易辨，形成“剑气从周身向八方迸发”的瞬间。整体紧凑、有爆发力、不追求机械对称；不要画成两道月牙相交的十字，也不要画成封闭圆环。主体集中在画布中央约75%的范围，四角留白，适合圆形裁剪；缩小到64像素仍能看出向四周放射的剑气。无人物、无实体长剑、无文字、无边框、无法阵符文、无山水背景、无复杂粒子，不用大面积光雾遮住月牙轮廓。
