- 第七层“啸风山崖”改为“震岳石关”。第2波原24隼改为9猿＋15隼；第11波的9猿换为9隼。前段出现虎、猿守关，飞行怪作为骚扰。整层总数、各物种总数、品阶总数不变；重型比例仍逐波不超过40%。不新增技能。
