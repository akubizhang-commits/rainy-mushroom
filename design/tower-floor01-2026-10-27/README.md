# 首层编排与獠王预览

入口：`review.html`，需从仓库根的本地HTTP服务打开。页面读取同一份首层及Boss设计JSON，不读写游戏存档。

交付：

- 20波、82个出生批次、378个必杀ID；方位、留口、出生预警与安全选点。
- 可切波、切批次、调整玩家起点，观察出生候选回退。
- 可查看獠王直冲/拱击的单招形状与时间。半血双冲的完整阶段表在16号稿；本预览不运行两段连招AI。
- 15号首层规则、16号首领规则、17号免费入塔和收益保留提案。

验证从仓库根运行：

```sh
python3 docs/xianxia/sect-tower-v1/data/build-floor01.py
node design/tower-floor01-2026-10-27/verify.mjs
node design/tower-floor01-2026-10-27/verify-browser.cjs
```

最后一条需要本机已有Playwright通过Node模块路径可用，以及8767端口本地服务。可设置`FLOOR_PREVIEW_URL`到对应服务页面。此轮使用已有依赖，没有安装新包。

`verification.json`记录1066个出生布置案例：中心、八个出生区、四角站位；独立断言验证距离、边界、留口、容量及ID不重复。第19波30只在不击杀示例中为24预约/6待生成；不是动态AI或真实对象池验收。

`browser-verification.json`记录1365×1000、390×844、360×640、720×1280、1080×2400五种窗口：20波按钮、批次切换、两招选择、播放/暂停、时间轴与坐标调整可用，按钮高至少48px，无横向溢出、无页面错误。

主线程目视复核`review-contact.jpg`：灰盒身份与信息层级可辨。限制：移动页面较长，次级批次表需滚动；全场审阅视角会缩小招式范围，不能代表正式游戏相机或六英寸实体触屏的可读性。背景、妖兽均为几何标记，不是美术交付；无实际受击、关卡通关、掉落事务、存档或真人平衡验证。

17号提案仍为产品建议，完整清层收益表未变；部分波次死亡的带出收益变化尚未实施。正式接入前需统一击杀收益与恢复快照，不能复用“钱包保留但怪物回滚到波初”的旧合同。
