# 剑气斩母图重做：以用户参考局部为准

## 主参考

`reference.png`为用户原图，`reference-blade-detail.png`为右上方单道剑气的局部放大，未重绘、未提取透明底。放大图中仍有场景和交叉剑光，不得将这些元素当作要生成的单道剑气。

## 可直接使用的制图 prompt

参考所附图片中右上方那一道冰青蓝色弧形剑气，制作一张单独的游戏技能特效母图。重点复现参考的发光质感和内侧能量残留，而不是只复制颜色。单道、开放的大弧形扫斩，朝右，开口朝左；外沿锋利，弧形不闭合，保留完整尖端。刃面中段稍厚，向两端自然收细，厚薄不做机械对称。主体是饱和冰青色的发光能量，有明亮的青白高光和深蓝透明层次，不能画成实体金属月牙。

最关键：刃面内缘不能是一条完整光滑的轮廓线。半透明能量从亮刃内侧连续撕出，形成长短不一、宽窄不同、互相叠搭的羽状、絮状薄片；靠近刃面较亮、较密，向内后方拉长后迅速变薄、断续、消失。残留应与刃面连在一起，有一致的扫斩拖曳趋势，但局部自然紊乱。局部可有少量轻薄脱落的能量絮片。保留参考里颗粒般的发光细节、软硬交替的边界与运动模糊，不要均匀填色或机械描边。

只有这一道剑气，纯黑背景，完整构图，四周留安全边距，1024×1024。不要人物、武器、场景、UI、文字、其他剑光、红色光线、金边。不要线条状闪电、细丝网、梳齿纹、规则噪点、圆形斑块、冰块、碎石、厚重烟团、塑料或金属质感、完整圆环。

## 验收顺序

1. 单张母图先与参考局部并排看：内缘是否与发光刃面连成一个被撕散的能量体，是否摆脱实体月牙和孤立斑块。
2. 在黑底及实际石地背景、实际显示尺寸分别检查。颜色、透明度、发光宽度与絮片尺度都需要视觉验收，不能以测试通过代替。
3. 母图通过后再做残留消散动画，接回真实角色挥剑。继续保留1–3级近身、4级起飞行、7级起原三连及其间隔。
