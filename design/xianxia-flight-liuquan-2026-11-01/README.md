# 御剑飞行 · 流泉剑替换

用户反馈截图里的飞剑不满意，要求换一把好看的。截图造型更接近旧程序剑，不能仅凭截图断言运行版本；当前源代码此前使用守山剑，但仍有程序剑加载回退。

这次从既有武器母图库选择流泉剑（eq_sword_liuquan-master.png）：银青剑身、流畅弧形护手、简洁握柄，无复杂垂饰。直接复用原画，旋转裁剪为透明横向512×128贴图，不调用生成模型。保留原图、来源哈希、守山剑版本和旧程序剑源码备份。

替换 FlightSwordArt 资源和节点名称，并从 TowerView 移除旧程序剑回退。资源加载前不显示旧方块护手剑，当前气流动画和四个光环停用状态保持。实机验证会检查节点名称为“流泉剑原画”、跟随转向及双横屏显示。

原图制作记录见 provenance.json；构建与测试见 build.log、tests.log，最终实机结果见 browser/report.json。
