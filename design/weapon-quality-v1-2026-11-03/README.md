# 四档武器品质光效 V1

用户批准先制作四档品质光效，技能附魔不考虑。本轮为独立 Canvas 动态美术预演，未修改生产游戏渲染、装备数据、战斗规则或存档。

- 下品：保留原剑，无光。
- 中品：每 3.2 秒一次掠光，历时 0.95 秒；挥剑轻微亮边。
- 上品：贴刃持续微光，每 2.2 秒流过；挥剑 3 层短残影。
- 极品：双束错时流光，1.7 秒周期，剑尖汇光、3 个离散光点；挥剑 7 层短残影。初版偏弱，已适度提高极品亮边和光点，旧版保存在 iterations/subtle。

颜色随武器：素问剑银白、镇岳剑暖金；未根据凡器/法器/宝器/灵器再叠加另一种光效。人物与剑图直接复制现有高清资源，asset-integrity.json 记录逐文件一致性。生成调用 0，费用 0，原图及历史版本保留。

## 观看

`quality-preview.mp4` 是浏览器原速录制，先素问剑深色背景，再镇岳剑浅色背景。`index.html` 提供武器、动作、暂停和背景切换。运行 `python3 -m http.server 8769 --bind 127.0.0.1 --directory design/weapon-quality-v1-2026-11-03` 后打开 http://127.0.0.1:8769 。

上排按照生产 108 设计像素人物高度绘制，下排按 162 设计像素重新绘制；不是放大截图。页面自适应缩放会影响物理显示大小，正式清晰度及性能仍应以 Cocos 实际集成为准。

## 验证与边界

`node --check preview.js` 通过；浏览器页面无异常（capture/check.json），两把武器、深浅背景及自动站立/挥剑已录制检查。未运行游戏全量测试：本轮只有独立预演文件，未改生产代码。浏览器首次启动遇到运行路径和沙箱权限问题，改用已安装的 Chromium 并取得执行权限后录制成功。

当前结果供视觉选型，未做 Cocos 接入或真机性能验收。下一步根据用户对强弱、颜色、拖尾的反馈修订，再把获批效果接入游戏内真实装备品质与暂停/死亡/换装生命周期。
