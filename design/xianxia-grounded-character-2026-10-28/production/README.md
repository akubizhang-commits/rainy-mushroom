# 剑修动作 · 游戏接入版

2026-10-29。基于用户已认可的 Scenario 走路、跑步、挥剑视频，执行本地抠图、帧选择、锚点校准与手持剑分离。本轮没有重新生成视频或消耗生成额度。

- 站姿1帧、走路12帧、跑步8帧、挥剑14帧，共35帧。
- 图集2048×1920，RGBA，每格256×384；真实透明边缘，统一脚底锚点。
- 跑步取25–32帧周期，统一向下校准27原始像素，保留腾空段，不逐帧强行贴地。
- 蓄势出画的原剑被移除；游戏依据逐帧护手位置和方向绘制完整装备剑，保留手部与握柄。
- 地面移动按实际速度切换走路/跑步，站立使用独立站姿。御剑飞行使用站姿与现有固定飞剑；未新增独立飞行动作。
- 普通攻击以逻辑层真实施放通知驱动，出手帧对齐释放时间；纯视觉通知不入存档、不增加伤害。
- 暂停冻结，倍率沿模拟时间生效，死亡隐藏人物并取消动画；资源未就绪时回退原角色。

## 当前边界

只有右向源动作及对应镜像展示，尚未制作独立前后方向；这是首批可玩接入，并非八方向完整动作库。受击专属动作、独立御剑挥剑和倒下动作留待后续制作。衣袍被原剑遮挡的窄区域采用邻域补绘，在游戏尺寸及独立武器覆盖下验收，不用于大幅角色立绘。

## 复现与验收

`scripts/prepare-swordsman-motion.py` 消费本目录三个 `*-track.json` 及上级 continuation 视频，输出图集、manifest和检查图；需 ffmpeg、Pillow、numpy。源视频不修改。游戏资源副本位于 `cocos-pilot/assets/resources/tower-character/`。

`review.html` 为透明层与方向/装备切换检查页；最终行为以游戏及 `scripts/verify-character-inventory.cjs` 验证为准。浏览器记录位于 `docs/xianxia/reports/character-inventory/`。
