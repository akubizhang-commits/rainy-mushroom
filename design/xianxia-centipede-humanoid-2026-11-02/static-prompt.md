# 五阶百足蜈王 · 半人形母图

为中国仙侠俯视动作游戏绘制“五阶·百足蜈王”的完整角色母图。半写实手绘游戏美术，与已有蝎王、鳄王统一材质精度与明暗。

雄性气质的半化形蜈族妖王，保留完整蜈蚣头部：扁宽而坚硬的铁黑色头甲，头部两侧的小而锐利的暗琥珀色眼睛，一对细长分节触角向前上方伸展，口部下侧有一对黄褐色弯曲毒颚。面部由甲壳和口器构成，不是人脸或头盔。

采用双足直立的人形躯干，体态修长坚韧，肩部适度宽阔，腰腹狭长。胸腹和脊背由连续、清楚的横向分节甲片包覆，铁黑色背甲带冷灰高光，腹侧为稍浅的深灰褐色。关节、触角与附肢以克制的黄褐色点缀。甲片有少量自然磨损，不画成金属机械或石雕。

两条主要手臂从肩部自然延伸，手掌为三指节肢爪手，两个前指与一个对握指清楚可辨，不是蝎钳。双臂自然微屈，离开躯干。两条主要腿支撑身体，腿部覆盖分节硬甲，足端为稳固的甲壳爪足。

躯干后侧从上背至腰部，左右各有三条较短的弯曲节肢，共三对，大小自上而下逐渐缩小，像收拢的蜈蚣步足。附肢根部藏在背甲侧缘，向身体后侧收束，末端保持可辨，不能遮脸、穿体或与主手臂融合。腰后可见短小分节末腹及一对后向尾足，不画长蝎尾或毒刺。

腰部只有窄幅深褐束带与简洁旧铜扣件，露出腹部甲节。空手，不持武器，不穿大披风或厚重裙甲。静止警戒姿态，双脚自然错开。

高位三分之四视角，适度俯视，面朝画面左下。单个角色、单一视图、完整全身。主体占画布约80%至85%，触角、短附肢和双脚完整入画，四周留白。纯中灰背景，柔和均匀照明，无地面、投影、毒雾、光效、法阵、文字或水印。2048×2048高清PNG。
