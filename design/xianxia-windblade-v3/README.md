# 剑气斩：青蓝扇形风刃 v3

本轮为现有Cocos程序特效的重做，不是AI生成贴图或真实3D模型。三层半透明光片以弧形向外扩散，中央青白亮带、青色腹部和渐隐边缘；相位变化使边缘流动，末段透明消散。出手表现26个模拟tick（约0.43秒），前摇与攻击逻辑不变。

剑气斩停止发送swordHit粒子表现事件，御剑术仍保留命中碎光。自动朝射程内最近活怪出手、前摇锁向、伤害/半径/角度/冷却均不改变；视觉扩散不额外多次结算伤害。

## 验证与证据

- npm test：691/691通过。新增渲染测试核对风刃全部顶点位于实际扇形范围、同tick暂停冻结、减少闪烁降低亮度、消散后清理。五级技能测试检查不发粒子表现事件。
- npm run check：通过。web-mobile构建成功。
- preview.png、windblade.webm：实际Cocos渲染，放大到350半径/110度以供观察；隐藏其他场景与HUD，6.5秒循环录像。index.html无文字/无UI自动播放。
- in-game.png：390×844实际试玩，等级1剑气斩（140半径/75度），受控敌人、冻结出手后第6tick、临时隐藏暂停菜单。不是通关或平衡证据。
- 录制时397个绘制调用，桌面p95约5ms，最大16.9ms；包含空白间隔与录制开销，不代表低端手机性能。移动真机性能未验证。

第一版渐变网格有明显条带，增加细分后复查放大及游戏尺寸。仍采用透明层叠的2D近似立体观感；用户主观满意度待实际试玩。
