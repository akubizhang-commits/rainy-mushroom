# 下一张：M11寒瘴泥沼地面母图

现有羽毛、音波、毒液弹体和蛛网已补，转向已实现的地面机制。M11已有6秒持续、减速与伤害逻辑，当前使用几何范围表现；素材库索引与文件名未找到专用泥沼母图。新图只用于该地面区域，不为毒液弹体新增落地毒池。

## Prompt

中国仙侠游戏技能特效素材，一片寒瘴泥沼，严格垂直俯视，单个近圆形地面覆盖纹理，手绘游戏风格。

低饱和灰青绿色的湿冷泥浆，中央稍深，外圈自然变薄，少量暗橄榄色淤泥斑纹、两三处细小气泡、稀薄的青灰寒雾。整体扁平贴地，中心纹理疏密有变化，不能糊成一团。边界略不规则但接近圆形，完整独立，外缘有少量湿润反光并柔和消散。缩小后仍能认出危险泥沼，不要明亮霓虹绿，不要实体凸起的盆壁或岩石围边。

1024×1024 PNG，主体居中，直径约占画布75%，四周留足空间。背景为均匀纯品红#FF00FF，主体之外和所有空隙同为纯品红；主体、雾气与反光不得含品红。保持正圆俯视，不画成透视椭圆。

不要人物、怪物、植物、地砖、完整场景、文字、图标、魔法阵、红圈、硬质圆环、火焰、冰刺、大面积浓烟、飞溅弹体、投影、边框、水印或多视图。
