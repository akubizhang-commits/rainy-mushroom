## 数值规则

- 等级比例仍为有效直伤的 4% / 6% / 10% / 15%，没有提高总倍率。
- 待落剑期间命中合并预算。0.48 秒落剑时一次兑现合并预算的 60%，余下 40% 在随后两秒内兑现；接触帧不再同时派发持续跳伤。
