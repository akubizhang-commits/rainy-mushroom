# 2026-11-13 三个问题

## 1. 隼妖精英发动 M07 时体型变大、翅膀被截断
- 原因：11-11 生成的重踏视频里，隼妖张开的翅膀伸出了视频画面，翼尖在源帧 18–78 被裁成直边。导出时为了把整只隼装进格子，按并集缩小后再用 displayScale 1.0623 放大还原，显示出来的宽度最大达到格子的 1.29 倍，看起来比立绘大了一圈。
- 处理：`TowerMonsterArt.ts` 去掉了 `falcon-humanoid` 的 M07→stomp 映射，M07 期间回到立绘。图集里的 stomp 帧和原片都保留。动画测试改为断言 M07 保持立绘。
- 后续：用“翅膀始终收拢贴身”的 prompt 重新生成（Scenario 10 CU）后再接入。

## 2. 4–6 级熊妖走路正面对着屏幕
- 原因：熊妖行走（11-06 Meowa）沿用的是三分之四正面的立绘母图，生成出来的就是一只朝镜头走来的熊。首尾帧都必须和这张母图一致，单靠视频没法把它转成侧身。
- 需要一张侧身母图，按 AGENTS.md 由用户出图，prompt 见 `bear-side-reference-prompt.md`。拿到图后用 Scenario 重做行走（10 CU）。

## 3. 周天剑阵飞剑太大
- `OrbitSwordArt.ts` 把 VISUAL_LENGTH（画面剑长 ÷ 判定剑长）从 1.25 改为 0.9，飞剑画面缩小 28%；判定和伤害都不变。测试同步更新。
- 实机：`orbit-after-1280.png`。
