## 真实机制和动作计划

- 原地爬行循环：四足交替、轻微尾摆，固定相机和体量。
- 普通横扫攻击：TowerEnemyAttacks将crocodile定义为sweep，不擅自改为咬合伤害。前摇普通1秒、精英1.1秒、Boss1.2秒，生效0.18秒，恢复0.9/1/1.1秒。侧身摆动/横扫姿态需符合扇形攻击。
- 回旋尾扫M08：独立可读蓄势、尾扫、恢复；1.2秒前摇、2秒恢复，伤害按原逻辑。可评估与普通横扫共用源片分段，不能先认定可复用。
- 毒痕追猎M12：2秒发动，生效期间3次在玩家位置生成毒区，再恢复。身体施法姿态与独立地面毒痕分离，不能把机制误做成鳄鱼行走留下毒路或口吐直线毒弹。
- 血怒狂暴M02：1.5秒发动完成后才变红、在Boss常态上额外放大20%，持续15秒，到期或死亡立即恢复。沿用现有移动速度×1.25、普通攻击冷却×0.75，无新增单次伤害。红色为本地派生/运行时状态，不要求用户另画红色母图。
- 受击：短促躯干收缩，固定落脚锚点。
- 死亡：躯干沉落、尾巴放松，保持末帧，不离屏触发。
