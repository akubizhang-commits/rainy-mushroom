# 御剑飞行 · 剑尾发射点修正

用户反馈向上移动时尾流起点穿过剑身，要求后移至脚下飞剑尾部。已复用原有32帧图集，不生成或修改原图。

发射点由角色中心改到当前固定横向飞剑的左后顶点（相对角色 -34，随飞剑浮动）；图片锚点由0.91改为0.98，对准原画右端亮头，使拉长和旋转不再把亮头伸进剑身。原画、上一版实录和本次修改前源码均保留。

4项状态测试、Cocos Web构建及1280×720/844×390两种横屏检查通过。实机逐一检查上下左右四方向的剑尾位置，并回归暂停、收尾、死亡、遗忘和退出；测试无存档写入。报告见 browser/report.json。资源成本0。
