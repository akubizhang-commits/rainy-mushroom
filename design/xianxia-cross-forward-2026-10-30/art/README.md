# 纵横剑气：两道月牙共同朝前

本目录是新的本地美术候选，不修改生产代码、生产资源或此前封包。源素材仍为已批准的 `sword-qi-crescent-v1.png`，旧的直十字及 ±45° 双月牙全部保留。模型生成 0 次、费用 0 CU、云端上传 0 次。

这次不再给月牙的前向轴施加平面旋转。每片源月牙以白锋中点 `(119,256)` 为原点，前向为 `u`、横向为 `v`，投影使用：

```text
x = sx * u ± shear * v
y = sy * v
```

两片的 `u` 轴都映射到屏幕右方 `(sx,0)`。正、负横向错切使两道月牙交叉，同时保留共同向前的凸面。三种候选的四个末端均位于中部锋面后方；这是本次“前面迎前、末端后掠”的几何约束。图上的方向箭头仅用于检查，没有烘焙进透明素材。
